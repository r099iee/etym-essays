• Darkness: Similar because both name the absence of light; differs because darkness is neutral and factual, mere absence without weight, while gloom adds a settled pervasive heaviness and a mood of sadness or foreboding.
  • Shadow: Similar because both name a dark area; differs because a shadow is a specific projected shape cast by an object, with light present elsewhere, while gloom is a shapeless, unbroken, all-enveloping darkness.
  • Murk: Similar because both name thick, obscuring darkness; differs because murk stresses physical impenetrability — fog, smog, dirty air — while gloom stresses desolation and an emotional heaviness.
  • Dusk: Similar because both are dim, low-light conditions; differs because dusk is a temporal term tied to the time of day, soft and often beautiful, while gloom is timeless and oppressive.
  • Twilight: Similar because both name a dim, low-light state; differs because twilight is the beautiful evening hour between day and night, while gloom is heavy, shapeless darkness with no schedule.
  • Dimness: Similar because both describe reduced light; differs because dimness is merely a quantitative condition, a reduction of brightness, lacking the weight and emotional charge of gloom.
  • Obscurity: Similar because both can mean lack of light; differs because obscurity stresses being hidden or hard to make out, and is often abstract (the obscurity of the past), while gloom is physical darkness with a mood.
  • Shade: Similar because both are areas of reduced light; differs because shade is a cool, often pleasant shelter from sun, while gloom is oppressive, uninviting darkness.
  • Penumbra: Similar because both name partial darkness; differs because penumbra is a precise astronomical term for the partial shadow at the edge of an eclipse, entirely technical and neutral.
  • Overcast: Similar because both describe a dark, dull sky; differs because overcast is a meteorological term for a cloud-covered sky, without the emotional weight of gloom.
  • Melancholy: Similar because both name a sad, low emotional state; differs because melancholy is a sustained, reflective sadness, while gloom is the heavier, more oppressive, near-tangible darkening of the spirit.
  • Dejection: Similar because both name despondency; differs because dejection describes a feeling of being cast down, while gloom names the whole dark atmosphere of which dejection is a part.
  • Despondency: Similar because both name loss of hope; differs because despondency is a clinical state of lost courage, while gloom is the atmospheric, word-picturable darkness that can contain it.
  • Depression: Similar because both name severe low mood; differs because depression is the medical/clinical term with a diagnostic register, while gloom is literary, atmospheric, and imprecise.
  • Sadness: Similar because both name unhappiness; differs because sadness is the plain, general emotion-word, mild and ordinary, while gloom is heavier, more pervasive, and blends into physical darkness.
  • Sullenness: Similar because both name a dark, morose state; differs because sullenness is a resentful, silent ill-temper of a person, while gloom can be a property of places and skies as well as moods.
