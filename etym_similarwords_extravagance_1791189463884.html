• lavishness: Similar because both mean generous luxurious spending; differs because lavishness can be admiring abundance, extravagance stresses waste beyond reason.
  • prodigality: Similar because both mean reckless wasteful spending; differs because prodigality stresses squandering one's own substance, extravagance stresses excess over need.
  • wastefulness: Similar because both condemn useless consumption; differs because wastefulness is broader moral condemnation, extravagance implies showy luxury.
  • profligacy: Similar because both mean shameless excess; differs because profligacy adds dissolute moral corruption, extravagance is mainly financial.
  • improvidence: Similar because both mean lack of thrift; differs because improvidence stresses failure to provide for future, extravagance stresses present excess.
  • opulence: Similar because both evoke rich display; differs because opulence describes wealthy abundance neutrally, extravagance judges it excessive.
  • luxury: Similar because both denote non-essential comfort; differs because luxury is the desirable thing itself, extravagance is disapproval of its cost.
  • splurge: Similar because both mean indulgent spending; differs because splurge is colloquial one-off indulgence, extravagance is habitual or grander excess.
  • excess: Similar because both mean going beyond limit; differs because excess is generic, extravagance specifies flamboyant wasteful excess.
  • immoderation: Similar because both mean lack of restraint; differs because immoderation covers any appetite, extravagance centres on money and display.
  • indulgence: Similar because both allow oneself gratification; differs because indulgence can be small and forgivable, extravagance is large-scale.
  • profusion: Similar because both suggest abundant pouring out; differs because profusion can be natural abundance, extravagance is human wasteful abundance.
