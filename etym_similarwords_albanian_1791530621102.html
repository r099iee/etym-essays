• Shqip: similar because it is the Albanian endonym for the language; differs because it is not English and does not carry the external, classical perspective of Albanian.
  • Shqiptar: similar because it is the endonym for an Albanian person; differs because it denotes a person, not the language or the adjective.
  • Arberesh: similar because it names Albanian-descended communities in Italy; differs because it is a specific diaspora subgroup and its archaic Tosk speech, not the whole nation.
  • Arvanite: similar because it names Albanian-descended communities in Greece; differs because it is a regional subgroup and its language is a variety, not the standard.
  • Gheg: similar because it is one of the two main Albanian dialect groups; differs because it is northern and not the basis of the modern standard.
  • Tosk: similar because it is the other main Albanian dialect group and underlies the standard; differs because it is a regional variety, not the whole language.
  • Illyrian: similar because Albanian is traditionally thought to descend from an Illyrian-related ancient language; differs because Illyrian is poorly attested and not securely identified as the direct ancestor.
  • Arbanasi: similar because it is an old Serbian and Croatian name for Albanian communities; differs because it is a foreign, historical exonym, not an English synonym.
  • Arnaut: similar because it is the Ottoman Turkish name for Albanians; differs because it is foreign, archaic, and sometimes pejorative.
  • Caucasian Albanian: similar because it shares the word Albanian; differs because it is an unrelated extinct language of the Caucasus, not the Balkan Albanian language.
