• Pierre Loti (full name): Similar because it is the same author; differs because full form is formal first mention, Loti alone is familiar shorthand.
  • Louis Viaud: Similar because it is Loti's real name; differs because it denotes the naval officer as person, not the author brand.
  • Gauguin: Similar because fellow French Tahiti romantic; differs because painter not novelist, more radically primitivist.
  • Stevenson (R.L. Stevenson): Similar because South-Seas writer of the same era; differs because Scots adventurer, more adventure-focused and less impressionistic.
  • Melville: Similar because early Pacific exoticist (Typee, Omoo); differs because American, a generation earlier, more philosophical.
  • Bougainville: Similar because French Pacific voyager-writer; differs because 18th-c. explorer, not novelist.
  • Lafcadio Hearn: Similar because French-Greek writer on Japan like Loti's Madame Chrysanthème; differs because naturalised Japanese, more folkloric.
  • Conrad: Similar because sea-officer turned exotic novelist; differs because Polish-British, darker and more modernist than Loti's melancholy idylls.
  • Maupassant: Similar because contemporary French naturalist; differs because metropolitan Norman tales, not overseas exoticism.
  • Exoticist / orientalist writer: Similar because it describes Loti's school; differs because generic category, not the individual.
  • Académicien: Similar because Loti was elected to the Académie française; differs because title, not person.
