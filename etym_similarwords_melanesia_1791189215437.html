• Polynesia: Similar because it is a Pacific island subregion ending in -nesia; differs because it means many islands of the eastern triangle, lighter-skinned Polynesian cultures.
  • Micronesia: Similar because it is a Pacific island subregion ending in -nesia; differs because it means small islands of the northern Pacific, tiny atolls versus Melanesia's large high islands.
  • Oceania: Similar because it denotes the Pacific island world; differs because Oceania is the whole, while Melanesia is one western part of it.
  • Australasia: Similar because it groups Australia with nearby islands; differs because Australasia centres on Australia and New Zealand, while Melanesia excludes them.
  • Pacific Islands: Similar because it names the same geography plainly; differs because it is descriptive and neutral, while Melanesia carries historical racial baggage.
  • South Seas: Similar because it is an old literary name for the same ocean; differs because South Seas is romantic-colonial, while Melanesia is quasi-scientific.
  • New Guinea: Similar because it is the largest landmass in Melanesia; differs because New Guinea is one island, while Melanesia is the whole archipelagic region.
  • Bismarck Archipelago: Similar because it lies inside Melanesia; differs because it is a sub-group (New Britain, New Ireland), while Melanesia is the umbrella.
  • Solomon Islands: Similar because they are archetypal Melanesian islands; differs because they are one nation, while Melanesia spans many nations.
  • Vanuatu: Similar because it is a Melanesian nation; differs because Vanuatu is a single state, while Melanesia is a multi-state region.
  • Fiji: Similar because it sits at Melanesia's eastern edge; differs because Fiji bridges Melanesian and Polynesian cultures, while core Melanesia is Papuan.
  • Near Oceania: Similar because it covers much the same Pleistocene-settled zone; differs because Near Oceania is an archaeological term, while Melanesia is geographic-political.
