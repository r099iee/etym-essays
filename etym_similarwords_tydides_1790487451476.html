• Diomedes: Similar because it names the identical hero; differs because Diomedes is the personal name, while Tydides is the lineage epithet used for honour and metre.
  • Son of Tydeus: Similar because it is the literal English gloss; differs because it is explanatory prose, while Tydides is compact poetic diction.
  • Atreides / Atrides: Similar because it is another Homeric patronymic (son of Atreus); differs because it denotes Agamemnon or Menelaus, not Diomedes.
  • Peleides / Pelides: Similar because it is the parallel patronymic for Achilles son of Peleus; differs because it marks a different lineage and hero.
  • Laertiades: Similar because it means son of Laertes (Odysseus); differs because it belongs to Ithaca, not Argos.
  • Argive chief: Similar because Tydides was king of Argos and leader of Argives; differs because it is a rank description applicable to others, not a unique name.
  • Hero of the Iliad: Similar because Tydides is a central Iliadic hero; differs because it is generic, covering Achilles, Ajax, and Hector as well.
  • King of Argos: Similar because it is Diomedes' title; differs because it denotes office, while Tydides denotes descent.
  • Telamonian Ajax: Similar because it is another father-based heroic style (Ajax son of Telamon); differs because it marks Salaminian, not Argive, lineage.
  • Meriones: Similar because he is another second-tier Achaean slayer admired by Ruskin's boyhood; differs because he is Idomeneus's aide, not Tydeus's son.
