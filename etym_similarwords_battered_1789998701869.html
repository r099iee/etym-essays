• beaten: Similar because both mean struck and overcome; differs because beaten stresses defeat in a contest, battered stresses cumulative physical damage.
  • bruised: Similar because both show injury from impact; differs because bruised is flesh discolouration, battered is broader structural wear.
  • mauled: Similar because both imply rough violent damage; differs because mauled suggests savage animal-like tearing, battered suggests pounding blows.
  • pummelled: Similar because both involve repeated hitting; differs because pummelled is the action of fists, battered is the resulting worn state.
  • weathered / weather-beaten: Similar because both show endurance of harsh conditions; differs because weathered can be dignified patina, battered leans more damaged.
  • worn / time-worn: Similar because both show age and use; differs because worn is neutral erosion, battered implies violent impact.
  • shabby / tatty: Similar because both look neglected; differs because shabby is about poor appearance, battered about damage history.
  • tattered / ragged: Similar because both are frayed and ruined; differs because tattered is torn fabric/paper, battered is dented hard surfaces or bodies.
  • dilapidated: Similar because both are in disrepair; differs because dilapidated is buildings/structures crumbling, battered is impact-damaged movables or persons.
  • bashed / dented: Similar because both are hit in; differs because bashed/dented are often single blows, battered is many blows over time.
