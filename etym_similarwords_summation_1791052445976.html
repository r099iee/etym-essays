• Summary: Similar because it condenses longer matter; differs because summary stresses brevity while summation stresses totality and finality.
  • Summing-up: Similar because it recapitulates evidence at the end; differs because summing-up is plainer and, in UK courts, often the judge's direction, while summation is more formal.
  • Recapitulation: Similar because it restates heads of argument; differs because recapitulation stresses going over again, summation stresses adding to a total.
  • Synopsis: Similar because it gives an overview; differs because synopsis is a brief outline, often written beforehand, not a culminating total.
  • Précis: Similar because it condenses text; differs because précis is a disciplined short abstract, summation is a grand closing.
  • Total: Similar because it denotes the added amount; differs because total is purely quantitative, summation includes the process and rhetorical sense.
  • Aggregate: Similar because it denotes combined sum; differs because aggregate is technical-statistical, summation is broader and rhetorical.
  • Culmination: Similar because it denotes the highest crowning point; differs because culmination need not involve adding parts, summation does.
  • Epitome: Similar because it embodies essence; differs because epitome is a perfect example, summation is the gathered whole.
  • Closing argument: Similar because in US law it is the summation; differs because closing argument is specifically forensic, summation also covers maths and general prose.
  • Addition: Similar because it denotes mathematical adding; differs because addition is the operation in general, summation often the formal prolonged or notated sum.
  • Tally: Similar because it counts up; differs because tally is informal running count, summation is formal final total.
