• passion: Similar because it denotes intense feeling; differs because passion can be tender or quiet, while vehemence stresses forceful outward expression.
  • fervour: Similar because it means burning earnestness and zeal; differs because fervour is warmer and often religious, vehemence is more abrupt and forceful.
  • ardour: Similar because it denotes burning enthusiasm; differs because ardour suggests love-like heat, vehemence suggests rushing force.
  • intensity: Similar because it means great strength of feeling; differs because intensity is neutral and sustained, vehemence is impetuous and eruptive.
  • forcefulness: Similar because it means vigour and emphasis; differs because it is plainer and stylistic, vehemence adds emotional heat.
  • vigour: Similar because it denotes energetic strength; differs because vigour can be healthy and controlled, vehemence implies near loss of control.
  • violence: Similar because it shares Latin vis-adjacent force; differs because violence entails harm or violation, vehemence need not harm.
  • fury: Similar because it is intense anger; differs because fury is wilder and more destructive than vehemence.
  • vehemency (archaic): Similar because it is a doublet with identical sense; differs only in that it is obsolete.
  • emphasis: Similar because vehement speech is emphatic; differs because emphasis can be calm and deliberate.
  • earnestness: Similar because it means serious conviction; differs because earnestness lacks the rushing, heated manner.
  • zeal: Similar because it is eager devotion to a cause; differs because zeal is sustained dedication, vehemence is momentary heat.
  • bluster: Similar because Tuppy-like vehemence can sound blustering; differs because bluster implies empty noisy bullying.
  • impetuosity: Similar because both involve rushing headlong; differs because impetuosity stresses hasty action, vehemence stresses force of expression.
