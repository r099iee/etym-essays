• dirty: Similar because both mean unclean; differs because dirty is broader and can mean mud-caked, while dingy stresses dull, faded griminess.
  • grimy: Similar because both mean ingrained dirt; differs because grimy implies blackish film you can feel, dingy implies faded dullness you see.
  • shabby: Similar because both describe neglected places/clothes; differs because shabby stresses worn-out poverty, dingy stresses dark dullness.
  • seedy: Similar because both describe run-down places with moral taint; differs because seedy adds disreputable, sordid behaviour, dingy is more visual.
  • sordid: Similar because both mean dirty and morally low; differs because sordid is stronger, implying greed or vice, dingy is milder and visual.
  • murky: Similar because both mean dark and gloomy; differs because murky is for liquids, air, or obscurity, dingy is for surfaces and rooms.
  • dusky: Similar because both mean darkish in colour; differs because dusky can be poetic and attractive (dusky beauty), dingy is always unattractive.
  • dull: Similar because both mean lacking brightness; differs because dull is neutral and broad (dull pain, dull lecture), dingy always implies dirt/neglect.
  • faded: Similar because both mean colour lost; differs because faded is neutral about cause (sun-faded), dingy blames dirt and gloom.
  • run-down: Similar because both describe neglected buildings; differs because run-down stresses disrepair needing work, dingy stresses depressing appearance.
  • gloomy: Similar because both evoke depressing darkness; differs because gloomy is about mood/light, dingy adds dirtiness.
  • fusty: Similar because both describe stale old rooms; differs because fusty stresses musty smell and airlessness, dingy stresses visual dullness.
