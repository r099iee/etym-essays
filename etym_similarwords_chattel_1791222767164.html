• cattle: Similar because it shares the same Latin-French root for head-count stock; differs because cattle now means livestock only, while chattel means movables generally.
  • capital: Similar because it shares capitale from caput; differs because capital is abstract investment wealth, while chattel is concrete movable things.
  • goods: Similar because goods are movable possessions; differs because goods is everyday-commercial, while chattel is legal-historical.
  • chattels (goods and chattels): Similar because it is the same word in fixed phrase; differs only in that the phrase stresses totality of belongings.
  • property: Similar because chattel is a kind of property; differs because property includes land, while chattel excludes real estate.
  • personalty: Similar because it is the lawyer's synonym for movables; differs because it is purely technical, while chattel carries historical-slavery resonance.
  • movables: Similar because it denotes things that can be moved; differs because it is civil-law plain term, while chattel is common-law historical.
  • effects: Similar because personal effects are belongings; differs because effects suggests small personal items, while chattel includes livestock and leases.
  • belongings: Similar because both mean what one owns; differs because belongings is warm-everyday, while chattel is cold-juridical.
  • possessions: Similar because both denote owned things; differs because possessions is general, while chattel is specifically non-land.
  • livestock: Similar because early chattel included animals; differs because livestock is now only animals, while chattel is now mostly inanimate goods and legal interests.
  • stock: Similar because stock is farm capital and inventory; differs because stock stresses breeding-supply, while chattel stresses movability.
  • paraphernalia: Similar because it means movable gear; differs because it implies equipment-trap, while chattel implies ownable value.
  • slave (chattel slave): Similar because a chattel slave is a person classed as chattel; differs because slave names the person-status, while chattel names the property-category.
