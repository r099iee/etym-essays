• Impassivity: Similar because it means showing no emotion; differs because it is clinical and neutral, while stolidity hints at dull heaviness.
  • Stoicism: Similar because it means calm endurance; differs because stoicism is philosophical and principled, stolidity is temperamental and bovine.
  • Phlegm: Similar because British phlegm means unflappable calm; differs because phlegm is praised as national character, stolidity can be dull.
  • Composure: Similar because it means self-control; differs because composure is active grace, stolidity is inert heaviness.
  • Equanimity: Similar because it means even temper; differs because equanimity is enlightened balance, stolidity is thick-skinned.
  • Apathy: Similar because both show lack of reaction; differs because apathy is indifference and not caring, stolidity is enduring without showing.
  • Impensiveness: Similar because it means unreadable face; differs because it is rare and literary, stolidity is common character description.
  • Dullness: Similar because original sense of stolid is dull; differs because dullness stresses stupidity, stolidity stresses calm.
  • Obtuseness: Similar because both imply thickness; differs because obtuseness is mental slowness, stolidity is emotional stillness.
  • Inertia: Similar because both imply immobility; differs because inertia is physical laziness, stolidity is emotional steadiness.
  • Woodenness: Similar because both evoke stuffed stiffness; differs because woodenness criticises acting, stolidity describes temperament.
  • Deadpan: Similar because deadpan humour needs stolid face; differs because deadpan is deliberate comic technique, stolidity is natural disposition.
  • Placidity: Similar because it means calm smoothness; differs because placidity is gentle and pleasant, stolidity is heavy and bovine.
  • Stodginess: Similar because both suggest heaviness; differs because stodginess criticises dull conventionality, stolidity can be dignified.
