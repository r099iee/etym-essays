• French: Similar because it denotes the same nationality; differs because it is purely denotative while Gallic adds a classical-literary flourish.
  • Parisian: Similar because it evokes French style; differs because it is specifically capital-city, while Gallic is national or ancient-tribal.
  • Gaulish: Similar because it names the ancient Celts of Gaul; differs because it stresses the pre-Roman language/people rather than modern Frenchness.
  • Gallo-Roman: Similar because it links Gaul and Rome; differs because it is strictly archaeological-historical for the Roman period.
  • Francophone: Similar because it concerns French language/culture; differs because it includes all French-speakers worldwide, not France itself.
  • Continental: Similar because Britons use it for European neighbours including France; differs because it is broader and vaguer.
  • Latin (in the cultural sense): Similar because it groups French with southern European temperament; differs because it spans Italy, Spain, and beyond.
  • Celtic: Similar because the Gauls were Celts; differs because Celtic covers Ireland, Scotland, Wales, and Brittany too.
  • Gallican: Similar because it derives from the same Latin root; differs because it specifically denotes the French Catholic tradition, not nationality.
  • bourgeois (stereotype sense): Similar because it is used for stereotypical French manners; differs because it is socio-economic rather than national.
