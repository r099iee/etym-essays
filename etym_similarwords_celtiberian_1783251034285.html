• Iberian: Similar because both name ancient peoples and languages of Spain; differs because Iberian proper is the non-Indo-European isolate of the eastern and southern coasts, entirely unrelated to Celtic, while Celtiberian is a Celtic language of the interior.
  • Hispano-Celtic: Similar because both name the Celtic languages of the peninsula; differs because Hispano-Celtic is the modern umbrella category covering all of them, of which Celtiberian is the best-attested single member.
  • Lusitanian: Similar because both are ancient peninsular languages of the pre-Roman West; differs because the Celticity of Lusitanian is still debated while Celtiberian is securely, undeniably Celtic.
  • Galatian: Similar because both are Continental Celtic languages attested only in inscriptions and onomastics; differs because Galatian was spoken in central Anatolia by migrating Celts, not in Spain.
  • Gaulish: Similar because both are Continental Celtic tongues of the pre-Roman West, bracketed together on this card; differs because Gaulish is P-Celtic (shifting *kʷ to p) and was spoken in France and the Low Countries, while Celtiberian is Q-Celtic and Spanish.
  • Q-Celtic / Goidelic: Similar because Celtiberian shares the conservative preservation of *kʷ; differs because Q-Celtic is a branch label (Irish, Scots Gaelic, Manx) and Celtiberian is the one Continental language that aligns with it.
  • Continental Celtic: Similar because Celtiberian is a member of this family; differs because Continental Celtic is the umbrella term for the extinct mainland Celtic languages (Gaulish, Lepontic, Galatian, Celtiberian), not a single language.
  • Celtici: Similar because both words derive from the same Celtic ethnonym and name Celtic peoples of Iberia; differs because the Celtici are a specific tribe-group of south-western Spain (Baetica and Lusitania), separate from the Celtiberians of the Meseta and Ebro.
  • Celt: Similar because it contributes the first element and the same Indo-European heritage; differs because Celt is the generic word for any member of the Celtic peoples or languages, whereas Celtiberian names only the Spanish fusion group.
