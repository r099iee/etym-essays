• ram (short form): Similar because it is the same engine, historically called just 'a ram' in English; differs because the full form battering-ram makes the repeated beating explicit and is the modern standard name.
  • siege engine: Similar because both are machines used to attack fortifications; differs because siege engine is the general category (including towers, catapults), while a battering-ram is specifically a breaching beam.
  • catapult: Similar because both are ancient siege weapons; differs because a catapult hurls projectiles over or at walls, while a battering-ram directly shoves and crashes against the wall.
  • trebuchet: Similar because both are massive medieval siege machines; differs because a trebuchet is a counterweight throwing engine, not a ramming beam.
  • ballista: Similar because both are Roman-era siege weapons; differs because a ballista is a large crossbow firing bolts, while the ram delivers its force by direct impact.
  • onager: Similar because both are Roman artillery; differs because the onager is a torsion stone-thrower, whereas the ram carries no projectile at all.
  • pile-driver: Similar because both slam a heavy beam repeatedly into a surface; differs because a pile-driver is a modern construction machine for sinking posts, not a weapon.
  • batter (verb): Similar because it names the repeated striking action inside the compound; differs because it is a verb and lacks the ram's image of the butting beast or the siege context.
