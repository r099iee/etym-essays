• Celtic: Similar because both refer to the ancient Indo-European ethno-linguistic family of the British Isles and Ireland; differs because Celtic is the broad umbrella covering both Goidelic (Gaelic/Irish/Manx) and Brythonic (Welsh/Cornish/Breton) branches, while Gaelic names only the Goidelic group.
  • Irish: Similar because both can name the language of Ireland; differs because Irish (or Gaeilge) is the precise modern name used in Ireland for the Irish language, while in British usage Gaelic often points specifically to Scottish Gaelic (Gàidhlig).
  • Gaeilge: Similar because it is the native Irish name for the Irish language; differs because Gaeilge is the Irish-language endonym used in Ireland, while Gaelic is the English exonym covering the wider branch.
  • Gàidhlig: Similar because it is the native Scottish Gaelic name for Scottish Gaelic; differs because Gàidhlig is the Scottish endonym spoken inside the language, while Gaelic is the English word for the whole branch.
  • Goidelic: Similar because it is the precise linguistic family to which Gaelic belongs; differs because Goidelic is the technical scholar's label for the Irish-Scottish-Manx branch (Q-Celtic), while Gaelic is the everyday name.
  • Erse: Similar because it is an older English name for Irish or Scottish Gaelic; differs because Erse (literally "Irish") is now obsolete and was often used dismissively, while Gaelic is the standard modern term.
  • Highland (as in Highland speech): Similar because both describe the northern Scottish culture and its tongue; differs because Highland is a geographic-cultural descriptor of the Scottish region, while Gaelic is the precise linguistic and ethnic name.
  • Manx: Similar because Manx is the Goidelic language of the Isle of Man, closely related to Gaelic; differs because Manx names only the Isle of Man tongue, while Gaelic covers Irish and Scottish Gaelic.
  • Brythonic: Similar because both are branches of Insular Celtic; differs because Brythonic is the other main branch (Welsh, Cornish, Breton) and is the technical label contrasted with Goidelic/Gaelic.
