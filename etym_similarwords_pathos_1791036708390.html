• Poignancy: Similar because it means keenly moving sadness; differs because it stresses sharpness of feeling rather than rhetorical appeal.
  • Pathetic (adjective, sympathetic sense): Similar because pathetic can mean full of pathos; differs because modern pathetic usually means contemptibly inadequate.
  • Pity: Similar because it is sorrow for another's suffering; differs because pity is the feeling, pathos the quality that causes it.
  • Compassion: Similar because it responds to suffering; differs because compassion implies desire to help, pathos only to move.
  • Sympathy: Similar because it shares feeling; differs because sympathy is broader and less sorrow-specific.
  • Sorrow: Similar because it is grief; differs because sorrow is the emotion itself, not its artistic power.
  • Melancholy: Similar because it is pensive sadness; differs because it is mood, not persuasive quality.
  • Tenderness: Similar because pathos softens hearers; differs because tenderness can be warm without sadness.
  • Sentimentality: Similar because it seeks tears; differs because sentimentality is pejorative for excessive or unearned emotion.
  • Bathos: Similar because it involves attempted pathos; differs because bathos is failed, anticlimactic pathos that amuses.
  • Tragedy: Similar because tragedy evokes pity and fear; differs because tragedy is a genre and event, pathos its emotional effect.
  • Emotion (rhetorical): Similar in the Aristotle trio; differs because emotion is generic, pathos specifically suffering-based appeal.
