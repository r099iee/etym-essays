• Dagger: Similar because it is a short thrusting blade; differs because it is hand-held alone, not designed to mount on a firearm.
  • Dirk: Similar because it is a long thrusting sidearm; differs because it is Scottish Highland dress weapon, not a muzzle attachment.
  • Pike: Similar because bayonet-tipped musket replaced the pike as infantry spear; differs because pike is a very long shafted spear, not a gun-mounted knife.
  • Lance: Similar because it is a cavalry spear for charging; differs because it is horseman's long point, distinct from infantry firearm blade.
  • Spear: Similar because fixed bayonet turns rifle into short spear; differs because spear is the generic shafted point, while bayonet presupposes gunpowder weapon.
  • Sword: Similar because early sword-bayonets were cut-down swords; differs because sword is a complete hand weapon for cut and thrust, not an accessory.
  • Cutlass: Similar because it is a short military blade; differs because it is naval sidearm for slashing, not muzzle-fixed.
  • Knife: Similar because modern bayonets double as field knives; differs because knife is general tool, bayonet is mounting system plus drill.
  • Stiletto: Similar because triangular socket blades resemble stilettos; differs because stiletto is a civilian piercing dagger, not military attachment.
  • Poniard: Similar because plug bayonets were poniards jammed in muzzles; differs because term is archaic literary for dagger, without modern socket system.
  • Javelin: Similar because passage groups lance, javelin, spear as stick-weapons; differs because javelin is thrown, bayonet is fixed for thrusting.
  • Halberd: Similar because it combined axe and spear on shaft like gun plus blade; differs because it is a polearm of guards, obsolete before bayonet dominance.
  • Spike: Similar because cruciform blades are called spikes; differs because spike is the blade shape, not the institution of fixing and charging.
