• drunk: Similar because it means intoxicated; differs because it is neutral-direct and stronger, while boozy is comic and milder.
  • tipsy: Similar because it means slightly drunk and merry; differs because it is lighter and more elegant than boozy, which implies heavier soaking.
  • maudlin: Similar because it describes sentimental drunkenness; differs because it stresses tearful emotion, not just alcohol content.
  • befuddled: Similar because it means mentally confused as by drink; differs because it can be non-alcoholic and lacks convivial warmth.
  • woozy: Similar because it means dizzy and unsteady; differs because it is physiological dizziness, not necessarily alcoholic.
  • alcoholic: Similar because it relates to alcohol excess; differs because it is clinical for dependence, while boozy is jocular for occasion.
  • bibulous: Similar because it means fond of drink; differs because it is formal-literary and admiring, while boozy is colloquial-mocking.
  • inebriated: Similar because it means drunk; differs because it is formal or legalistic, lacking boozy humour.
  • sodden: Similar because it suggests soaked with drink; differs because it is heavier, bleaker, implying chronic saturation.
  • merry: Similar because it euphemizes tipsy cheer; differs because it is coy Victorian euphemism, while boozy is blunt about drink.
