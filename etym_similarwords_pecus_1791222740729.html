• cattle: Similar because it denotes bovine livestock as property; differs because it is the modern English farm word, while pecus is the Latin ancestor with explicit wealth-money sense.
  • livestock: Similar because it means domestic animals kept for use; differs because it is a neutral collective, lacking pecus's archaic cattle-equals-money equation.
  • herd: Similar because it denotes a group of grazing animals; differs because it stresses the group shape, not the value-wealth aspect central to pecus.
  • flock: Similar because it denotes sheep, goats or birds kept together; differs because it is usually small stock, while pecus prototypically centres on cattle.
  • stock: Similar because it means farm animals and stored wealth; differs because it is broader (live-stock, dead-stock, shop-stock), while pecus is specifically live herd-wealth.
  • kine: Similar because it is an archaic plural for cows; differs because it is poetic-English, while pecus is Latin and includes sheep and goats.
  • oxen: Similar because oxen were the prestige pecus stamped on coins; differs because oxen names a species-use, while pecus names the whole holding.
  • beasts: Similar because farm beasts are pecus; differs because beasts can be wild or contemptuous, while pecus is always domestic and owned.
  • property: Similar because pecus was property par excellence; differs because property is abstract-general, while pecus is concrete livestock-property.
  • wealth: Similar because a full pecus meant riches; differs because wealth is abstract, while pecus is wealth on the hoof.
  • capital: Similar because both derive from head-count livestock as breeding stock; differs because capital is modern abstract finance, while pecus is the ancient herd itself.
  • chattel: Similar because chattel is movable property descended from cattle-counting; differs because chattel is legal English for goods, while pecus is Latin for the herd.
  • fortune: Similar because pecus constituted a Roman's fortune; differs because fortune implies chance and total estate, while pecus is countable animals.
  • flock (congregation): Similar because Christian Latin used pecus for the faithful flock; differs because that is metaphorical-human, while core pecus is animal.
