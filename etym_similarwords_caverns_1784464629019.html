• Dungeon: Similar because both are underground chambers entered from the surface; differs because a dungeon is built — a stronghold keep or prison vault — while a cavern is a natural rock chamber.
  • Cave: Similar because both are hollows in the earth; differs because cave is the general, often smaller and everyday term, without cavern's vastness, darkness, and grandeur.
  • Grotto: Similar because both are rock chambers; differs because a grotto can be smaller, ornamental, or artificial and picturesque, while a cavern is a large natural geological void.
  • Hollow: Similar because both name a sunken or empty space; differs because hollow is broad and often smaller or surface-level, lacking cavern's subterranean scale and formality.
  • Vault: Similar because both can name a roofed, arched interior space; differs because vault is usually built masonry or an architectural arch, not a natural rock chamber.
  • Abyss: Similar because both evoke deep, dark underground vastness; differs because an abyss stresses depth and void without a defined chamber, while a cavern is a bounded space.
  • Tunnel: Similar because both run underground; differs because a tunnel is an artificial passage, usually horizontal and through-going, not a chamber.
  • Catacomb: Similar because both are underground hollows; differs because catacombs are human-built burial galleries, often extensive and tunnelled, not natural rock chambers.
  • Chasm: Similar because both are large openings in rock; differs because a chasm is a deep fissure or gap, usually open to the sky, not an enclosed cave-hall.
  • Subterrane / underground: Similar because both denote what lies beneath the earth; differs because these are broad locative terms, not names for a specific large chamber.
