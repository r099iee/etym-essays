• conquerors: Similar because it is the direct English equivalent; differs because it is generic for any victors, while conquistadores specifies 16th-century Spaniards.
  • invaders: Similar because both seize чуждо territory by force; differs because invader stresses unlawful entry and is pejorative, while conquistador can be neutral-historical.
  • explorers: Similar because conquistadores also mapped new lands; differs because explorer stresses discovery, while conquistador stresses subjugation and settlement.
  • colonizers: Similar because both establish overseas dominion; differs because colonizer stresses settlement and administration after conquest.
  • conquistadors (anglicized): Similar because it names the same men; differs only in spelling/plural formation (-s vs. Spanish -es).
  • soldiers: Similar because conquistadores fought; differs because soldier is a profession in any army, not a licensed adventurer-band.
  • mercenaries: Similar because many served for profit; differs because mercenaries sell service to a paymaster, while conquistadores invested for Crown-granted spoils.
  • missionaries: Similar because they accompanied conquest to evangelize; differs because their weapon was preaching, not arms, though often allied.
  • settlers: Similar because many stayed as encomenderos; differs because settler stresses farming and family life after pacification.
  • adventurers: Similar because it captures risk-seeking hidalgos; differs because adventurer lacks the legal-religious mandate and imperial consequence.
  • warlords: Similar because captains wielded personal armed followings; differs because warlord implies autonomous rule, while conquistadores claimed to act for the king.
  • crusaders: Similar because Reconquista ideology framed conquest as holy war; differs because crusaders fought Muslims in the Holy Land, not Indigenous Americans.
  • pioneers: Similar because both open new frontiers; differs because pioneer is generally positive and non-military, while conquistador is morally contested.
