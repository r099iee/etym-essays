• Cart: Similar because both are wheeled load-carriers; differs because cart prototypically has two wheels and is smaller, wagon has four and is heavier.
  • Wain: Similar because it is the native Old English cognate for wagon; differs because wain is archaic and poetic, wagon is everyday.
  • Carriage: Similar because both are horse-drawn four-wheelers; differs because carriage carries people in comfort, wagon carries goods.
  • Coach: Similar because both carry people or goods on wheels; differs because coach is enclosed and passenger-focused.
  • Buggy: Similar because both are horse-drawn; differs because buggy is light and one-horse, wagon is heavy and team-drawn.
  • Trolley: Similar because both are load platforms on wheels; differs because trolley is typically hand-pushed or rail-guided and smaller.
  • Truck / Lorry: Similar because both haul freight; differs because truck is motorised, wagon was originally animal-drawn.
  • Van: Similar because both enclose or carry loads; differs because van is a motor vehicle with covered body.
  • Trailer: Similar because both are hauled load-beds; differs because trailer is unpowered and towed by a cab.
  • Freight car / Goods wagon: Similar because railway wagons are freight cars; differs because American freight car is the standard term, wagon is British for open trucks.
  • Station wagon / Estate car: Similar because it bears the wagon name for load space; differs because it is a passenger car, not a farm cart.
  • Chariot: Similar because both are wheeled carriers from the same PIE root; differs because chariot is ancient, fast and warlike, wagon is slow and utilitarian.
