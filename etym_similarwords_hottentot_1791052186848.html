• Khoikhoi: Similar because it denotes the same peoples; differs because it is the respectful self-name, while Hottentot is the offensive outsider name.
  • Khoekhoe: Similar because it is the modern linguistic/people term; differs because it is the current scholarly standard, not a slur.
  • Nama: Similar because Nama are the largest surviving Khoikhoi group; differs because it is a specific subgroup, not a blanket exonym.
  • San: Similar because San are related Khoe-San hunter-gatherers often grouped with Khoikhoi; differs because San are traditionally foragers, not herders.
  • Khoe-San: Similar because it is the collective term for Khoikhoi plus San; differs because it is modern inclusive and neutral.
  • Bushman: Similar because it is another dated colonial label for San neighbours; differs because it refers to hunter-gatherers, and is also now sensitive though less taboo than Hottentot.
  • aborigine: Similar because it means original inhabitant; differs because it is generic global, capitalised Aborigine for Australia, not Cape-specific.
  • native: Similar because colonial texts say natives for indigenous peoples; differs because it is general and now often patronising but not a slur to the same degree.
  • tribesman: Similar because it denotes member of a tribe; differs because it is generic and can be neutral, lacking the mocking etymology.
  • exonym: Similar because Hottentot is a classic exonym (outsider name); differs because exonym is the category (like Eskimo, Gypsy), not the people.
  • slur: Similar because Hottentot now functions as ethnic slur; differs because slur is the pragmatic status, not the referent.
  • Kaffir (historical): Similar because it is another South African colonial slur now banned; differs because it targeted Black Africans generally and is legally hate speech, even more taboo.
