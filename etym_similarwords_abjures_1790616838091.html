• renounces: Similar because it denotes formally gives up claim or belief; differs because it is broader and can be without oath, while abjures stresses swearing off.
  • repudiates: Similar because it denotes rejects with disapproval; differs because it stresses refusal to accept, often publicly, less oath-bound.
  • recants: Similar because it denotes withdraws former belief publicly; differs because it is specific to taking back words, often under pressure.
  • forswears: Similar because it denotes renounces under oath; differs because it is closest twin, slightly more archaic and personal.
  • disavows: Similar because it denotes denies responsibility or support; differs because it is distancing, not necessarily once-held faith.
  • disowns: Similar because it denotes refuses to acknowledge; differs because it is often familial or possessive.
  • rejects: Similar because it denotes refuses to accept; differs because it is general and can be instant, without solemnity.
  • relinquishes: Similar because it denotes gives up possession; differs because it is about holding, not believing, and without oath.
  • eschews: Similar because it denotes deliberately avoids; differs because it is habitual shunning, not formal oath.
  • abandons: Similar because it denotes gives up entirely; differs because it can be desertion without declaration.
