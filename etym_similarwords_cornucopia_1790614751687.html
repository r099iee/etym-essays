• horn of plenty: Similar because it is the literal English translation denoting overflowing abundance; differs because it is the transparent calque, while cornucopia is the learned Latinate single-word emblem.
  • abundance: Similar because it means plentifulness; differs because abundance is abstract quantity, while cornucopia pictures the horn-shaped source of that quantity.
  • profusion: Similar because it means lavish pouring-forth; differs because profusion stresses extravagant spilling, while cornucopia stresses fruitful container.
  • plenitude: Similar because it means fullness, completeness; differs because plenitude is philosophical and of Germanic-Latin formality, while cornucopia is mythologically visual.
  • bounty: Similar because it means generous gifts of nature; differs because bounty stresses generous giver, while cornucopia stresses inexhaustible vessel.
  • treasure trove: Similar because it denotes rich discovered store; differs because trove implies hidden find with legal overtones, while cornucopia implies open overflow.
  • mine: Similar because as in a mine of information it means rich source; differs because mine is industrial-subterranean, while cornucopia is agricultural and festive.
  • welter: Similar because it means confused abundant mass; differs because welter can be pejorative chaos, while cornucopia is celebratory order.
  • plethora: Similar because it means overabundance; differs because plethora is often medical-excessive, while cornucopia is desirable plenty.
