• Haudenosaunee: Similar because it denotes the same Six Nations people; differs because it is the self-chosen endonym and now preferred, while Iroquois is a French-derived exonym.
  • Mohawk (Kanienʼkehá꞉ka): Similar because Mohawk are one Iroquois nation; differs because it names only the easternmost nation, not the whole confederacy.
  • Oneida: Similar because Oneida are a constituent Iroquois nation; differs because it is narrower, naming one people, not all six.
  • Onondaga: Similar because Onondaga are the central fire-keepers of the league; differs because it names one nation and its language, not the collective.
  • Cayuga: Similar because Cayuga belong to the confederacy; differs because it is one nation only.
  • Seneca: Similar because Seneca are the westernmost Iroquois nation; differs because Seneca alone is not the league.
  • Tuscarora: Similar because Tuscarora joined as the Sixth Nation in 1722; differs because Tuscarora864 was originally southern and linguistically distinct.
  • Huron / Wyandot: Similar because Huron speak a related Northern Iroquoian language and shared longhouse culture; differs because Huron were enemies and victims of the Iroquois, not members.
  • Cherokee: Similar because Cherokee is Southern Iroquoian linguistically; differs because Cherokee lived in the Southeast and were never part of the northern league.
  • Algonquin / Algonquian peoples: Similar because they were neighbours and fur-trade rivals in the same region; differs because they speak wholly unrelated Algonquian languages and were often at war with the Iroquois.
  • Sioux: Similar because Sioux is another French-derived collective exonym for a confederacy; differs because it denotes Plains Siouan peoples, not woodland Iroquoians.
  • Confederacy / League: Similar because the Iroquois League is the political form; differs because confederacy is a generic term, while Iroquois names the specific holders.
