• here: Similar because both locate a point at the speaker's position; differs because here is a static locative ("I am here") while hither is a directional adverb of approach ("to here"), and here is the living everyday word while hither is archaic-literary.
  • thither: Similar because it is the exact parallel form meaning "to that place," and the two share structure and history; differs because it points away from the speaker, whereas hither points toward; both are archaic, but thither is even rarer today.
  • whither: Similar because it is the same -ither adverb family, "to which place?"; differs because it is interrogative/relative, whereas hither is declarative ("to this place").
  • hence: Similar because it is the archaic directional counterpart of hither; differs because it means "from this place" (source), not "to this place" (goal), and it survives mainly in "henceforth."
  • thence: Similar because it completes the ancient system (hither/thither/whither... hence/thence/whence); differs because it means "from that place" and is nearly obsolete outside fixed phrases.
  • whence: Similar because it is the interrogative source-word, "from which place?"; differs in meaning ("from where," not "to here") and in its near-archaic status.
  • hereto: Similar because both are formal adverbs built on the same deictic "here/hither"; differs because hereto means "to this (document/thing)" in legal usage and is not about physical movement.
  • hitherto: Similar because it contains hither; differs because the compound means "up to this time" (temporal), whereas the simple word is spatial.
  • toward(s): Similar because both express direction of motion; differs because toward is a fully modern preposition needing an object ("toward me"), is deictically neutral, and has none of the archaic colour.
