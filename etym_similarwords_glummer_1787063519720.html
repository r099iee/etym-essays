• Gloomier: Similar because both are comparatives meaning “more gloomy and depressing”; differs because gloomier also applies to darkness of light and to whole scenes or forecasts, while glummer is more about a person’s downcast mood and manner.
  • Sadder: Similar because both describe increased low spirits; differs because sad is a far broader and deeper emotion — genuine grief or heartache — whereas glum is a lighter, more visible, more sulky dejection.
  • More morose: Similar because both describe silent, withdrawn ill-humour; differs because morose adds bitterness, hostility, and a readiness to be disagreeable, while glum is passive and unaggressive.
  • More sullen: Similar because both describe silent displeasure; differs because sullen implies resentfulness and defiance — a sulky refusal to respond — while glum is simply cheerless and downcast.
  • More dejected: Similar because both describe a cast-down, discouraged state; differs because dejected emphasises disappointment and a loss of hope, while glum emphasises the visible dullness of mood.
  • More downcast: Similar because both describe eyes and spirits turned down; differs because downcast is chiefly about appearance and gaze, while glum covers the whole manner and temper.
  • More melancholy: Similar because both describe a sad, pensive mood; differs because melancholy is a deeper, more romantic, more thoughtful sadness, while glum is plain, everyday, and slightly grumpy.
  • More doleful: Similar because both describe a mournful look or air; differs because doleful is archaic and suggests visible mourning and woe, while glum is modern and understated.
  • More forlorn: Similar because both describe being low and abandoned-feeling; differs because forlorn adds loneliness and hopelessness, while glum is just a bad mood without the pathos.
  • More despondent: Similar because both describe a loss of cheer; differs because despondent is stronger and more clinical — a serious loss of hope — while glum is a passing, visible grumpiness.
