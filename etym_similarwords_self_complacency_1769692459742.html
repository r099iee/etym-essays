• Smugness: Similar because both name proud, uncritical self-satisfaction; differs because smugness stresses an irritating, self-righteous display of self-approval, while self-complacency stresses the passive inner blindness to one's own faults.
  • Complacency: Similar because both name uncritical satisfaction with the status quo; differs because complacency generally refers to satisfaction with circumstances (often without the reflexive focus on self), while self-complacency is explicitly satisfaction directed at oneself.
  • Self-satisfaction: Similar because both literally mean being pleased with oneself; differs because self-satisfaction is more neutral and can describe justifiable pride, while self-complacency is normally critical and implies blindness to faults.
  • Conceit: Similar because both involve an inflated opinion of oneself; differs because conceit is active self-importance and boastfulness, while self-complacency is quiet, passive self-approval.
  • Vanity: Similar because both name self-regard; differs because vanity seeks admiration from others and is outward-looking, while self-complacency is inner and needs no audience.
  • Self-approbation: Similar because both name approving of oneself; differs because self-approbation is a neutral, even positive self-endorsement, while self-complacency is pejorative.
  • Self-admiration: Similar because both involve admiring oneself; differs because self-admiration implies deliberate contemplation of one's own merits, while self-complacency is an unexamined state of being satisfied.
  • Hubris: Similar because both name dangerous overconfidence; differs because hubris is the tragic, defiant pride that offends the gods and invites catastrophe, while self-complacency is milder, passive smugness.
  • Egotism: Similar because both involve excessive self-focus; differs because egotism is self-centredness and boastful talk about the self, while self-complacency is quiet self-satisfaction without display.
  • Priggishness: Similar because both imply a smug sense of one's own virtue; differs because a prig is ostentatiously and self-righteously moral, while the self-complacent person need not parade morality.
  • Contentment (contrast): Similar because both involve satisfaction with one's state; differs because contentment is a wholesome, admired peace, while self-complacency is a criticized, complacent smugness.
  • Smugness before a crisis / false security: Similar because both warn of dangerous self-satisfaction; differs because "false security" names the situation of being wrongly confident about safety, while self-complacency names the psychological attitude itself.
