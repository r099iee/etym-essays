• swamp: Similar because it denotes waterlogged ground; differs because it is typically wooded and warmer/subtropical, while marsh is open and grassy.
  • bog: Similar because it denotes soft wet ground; differs because it is acidic, peaty, and moss-covered with stagnant water.
  • fen: Similar because it denotes low marshy land; differs because it is alkaline peatland, especially of East Anglia, with specific ecology.
  • mire: Similar because it denotes muddy wet ground; differs because it is literary and stresses sinking mud and figurative entanglement.
  • morass: Similar because it denotes marshy waste; differs because it is literary-formal and strongly figurative for confusion.
  • slough: Similar because it denotes muddy inlet or swamp; differs because it is regional and also means a side channel or casts-off skin.
  • wetland: Similar because it is the umbrella ecological term; differs because it is technical and neutral, covering marshes, swamps, bogs together.
  • marshland: Similar because it is near-identical; differs only in stressing the tract as land type, slightly more formal-geographical.
  • quagmire: Similar because it denotes soft sinking ground; differs because it stresses danger of sinking and is heavily figurative for predicaments.
  • moor: Similar because it denotes wild open wet ground; differs because it is upland, peaty heath, not lowland reed-bed.
  • estuary: Similar because salt marshes fringe estuaries; differs because it denotes the tidal river mouth itself, not the vegetated flat.
  • mangrove: Similar because it denotes tidal wetland forest; differs because it is tropical and tree-dominated.
