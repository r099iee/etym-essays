• gasp: Similar because it is an audible laboured breath; differs because a gasp is a sudden sharp intake from shock or effort, not a prolonged whistling exhalation.
  • pant: Similar because it is heavy audible breathing; differs because panting is rapid open-mouth breathing from heat or exertion without the whistling obstruction tone.
  • puff: Similar because it is a short expulsion of breath; differs because puffing is voluntary and often with cheeks, while wheezing is involuntary and whistling.
  • whistle: Similar because it shares the high-pitched sibilant sound; differs because whistling is usually voluntary and musical, wheezing is pathological and uncontrolled.
  • hiss: Similar because it is a fricative sibilant sound; differs because hissing is typically produced through teeth or by snakes/steam, not through constricted bronchi.
  • cough: Similar because it is a respiratory symptom involving airways; differs because a cough is explosive and clearing, a wheeze is continuous and whistling.
  • sneeze: Similar because it is a noisy respiratory reflex; differs because sneezing is a sudden nasal expulsion, wheezing is sustained bronchial narrowing.
  • snore: Similar because it is noisy breathing with vibration; differs because snoring occurs in sleep via throat vibration, wheezing occurs awake via lower airways.
  • rasp: Similar because it denotes a harsh grating breath or voice; differs because rasp is rougher and lower, wheeze is higher and more musical.
  • rattle: Similar because lungs can rattle with mucus (death rattle); differs because rattling is loose and bubbly, wheezing is tight and whistling.
  • trick: Similar because in the clever-wheeze sense it means a scheme; differs because trick is generic and can be mean, while a wheeze is specifically an ingenious, often amusing dodge.
  • ruse: Similar because it matches the cunning-plan sense; differs because ruse is formal and implies deception, wheeze is informal and often admiring.
  • gimmick: Similar because a publicity wheeze equals a gimmick; differs because gimmick implies cheap attention-seeking, wheeze can be genuinely clever.
