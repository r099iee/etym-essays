• doctrines: Similar because both denote authoritative taught beliefs; differs because doctrine stresses systematic teaching and orthodoxy more than the act of holding.
  • dogmas: Similar because both denote fixed authoritative principles; differs because dogma is stronger, more pejorative, implying unquestionable and rigid authority.
  • creeds: Similar because both denote confessed articles of faith; differs because creed is explicitly religious and formulaic, often a recited text.
  • principles: Similar because both denote foundational guides for action; differs because principle is broader and more moral-practical, while tenet is more propositional and school-defining.
  • beliefs: Similar because both denote held convictions; differs because belief is generic and individual, while tenet is collective and identity-defining.
  • convictions: Similar because both denote firmly held positions; differs because conviction stresses personal firmness and conscience rather than school membership.
  • precepts: Similar because both denote rules taken as guides; differs because precept is more prescriptive and rule-like, a maxim for conduct.
  • maxims: Similar because both denote pithy authoritative propositions; differs because maxim stresses brevity and practical wisdom.
  • articles of faith: Similar because both denote non-negotiable commitments; differs because the phrase is idiomatic and usually religious or ideological.
  • ideals: Similar because both denote guiding commitments; differs because ideals are aspirational perfections, while tenets are asserted truths.
  • values: Similar because both denote shared normative commitments; differs because values are broader evaluative preferences, less propositional.
  • orthodoxy: Similar because it denotes the body of received tenets; differs because orthodoxy is the collective system, not the individual propositions.
