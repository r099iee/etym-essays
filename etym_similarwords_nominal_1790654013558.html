• titular: Similar because it means holding a title without power; differs because it stresses the title itself, while nominal stresses the gap between name and reality.
  • token: Similar because it denotes minimal symbolic presence; differs because as an adjective it stresses smallness done for show rather than naming.
  • supposed: Similar because it marks a claimed but doubtful status; differs because it casts doubt from the speaker, while nominal can be neutrally technical.
  • ostensible: Similar because it means professed or apparent; differs because it implies deliberate pretence or cover.
  • nounal: Similar because it relates to nouns grammatically; differs because it is rarer and purely morphological, while nominal covers style, economics, and naming.
  • substantival: Similar because it means functioning as a substantive/noun; differs because it is highly technical and limited to syntax.
  • face-value: Similar because it captures the unadjusted economic sense; differs because it is colloquial and financial rather than general.
  • symbolic: Similar because nominal damages or fees are symbolic; differs because symbolic celebrates meaning, while nominal often minimises substance.
  • abstract (of style): Similar because nominal style is abstract and noun-packed; differs because abstract is broader, covering any non-concrete language.
  • bureaucratic: Similar because nominal prose feels bureaucratic; differs because bureaucratic names an institutional manner, while nominal names its noun-heaviness.
