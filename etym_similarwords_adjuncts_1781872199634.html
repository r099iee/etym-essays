• Accessory: Similar because both name something secondary attached to a main thing; differs because an accessory is often optional equipment chosen for use or style, while an adjunct is more structural or scholarly.
  • Appendage: Similar because both denote something attached; differs because appendage stresses physical attachment and can sound pejorative or grotesque, while adjunct is cooler and more Latinate.
  • Supplement: Similar because both are things added to something else; differs because a supplement completes a whole that was lacking, while an adjunct may never have been needed for completeness.
  • Attribute: Similar because both are qualities or things joined to a subject; differs because an attribute can be an essential property, whereas Pater's adjuncts are precisely not the essential virtue.
  • Circumstance: Similar because both name what surrounds a central object or event; differs because a circumstance is a surrounding condition, while an adjunct is any joined secondary quality, including but not limited to circumstances.
  • Accompaniment: Similar because both are things that go along with another; differs because accompaniment is neutral and often pleasant, while adjunct implies an attached-but-inessential status requiring separation.
  • Addendum: Similar because both are things added on; differs because an addendum is a textual or documentary addition to a finished work, while an adjunct is a general secondary attachment.
  • Accoutrement: Similar because both can name the trappings that accompany something; differs because accoutrement is restricted to equipment and dress, while adjunct spans grammar, philosophy, and aesthetics.
  • Byproduct / byproduct: Similar because both are secondary outcomes alongside a main result; differs because a byproduct is produced incidentally by the main process, while an adjunct is joined on externally rather than generated.
