• Here: Similar because both point to the speaker's location; differs because here states place (rest), while hither states motion toward that place.
  • Thither: Similar because both are archaic directional adverbs ending in -ther; differs because thither means "to that place" (away from the speaker), while hither means "to this place" (toward the speaker).
  • Whither: Similar because both are members of the same deictic direction system; differs because whither is interrogative or relative ("to what/which place"), while hither is demonstrative ("to this place").
  • Hence: Similar because both are archaic directional adverbs; differs because hence is ablative ("from here"), while hither is allative ("to here").
  • Thence: Similar because both are archaic deictic adverbs; differs because thence means "from there", while hither means "to here".
  • This way: Similar because both mean "in this direction"; differs because this way is the plain modern colloquial phrase, while hither is archaic, literary, and self-contained.
  • Over here: Similar because both point toward the speaker; differs because over here is casual, modern, and implies location as much as motion, while hither is formal, archaic, and purely directional.
  • Toward: Similar because both express direction; differs because toward is a preposition needing an object ("toward the house"), while hither is a complete adverb needing none.
  • Yon: Similar because both are archaic deictic words; differs because yon points to a distant place ("yonder"), while hither points to the speaker's own place.
  • Near: Similar because both imply closeness to a point; differs because near is an adjective or preposition of proximity without direction, while hither is an adverb of directed motion.
