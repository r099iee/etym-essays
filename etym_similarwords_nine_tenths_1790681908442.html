• the lion’s share: Similar because both name the biggest portion; differs because it is purely idiomatic and unmeasured, while nine-tenths pretends to exact decimal quantity.
  • the bulk: Similar because both mean the greater part; differs because bulk is vague and physical (mass, volume), lacking numerical dress.
  • the majority: Similar because both mean more than half, usually most; differs because majority is formal-political and threshold-based (50%+), not near-total.
  • most: Similar because both quantify the greater part; differs because most is the plain unmarked quantifier, while nine-tenths adds rhetorical precision.
  • nearly all: Similar because both mean almost everything; differs because nearly all is openly approximate, while nine-tenths performs exactness.
  • ninety percent: Similar because both denote 90/100; differs because percent belongs to statistics and reports, whereas nine-tenths belongs to prose idiom and proverb.
  • the greater part: Similar because both name the predominant share; differs because it is formal and literary, without fractional imagery.
  • the mass: Similar because both name the preponderant body; differs because mass stresses undifferentiated multitude (of people, data).
  • predominantly / preponderantly: Similar because both assert overwhelming proportion; differs because they are adverbs of dominance, not fractions of a whole.
  • almost entirely: Similar because both mean with little exception; differs because it modifies completeness of state, not a counted share.
  • well-nigh all: Similar because both mean practically everything; differs because it is archaic-literary, while nine-tenths sounds briskly modern and numerical.
