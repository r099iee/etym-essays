• chemin de fer: Similar because it is the classic French two-hand baccarat; differs because the bank rotates among players, while punto banco is house-banked.
  • punto banco: Similar because it is the modern American baccarat; differs because all draws are forced, while old chemin de fer allowed choice.
  • banque / baccarat banque: Similar because it is the original three-person baccarat; differs because it needs two punter tables, while modern forms need one.
  • blackjack / vingt-et-un: Similar because it is a comparing banking card game near a target number; differs because skill (hit/stand, counting) matters, while baccarat is near-automatic.
  • faro: Similar because it was the earlier aristocratic casino bank game; differs because you bet on card order, while baccarat bets on totals.
  • pontoon: Similar because it is a British comparing game; differs because it is domestic-low-stakes, while baccarat is high-limit glamour.
