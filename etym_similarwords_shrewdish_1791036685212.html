• Shrewd: Similar because it is the base meaning astute; differs because it is stronger and fully commendatory, while shrewdish hedges the degree.
  • Astute: Similar because it means keenly perceptive; differs because it is formal and implies sustained acumen, not mild occasional cleverness.
  • Canny: Similar because it means worldly-wise and careful; differs because it stresses cautious thrift, especially Scottish, rather than scheming.
  • Crafty: Similar because it means cunningly skilful; differs because it leans toward deceit and trickery.
  • Wily: Similar because it means full of cunning; differs because it implies sustained slyness, stronger than -ish.
  • Artful: Similar because it means cleverly contrived; differs because it can imply artistry or deceit.
  • Sly: Similar because it means furtively clever; differs because it is more secretive and morally dubious.
  • Sharp: Similar because a sharp person grasps quickly; differs because it is broader and more colloquial.
  • Clever: Similar because it means mentally quick; differs because clever can be academic or inventive, not necessarily worldly.
  • Discerning: Similar because it means showing good judgment; differs because it is formal and aesthetic-moral rather than strategic.
  • Sagacious: Similar because it means wise; differs because it is lofty and implies deep wisdom, not petty plotting.
  • Knavish (archaic overlap): Similar via historic shrew = villain; differs because knavish is now purely dishonest, while shrewdish is positive.
