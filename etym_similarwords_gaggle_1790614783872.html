• flock: Similar because it denotes a group of birds or people; differs because it is neutral and general, without noisy disorder implication.
  • herd: Similar because it denotes a crowded animal or human group; differs because it implies mindless movement, typically of mammals, not cackling noise.
  • pack: Similar because it denotes a tight group; differs because it suggests hunting cohesion or aggression, not chatter.
  • crowd: Similar because it denotes many people together; differs because it is neutral about sound and order.
  • horde: Similar because it denotes a large unruly group; differs because it implies invasion and menace, stronger than comic gaggle.
  • swarm: Similar because it denotes a buzzing multitude; differs because it suggests insects or rapid movement, not waddling gabble.
  • cluster: Similar because it denotes things grouped together; differs because it is neutral, static, and often small.
  • mob: Similar because it denotes a disorderly crowd; differs because it implies anger or violence, while gaggle is noisy but harmless.
  • skein: Similar because it also denotes geese; differs because it refers specifically to geese in flight in V-formation, not on ground.
  • bevy: Similar because it is a fanciful collective for birds or girls; differs because it is more admiring and less noisy.
