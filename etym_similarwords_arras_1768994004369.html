• Tapestry: Similar because both name a rich ornamental woven wall hanging; differs because tapestry emphasizes the woven pictorial narrative and is the general modern term, while arras is the specific, archaic product of the Arras workshops that carries full, wall-like concealment.
  • Hanging: Similar because both name a fabric panel suspended on a wall; differs because hanging is plain and colorless, a generic term with none of the heraldic wealth or hiding associations of arras.
  • Curtain: Similar because both are hangings that cover a space; differs because a curtain is a functional partition that can be drawn aside and implies windows or openings, while an arras is opaque and furniture-like, hiding an entire space completely.
  • Drapery: Similar because both are decorative fabric hung on walls; differs because drapery stresses loose ornamental folds rather than the woven fabric itself, while an arras is a specific woven textile patterned with scenes.
  • Veil: Similar because both are coverings that conceal; differs because a veil is thin, delicate, and usually partial, associated with modesty or mourning, while an arras is thick and opaque — where a veil is translucent, an arras is a wall.
  • Portière: Similar because both are heavy fabric hangings; differs because a portière is specifically a curtain over a doorway (from French porte, "door"), while an arras is a wall hanging proper, not a door-curtain.
  • Hanging-screen / screen: Similar because both hide what lies behind them; differs because a screen is usually free-standing, movable, and architectural, while an arras is woven textile fixed to the wall.
  • Arrascal / arras-work: Similar because the same root; differs because these are the archaic adjectival and material forms naming the fabric itself, now almost wholly obsolete, whereas arras names the hung object or its metaphorical covering.
