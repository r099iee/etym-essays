• straining: Similar because intense exertion beyond comfort; differs because neutral effort, lacking torture-frame violence.
  • tormenting: Similar because inflicting anguish; differs because often deliberate cruelty by another, while racking can be self-exertion.
  • agonizing: Similar because extreme suffering; differs because emphasizes pain felt, not effort to extract something.
  • excruciating: Similar because piercing pain; differs because scalar intensity of sensation, not stretching image.
  • wracking (variant): Similar because same idiom for brains and nerves; differs because spelling tied to ruin rather than frame.
  • wrenching: Similar because violent twisting strain; differs because sudden twist, while racking is prolonged stretch.
  • torturing: Similar because literal judicial torment; differs because historical-literal versus modern figurative.
  • taxing: Similar because using faculties hard; differs because neutral or positive, without pain.
  • harassing: Similar because persistent torment; differs because usually external annoyance, not inner stretch.
  • afflicting: Similar because causing suffering; differs because formal, often circumstantial, less graphic.
  • convulsing: Similar because shaking the frame in coughs and sobs; differs because spasmodic motion, not deliberate effort.
  • extorting: Similar because squeezing to maximum as in rack-rent; differs because economic extraction, not intellectual effort.
