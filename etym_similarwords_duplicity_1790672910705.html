• deceit: Similar because it names misleading; differs because deceit is general, duplicity specifies doubling or two-facedness.
  • deception: Similar because it names causing false belief; differs because deception can be single act, duplicity implies sustained double dealing.
  • hypocrisy: Similar because it names professing virtue while acting otherwise; differs because hypocrisy is moral pretence, duplicity is any strategic doubling.
  • two-facedness: Similar because it names showing different faces; differs because it is colloquial and personal, duplicity is formal and institutional.
  • double-dealing: Similar because it names dealing differently with different parties; differs because it stresses transactions, duplicity stresses character.
  • double-talk: Similar because it names ambiguous misleading speech; differs because double-talk stresses verbiage, duplicity stresses intent.
  • dissembling: Similar because it names concealing true motives; differs because dissembling stresses hiding, duplicity stresses doubling.
  • dissimulation: Similar because it names feigning; differs because it is more literary and philosophical, duplicity more political.
  • guile: Similar because it names crafty deceit; differs because guile can be admired as cleverness, duplicity never is.
  • chicanery: Similar because it names trickery in argument; differs because chicanery stresses legalistic quibbling, duplicity stresses moral folding.
  • perfidy: Similar because it names betrayal of trust; differs because perfidy stresses broken faith, duplicity stresses maintained pretence.
  • treachery: Similar because it names betrayal; differs because treachery acts against allegiance, duplicity manipulates appearances.
  • fraudulence: Similar because it names dishonest dealing; differs because fraud is often criminal and financial, duplicity is moral and verbal.
  • insincerity: Similar because it names lack of sincerity; differs because insincerity can be mild social flattery, duplicity is calculated.
