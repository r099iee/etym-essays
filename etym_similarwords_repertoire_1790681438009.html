• repertory: Similar because it is the anglicized doublet for theatrical stock; differs because repertory often denotes the system or company, repertoire the list.
  • stock: Similar because it is stored supply ready for use; differs because stock is commercial while repertoire is artistic.
  • store: Similar because it is accumulated reserve; differs because store is generic, repertoire implies performance.
  • arsenal: Similar because it is weapons ready to deploy; differs because arsenal is combative metaphor.
  • portfolio: Similar because it is collection of works; differs because portfolio is visual or financial showcase.
  • collection: Similar because it gathers pieces; differs because collection can be passive, repertoire must be performable.
  • canon: Similar because it lists authoritative works; differs because canon is sanctioned classics, repertoire is practical.
  • range: Similar because it spans abilities; differs because range is breadth, repertoire is itemized stock.
  • range of roles: Similar because sociologists mean role set; differs because phrase is analytic while repertoire is dramaturgic.
  • toolkit: Similar because it is set of techniques; differs because toolkit is manual and practical.
  • grab-bag: Similar because it is miscellaneous stock; differs because grab-bag is informal and random.
  • vocabulary: Similar because verbal repertoire is word stock; differs because vocabulary is lexical only.
  • roster: Similar because it lists members or pieces; differs because roster is schedule of persons.
  • programme: Similar because it is planned performance list; differs because programme is one evening, repertoire is season.
