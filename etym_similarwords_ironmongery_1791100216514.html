• hardware: Similar because it denotes metal fittings and tools; differs because hardware is the modern general term while ironmongery is older and chiefly British.
  • ironware: Similar because it means goods made of iron; differs because ironware stresses material, while ironmongery stresses the trade and shop.
  • metalware: Similar because it covers metal goods; differs because it is broader and includes non-iron metals without the shop sense.
  • cutlery: Similar because it is metal goods sold by ironmongers; differs because cutlery is specifically knives, forks, and spoons.
  • tools: Similar because ironmongers sell them; differs because tools is far broader and includes non-metal implements.
  • implements: Similar because it means utensils for work; differs because it is formal and generic, lacking the iron-trade flavour.
  • fixtures: Similar because it means fixed hardware like hinges; differs because fixtures stresses attachment to buildings.
  • fittings: Similar because it means small hardware parts; differs because fittings is narrower and technical.
  • housewares: Similar because it covers domestic goods; differs because housewares includes plastic and crockery, not just metal.
  • haberdashery (false friend contrast): Similar because it names a small-goods shop trade; differs because haberdashery sells sewing notions, not metal.
  • chandlery: Similar because it is an old trade-shop word; differs because a chandlery sells candles, rope, and ship supplies.
  • smithy: Similar because it works iron; differs because a smithy forges metal rather than retailing finished goods.
