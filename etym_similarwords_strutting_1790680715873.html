• swaggering: Similar because it denotes confident, showy walking; differs because it stresses insolent self-assurance and rhythm rather than stiff erectness.
  • parading: Similar because it denotes displaying oneself while moving; differs because it stresses the exhibition itself, often in formation, rather than the gait.
  • swanking: Similar because it denotes showing off impressively; differs because it is slangier and covers dress and behaviour, not just walking.
  • prancing: Similar because it denotes springy, showy movement; differs because it suggests liveliness and high steps rather than stiff dignity.
  • striding: Similar because it denotes walking with long, decisive steps; differs because it is neutral or admiring, lacking strut’s vanity.
  • sashaying: Similar because it denotes moving ostentatiously to attract notice; differs because it suggests gliding, often flirtatious motion rather than rigidity.
  • glorying: Similar because it denotes exulting in display; differs because it names the feeling of triumph, not the walk.
  • posturing: Similar because it denotes adopting attitudes for effect; differs because it stresses artificial poses and opinions rather than locomotion.
  • showing off: Similar because it denotes performing for admiration; differs because it is the general colloquial cover-term, broader than gait.
  • peacocking: Similar because it denotes male display like the bird; differs because it is modern slang centred on dress and attention-seeking, while strutting centres on the walk.
