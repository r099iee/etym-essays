• hutu: Similar because it is the standard Tahitian name for the same Barringtonia fish-poison tree complex; differs because hutu is the widely attested modern vernacular while hora is a rare historical variant.
  • huteo: Similar because it is the companion fish-poison nut pounded with hora in this passage; differs because huteo denotes the nut source while hora denotes the plant admixture.
  • Barringtonia: Similar because it is the scientific genus covering the fish-poison tree behind these vernaculars; differs because it is formal Latin taxonomy, not a Tahitian folk name.
  • fish-poison tree: Similar because it is the English gloss for the same ichthyotoxic use; differs because it is a descriptive common name, not the borrowed Tahitian form.
  • putat: Similar because it is a Malay-Indonesian vernacular for Barringtonia asiatica with identical fishing use; differs because it belongs to western Austronesian, not Tahitian.
  • futu: Similar because it is the Samoan and Tongan cognate of Tahitian hutu for the same tree; differs because it reflects Proto-Polynesian *f preserved as f, not shifted to Tahitian h.
  • derris: Similar because it is another Pacific fish-poison plant genus used to stun fish; differs because derris acts via rotenone, not Barringtonia saponins, and belongs to legumes.
  • tephrosia: Similar because it is another ichthyotoxic plant used in the same narcotic-fishing method; differs because it is a distinct genus with different chemistry and distribution.
  • intoxicant: Similar becausehora material functions as a water-borne fish intoxicant; differs because intoxicant is a generic chemical role, not a plant name.
  • narcotic (fishing narcotic): Similar because the passage calls these materials narcotics thrown into streams; differs because narcotic describes pharmacological effect, not botanical identity.
