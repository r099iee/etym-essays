• middle class: Similar because direct English equivalent — intermediate social stratum; differs because neutral-descriptive, lacking French pejorative-cultural charge.
  • bourgeois (as noun/adjective): Similar because member of or pertaining to bourgeoisie; differs because singular person or attitude, not collective class.
  • petite bourgeoisie: Similar because lower-middle stratum of shopkeepers and clerks; differs because specifically modest, anxious respectability.
  • haute bourgeoisie / grande bourgeoisie: Similar because wealthy upper-middle owners and professionals; differs because elite, often culturally powerful, close to aristocracy.
  • capitalist class: Similar because Marxist owners of capital; differs because strictly economic, without cultural-philistine overtone.
  • establishment: Similar because entrenched respectable powers; differs because broader — political, military, cultural — not specifically middle-class.
  • philistines: Similar because Arnoldian term for culturally dull respectable; differs because purely cultural-moral, no economic definition.
  • suburbanites: Similar because stereotype of comfortable conformity; differs because geographic-residential, modern and Anglo-American.
  • burgesses / townsfolk: Similar because historical townspeople root sense; differs because archaic-medieval, neutral-legal, no capitalist sense.
  • proletariat (antonym-reference): Similar because paired Marxist class term; differs because opposite — wage-workers — included to clarify boundary.
  • aristocracy (contrast): Similar because fellow privileged class term; differs because birth-rank versus town-wealth, old versus new power.
