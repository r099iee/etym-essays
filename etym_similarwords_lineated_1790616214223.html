• lined: Similar because it denotes marked with or arranged in lines; differs because it is plain and everyday, while lineated is formal, technical, and often biological or prosodic.
  • striped: Similar because it denotes banded with lines of colour; differs because it implies bold contrasting colour bands, while lineated can be faint grooves or text rows.
  • striated: Similar because it denotes grooved or ridged in parallel lines; differs because it is more geological and anatomical, implying fine parallel furrows.
  • streaked: Similar because it denotes marked with irregular lines; differs because it suggests messier, less uniform smears rather than even ruling.
  • ruled: Similar because it denotes provided with straight lines for writing; differs because it refers specifically to paper prepared with guidelines.
  • hatched: Similar because it denotes shaded with close parallel lines in drawing; differs because it is an engraving technique, not general arrangement.
  • veined: Similar because it denotes patterned with thread-like lines; differs because it implies branching organic vessels like in leaves or marble.
  • wrinkled: Similar because it denotes furrowed with lines by age; differs because it implies skin folds, not deliberate layout.
  • versified: Similar because in prosody it denotes cast into verse lines; differs because it implies metrical poetry, while lineated can be prose broken for voice.
  • inscribed: Similar because it denotes written in lines on a surface; differs because it stresses carving or writing act, not line arrangement.
