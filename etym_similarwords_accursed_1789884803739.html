• Cursed: Similar because both mean under a curse; differs because cursed is plainer and broader, while accursed is more literary and venomous.
  • Accurst: Similar because identical in meaning; differs because accurst is the clipped poetic variant, while accursed is the full modern spelling.
  • Damned: Similar because both consign to evil fate; differs because damned is theological and also a swear-word, while accursed stresses spell-like blight.
  • Doomed: Similar because both face dreadful fate; differs because doomed stresses inevitable ruin, while accursed stresses malign imprecation.
  • Bewitched: Similar because both imply spell-work; differs because bewitched diagnoses enchantment, while accursed condemns and hates.
  • Execrable: Similar because both mean detestable; differs because execrable is formal Latinate disgust, while accursed is tale-like fury.
  • Abominable: Similar because both express hatred; differs because abominable stresses moral loathing, while accursed stresses curse-struck obstruction.
  • Wretched: Similar because both brand misery; differs because wretched pities or despises pitiably, while accursed damns actively.
  • Ill-fated: Similar because both suffer bad fortune; differs because ill-fated is neutral about cause, while accursed blames a curse.
