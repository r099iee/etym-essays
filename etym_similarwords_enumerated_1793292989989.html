• Listed: Similar because both name items one after another in order; differs because listed is the plain everyday word for any written series, while enumerated stresses numbering and completeness.
  • Counted: Similar because enumeration tallies units to a total; differs because counted emphasises the arithmetic total, while enumerated emphasises naming each member distinctly.
  • Catalogued: Similar because both produce systematic ordered inventories; differs because catalogued suggests a permanent descriptive record, while enumerated suggests a spoken or written run-through in sequence.
  • Itemised: Similar because both break a whole into billed or stated particulars; differs because itemised belongs to accounts and invoices, while enumerated belongs to rhetoric, law, and logic.
  • Specified: Similar because both pin things down explicitly; differs because specified stresses exact description of qualities, while enumerated stresses covering every member of a set.
  • Tallied: Similar because both reckon quantities mark by mark; differs because tallied evokes strokes on a slate and running scores, while enumerated evokes numbered heads in a formal list.
  • Recited: Similar because both run through a series aloud in order; differs because recited stresses vocal performance from memory, while enumerated stresses the logical completeness of the series.
  • Indexed: Similar because both assign numbers or keys for retrieval; differs because indexed builds a finding aid pointing elsewhere, while enumerated presents the members themselves in place.
