• vibrato: Similar because it is also a rapid wavering of tone; differs because vibrato is pitch wobble, tremolo is volume or reiteration.
  • trill: Similar because it is rapid alternation producing shimmer; differs because trill alternates two adjacent pitches, tremolo repeats one.
  • tremor: Similar because it means trembling; differs because tremor is bodily or seismic shaking, tremolo is musical.
  • quaver: Similar because it means to waver in voice; differs because quaver is generic verb, tremolo is notated musical device.
  • warble: Similar because it means to sing with wavering; differs because warble suggests bird-like ornament, tremolo is even pulsation.
  • waver: Similar because it means to become unsteady in sound; differs because waver is general, tremolo is technical and rapid.
  • flutter: Similar because it is rapid wavering; differs because flutter is light and irregular, tremolo is measured.
  • shake: Similar because in Baroque it meant trill/tremolo ornament; differs because modern shake is archaic term, tremolo is current.
  • wobble: Similar because it describes unsteady tone; differs because wobble is pejorative for faulty vibrato, tremolo can be intentional.
  • shudder: Similar because it is trembling from emotion; differs because shudder is single convulsive shiver, tremolo is sustained pulsation.
  • oscillation: Similar because it means regular variation; differs because oscillation is physics term, tremolo is musical instance.
  • pulsation: Similar because tremolo pulses loudness; differs because pulsation is general, tremolo is musical effect.
