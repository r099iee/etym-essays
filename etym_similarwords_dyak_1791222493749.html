• Dayak: Similar because standard modern spelling of same people; differs only in orthography (Dayak preferred).
  • Dajak: Similar because Dutch colonial spelling; differs because archaic, used in Dutch sources.
  • Iban (Sea Dayak): Similar because largest Dayak group; differs because specific Sarawak people, not umbrella.
  • Bidayuh (Land Dayak): Similar because Dayak subgroup; differs because western Sarawak highlanders specifically.
  • Kayan: Similar because major Dayak river people; differs because stratified chiefly society on Baram and Kayan rivers.
  • Kenyah: Similar because related Apo Kayan group; differs because distinct language and carving tradition.
  • Ngaju: Similar because southern Kalimantan Dayak; differs because Kahayan river, Protestant mission heartland.
  • Murut / Lun Dayeh: Similar because northern interior Dayak; differs because Sabah highlands, upstream etymology preserved.
  • Kadazan-Dusun: Similar because Bornean Indigenous neighbours; differs because Sabah groups not always classed as Dayak.
  • Malay: Similar because fellow Borneans and source of the exonym; differs because coastal Muslim traders, contrast group.
  • Aborigine / native: Similar because generic Indigenous person; differs because worldwide, not Borneo-specific.
  • headhunters (historic): Similar because colonial stereotype of Dyaks; differs because practice, not people; now obsolete and offensive if generalized.
