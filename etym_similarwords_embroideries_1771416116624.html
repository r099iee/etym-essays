• Needlework: Similar because it denotes hand-stitching applied to cloth; differs because it is the broad, neutral umbrella term for all sewing done by needle, whereas embroideries are specifically ornamental stitched designs.
  • Brocade: Similar because it is a richly patterned textile used in luxury dress; differs because the pattern is woven into the cloth on the loom, not stitched onto a finished ground as embroidery is.
  • Tapestry: Similar because it is a pictorial textile used for decoration; differs because a tapestry is a large wall-hanging whose image fills the whole field, while embroideries are decorative additions to garments or smaller cloths.
  • Appliqué: Similar because it decorates a fabric surface with applied ornament; differs because it attaches cut-out fabric shapes rather than working thread directly through the ground.
  • Ornamentation: Similar because both mean decorative embellishment; differs because ornamentation is a general term for any decoration (carving, gilding, print), whereas embroideries are specifically needlework on cloth.
  • Fringe: Similar because it is a stitched, decorative edging on fabric; differs because fringe is an open thread edging rather than a closed pictorial or patterned stitching.
  • Lace: Similar because both are ornamental textiles used in dress; differs because lace is an openwork fabric with an independent structure, while embroideries are stitched onto a pre-existing cloth ground.
