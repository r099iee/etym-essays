• Scaffolding: similar because it denotes the same temporary support system; differs because it is a mass or collective noun and usually refers to the whole assembly or material rather than one platform.
  • Framework: similar because it is a supporting structure; differs because a framework is often permanent and internal, while a scaffold is temporary and external.
  • Platform: similar because both are raised surfaces; differs because a platform need not have an exposed supporting frame, and the word lacks the execution and construction associations.
  • Staging: similar because it means temporary working platforms; differs because staging is more often theatrical or plural and less likely to mean a single tall building structure.
  • Gantry: similar because it is a raised frame for workers or equipment; differs because a gantry is usually a permanent bridge-like structure over a road or railway.
  • Gallows: similar because both can name an execution structure; differs because gallows specifically means the apparatus for hanging and never means a builder's platform.
  • Catafalque: similar because it is a raised ceremonial platform and shares the same Latin ancestor; differs because it is specifically a bier for a coffin and has no construction sense.
  • Trestle: similar because it is a temporary supporting frame; differs because a trestle is a small folding support, not a full working platform.
  • Armature: similar because it supports a structure; differs because an armature is an internal skeleton, often in sculpture, and is not designed for people to stand on.
  • Support: similar because a scaffold supports something; differs because support is abstract and general, while scaffold names a specific physical construction.
  • Stage: similar because a scaffold can be a raised stage; differs because stage is primarily theatrical and does not imply a temporary builder's frame.
  • Falsework: similar because it is temporary construction used to support a permanent structure; differs because falsework is an engineering term for formwork and centring, not for a platform for workers.
