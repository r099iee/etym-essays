• Debossing: Similar because it is the same press-and-die relief process on paper/leather; differs because the image is pressed inward (intaglio) rather than raised outward.
  • Engraving: Similar because it incises a design into metal/plate for reproduction; differs because the image is cut in, not raised up, and usually inked for intaglio printing.
  • Stamping: Similar because it impresses a die into material with pressure; differs because stamping is broader and often flat/inked, while embossing specifically creates three-dimensional relief.
  • Repoussé: Similar because it hammers metal from the reverse to create relief; differs because it is hand-wrought sculptural metalwork, not a generic press process, and carries high-art connotations.
  • Chasing: Similar because it ornaments metal in relief from the front; differs because chasing refines from the face with punches, while embossing pushes from behind/between dies.
  • Foil blocking: Similar because it uses heat, die and pressure on covers/cards; differs because the salient feature is metallic foil transfer, which may but need not be embossed.
  • Letterpress: Similar because it presses type into paper leaving an impression; differs because classic letterpress is kiss or debossed, whereas embossing is raised and usually without ink.
  • Imprinting: Similar because it marks a surface with a design; differs because imprinting is generic and flat, lacking the raised-relief requirement.
  • Etching: Similar because it produces a design in/on a substrate via removal; differs because etched lines are recessed and the chemistry/register is entirely different.
  • Moulding: Similar because it shapes material into raised patterns; differs because moulding casts liquid into a mould, while embossing deforms an existing sheet.
  • Quilting: Similar because padded stitching creates raised puffy patterns on textile; differs because the relief comes from stitch + wadding, not die pressure.
  • Bas-relief: Similar because both describe sculptural raising from a ground; differs because relief is the art-historical product category, embossing is one mechanical method to achieve it.
