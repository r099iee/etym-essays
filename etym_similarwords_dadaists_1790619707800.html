• Dada practitioners / Cabaret Voltaire circle: Similar because core Zurich group; differs because descriptive phrase, not movement label.
  • Futurists: Similar because fellow typographic revolutionaries named alongside; differs because pro-machine, pro-war versus Dada anti-war nonsense.
  • Surrealists: Similar because direct heirs via Breton, sharing collage and chance; differs because dream-logic and psychoanalysis versus pure negation.
  • Vorticists: Similar because pre-war avant-garde of blast and abstraction; differs because English, geometric, still believed in art.
  • Constructivists: Similar because montage and typographic experiment; differs because constructive-utilitarian and pro-revolution versus Dada negation.
  • Situationists: Similar because later prankster-provocateurs of détournement; differs because 1950s-60s Marxist theory, not WWI cabaret.
  • absurdists: Similar because embrace of nonsense and illogic; differs because broader philosophical-literary, not historical membership.
  • nihilists (artistic): Similar because rejection of values and meaning; differs because philosophical doctrine, lacking Dada play and humour.
  • iconoclasts: Similar because breakers of art conventions; differs because generic, no nonsense-chance program.
  • provocateurs: Similar because deliberate shock of bourgeois audience; differs because general behaviour, not specific Zurich lineage.
  • performance artists: Similar because live cabaret actions; differs because contemporary medium, descendant not synonym.
