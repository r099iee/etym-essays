• That: Similar because both are distal demonstratives pointing away from the speaker; differs because that can point to the abstract, the remembered, or the just-mentioned, while yon always gestures at something actually visible out in the world.
  • Yonder: Similar because it means the same "over there" and shares the same root; differs because yonder is the fuller adverb/adjective form, more consciously archaic and dialectal, while yon is the compressed poetic determiner.
  • Yond: Similar because it is the apocopated Elizabethan form of the same word; differs because it survives only as an archaism in fixed literary quotations, whereas yon still has a living (if narrow) use.
  • Thither: Similar because it belongs to the same archaic system of distance words; differs because thither denotes direction of motion ("to there"), while yon fixes a specific, visible place.
  • Thence: Similar because it is the archaic spatial sibling; differs because it means "from there," a source or origin, not a located object of pointing.
  • Beyond: Similar because it descends from the same root (be-ġeondan) and means "on the other side"; differs because it is a living preposition of extension, not a demonstrative that points at a visible referent.
  • Hither: Similar because it is yon's partner in the fixed pair "hither and yon"; differs because it means "to this place," the near counterpart, opposite in direction and now equally archaic.
  • That there: Similar because it is the colloquial periphrasis for a visible distant object; differs because it is emphatic folk speech with no poetic register, while yon is literary and compressed.
