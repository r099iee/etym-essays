• Devastation: Similar because both denote widespread destruction; differs because devastation emphasises the destructive act and its material ruin, while desolation stresses the emptiness and abandonment that follow.
  • Destruction: Similar because both describe ruin; differs because destruction is the act or result of destroying, without the emotional overtone of loneliness that desolation carries.
  • Desert: Similar because both denote empty, barren places; differs because a desert is a geographic region, while desolation is the quality or condition of emptiness.
  • Wasteland: Similar because both name barren, unusable land; differs because wasteland is concrete and often neutral (the Wasteland of Eliot), while desolation carries grief.
  • Solitude: Similar because both involve being alone; differs because solitude can be pleasant and chosen, while desolation is painful abandonment.
  • Isolation: Similar because both imply separation; differs because isolation is a neutral state of being cut off, while desolation is emotionally ruinous emptiness.
  • Ruins: Similar because both are results of destruction; differs because ruins are the visible remains, while desolation is the felt condition of emptiness over the scene.
  • Loneliness: Similar because both involve aloneness and grief; differs because loneliness is a personal feeling, while desolation is both a feeling and a description of place.
  • Barrenness: Similar because both describe unproductive emptiness; differs because barrenness emphasises infertility, desolation emphasises abandonment and ruin.
  • Wilderness: Similar because both describe uncultivated empty land; differs because wilderness is neutral or positive (natural, wild), while desolation is negative (ravaged).
