• armful: Similar because it denotes as much as the arms can hold; differs because it stresses fullness to capacity rather than weight of load.
  • load: Similar because it denotes something carried; differs because it is generic and often implies vehicle or heavy burden, not specifically arms.
  • bundle: Similar because it denotes a gathered mass carried together; differs because it implies tying or wrapping, while armload is loose.
  • bunch: Similar because it denotes a collected group; differs because it is smaller and often tied at one point.
  • heap: Similar because it denotes a piled quantity; differs because it emphasizes pile shape, not carrying.
  • stack: Similar because it denotes piled items; differs because it implies orderly arrangement, not bodily carrying.
  • handful: Similar because it is a body-based measure; differs because it is much smaller, limited to one hand.
  • lapful: Similar because it is a body-based informal measure; differs because it refers to what sits on seated lap, not carried.
