• Sullenly: Similar because both describe silent, gloomy ill-humour in behaviour; differs because sullenly stresses a resentful refusal to speak out of anger, while morosely emphasises the heavy, brooding, melancholy tone as much as the bad temper.
  • Glumly: Similar because both describe a downcast, dejected manner; differs because glumly is milder — quiet disappointment or low spirits — while morosely is darker, sourer, and more irritable.
  • Gloomily: Similar because both convey darkness and low spirits; differs because gloomily describes mere dark pessimism or sadness, without the peevish, ill-tempered edge that morosely retains.
  • Sulkily: Similar because both name a withdrawn, resentful mood; differs because sulkily is the childish, pouting refusal to be pleased, while morosely is adult, heavy, and more melancholy than petulant.
  • Moodily: Similar because both describe a temperamental, changeable gloom; differs because moodily implies variation — fits of dark feeling — whereas morosely describes a settled, persistent sourness.
  • Dejectedly: Similar because both describe a downcast, spiritless manner; differs because dejectedly is pure sadness and discouragement with no ill-temper, while morosely keeps the peevish, disagreeable element.
  • Despondently: Similar because both describe a loss of hope; differs because despondently is heartbroken resignation, while morosely is more a sour and irritable gloom than an actual despair.
  • Somberly / Sombrely: Similar because both suggest gravity, darkness, and seriousness; differs because somberly is dignified and grave — even noble — while morosely is crabby, unsociable, and ill-humoured.
  • Lugubriously: Similar because both describe an exaggerated, theatrical gloom; differs because lugubriously suggests mournful, doleful wailing or self-pity, whereas morosely is a quieter, bitterer sullenness.
  • Mournfully: Similar because both convey sadness in manner; differs because mournfully expresses grief over a specific loss, while morosely is a general sour disposition without a named object.
  • Dourly: Similar because both describe a stern, grim, unyielding manner; differs because dourly emphasises strictness and severity (Scottish register), while morosely stresses the gloom and bad humour.
  • Sourly: Similar because both describe a bitter, acidic manner; differs because sourly applies to a resentful, sarcastic tone of speech, while morosely is more about silent, brooding gloom.
  • Grumpily: Similar because both describe irritable bad humour; differs because grumpily is a casual, mildly comic grumbling, while morosely is literary, heavy, and melancholy.
  • Churlishly: Similar because both describe an ill-natured, rude manner; differs because churlishly stresses boorish surliness and meanness to others, while morosely can be a purely inward gloom.
  • Peevishly: Similar because both describe irritability; differs because peevishly is fretful, querulous annoyance over trifles, while morosely is a deeper, darker, more silent despondency.
  • Petulantly: Similar because both describe bad-tempered behaviour; differs because petulantly is impatient, childishly sulky complaint, while morosely is grown-up, heavy gloom.
