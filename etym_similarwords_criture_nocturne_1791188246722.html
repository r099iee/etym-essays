• Night writing: Similar because it is the literal English translation of the same Barbier system; differs because it loses the French historical specificity and scholarly register.
  • Sonography (Barbier's term): Similar because Barbier himself called his code sonographie, sound-writing; differs because sonography now also means ultrasound imaging, causing ambiguity.
  • Braille: Similar because it is the direct descendant tactile dot script read by touch; differs because Braille uses six dots encoding letters, is far more compact, and is a living global standard while écriture nocturne is obsolete.
  • Moon type: Similar because it is another 19th-century embossed tactile script for blind readers; differs because Moon uses raised curves mimicking print capitals, not dots.
  • Embossed roman letters (Haüy type): Similar because it is the rival raised-letter tactile system of the same era; differs because it embosses ordinary alphabet shapes rather than dot codes.
  • Tactile writing: Similar because it is the generic category including all touch-read scripts; differs because it is broader and includes Braille, Moon, and modern haptics.
  • Cipher / code: Similar because night writing functioned as an encoded military communication; differs because ciphers prioritise secrecy, while night writing prioritised legibility without light.
  • Semaphore / signal code: Similar because Napoleonic armies used multiple silent night-signalling methods; differs because semaphore is visual-manual, not tactile-dot.
  • Automatic writing (écriture automatique): Similar because the French head noun overlaps and both belong to French cultural history; differs because automatic writing is surrealist unconscious composition, unrelated to touch or night tactics.
  • Nocturne (musical): Similar because it shares the adjective and nocturnal aesthetic; differs because it denotes a dreamy piano piece, not a writing system.
