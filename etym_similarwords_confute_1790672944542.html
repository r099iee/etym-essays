• refute: Similar because it means to prove false; differs because refute is the everyday equivalent, confute more formal and archaic.
  • rebut: Similar because it means to answer opposing argument; differs because rebuttal counters without necessarily disproving, confutation claims success.
  • disprove: Similar because it means to show to be false; differs because disprove stresses evidence, confute stresses argumentative victory.
  • debunk: Similar because it means to expose falsity; differs because debunking is public and demystifying, confuting is logical and formal.
  • demolish (an argument): Similar because it means to destroy a case; differs because it is metaphorical and colloquial, confute is literal and learned.
  • overturn: Similar because it means to reverse a holding or thesis; differs because overturning is institutional, confuting is intellectual.
  • negate: Similar because it means to deny the truth of; differs because negation is logical operation, confutation is extended proof.
  • contradict: Similar because it means to oppose in statement; differs because contradiction merely asserts the opposite, confutation proves it.
  • counter: Similar because it means to oppose with contrary argument; differs because countering meets force with force, confuting ends the contest.
  • explode (a myth): Similar because it means to destroy belief; differs because exploding is journalistic and sudden, confuting is scholarly and step-by-step.
  • invalidate: Similar because it means to show to be without force; differs because invalidation is procedural, confutation is substantive.
  • controvert: Similar because it means to dispute formally; differs because controverting sustains debate, confuting claims to close it.
  • confound (archaic sense): Similar because older writers used both for overthrow; differs because confound now means to confuse or amaze, confute retains refutation.
