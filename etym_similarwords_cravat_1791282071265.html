• necktie: Similar because it is a neck band worn with a shirt for smart dress; differs because it denotes the modern long tie, while cravat is its wider historical ancestor or soft formal variant.
  • ascot: Similar because it is a soft gathered neck scarf for formal wear; differs because ascot is the specific modern descendant worn with morning dress, while cravat can mean the historical original.
  • bow tie: Similar because it is a knotted neck adornment descended from the cravat; differs because it is small, winged and tied in a bow, not a draped cloth.
  • neckerchief: Similar because it is a cloth worn around the neck; differs because it is generally casual, square and rustic, while cravat is tailored and fashionable.
  • scarf: Similar because it wraps the neck for warmth or style; differs because it is longer, outerwear and functional against cold, while cravat is indoor formal dress.
  • stock: Similar because it was a stiff band worn around the neck in military and riding dress; differs because it was rigid and functional-uniform, while cravat is soft and knotted fashionably.
  • bandana: Similar because it is a folded cloth that can be worn at the neck; differs because it is casual, patterned cotton with workwear connotations, opposite in register.
  • kerchief: Similar because it is a cloth for the head or neck; differs because it is older, plainer and often utilitarian, lacking the elite fashion history of cravat.
  • jabot: Similar because it is a lace or ruffled neck adornment of the same era; differs because it hangs down the chest from the throat rather than wrapping the neck.
  • tie: Similar because it is the generic modern term for neckwear; differs because it is everyday and broad, while cravat is specific, historical or wedding-formal.
