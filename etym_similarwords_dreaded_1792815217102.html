• Feared: Similar because both describe something regarded with fear; differs because feared is the plain general term while dreaded stresses anxious anticipation beforehand.
  • Dreadful: Similar because both spring from dread and describe horrors; differs because dreadful means causing dread or simply very bad, while dreaded means being dreaded in advance.
  • Fearsome: Similar because both mark something frightening in aspect; differs because fearsome describes a terrifying appearance, while dreaded describes the anticipation of sufferers.
  • Frightening: Similar because both involve fear as the core emotion; differs because frightening causes sudden alarm, while dreaded involves prolonged looking-forward unease.
  • Terrifying: Similar because both name intense fear; differs because terrifying is stronger and immediate, while dreaded can be mild and is always anticipatory.
  • Daunting: Similar because both describe prospects faced with reluctance; differs because daunting intimidates through difficulty or scale, while dreaded repels through expected unpleasantness.
  • Formidable: Similar because both command awe and apprehension; differs because formidable respects power or difficulty neutrally, while dreaded always carries dislike or fear.
  • Loathed: Similar because the dreaded meeting is usually also hated; differs because loathed names hatred already felt, while dreaded names fear of what is still to come.
