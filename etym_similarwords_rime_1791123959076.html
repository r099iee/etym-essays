• Frost: Similar because it means frozen coating; differs because frost is the everyday general term, while rime is literary or technical for feathery fog-freeze.
  • Hoarfrost: Similar because it means white crystalline frost; differs because hoarfrost strictly forms by direct deposition on still nights, while rime forms from freezing fog with wind.
  • Rime ice: Similar because it is the technical synonym; differs because rime ice specifies aviation/meteorological accretion, while rime alone can be poetic.
  • Freeze: Similar because it means ice formation; differs because freeze is the process verb, while rime is the product noun.
  • Glaze (ice): Similar because it means ice coating; differs because glaze is clear smooth ice from freezing rain, while rime is white granular.
  • Sleet: Similar because it is wintry precipitation; differs because sleet falls as pellets, while rime accretes on surfaces.
  • Icicle: Similar because it is hanging ice; differs because icicle is a pendant of frozen drip, while rime is a surface frosting.
  • Hoar: Similar because hoar means grey-white with age/frost; differs because hoar is archaic poetic adjective, while rime is the noun for the coating itself.
  • Frostwork: Similar because it means decorative frost patterns; differs because frostwork stresses lacy beauty on windows, while rime stresses granular accretion.
  • White frost: Similar because it describes same appearance; differs because white frost is descriptive phrase, while rime is the single precise term.
  • Jack Frost (coating): Similar because it personifies frost patterns; differs because Jack Frost is folkloric personification, while rime is physical deposit.
  • Hard rime: Similar because it is a subtype; differs because hard rime is dense wind-driven ice, while generic rime includes soft feathery forms.
