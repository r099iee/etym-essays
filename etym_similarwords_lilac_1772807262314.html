• Lavender: Similar because both are pale-purple flower-and-colour terms; differs because lavender is softer, greyer and more powdery, and strongly scented in association, while lilac leans bluish and brighter.
  • Violet: Similar because both name the blue-purple family; differs because violet is the broader spectral name and can be deeper and more jewel-like than pale lilac.
  • Mauve: Similar because both denote a light purple; differs because mauve is a nineteenth-century aniline fashion colour, often pinker or duskier, while lilac is the natural blossom hue.
  • Purple: Similar because both cover the same hue family; differs because purple is heavier and ranges from imperial Tyrian dye to ecclesiastical solemnity, lacking lilac's gentle delicacy.
  • Amethyst: Similar because both are purple-adjacent colour terms; differs because amethyst suggests the deep violet of the gemstone, more saturated and precious than pale lilac.
  • Orchid: Similar because both name flower-derived purples; differs because orchid is a pinkish-purple, redder and warmer, while lilac is cooler and bluer.
  • Heliotrope: Similar because both are pale purple flower-colours; differs because heliotrope is rarer and more literary, tinged with grey, while lilac is the everyday colour name.
  • Periwinkle: Similar because both are soft blue-purples; differs because periwinkle is bluer and greyer, closer to blue than the violet-toned lilac.
