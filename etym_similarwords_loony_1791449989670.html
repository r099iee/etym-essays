• Crazy: similar because it is the general informal term for insanity or absurdity; differs because it is broader and more neutral in slang, and lacks the specific moon-madness history.
  • Mad: similar because it means insane or wildly foolish; differs because in British English it also means “angry,” and in older usage it suggests a stronger, more frightening derangement.
  • Insane: similar because it denotes serious mental illness; differs because it is more clinical and legal, and is not used for merely eccentric behaviour.
  • Deranged: similar because it suggests disordered thinking; differs because it implies dangerous or pathological instability, far stronger than the often playful loony.
  • Unhinged: similar because it describes a mind that has lost its balance; differs because it evokes a violent or sudden breakdown, not harmless oddity.
  • Demented: similar because it once meant mad; differs because it is now strongly associated with dementia and is avoided in informal description of mere foolishness.
  • Lunatic: similar because it is the direct source and shares the moon-madness image; differs because it is more formal, older, and now often offensive in legal or medical contexts.
  • Bonkers: similar because it is a playful British synonym for crazy; differs because it is warmer and more affectionate, rarely used as a serious insult.
  • Crackers: similar because it means mad or absurd in British slang; differs because it is dated, upper-class, and usually comic.
  • Batty: similar because it suggests eccentric or slightly mad behaviour; differs because it is gentler, often applied to harmless older people, and implies oddity rather than insanity.
  • Cuckoo: similar because it means silly or mad; differs because it is childish and carries the image of the cuckoo’s repetitive call.
  • Nuts: similar because it is informal for crazy; differs because it is more American, more slangy, and can also mean “enthusiastic.”
  • Screwy: similar because it means odd or irrational; differs because it often describes plans or mechanisms rather than people.
  • Loopy: similar because it is a close derivative meaning eccentric or confused; differs because it is milder, often affectionate, and suggests giddiness rather than insanity.
  • Eccentric: similar because it describes unusual behaviour; differs because it is respectable and neutral, implying chosen oddity rather than illness.
  • Foolish: similar because it criticizes judgement; differs because it does not imply mental derangement at all.
  • Absurd: similar because it describes something ridiculous; differs because it evaluates the thing itself, not the mind that produced it.
  • Zany: similar because it suggests comic craziness; differs because it is a style of performance, deliberately exaggerated and entertaining.
  • Wacky: similar because it means amusingly odd; differs because it is light, informal, and usually positive.
