• humiliating: Similar because it causes loss of dignity; differs because humiliating is the plain modern synonym for the shame sense, while mortifying adds a killing intensity and retains medical overtones.
  • embarrassing: Similar because it causes awkward shame; differs because embarrassing is mild and everyday, while mortifying is acute and face-destroying.
  • shameful: Similar because it involves disgrace; differs because shameful judges the act as disgraceful, while mortifying describes the felt sting in the sufferer.
  • cringeworthy: Similar because it describes things that make one wince; differs because cringeworthy is slangy and often amused, while mortifying is earnest and painful.
  • gangrenous: Similar because it is the modern medical equivalent of the source sense; differs because gangrenous is purely clinical, while mortifying carries moral and emotional resonance.
  • necrotic / necrotising: Similar because they denote dying tissue; differs because necrotic is Greek-based pathology jargon, while mortifying is the older Latin-based bedside word.
  • chastening: Similar because it subdues pride through suffering; differs because chastening implies corrective benefit, while mortifying need only imply pain.
  • abasing: Similar because it lowers self-regard; differs because abasing is literary and deliberate, while mortifying can be accidental and social.
  • disgracing: Similar because it brings dishonour; differs because disgracing focuses on public reputation, while mortifying focuses on inward shame.
  • ascetic (as adjective): Similar in the self-denial branch (mortifying discipline ≈ ascetic discipline); differs because ascetic names a whole way of life, while mortifying names the act of killing appetite.
