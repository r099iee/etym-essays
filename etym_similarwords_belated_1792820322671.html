• Late: Similar because both mean arriving after the expected time; differs because late is the plain neutral fact (a late bus), while belated confesses the failure and often apologises for it.
  • Overdue: Similar because both describe what should have arrived sooner; differs because overdue scolds and tallies (overdue bills, overdue library books), while belated smiles ruefully and begs pardon.
  • Delayed: Similar because both mean held back past schedule; differs because delayed names the cause-neutral event (a delayed flight), while belated names the rueful lateness of the arrival itself.
  • Tardy: Similar because both mean slow to arrive; differs because tardy is institutional and faintly disciplinary (tardy pupils, tardy performance), while belated is social and forgiving.
  • Behindhand: Similar because both mean behind schedule; differs because behindhand is old-fashioned and often financial (behindhand with the rent), while belated is current and warmly apologetic.
  • Deferred: Similar because both involve postponement to a later time; differs because deferred is a deliberate decision (deferred payment, deferred dreams), while belated is an acknowledged failure to be on time.
  • Postponed: Similar because both concern things moved later than planned; differs because postponed is rescheduled by choice (a postponed match), while belated simply arrived too late.
  • Unpunctual: Similar because both describe failure to keep time; differs because unpunctual judges the person's habit (an unpunctual colleague), while belated judges the single late arrival.
  • Long-delayed: Similar because both emphasise the length of the wait; differs because long-delayed is the journalist's formal phrase (a long-delayed report), while belated is shorter, warmer, and fits on an envelope.
