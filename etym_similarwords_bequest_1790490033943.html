• legacy: Similar because it is property left by will; differs because legacy is Latinate and elegant, while bequest is Germanic and legal-plain.
  • inheritance: Similar because it is what passes on death; differs because inheritance is the heir's receipt, while bequest is the testator's gift.
  • devise: Similar because it is a will gift; differs because devise in strict law is land, while bequest is money and goods.
  • endowment: Similar because charities live on bequests; differs because endowment is invested fund yielding income, while bequest is the one-off gift creating it.
  • gift in will / legacy gift: Similar because fundraisers use it for bequest; differs because it is modern euphemism, while bequest is traditional law.
  • donation (posthumous): Similar because both benefit others; differs because donation is usually lifetime, while bequest is strictly after death.
  • heirloom: Similar because it passes down generations; differs because heirloom is a kept object with sentiment, while bequest is any willed property.
  • settlement: Similar because both convey property to kin; differs because settlement is trust deed, while bequest is will clause.
  • benefaction: Similar because great bequests are benefactions; differs because benefaction stresses kindness, while bequest stresses mechanism.
  • birthright: Similar because both come from family; differs because birthright is by birth, while bequest is by will.
