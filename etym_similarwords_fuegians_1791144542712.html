• Yaghan (Yámana): Similar because they are the best-known Fuegian canoe people; differs because it names one specific people/language, not the whole archipelago’s inhabitants.
  • Kawésqar (Alacaluf): Similar because they are the western-channel canoe Fuegians; differs because it is the group’s self-name, narrower and modern-preferred.
  • Selk’nam (Ona): Similar because they are the best-known terrestrial Fuegians; differs because they were guanaco-hunting foot nomads, culturally distinct from the canoe peoples.
  • Patagonians (Tehuelche): Similar because they are the neighbouring mainland Indigenous peoples; differs because they lived north of the Strait of Magellan, not on the islands.
  • Aborigines: Similar because it is a generic term for Indigenous inhabitants; differs because unqualified it points to Australia, and it carries its own contested history.
  • Amerindians: Similar because Fuegians are Indigenous Americans; differs because it is continent-scale, far broader than one archipelago.
  • Canoe Indians: Similar because it was the old synonym for the maritime Fuegians; differs because it is now seen as crude and obsolete.
  • Hunter-gatherers: Similar because it describes the Fuegian economy; differs because it is an economic category, not a people or place.
  • Islanders: Similar because Fuegians are archipelago dwellers; differs because it says nothing about indigeneity or which islands.
  • Natives: Similar because older texts call Fuegians “natives of Tierra del Fuego”; differs because it is vague and now often avoided as patronising.
  • Ethnic group: Similar because each Fuegian people is one; differs because it is an abstract sociological term, not a name.
  • Magellanic peoples: Similar because it groups the far-southern channel cultures; differs because it is a scholarly areal term, rarer and broader in time depth.
