• Morning: Similar because it denotes exactly the same time of day; differs because it is the standard modern prose word, while morn is the short poetic-archaic form.
  • Dawn: Similar because it denotes the first light of day; differs because it names the moment of daybreak rather than the whole early day, and remains fully alive in prose.
  • Daybreak: Similar because it marks the same first-light moment; differs because it emphasizes the action of light breaking, is neutral-prose, and lacks morn's ancient melody.
  • Sunrise: Similar because it marks the morning's beginning; differs because it is astronomical and event-focused (the sun's appearance) and belongs to schedules and forecasts.
  • Sunup: Similar because it is another name for daybreak; differs because it is casual American speech with no poetic aura at all.
  • Cockcrow: Similar because it names dawn as signalled by the rooster; differs because it is biblical-rural in flavour and denotes the very earliest hour.
  • First light: Similar because it denotes the first glimmer of morning; differs because it is a modern collocation, common in military and wilderness usage rather than verse.
  • Aurora: Similar because it is the poetic, divinized name for dawn; differs because it is a learned classical borrowing (and now also the polar lights), not the plain English word.
  • Morrow: Similar because it descends from the same Old English morgen; differs because it has specialized to mean 'the next day,' not the morning.
  • Forenoon: Similar because it denotes the late morning hours; differs because it is administrative-technical in tone and excludes dawn altogether.
  • Daylight: Similar because it arrives with the morning; differs because it names light itself rather than the time of day.
