• stealthy: Similar because both mean quiet and secretive; differs because stealthy is neutral-to-admiring (a stealthy hunter), while furtive implies guilt and bad conscience.
  • secretive: Similar because both describe concealment; differs because secretive is about personality and withholding information, while furtive is about sneaky, guilty behaviour.
  • surreptitious: Similar because both describe actions done secretly to avoid notice; differs because surreptitious is more neutral and factual (surreptitious recording), while furtive suggests shifty guilt.
  • clandestine: Similar because both mean concealed; differs because clandestine usually applies to organised secret activities (meetings, operations), while furtive applies to personal sneaking.
  • covert: Similar because both mean hidden or secret; differs because covert is a clinical, often military term for concealed operations, while furtive is a judgment on character and manner.
  • sneaky: Similar because both describe sly, underhanded behaviour; differs because sneaky is informal and playful-to-disdainful, while furtive is formal and suspicious.
  • shifty: Similar because both describe a distrustful, evasive manner; differs because shifty focuses on dishonest eyes and movements, while furtive focuses on avoiding notice.
  • sly: Similar because both imply cunning concealment; differs because sly emphasises clever, fox-like cunning, while furtive emphasises guilty stealth.
  • lurking: Similar because both describe hidden presence; differs because lurking is about waiting in concealment, while furtive is about sneaky movement and behaviour.
