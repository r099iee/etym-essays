• Brag: Similar because it vaunts achievements; differs because brag is blunt and colloquial, while boast can be literary and possessive.
  • Vaunt: Similar because it proudly displays; differs because vaunt is elevated and archaic, while boast is everyday.
  • Crow: Similar because it exults loudly; differs because crow stresses triumphant cry, while boast stresses content of pride.
  • Gloat: Similar because it revels in advantage; differs because gloat adds malice over others misfortune, while boast centres on self.
  • Bluster: Similar because it is loud self-assertion; differs because bluster adds empty threat, while boast adds claimed possession.
  • Swagger: Similar because it shows off; differs because swagger is bodily strut, while boast is verbal.
  • Show off: Similar because it displays superiority; differs because show off is phrasal and visual, while boast is verbal.
  • Trumpet: Similar because one trumpets successes; differs because trumpet metaphorizes blowing a horn, while boast is plain speech.
  • Exult: Similar because it rejoices proudly; differs because exult can be inward joy, while boast needs an audience.
  • Skite (Scots/Australian): Similar because it brags; differs because skite is regional slang, while boast is standard.
