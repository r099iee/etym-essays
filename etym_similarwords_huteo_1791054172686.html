• hora (plant): Similar because it is the co-mentioned Tahitian fish-stupefier; differs because hora denotes a different species/preparation, not the Barringtonia nut.
  • hutu / futu / utu: Similar because they are cognate Polynesian names for Barringtonia fish-poison trees; differs because they are modern standard forms, huteo is an archaic Tahitian spelling variant.
  • Barringtonia (sea putat): Similar because it is the likely botanical identity of huteo; differs because Barringtonia is the Linnaean genus, huteo the vernacular nut.
  • Derris root (tuba): Similar because it is another tropical fish-poison pounded into streams; differs because Derris acts by rotenone, huteo by saponins, and regions differ.
  • Tephrosia (fish-poison bean): Similar because its leaves stupefy fish pantropically; differs because Tephrosia is a legume herb, huteo a coastal tree nut.
  • fish poison / piscicide: Similar because it is the functional category containing huteo; differs because piscicide is the general technical term, huteo one instance.
  • rotenone plant: Similar because it narcotises fish gills; differs because rotenone is the specific chemistry of Derris, not necessarily huteo.
  • mullein (Verbascum): Similar because Europeans also stupefied fish with its seeds; differs because mullein is temperate Old World, huteo tropical Pacific.
  • buckeye: Similar because Native Americans similarly crushed its nuts to stun fish; differs because buckeye is North American Aesculus, unrelated botanically.
  • kava (Piper methysticum): Similar because it is another Pacific intoxicating plant preparation; differs because kava stupefies drinkers ceremonially, huteo stupefies fish.
