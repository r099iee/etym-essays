• contradicted: Similar because it means to deny or oppose; differs because contradicted is direct verbal opposition, while belied is usually indirect misleading by appearance.
  • misrepresented: Similar because it means to give a false account; differs because misrepresented implies active distortion, while belied can be unintentional.
  • masked: Similar because it means to hide reality; differs because masked stresses concealment behind a cover, while belied stresses the false impression itself.
  • disguised: Similar because it means to hide true nature; differs because disguised implies deliberate costume or intent, while belied often does not.
  • concealed: Similar because it means to keep truth hidden; differs because concealed is general hiding, while belied specifically gives an opposite impression.
  • distorted: Similar because it means to twist truth; differs because distorted stresses warping facts, while belied stresses surface versus reality.
  • falsified: Similar because it means to make false; differs because falsified is technical forgery or data fraud, while belied is literary and visual.
  • negated: Similar because it means to deny or nullify; differs because negated is logical cancellation, while belied is ironic contrast.
  • slandered (archaic sense): Similar because older belie meant to tell lies about; differs because slandered is now the explicit legal term for spoken defamation, while belied in this sense is obsolete.
  • disappointed (archaic sense): Similar because to belie hopes is to disappoint them; differs because disappointed is the everyday emotion, while belied is formal and literary.
  • betrayed (contrast): Similar because both concern surface versus truth; differs because betrayed usually reveals truth, while belied usually hides it — useful antonymic pair.
