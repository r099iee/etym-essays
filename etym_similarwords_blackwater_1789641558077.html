• River Pant: Similar because it is the same Essex watercourse above Bocking; differs because Pant names only the headwaters, while Blackwater names the whole lower system.
  • River Chelmer: Similar because it is the sister Essex river joining at Maldon; differs because it is freshwater navigation, while Blackwater below Maldon is tidal estuary.
  • Estuary: Similar because the Blackwater below Maldon is estuarine; differs because estuary is generic, while Blackwater is the specific Essex estuary.
  • Blackwater river (generic type): Similar because it shares dark tannin-water colour; differs because the ecological type (acidic, nutrient-poor) does not describe Essex’s clay-mud water.
  • Greywater: Similar because it is the paired wastewater-management term; differs because greywater is sink/shower water, while blackwater (sanitary sense) is toilet waste.
  • Whitewater / Clearwater: Similar because they are the contrasting river-colour classes; differ because they name sediment-rich or transparent waters, opposite of dark.
  • Heybridge Creek / NortheyChannel: Similar because they are tidal channels of the same system; differ because they name parts, not the whole river.
