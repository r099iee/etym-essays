• tendon: Similar because it is the anatomical cord muscle-to-bone; differs because it is clinical and precise, while sinew is archaic-poetic and also means strength.
  • ligament: Similar because it is fibrous connective tissue; differs because it joins bone to bone, not muscle to bone.
  • muscle: Similar because it is contractile strength tissue; differs because muscle is red flesh that pulls, sinew is white cord that transmits.
  • nerve: Similar because Old English used sinew for nerves; differs because modern nerve carries signals, not mechanical pull.
  • gristle: Similar because it is tough inedible cartilage in meat; differs because it is informal cookery term, chewy and undesirable.
  • cartilage: Similar because it is firm connective tissue; differs because it cushions joints rather than transmitting pull.
  • cord: Similar because prepared sinew was used as cord; differs because cord is generic manufactured string.
  • bowstring: Similar because sinew was the classic bowstring material; differs because it names the weapon part, not the tissue.
  • strength: Similar because sinews signify power figuratively; differs because strength is abstract, sinew is concrete tissue.
  • power: Similar because sinew metaphors denote sustaining force; differs because power is general capacity, not bodily.
  • backbone: Similar because it figuratively means main support; differs because it is axial skeleton, connoting resolve rather than tension.
  • mainstay: Similar because it means chief support (sinew of organization); differs because it is wholly figurative, never anatomical.
