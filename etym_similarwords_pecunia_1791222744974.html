• money: Similar because it is the general medium of exchange; differs because it is Germanic-neutral, while pecunia etymologically recalls cattle.
  • cash: Similar because it means ready coin and notes; differs because it stresses immediacy, while pecunia covers total wealth.
  • currency: Similar because it means circulating coinage; differs because it stresses circulation, while pecunia stresses stored value.
  • coinage: Similar because early pecunia was bronze coin; differs because coinage names minted pieces, while pecunia names value generally.
  • wealth: Similar because pecunia meant fortune; differs because wealth is broader (land, goods), while pecunia centres on money-value.
  • fortune: Similar because it means large possessions; differs because it implies luck and scale, while pecunia is neutral money.
  • property: Similar because Roman law used pecunia for claimable things; differs because property includes land, while pecunia prototypically is movables-money.
  • funds: Similar because pecunia publica were public funds; differs because funds is usually plural-earmarked, while pecunia can be singular mass.
  • capital: Similar because both descend from livestock-head counting; differs because capital is wealth that breeds increase, while pecunia is money as such.
  • riches: Similar because pecunia made men rich; differs because riches is rhetorical-plural, while pecunia is technical.
  • means: Similar because pecunia were one's means; differs because means is euphemistic-modern, while pecunia is direct.
  • lucre: Similar because it means monetary gain; differs because lucre is pejorative, while pecunia can be neutral or honourable.
  • mammon: Similar because it personifies wealth; differs because it is biblical-moralising, while pecunia is juridical.
