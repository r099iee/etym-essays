• parison: Similar because it denotes parallel grammatical structure; differs because strict syllabic equality is not required.
  • parallelism: Similar because it covers balanced phrasing; differs because it is the broad genus while isocolon is a measured species.
  • tricolon: Similar because it is a three-member balanced unit; differs because number is fixed and equality may be approximate.
  • antithesis: Similar because it often uses balanced cola; differs because opposition of meaning, not equality of length, is essential.
  • anaphora: Similar because it reinforces balanced cola by repetition; differs because initial-word repetition rather than clausal equality defines it.
  • homoioteleuton: Similar because it gives similar-sounding balanced endings; differs because sameness of ending sound, not length, is the criterion.
  • chiasmus: Similar because it arranges balanced members artfully; differs because reversed ABBA order rather than straight equality organises it.
  • balanced sentence: Similar because it names parallel sentence halves; differs because it is a plain-English descriptive term without quantitative rigour.
