• Place-name: Similar because both name a geographic place; differs because place-name is the plain everyday compound, while toponym is the precise, learned onomastic term.
  • Demonym: Similar because both are terms of onomastic classification built on the same -onym element; differs because a demonym names the INHABITANTS of a place (Parisian, New Yorker), while a toponym names the PLACE itself (Paris, New York).
  • Eponym: Similar because both classify the origin of names; differs because an eponym is a name derived from a PERSON (the city Washington is an eponym of George Washington), whereas a toponym is a name of or for a PLACE.
  • Ethnonym: Similar as a fellow -onym classification term; differs because an ethnonym names a people or ethnic group, not a place.
  • Hydronym: Similar as a subclass of toponym; differs because a hydronym names only bodies of water (rivers, lakes, seas), a narrow slice of toponyms.
  • Oronym: Similar as a subclass of toponym; differs because an oronym names only mountains and hills.
  • Anthroponym: Similar in being an onomastic -onym; differs because it names a person (a personal name), the human counterpart to the place name.
  • Topography: Similar because both begin with the Greek element tópos "place"; differs because topography is the physical mapping or depiction of terrain, not a naming term.
  • Topic: Similar because both descend from Greek tópos "place" (via "commonplace"); differs because topic names a subject of discourse, while toponym names a place itself.
