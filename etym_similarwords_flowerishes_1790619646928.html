• flourishes: Similar because identical standard spelling and meaning — ornamental sweeps; differs because Flowerishes is Burke's archaizing floral spelling foregrounding flower.
  • embellishments: Similar because added ornament to plain ground; differs because more neutral and general, lacking the sweeping gestural bravura of flourish.
  • ornaments: Similar because decorative additions; differs because more static and architectural, less performative than flourish.
  • adornments: Similar because beautifying additions; differs because implies wearing or affixing, not the act of brandishing.
  • frills: Similar because superfluous pretty edging; differs because almost always pejorative and trivializing, often clothing metaphor.
  • fripperies: Similar because showy trifles; differs because strongly dismissive, implying emptiness and fashion.
  • curlicues: Similar because spiral pen or typographic ornaments; differs because specifically graphic and small-scale, not rhetorical.
  • arabesques: Similar because intricate intertwined ornament in art, music, ballet; differs because suggests delicate interlace rather than bold sweep.
  • fanfares: Similar because showy introductory flourishes of trumpets; differs because auditory and ceremonial, not graphic.
  • bravura passages: Similar because virtuosic display passages; differs because primarily musical or performative, implying technical difficulty.
  • purple patches: Similar because ornate literary passages; differs because always critical, implying overwriting.
  • grandiloquence: Similar because lofty ornate speech; differs because focuses on inflated diction, not visual gesture.
