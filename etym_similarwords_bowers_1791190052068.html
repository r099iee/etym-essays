  • alcoves: Similar because recessed secluded nook; differs because usually indoor or stone niche, not leafy.
  • nooks: Similar because cosy hidden corner; differs because generic, lacking greenery entailment.
  • retreats: Similar because secluded refuge; differs because abstract-functional, not necessarily vegetative.
  • dens: Similar because animal shelter and hideout; differs because often enclosed cave-like, while bower is airy leaf-roof.
  • nests: Similar because bird-built home paired in source; differs because cup for eggs, while bowerbird bower is display court.
  • huts: Similar because primitive small dwelling paired in source; differs because human-built of wood or mud.
  • pavilions: Similar because ornamental shelter; differs because grander, often canvas or stone.
  • thickets: Similar because dense growth giving cover; differs because wild tangle, not arching shelter shape.
