• rotter: Similar because it is Wodehousian slang for a contemptible cad; differs because rotter stresses moral rottenness, stinker adds foul-smell imagery and failure senses.
  • cad: Similar because it denotes an ungentlemanly rotter; differs because cad is specifically dishonourable to women, stinker is broader.
  • bounder: Similar because it is period British insult for a low fellow; differs because bounder stresses social overstepping.
  • swine: Similar because it animalises a despicable person; differs because swine is stronger and coarser.
  • rat: Similar because it names a treacherous informer; differs because rat specifies betrayal, stinker is more general.
  • skunk: Similar because it fuses smell and contempt; differs because skunk is chiefly American and also means a cheat.
  • blighter: Similar because it is mild British abuse; differs because blighter can be affectionate and lacks smell metaphor.
  • beast: Similar because it can tease a horrid person; differs because beast stresses brutishness.
  • brute: Similar for cruel persons; differs because brute stresses physical cruelty.
  • flop: Similar for the failure sense (a stinker of a show = flop); differs because flop lacks personal insult force.
  • dud: Similar because a dud fails or disappoints; differs because dud stresses uselessness, not offensiveness.
  • lemon (slang): Similar for a defective thing; differs because lemon is chiefly for cars and products.
  • washout: Similar for a failed event or person; differs because washout stresses total failure.
  • stinkeroo (jocular): Similar as playful extension; differs only in being rarer and more comic.
