  • plaice: Similar because it is a common flatfish species; differs because it is one species with orange spots, narrower than the group.

  • turbot: Similar because it is a premium flatfish; differs because it is a particular round-bodied valuable species.
  • dab: Similar because it is a small flatfish; differs because it is specifically a minor species, often the butt of jokes.
  • brill: Similar because it is another edible flatfish; differs because it is a distinct Scophthalmid species.
  • bottomfish: Similar because it lives on the seabed; differs because it includes round-bodied bottom dwellers like cod, not only flatfish.
