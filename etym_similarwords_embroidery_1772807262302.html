• Needlework: Similar because both involve needle and thread working on cloth; differs because needlework is the broad umbrella for any sewing including plain mending, while embroidery is specifically decorative stitchwork that ornaments cloth with design.
  • Sewing: Similar because both use needle and thread; differs because sewing can mean constructing garments or simply joining fabric, whereas embroidery assumes a finished base fabric that is then ornamented.
  • Tapestry: Similar because both produce decorative fabric art; differs because tapestry is woven as a picture on a loom, while embroidery applies stitches to an existing ground.
  • Appliqué: Similar because both decorate cloth; differs because appliqué attaches separate cut pieces of fabric to a ground, whereas embroidery builds its design primarily with stitches of thread or yarn.
  • Quilting: Similar because both are needlework crafts with decorative potential; differs because quilting stitches layers of fabric together for warmth and comfort, while embroidery ornaments a single surface.
  • Fancywork: Similar because both denote ornamental handcraft; differs because fancywork is a loose, old-fashioned umbrella term for decorative crafts, while embroidery names one precise technique.
  • Beading: Similar because both add ornamental detail to fabric; differs because beading applies beads or sequins, while embroidery uses thread or yarn stitches.
  • Smocking: Similar because both are decorative needle techniques on cloth; differs because smocking gathers fabric into honeycomb stitches for fit and texture, while embroidery freely draws a design on the surface.
