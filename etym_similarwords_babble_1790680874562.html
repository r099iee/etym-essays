• prattle: Similar because it is childish inconsequential talk; differs because prattle stresses silliness rather than unintelligibility.
  • chatter: Similar because it is rapid light talk; differs because chatter can be intelligible and social while babble is incoherent.
  • gabble: Similar because it is rapid unintelligible speech; differs because gabble stresses speed like geese, babble stresses meaningless flow.
  • gibber: Similar because it is nonsense utterance; differs because gibber suggests madness or fright, often with jabber.
  • jabber: Similar because it is fast confused talk; differs because jabber is harsher and more excited.
  • blabber: Similar because it is foolish loquacious talk; differs because blabber adds indiscretion and revealing secrets.
  • blab: Similar because it reveals through talk; differs because blab focuses on betrayal, not sound quality.
  • burble: Similar because it is gurgling speech or water sound; differs because burble is softer and more cheerful, coined by Carroll.
  • murmur: Similar because it is low continuous sound; differs because murmur can be meaningful and intimate while babble is confused.
  • gurgle: Similar because it is bubbling sound of baby or water; differs because gurgle is throatier and usually pleasant.
  • prate: Similar because it is foolish boastful talk; differs because prate is pompous while babble is empty.
  • drivel: Similar because it is silly nonsense; differs because drivel is more contemptuous, like saliva.
  • patter: Similar because it is rapid glib talk; differs because patter can be skilled, as of salesmen, while babble is uncontrolled.
  • tattle: Similar because it is revealing talk; differs because tattle reports others misdeeds, babble merely flows.
