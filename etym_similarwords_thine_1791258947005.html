• thy: Similar because it is the same second-person singular possessive in the thou paradigm; differs because thy was used before consonants while thine was used absolutely or before vowels.
  • yours: Similar because it is the exact modern equivalent in absolute use; differs because yours is current and neutral while thine is archaic and solemn.
  • your: Similar because it expresses second-person possession attributively; differs because your serves all persons and registers today while thine is singular familiar and archaic.
  • mine: Similar because it is the parallel first-person archaic doublet with the same my/mine alternation; differs because mine still survives in modern English while thine does not.
  • my: Similar because it is the attributive possessive counterpart; differs because my is fully current while thine is restricted to liturgy and verse.
  • his: Similar because it is a third-person singular possessive pronoun/determiner; differs because his distinguishes gender and survives normally while thine marks obsolete thou-address.
  • hers: Similar because it is an absolute possessive pronoun; differs because hers is modern and gendered while thine is archaic and second-person.
  • ours: Similar because it encodes possession by pronoun; differs because ours is first-person plural and current while thine is second-person singular and obsolete.
  • theirs: Similar because it is an absolute possessive; differs because theirs is third-person plural and neutral while thine is singular and reverent.
  • thyself: Similar because it belongs to the same thou paradigm and signals intimate singular address; differs because thyself is reflexive/intensive while thine is possessive.
  • thee: Similar because it is the same archaic thou paradigm and appears in identical texts; differs because thee is objective case while thine is possessive.
  • thou: Similar because it is the base nominative of the same paradigm; differs because thou is subject pronoun while thine is possessive.
