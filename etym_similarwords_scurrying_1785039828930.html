• Scampering: Similar because both describe quick, light, hurried movement; differs because scampering adds a playful, bounding, frolicsome quality, while scurrying is agitated and panicked.
  • Scuttling: Similar because both describe fast, short movement of small creatures; differs because scuttling is a furtive sidling withdrawal, like a crab darting into cover, while scurrying is a forward, bustling rush.
  • Skittering: Similar because both describe light, quick, erratic movement; differs because skittering pictures something skipping lightly across a surface (as an insect on water), while scurrying is a grounded, foot-driven hurry.
  • Darting: Similar because both describe swift movement; differs because darting is a single sudden, straight burst, while scurrying is a repeated, agitated series of short steps.
  • Hurrying: Similar because both describe making haste; differs because hurrying is the neutral term for moving fast, without the diminutive, animal-like, or panicked flavor of scurrying.
  • Hastening: Similar because both describe moving with speed; differs because hastening is deliberate and purposeful urgency, while scurrying is fussy, agitated, and slightly chaotic.
  • Bustling: Similar because both describe busy, energetic movement; differs because bustling is the purposeful, sociable activity of a crowd or workplace, while scurrying is smaller-scale, more frantic, and less dignified.
  • Rushing: Similar because both describe rapid movement; differs because rushing can be large-scale and urgent in any direction, while scurrying specifically pictures short, quick, close-set steps.
  • Scrambling: Similar because both describe urgent, disorderly motion; differs because scrambling emphasizes clawing, all-fours struggle over obstacles, while scurrying emphasizes fast, small footwork on level ground.
  • Trotting: Similar because both describe a quick, even gait; differs because trotting is a brisk, rhythmic, purposeful pace (of horses or joggers), while scurrying is agitated, irregular, and undignified.
