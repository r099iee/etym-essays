• Joke: Similar because it is the exact modern synonym for a jest; differs because it is neutral everyday speech, while jest is now literary, dated or consciously wry.
  • Quip: Similar because it is a short witty remark; differs because it is quick, pointed — a single retort — and informal-modern.
  • Witticism: Similar because it is a clever, amusing remark; differs because it stresses intellectual cleverness and leans pretentious.
  • Wisecrack: Similar because it is a joking remark; differs because it is American slang with an aggressive, cutting edge.
  • Gag: Similar because it is a joke, especially in performance; differs because it belongs to show business and short comic routines.
  • Crack: Similar because 'a crack' is a joke, especially in British and Irish speech; differs because it is informal-vernacular, from the older 'to crack jokes.'
  • Pun: Similar because a pun is a joke; differs because it is specifically wordplay on double meanings — a subset of jesting.
  • Pleasantry: Similar because it is a light, polite joking remark; differs because it is social lubrication without a punchline and neutral-polite in register.
  • Jape: Similar because it is an archaic word for a jest or trick; differs because it is now obsolete-literary and stresses playful deception.
  • Sally: Similar because 'a sally' is a witty outburst; differs because it is rhetorical-elevated and images a military sortie.
  • Bon mot: Similar because it is a witty remark; differs because it is a French borrowing implying refined, premeditated wit.
  • One-liner: Similar because it is a very short joke; differs because it belongs to stand-up comedy, where brevity is the whole point.
  • Antic: Similar because it is a playful trick or caper; differs because it is physical and gesticular rather than verbal.
  • Prank: Similar because a practical joke is a kind of jest; differs because it is an enacted trick played on someone, not a spoken joke.
  • Caper / Lark: Similar because they are playful escapades; differs because they imply adventure and mischief rather than wit.
  • Mockery / Jeer: Similar because 'jest at' once meant to mock, and jesting can cut; differs because they are hostile and wounding, outside jest's playful core.
  • Exploit / Feat (archaic sense): Similar because the ancestor geste meant a deed of arms and 'jest' once bore that sense; differs because the heroic sense is long obsolete.
  • Banter: Similar because to jest is to banter; differs because banter is civil, ongoing, good-natured exchange rather than a single joke.
  • Kid / Tease / Josh (verb): Similar because they all mean playful mocking; differs because they are colloquial-modern, gentler, and directed at a person rather than at an audience.
