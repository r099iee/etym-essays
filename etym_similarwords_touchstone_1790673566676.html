• criterion: Similar because both denote a standard of judgment; differs because criterion is abstract and pluralizable, while touchstone keeps its concrete testing metaphor.
  • benchmark: Similar because both denote a reference standard; differs because benchmark is quantitative and corporate, often a measured target.
  • yardstick: Similar because both denote a measure for comparison; differs because yardstick implies graduated measurement rather than genuineness testing.
  • litmus test: Similar because both denote a decisive trial; differs because litmus test implies a binary pass/fail, often political.
  • gold standard: Similar because both denote the supreme model; differs because gold standard claims unsurpassed excellence, not merely reliability.
  • standard: Similar because both denote an accepted measure; differs because standard is generic, while touchstone is vivid and selective.
  • measure: Similar because both denote means of assessing; differs because measure is neutral and often numeric.
  • test: Similar because both denote a trial of quality; differs because test is plain and procedural, lacking the metaphor.
  • barometer: Similar because both reveal underlying condition; differs because barometer tracks fluctuating pressure or mood rather than intrinsic worth.
  • bellwether: Similar because both signal what is representative; differs because bellwether leads or predicts a trend rather than assaying value.
  • exemplar: Similar because both embody ideal quality; differs because exemplar is the perfect instance itself, not the stone it is rubbed on.
  • paragon: Similar because both denote supreme models; differs because paragon praises flawlessness, while touchstone praises diagnostic power.
