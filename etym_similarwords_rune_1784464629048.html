• Letter: Similar because both are alphabetic written units; differs because letter is the general term for any alphabetic character with no magic attached, while rune specifically names Germanic carved letters and carries a charge of secrecy and power.
  • Character: Similar because both are written symbols; differs because character is the neutral, technical word for any written or printed sign, while rune belongs to the old Germanic alphabets and to the world of mystery.
  • Glyph: Similar because both are individual marks in a writing system; differs because glyph is a broad, script-neutral term from typography and epigraphy, while rune names a specific Germanic letter with a magical history.
  • Grapheme: Similar because both are minimal units of writing; differs because grapheme is a cold linguistic term for the smallest unit in a script, while rune is the cultural, historic word for the Germanic letter.
  • Symbol: Similar because both can stand for something beyond themselves; differs because symbol is a general term for any sign with meaning, while rune is specifically an alphabetic character of the Germanic scripts with its own folklore.
  • Sign: Similar because both are marks that carry meaning; differs because sign is the most general term for any indicator, while rune is restricted to the old Germanic letters and their magical associations.
  • Mark: Similar because both are visible characters or impressions; differs because mark is informal and non-specific (a scratch, a stain, a tick), while rune is a deliberate alphabetic character of ancient script.
  • Sigil: Similar because both are symbols with magical or occult significance; differs because a sigil is typically a designed, individually charged magical seal, while a rune is an alphabetic letter from an established script.
  • Hieroglyph: Similar because both are ancient sacred scripts of carved symbols; differs because hieroglyphs belong to the Egyptian (or analogous) writing systems and are pictographic, while runes are linear alphabetic letters of the Germanic peoples.
  • Cipher: Similar because both involve hidden, secret writing; differs because a cipher is a code system for disguising ordinary text, while a rune is a real alphabetic letter that was simply felt to carry secrecy.
  • Talisman: Similar because both are objects charged with protective or magical power; differs because a talisman is a physical charm or object, while a rune is a written character that may be used on such objects.
  • Charm: Similar because both carry magical significance; differs because a charm is an object, word, or verse believed to work magic, while a rune is a letter or alphabetic mark.
  • Ogham: Similar because both are ancient alphabets of the British Isles used on stone monuments; differs because ogham is the early Irish script of notched strokes, while runes are the Germanic alphabet (Anglo-Saxon futhorc being the English branch).
  • Futhark: Similar because both belong to the same script system; differs because futhark is the name of the runic alphabet itself (after its first six letters), while rune is the individual letter within it.
