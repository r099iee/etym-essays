• garnets: Similar because they are the mineral family most carbuncles actually belong to; differs because garnet is the scientific family name (pyrope, almandine, spessartine), while carbuncle is the old shape-and-glow term for a garnet polished without facets — tradition versus mineralogy.
  • rubies: Similar because they are deep-red precious stones; differs because a ruby is the modern jeweller’s word for transparent red corundum of the highest value, typically brilliant-cut and bright, while a carbuncle is a smouldering, coal-like glow — old-fashioned and unfaceted.
  • spinels: Similar because they are red stones confused with rubies in old gem-lists; differs because spinel is a distinct, rarer mineral that medieval lapidaries often mislabelled as balas ruby, while a carbuncle glows with an internal ember rather than a brilliant fire.
  • balas rubies: Similar because they are the old trade-name for red spinel, a gem of the same medieval lists; differs because “balas ruby” was a merchant’s name that hid a different mineral, while “carbuncle” named the glowing shape rather than the species.
  • pyrope: Similar because pyrope is a deep-red garnet, the type most carbuncles actually were; differs because pyrope is the modern mineralogist’s name for a specific magnesium-aluminium garnet, while carbuncle is the pre-scientific word for the glowing cabochon.
  • almandine: Similar because almandine is another deep-red garnet variety; differs because almandine is iron-aluminium garnet, usually cut with facets today, while the classic carbuncle was the rounded, unfaceted dome.
  • bloodstones: Similar because they belong to the same medieval gem-lore; differs because bloodstone is a dark green stone flecked with red — a different effect entirely — while a carbuncle is a single smouldering red dome like a live coal.
  • carnelians: Similar because they are reddish translucent gems of the older lapidary tradition; differs because carnelian is a red-brown chalcedony — translucent, modest, and cheaper — while a carbuncle is a deep, glowing, coal-like red with internal fire.
  • boils: Similar because the word “carbuncle” is shared — a carbuncle is also a deep, burning cluster of boils; differs because the medical carbuncle is an inflamed abscess named for the same burning sensation, a homonym of the gem rather than a synonym.
