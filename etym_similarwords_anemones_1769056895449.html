• windflower: Similar because it is the plain-English name for the same plant, the anemone; differs because "windflower" is a descriptive native compound that names only the garden plant, while "anemone" is the classical name used for both the plant and the sea creature.
  • buttercup: Similar because the anemone is a member of the same plant family (Ranunculaceae); differs because the buttercup is a small, low, yellow meadow flower, while the anemone is a larger, often white-to-red spring bloom with showy petal-like sepals.
  • sea anemone: Similar because it is the same word extended to the marine polyp; differs because "sea anemone" names only the animal (order Actiniaria) with its stinging tentacles, while plain "anemone" defaults to the garden flower in modern usage.
  • coral: Similar because both are cnidarians, flower-like marine animals of the reef and shore; differs because coral is a colonial animal that builds a hard limestone skeleton, while an anemone is a solitary soft-bodied polyp with no skeleton.
  • polyp: Similar because the sea anemone is technically a polyp — the same body-form as corals; differs because "polyp" is the scientific term for the body form itself (and for the non-mobile stage of jellyfish), while "anemone" names the particular flower-like animal.
  • jellyfish: Similar because both are cnidarians with stinging tentacles; differs because a jellyfish is free-swimming, bell-shaped and gelatinous, while an anemone is anchored to the rock and rooted like a plant.
  • sea slug: Similar because it is another soft, often vividly coloured marine animal of tide-pools; differs because a sea slug (nudibranch) is a crawling mollusc with no stinging tentacle crown, while an anemone is a sessile polyp.
  • sea urchin: Similar because it shares the same rock-pool habitat and ornamental tide-pool fame; differs because a sea urchin is a spiny, globe-like echinoderm that grazes algae, with nothing flower-like about it, while an anemone is a soft, flower-shaped animal.
