• chewing: Similar because it denotes grinding with teeth; differs because it is neutral and general, while gnawing stresses persistence, effort and wearing away.
  • nibbling: Similar because it means taking small bites; differs because it is light, dainty or tentative, while gnawing is sustained, anxious and damaging.
  • biting: Similar because it means seizing with teeth; differs because it is a single sharp act, while gnawing is repeated and attritional.
  • munching: Similar because it means chewing audibly and steadily; differs because it is hearty and contented, while gnawing implies compulsion or erosion.
  • gnawing (anxiety): Similar in the sense of tormenting persistence; differs from physical chewing because the object is mental — used here to show the literal-figurative split within the same form.
  • eating away: Similar because it captures gradual destructive consumption; differs because it is a phrasal paraphrase, broader and less vividly dental than gnawing.
  • eroding: Similar because waves or doubts erode as teeth gnaw; differs because it is impersonal and geological-chemical, while gnawing keeps an animal agency.
  • tormenting: Similar because gnawing guilt torments; differs because it is purely psychological and stronger, lacking the slow-bite image.
  • nagging: Similar because a nagging doubt persists like gnawing; differs because it suggests irritating repetition in words, while gnawing suggests internal ache.
  • worrying at: Similar because dogs worry at bones as minds worry at problems; differs because it is idiomatic and suggests restless handling rather than dental attrition.
  • bothering: Similar because a gnawing issue bothers one; differs because it is weak, general and casual, while gnawing implies deep, continuous unease.
