• Eighty: Similar because both name the same cardinal number (80); differs because "eighty" is the plain modern decimal form used in everyday speech, while "fourscore" is the archaic, scriptural, and literary vigesimal form carrying solemnity.
  • Four twenties: Similar because it is the same transparent arithmetic (4 × 20 = 80) and the same vigesimal logic; differs because "four twenties" is an ad hoc descriptive phrase in English, not a frozen word, whereas "fourscore" is a single established compound with biblical and oratorical resonance.
  • Four decades: Similar because it also names the same length of time (80 years); differs because "decade" is modern, decimal, and statistical in tone, lacking the archaic vigesimal dignity of "fourscore."
  • Fourscore and ten: Similar because it belongs to the same archaic counting system and uses the same "score" element; differs because it names ninety (80 + 10), not eighty, and appears in scriptural phraseology ("fourscore and ten years" of a long life).
  • Score: Similar because "score" is the second element and means twenty, so "fourscore" is built on it; differs because "score" alone names twenty (and also a tally, a game's points, or a musical notation), while "fourscore" names the product four times twenty.
  • Quatre-vingts: Similar because the French expression also means eighty by the vigesimal system (four twenties); differs because it is French and remains the normal everyday word for 80 in modern French, whereas "fourscore" is archaic in English.
