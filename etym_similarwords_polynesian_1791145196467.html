• Polynesia: Similar because it is the same root region; differs because it is the place noun, while Polynesian is the adjective/people noun.
  • Pacific Islander: Similar because Polynesians are Pacific Islanders; differs because it is broader, including Melanesians and Micronesians.
  • Melanesian: Similar because it is a neighbouring Oceanic group; differs because it denotes western Pacific peoples (Fiji, Vanuatu, Solomons), not the Polynesian Triangle.
  • Micronesian: Similar because it is the third Oceanic division; differs because it means small-island peoples of Kiribati, Guam, Palau etc.
  • Austronesian: Similar because Polynesian languages are Austronesian; differs because Austronesian is the vast family from Madagascar to Easter Island.
  • Oceanic: Similar because Polynesian is an Oceanic subgroup; differs because Oceanic covers all Pacific Austronesian languages.
  • Tahitian: Similar because Tahitians are Polynesians; differs because it is one specific people/island, not the whole Triangle.
  • Samoan: Similar because Samoans are archetypally Polynesian; differs because it names one nation/culture.
  • Hawaiian / Native Hawaiian: Similar because Hawaiians are Polynesians; differs because it is the northern-apex culture with US-state context.
  • Māori: Similar because Māori are Polynesians of Aotearoa; differs because it is the southern-apex Indigenous people of New Zealand.
  • Pasifika: Similar because it is a modern umbrella for Pacific peoples including Polynesians; differs because it is a diaspora identity term, broader and political.
  • South Sea Islander: Similar because it historically meant Pacific islanders; differs because it is archaic/colonial and imprecise.
