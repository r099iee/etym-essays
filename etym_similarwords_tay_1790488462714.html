• River Forth: Similar because it is another great eastern Scottish river with a firth and famous bridges; differs because the Forth drains Edinburgh and Stirling, while the Tay drains Perth and Dundee.
  • River Tweed: Similar because it is a famous Scottish salmon river with literary fame; differs because the Tweed forms the Border with England, while the Tay is wholly Scottish and larger in flow.
  • River Spey: Similar because it is a swift Highland salmon river prized by anglers; differs because the Spey is shorter, more northerly, and whisky-associated, while the Tay is longest and city-associated.
  • River Dee (Aberdeenshire): Similar because it is a clear Highland river flowing to the North Sea; differs because the Dee is Royal Deeside (Balmoral), while the Tay is Perthshire and Tayside.
  • River Earn: Similar because it is a Tay tributary joining near Perth; differs because the Earn is a tributary, while the Tay is the main stem receiving it.
  • Firth of Tay: Similar because it is the tidal mouth of the same water; differs because the Firth is estuary (salt, wide, bridged), while the Tay proper is river (fresh, narrower).
  • Loch Tay: Similar because it is part of the same Tay system in Breadalbane; differs because a loch is standing lake water, while the Tay is flowing river.
  • Waterway / river: Similar because both name flowing water; differs because waterway is generic, while Tay is a unique proper name with history.
  • Salmon river: Similar because the Tay exemplifies it; differs because salmon river describes function, while Tay names identity.
  • Tayside: Similar because it is the region named for the river; differs because Tayside is land and administration, while Tay is water itself.
