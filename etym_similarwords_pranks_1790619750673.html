• tricks: Similar because deceptive acts for effect; differs because broader — magic tricks, confidence tricks — not necessarily playful.
  • practical jokes: Similar because staged deceptions for laughter; differs because prototypically interpersonal, less political-artistic than prank.
  • japes: Similar because sportive tricks, literary word; differs because archaic-playful, Shakespearean flavour.
  • capers: Similar because playful escapades and antics; differs because emphasizes frolic and movement, not necessarily victim.
  • antics: Similar because absurdattention-seeking acts; differs because emphasizes grotesque behaviour, plural mannerisms.
  • larks: Similar because merry adventures; differs because British, affectionate, implies high spirits more than deception.
  • stunts: Similar because daring public feats; differs because emphasizes risk and spectacle, often for publicity.
  • hoaxes: Similar because deceptions revealed; differs because larger, often media-wide, implies belief-manipulation.
  • shenanigans: Similar because mischievous activity; differs because informal-collective, vague and often disapproving.
  • monkeyshines: Similar because playful mischief; differs because American colloquial, childish.
  • provocations: Similar because acts to pique and challenge; differs because more serious-political, less laughing.
  • put-ons: Similar because teasing deceptions; differs because verbal-pretence focused, countercultural slang.
