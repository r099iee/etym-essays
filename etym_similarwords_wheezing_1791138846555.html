• gasping: Similar because it is laboured breathing; differs because it is sudden, open-mouthed and not necessarily whistling.
  • panting: Similar because it is audible heavy breathing; differs because it is rapid and breathy after exertion, not musical.
  • puffing: Similar because it pushes air noisily; differs because it stresses short blasts, often of smoke or effort.
  • hissing: Similar because it is a sustained sibilant sound; differs because it need not involve lungs (snakes, steam).
  • whistling: Similar because it is high-pitched and musical; differs because it can be voluntary and tuneful.
  • rasping: Similar because it is harsh breath-sound; differs because it is grating and dry, not musical.
  • rattling: Similar because it describes chest sounds; differs because it implies loose mucus, not narrowed whistle.
  • coughing: Similar because it is a respiratory symptom; differs because it is explosive, not continuous whistle.
  • snoring: Similar because it is noisy breathing; differs because it occurs in sleep via throat vibration.
  • snuffling: Similar because it is noisy nasal breathing; differs because it is sniffly and nasal.
  • struggling for breath: Similar because it denotes distress; differs because it is a phrase, not the specific whistle.
  • heaving: Similar because it labours to breathe; differs because it stresses chest movement, not sound.
