• Seer: Similar because both name someone who perceives the future; differs because a seer relies on mystical vision or clairvoyance, while a prophet proclaims a divine message or reasoned warning.
  • Oracle: Similar because both involve divine communication about the future; differs because an oracle is the shrine, priest(ess), or cryptic answer itself, while a prophet is a person who speaks a message.
  • Soothsayer: Similar because both name future-tellers; differs because a soothsayer reads omens or makes predictions professionally and often for pay, while a prophet claims divine inspiration.
  • Diviner: Similar because both involve supernatural knowledge; differs because a diviner practices divination through tools (rods, entrails, cards), while a prophet proclaims a message received from God.
  • Augur: Similar because both interpret signs about the future; differs because an augur is a Roman official reading bird omens, while a prophet is a religious spokesman of divine will.
  • Visionary: Similar because both see what others do not yet see; differs because a visionary is a secular idealist or dreamer of new possibilities, not necessarily a religious spokesman.
  • Forecaster: Similar because both predict future events; differs because a forecaster uses data and probabilities (weather, economics), while a prophet claims inspired or moral authority.
  • Harbinger: Similar because both announce what is coming; differs because a harbinger is an unconscious sign or forerunner (e.g., the first robin), while a prophet is a conscious speaker of warnings.
  • Herald: Similar because both proclaim a message; differs because a herald announces present news or persons officially, while a prophet reveals divine or future truth.
  • Mystic: Similar because both involve direct contact with the divine; differs because a mystic seeks union with God in contemplation, while a prophet delivers a message to a community.
  • Nostradamus (by extension): Similar because both name famous predictors of the future; differs because Nostradamus is the proper name of a 16th-century astrologer, used metaphorically for any cryptic predictor, while prophet is the general term.
  • Clairvoyant: Similar because both claim knowledge of the future; differs because a clairvoyant uses psychic perception rather than divine commission or reasoned analysis.
