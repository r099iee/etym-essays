• Accumulated: Similar because it means gathered gradually into a mass; differs because accumulated stresses piling without necessarily fusing, while accreted stresses growing together.
  • Accrued: Similar because it denotes growth by addition over time, often financial; differs because accrued comes via French and suits money and benefits, while accreted suits physical and cultural layers.
  • Amassed: Similar because it means collected into a large quantity; differs because amassed implies deliberate heaping by effort, while accreted implies slow impersonal deposition.
  • Aggregated: Similar because it means combined into a whole; differs because aggregated is technical-statistical, while accreted is organic and temporal.
  • Agglomerated: Similar because it denotes clustered into a mass; differs because agglomerated suggests a jumbled lump, while accreted suggests layered growth.
  • Conglomerated: Similar because it means fused diverse bits together; differs because conglomerated stresses heterogeneity, while accreted stresses adhesion from outside.
  • Built-up: Similar because it describes gradual increase; differs because built-up is plain and often planned, while accreted is formal and often unplanned.
  • Encrusted: Similar because it evokes a hard outer coat; differs because encrusted stresses surface covering, while accreted covers whole-mass growth.
  • Coalesced: Similar because it means merged into one; differs because coalesced stresses union of separate wholes, while accreted stresses addition of particles.
  • Compounded: Similar because it denotes increase by combination; differs because compounded often worsens (problems compound), while accreted is neutral about value.
