• rubbish: Similar because both name waste material; differs because rubbish (British English) is general collected refuse, while litter specifically names waste scattered in an open public place — which is why only litter can be "littered."
  • garbage: Similar because both name discarded waste; differs because garbage (American English) often implies organic household waste awaiting collection, while litter is visible, scattered, outdoor refuse.
  • trash: Similar because both name waste; differs because trash is a general American word for refuse, while litter emphasises dispersal across open public space.
  • refuse: Similar because both name discarded matter; differs because refuse is the formal, municipal, collected category, while litter is the informal, scattered deposit.
  • waste: Similar because both name discarded material; differs because waste is the broadest, most abstract category, of which litter is one socially disapproved subset.
  • debris: Similar because both name scattered material; differs because debris implies the broken fragments left by destruction or disaster, while litter is casually discarded everyday items.
  • detritus: Similar because both name scattered refuse; differs because detritus is a technical word (geological, biological, or figurative) for disintegrated remains, while litter is the plain civic word.
  • junk: Similar because both name discarded things; differs because junk implies bulky, possibly still-usable items, while litter is small, dispersed, and worthless.
  • scraps: Similar because both name small leftover pieces; differs because scraps usually means fragments of food or fabric, while litter can be any discarded item.
  • mess: Similar because both involve disorder; differs because mess is general untidiness, while litter is specifically waste scattered in a public place.
  • clutter: Similar because both name a disordered scattering; differs because clutter is a disorder of useful things indoors, while litter is waste out of doors.
  • brood (offspring sense): Similar because both name the offspring of a single birth; differs because brood applies to birds, fish, or a human family's many children, while litter is restricted to the young of mammals born at one time.
  • spawn (offspring sense): Similar because both name young produced in quantity; differs because spawn is the eggs or young of fish and amphibians, laid in water, while a litter is live-born mammal young.
  • scatter / strew (verb senses): Similar because both mean to spread things loosely over an area; differs because scatter is random spreading in many directions, while litter (as a verb) specifically means to leave waste carelessly in a public place.
  • stretcher (carrying sense): Similar because both are devices for carrying people; differs because a stretcher is a plain hospital or emergency frame, while a litter retains the historical idea of a bed-like platform (and an aristocratic covered couch).
