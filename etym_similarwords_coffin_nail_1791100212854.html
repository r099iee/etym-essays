• nail: Similar because it denotes a pointed metal fastener driven into wood; differs because it is the generic term while coffin-nail specifies large nails for coffins or slang cigarettes.
  • spike: Similar because it is a large heavy nail; differs because spike implies greater size and force and lacks the coffin or cigarette associations.
  • brad: Similar because it is a small finishing nail; differs because brad is thin and for trim work, opposite in scale to a coffin-nail.
  • hobnail: Similar because it is a large-headed nail with funerary and boot associations; differs because hobnails stud boot soles rather than coffins.
  • tack: Similar because it is a short sharp nail; differs because tacks hold carpet or upholstery and are far smaller and lighter.
  • rivet: Similar because it is a permanent metal fastener; differs because rivets clamp metal plates by hammering both ends, not by driving into wood.
  • screw: Similar because it fastens wood; differs because it has threads and is turned rather than hammered.
  • cigarette: Similar because coffin-nail is slang for it; differs because cigarette is the neutral standard term without the morbid joke.
  • fag: Similar because it is British slang for a cigarette; differs because it is informal and potentially offensive in American English, while coffin-nail is a facetious metaphor.
  • cigar: Similar because it is a tobacco roll also linked to health harm; differs because cigars are larger, unfiltered, and smoked differently.
  • death stick: Similar because it is modern slang equating smoking with death; differs because it is contemporary and general, while coffin-nail is older and specifically evokes the coffin.
  • coffin nail (figurative habit): Similar because it means any self-destructive habit hastening ruin; differs because the figurative sense extends beyond tobacco to drink, overwork, or vice.
