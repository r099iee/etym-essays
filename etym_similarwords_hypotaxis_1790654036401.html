• subordination: Similar because it denotes dependent clause structure; differs because it is the plain Latinate equivalent without the Greek stylistic aura.
  • embedding: Similar because it denotes nesting of clauses; differs because it is a formal syntactic mechanism rather than a style label.
  • periodic sentence: Similar because it typically exploits hypotaxis; differs because it names a sentence shape with suspended completion, not subordination itself.
  • hypotactic: Similar because it is the adjectival form describing such syntax; differs because it modifies style rather than naming the principle.
  • subjunction: Similar because it marks joining by subordination; differs because it is rarer and stresses the joining device.
  • complex sentence: Similar because school grammar uses it for main-plus-subordinate patterns; differs because it is pedagogical and purely structural.
  • nesting: Similar because it images clauses within clauses; differs because it is metaphorical and applies beyond grammar.
  • qualification: Similar because hypotaxis qualifies assertions; differs because it names the semantic effect rather than the syntax.
