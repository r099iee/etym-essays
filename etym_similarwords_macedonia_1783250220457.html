• Macedon: Similar because it names the same ancient land and people; differs because it is the narrower, archaic English form reserved for the classical kingdom (“Philip of Macedon”), while Macedonia is the wider, modern term for region and province.
  • Hellas / Greece: Similar because Macedonia was a Greek-speaking land within the Greek world; differs because to the classical city-states Macedonia was a semi-barbarous northern frontier whose Hellenism was doubted at Athens, not the heartland Hellas.
  • Balkans: Similar because Macedonia lies within the Balkan Peninsula; differs because the Balkans is a modern geopolitical label covering many peoples and countries, without the specific ancient-regal resonance of Macedonia.
  • Thrace: Similar because it is a neighbouring ancient region of the northern Aegean; differs because Thrace was never the seat of an empire and its name was not claimed by a modern state in the same way.
  • Epirus: Similar because it is a neighbouring Greek region of the northwest; differs because Epirus was a smaller, less central kingdom that never produced a world-conqueror.
  • Macedonian: Similar because it is the adjective and people's name derived from the same root; differs because it denotes the people, language, and dynasty, while Macedonia names the land, region, and state.
  • North Macedonia: Similar because it is the official name of the modern state occupying the northern part of the region; differs because it is a post-2019 diplomatic compromise that carefully distinguishes the state from the wider region and from Greek Macedonia.
  • Alexander's empire: Similar because it names the power that Macedonia became; differs because it is a personal, dynastic label for the conquests rather than the name of the homeland itself.
