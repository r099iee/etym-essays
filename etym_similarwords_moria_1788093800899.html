• Khazad-dûm: Similar because it is the very same place — the Dwarves' own Khuzdul name for their realm; differs because it is the proud, native name of the living city, whereas Moria is the Elvish name for its dark, ruined state.
  • Hadhodrond: Similar because it is the Elves' other, older Sindarin name for the same city (“Dwarf-cave”); differs because it predates the ruin and carries none of Moria's dread associations.
  • Dwarrowdelf: Similar because it is Tolkien's archaizing English rendering of Khazad-dûm (“dwarf-delving”); differs because it is a translation-equivalent, not the word used in the narrative's Sindarin register.
  • Mines of Moria: Similar because this is the common popular designation of the site; differs because it foregrounds the mineral extraction and the later ruin, while Moria alone names the realm itself.
  • Abyss / chasm / gulf: Similar because these words gloss the second element of the name (iâ, “void”); differ because they are generic topographic nouns, whereas Moria is a proper name fused with Dwarven history.
  • Moriah: Similar because the spelling and sound nearly coincide and both evoke a mountain both sacred and terrible; differs because Moriah is the biblical mount of the Akedah in Jerusalem, entirely unrelated to Tolkien's invention.
  • Underworld / netherworld: Similar because both denote a vast subterranean realm; differ because these are mythological categories of the dead, while Moria was a living city whose catastrophe made it hellish.
  • Catacombs / labyrinth: Similar because both denote extensive underground passages; differ because they lack the political and industrial grandeur of a Dwarven kingdom and the specific Tolkienian history.
