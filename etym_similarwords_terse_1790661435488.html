• terse (modern spelling): Similar because it is the same word in current orthography; differs only in spelling and currency, not meaning.
  • concise: Similar because it denotes brevity with completeness; differs because it stresses cutting length rather than polish.
  • laconic: Similar because it praises pithy speech; differs because Spartan bluntness and reserve colour it.
  • pithy: Similar because it joins brevity with forceful meaning; differs because vigour and point are foregrounded.
  • succinct: Similar because it denotes compact expression; differs because formal neatness rather than shine is implied.
  • crisp: Similar because it praises fresh, neat brevity; differs because lively sharpness rather than rubbed smoothness is imaged.
  • neat: Similar because it descends from the same wiped-clean idea; differs because general tidiness rather than verbal density is meant.
  • polished: Similar because it names refined finish; differs because it need not imply brevity.
  • compact: Similar because it denotes dense structure; differs because solidity of packing, not elegance, is stressed.
  • epigrammatic: Similar because it praises pointed brevity; differs because witty sting is essential.
