• Chaise (alone): Similar because it is the vehicle body without the hire system; differs because chaise can be owned and one-horse, while postchaise implies hired relays and a pair.
  • Stagecoach: Similar because it is a horse-drawn long-distance carriage; differs because stage runs to timetable for many passengers, while postchaise is private hire for one party.
  • Mail coach: Similar because it also posted with relays at speed; differs because mail carried letters and outside passengers under guard, while postchaise carried private travellers.
  • Coach (private): Similar because it is a closed four-wheeled carriage; differs because a coach was owned and kept with servants, while a postchaise was hired by the mile.
  • Gig / curricle / phaeton: Similar because they are light Regency carriages; differs because they are open, owner-driven sporting vehicles, while postchaise is closed and postilion-driven.
  • Landau / barouche: Similar because they are fashionable touring carriages; differs because they are open or convertible parade vehicles, while postchaise is a plain travelling box built for speed.
  • Diligence (French): Similar because it is the French public long-distance coach; differs because diligence is communal and lumbering, while postchaise is private and fast.
  • Hansom cab / taxi (successor): Similar because both are hired point-to-point transport; differs because hansom is urban and two-wheeled, while postchaise was inter-city and four-wheeled.
  • Post-horses / postilion system: Similar because it is the motive half of posting; differs because it names horses and riders, while postchaise names the whole equipage.
  • Railway carriage (replacement): Similar because it took over long-distance panoramic travel; differs because rail is fixed-track and mass, while posting was road-based and private.
