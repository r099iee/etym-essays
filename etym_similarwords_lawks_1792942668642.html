• Lor: Similar because both clip Lord into a Cockney gasp of surprise; differs because lor is the shorter, still faintly living form (lor lumme, lor love you), while Lawks is the fuller archaic stage form with its exclamatory -s.
  • Golly: Similar because both are softened exclamations of astonishment; differs because golly softens God rather than Lord and survives in nursery speech, while Lawks is period-rustic and theatrical.
  • Gosh: Similar because both dodge blasphemy while crying out; differs because gosh is the universal modern minced oath, neutral and current, while Lawks is class-marked and frozen in the gaslight era.
  • Goodness: Similar because both exclaim goodness me style wonder politely; differs because goodness stays respectable in any mouth today, while Lawks deliberately signals a humble rustic speaker.
  • Gracious: Similar because good gracious voices the same wide-eyed wonder; differs because gracious keeps genteel drawing-room polish, while Lawks belongs below stairs and on the farm.
  • Heavens: Similar because both appeal heavenward in surprise; differs because heavens still works in modern mouths, while Lawks now reads as costume-drama diction.
  • Blimey: Similar because both are London-flavoured startled oaths from sacred names; differs because blimey (blind me) stays rowdily alive, while Lawks has retired to Dickens, the stage, and the Shire.
  • Cor: Similar because both are short working-class gasps (cor, lawks); differs because cor (God) is brusquer and still heard on terraces, while Lawks is rounder, longer, and more comic.
  • Well I never: Similar because both voice delighted disbelief at a sight; differs because well I never is a whole surviving phrase for any speaker, while Lawks is a single archaic syllable doing the same work in one gulp.
