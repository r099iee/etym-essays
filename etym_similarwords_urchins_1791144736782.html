• Sea urchin (echinoid): Similar because in the passage this IS the referent; differs because the bare plural “urchins” can also mean children, while “sea urchins” cannot.
  • Hedgehog: Similar because it is the original meaning of urchin and the visual model (round, spiny); differs because it is the land mammal, not the marine animal or the child.
  • Echinoderm: Similar because sea urchins belong to this phylum; differs because it also covers starfish, sea cucumbers, and crinoids — far broader.
  • Sand dollar: Similar because it is a flattened urchin cousin (order Clypeasteroida); differs because it is disc-shaped and spineless-looking, not globular-spiny.
  • Starfish (sea star): Similar because it is a fellow spiny echinoderm of the same shores and menus; differs because of its star shape and non-urchin anatomy.
  • Street urchin: Similar because it is the other live sense of the same word; differs because it denotes a child, not an animal.
  • Ragamuffin: Similar because it means a ragged (often child) vagrant; differs because it stresses ragged dress over mischief and has no marine sense.
  • Gamin: Similar because it is the French-flavoured synonym for a streetwise poor boy; differs because it is admiring (spirited, quick) and borrowed, less Dickensian.
  • Guttersnipe: Similar because it names a neglected street child; differs because it is harsher and more contemptuous than usually-affectionate urchin.
  • Waif: Similar because it denotes a homeless neglected child; differs because it stresses abandonment and pathos, not mischief.
  • Mudlark: Similar because Victorian mudlarks WERE Thames urchins scavenging the foreshore; differs because it names the scavenging trade specifically.
  • Goblin/imp (Shakespearean urchin): Similar because Elizabethan “urchin” could mean a hedgehog-goblin; differs because the fairy sense is obsolete except in footnotes to Caliban.
