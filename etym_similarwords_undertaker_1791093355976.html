• funeral director: Similar because it organises funerals professionally; differs because it is the modern American polite term, broader in managerial tone.
  • mortician: Similar because it prepares bodies and directs rites; differs because it is American and emphasises embalming science.
  • embalmer: Similar because it preserves the corpse; differs because it names only the technical preparation, not full arrangement.
  • gravedigger: Similar because it handles burial labour; differs because it digs the grave manually rather than managing the whole funeral.
  • sexton: Similar because it maintains churchyard and burial; differs because it is a parish officer with bell and grave duties, not a private business.
  • coroner: Similar because it deals officially with the dead; differs because it investigates cause of death legally rather than arranging rites.
  • pallbearer: Similar because it carries the coffin in ceremony; differs because it is a ceremonial role, often kin, not the hired organiser.
  • mourner: Similar because both appear in burial registers; differs because mourner grieves personally while undertaker works professionally.
  • contractor: Similar because early undertakers contracted works; differs because contractor now means building supplier, not funeral arranger.
  • entrepreneur: Similar because it shares the take-on-enterprise root; differs because it now means business founder, the old general sense undertaker lost.
  • organiser: Similar because both coordinate events; differs because organiser is generic while undertaker is death-specific.
  • officiant: Similar because it leads the funeral rite; differs because officiant is clergy or celebrant conducting words, not logistics.
