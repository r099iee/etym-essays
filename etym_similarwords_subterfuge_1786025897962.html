• Deception: Similar because both involve misleading others about the truth; differs because deception is the broad, generic noun for any misleading, while subterfuge implies a specific, elaborate stratagem of concealment or evasion rather than a simple lie.
  • Trickery: Similar because both are dishonest practices; differs because trickery is more general, folksy, and playful, while subterfuge is formal and suggests a calculated, sustained device of evasion.
  • Ruse: Similar because both are deceptive devices; differs because a ruse is a single, tactical trick (often a feint or diversion), whereas subterfuge can be an ongoing strategy or system of concealment.
  • Stratagem: Similar because both denote clever, planned devices; differs because stratagem is neutral or even admirable in a military context (a general's stratagem), while subterfuge is morally negative - deceit aimed at concealment.
  • Evasion: Similar because both involve avoiding a confrontation, duty, or question; differs because evasion names the act of dodging (as in tax evasion), while subterfuge names the deceptive device by which the dodging is achieved.
  • Dodge: Similar because both are ways of avoiding something; differs because dodge is informal and concrete, while subterfuge is formal and suggests polished, sophisticated concealment.
  • Ploy: Similar because both are schemes to gain an advantage; differs because a ploy is a single manoeuvre or gambit, often transparent, while subterfuge suggests deeper, more systematic concealment.
  • Wile: Similar because both are cunning tricks; differs because wiles are associated with charm or seductive cunning and are not always openly hostile, while subterfuge is a formal, neutral-to-negative device of concealment.
  • Artifice: Similar because both denote a clever, contrived device; differs because artifice can be purely aesthetic or technical (an artistic device) without dishonesty, while subterfuge always involves concealment and deceit.
  • Chicanery: Similar because both are legalistic or bureaucratic trickery; differs because chicanery stresses sharp practice and sophistry in argument or law, while subterfuge stresses hiding one's true objective.
  • Dissimulation: Similar because both involve hiding one's true intentions; differs because dissimulation is specifically about disguising one's feelings or purposes by feigning, while subterfuge is the broader device of evasive deceit.
  • Duplicity: Similar because both involve double-dealing deceit; differs because duplicity describes a treacherous, two-faced character trait, while subterfuge describes a concrete stratagem or act.
