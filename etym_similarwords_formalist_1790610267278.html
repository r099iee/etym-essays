• pedant: Similar because it means stickler for rules and correctness; differs because it stresses showy learning and trivial accuracy, not theory of form.
  • stickler: Similar because it insists on procedure; differs because it is colloquial and general, without intellectual doctrine.
  • dogmatist: Similar because it adheres rigidly to doctrine; differs because it stresses belief content, while formalist stresses shape and method.
  • literalist: Similar because it clings to letter over spirit; differs because it is interpretive, especially biblical or textual, not aesthetic.
  • ritualist: Similar because it values ceremony and form; differs because it is religious and performative, not critical-theoretical.
  • structuralist: Similar because it studies underlying structures; differs because it is a later, linguistic-anthropological theory seeking systems, not just artistic devices.
  • classicist: Similar because it honours order, proportion, and rule; differs because it is historical-stylistic allegiance to antiquity, broader than method.
  • aesthete: Similar because it cares for artistic form and beauty; differs because it cherishes sensuous experience, while formalist analyses technique.
  • technician: Similar because it focuses on craft and device; differs because it is practical and neutral, without ideological commitment to form.
  • New Critic: Similar because it practises close formal reading; differs because it is a specific Anglo-American school, while formalist is generic and includes Russians.
