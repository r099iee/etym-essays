• Brightly dressed: Similar because it describes clothing vivid in colour; differs because it is purely chromatic, asserting no cheerfulness or festive mood, which the “gaily” element of the compound contributes.
  • Colorfully dressed: Similar because it denotes clothing of many hues; differs because it is emotionally neutral, whereas “gaily” adds joy and light-hearted display.
  • Showily dressed: Similar because it describes conspicuous, attention-drawing clothing; differs because it implies display verging on excess or vanity, while “gaily” keeps the tone cheerful and unselfconscious.
  • Flashily dressed: Similar because it describes loud, striking clothing; differs because it carries a judgment of vulgarity or gaudiness that “gaily-dressed” entirely lacks.
  • Festively dressed: Similar because it names clothing appropriate to celebration; differs because it describes dress for a specific occasion, while “gaily-dressed” describes the manner of dress regardless of occasion.
  • Cheerfully dressed: Similar because it links clothing to a happy mood; differs because it emphasizes the wearer’s disposition rather than the colour and showiness of the clothes themselves.
