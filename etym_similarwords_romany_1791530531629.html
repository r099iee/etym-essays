• Romani: similar because it is the same language and people; differs because it is the modern preferred spelling and avoids the archaic, literary flavour of Romany.
  • Roma: similar because it names the same ethnic group; differs because it is the plural name of the people, not the language or a singular person.
  • Rom: similar because it is the singular self-designation behind Romany; differs because it denotes one person and is not used for the language.
  • Gypsy: similar because it is the older English name for the same people; differs because it is an exonym based on a false Egyptian origin and is widely considered pejorative.
  • Sinti: similar because it is a Roma group with its own dialect; differs because it names a specific western European subgroup, not the whole Romani language.
  • Kale: similar because it is a Roma subgroup with a distinct variety; differs because it is regional and does not cover all Roma.
  • Domari: similar because it is a related Indo-Aryan language spoken by Dom people; differs because it is a separate language with a different history and is not Romani.
  • Lomavren: similar because it is a mixed language of the Lom people with Indo-Aryan elements; differs because it is heavily Armenian-influenced and not a Romani dialect.
  • Bohemien: similar because it is a French exonym for Roma; differs because it is foreign, dated, and also carries the artistic meaning of "bohemian".
  • Zingaro: similar because it is an Italian exonym for Roma; differs because it is a different national label and can be pejorative.
  • Gitano: similar because it is the Spanish exonym for Roma; differs because it is a separate linguistic and cultural tradition and is not the self-designation.
