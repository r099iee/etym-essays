• preen: Similar because birds dress feathers and people groom with pride; differs because preen stresses grooming, plume oneself stresses boasting.
  • pride oneself: Similar because reflexive self-congratulation; differs because neutral-positive, lacking bird-vanity irony.
  • congratulate oneself: Similar because self-approval; differs because episodic, while plume implies sustained vaunting.
  • boast: Similar because vaunting superiority; differs because loud verbal bragging, while plume can be quiet complacency.
  • vaunt: Similar because literary boasting; differs because archaic-formal, often of lineage or deeds.
  • pique oneself: Similar because reflexive pride on punctiliousness; differs because slightly dated and narrower.
  • flatter oneself: Similar because self-deceptive pride; differs because implies illusion, while plume need not be false.
  • adorn: Similar because literal decking with plumes; differs because general decoration, not reflexive pride.
  • preen oneself: Similar because near-synonym for self-satisfied grooming; differs because broader, clothes and appearance.
  • feather: Similar because literal plumage kin; differs because anatomical-material, while plume is ornamental or verb.
  • panache: Similar because feather-ornament as flamboyant style; differs because loanword for flair, not verb of pride.
  • honour: Similar because figurative feather-trophy in cap; differs because abstract reward, while plume pictures it.
