• structural metaphor: Similar because both are basic types of conceptual metaphor mapping one domain onto another; differs because structural metaphor organizes an entire complex concept by another concept (argument is war), while an ontological metaphor merely confers entity, container, or substance status on an abstraction.
  • orientational metaphor: Similar because both are categories of conceptual metaphor from Lakoff and Johnson's system; differs because orientational metaphors organize concepts along spatial axes (happy is up), while ontological metaphors give abstractions physical thinghood or boundedness.
  • personification: Similar because both treat an abstraction as something concrete; differs because personification specifically treats it as a human being with intentions and agency, whereas ontological metaphor may treat it as any physical object, substance, or container.
  • container metaphor: Similar because both treat an abstraction as a physical thing; differs because a container metaphor is a specific subtype that gives the abstraction an inside and outside, while ontological metaphor is the broader genus including entity, substance, and person metaphors.
  • conduit metaphor: Similar because both are ways of making abstract ideas concrete; differs because the conduit metaphor is a specialized ontological metaphor for communication (ideas as objects sent through words as containers), not a general category.
  • conceptual metaphor: Similar because both describe metaphors that shape everyday thought rather than just poetic language; differs because conceptual metaphor is the umbrella term for all such mappings, while ontological metaphor is one specific class of them.
  • reification: Similar because both treat an abstraction as if it were a concrete thing; differs because reification is a philosophical term for the fallacy of treating abstractions as real objects, while ontological metaphor is a descriptive cognitive-linguistic term for how speakers do this in ordinary speech.
  • hypostatization: Similar because both name the act of treating an abstraction as a substance or entity; differs because hypostatization is a technical philosophical term, whereas ontological metaphor is the cognitive-linguistic label tied to Lakoff and Johnson's framework.
  • embodiment: Similar because both connect abstract thought to physical, bodily experience; differs because embodiment is the general theory that thought is grounded in bodily experience, while ontological metaphor is one specific mechanism by which that grounding occurs.
  • metonymy: Similar because both are conceptual mappings affecting how we think; differs because metonymy uses one entity to stand for another within the same domain (part for whole), while ontological metaphor maps a physical source onto an abstract target from a different domain.
