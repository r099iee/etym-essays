• warble: Similar because both describe musical, quavering bird song; differs because warble stresses melody with rapid variation, trill the rapid shaking between notes.
  • quaver: Similar because both mean tremulous sound; differs because quaver suggests trembling hesitation, trill a brisk controlled alternation.
  • twitter: Similar because both describe light bird sounds; differs because twitter is a series of short chirps, trill a continuous fast vibration.
  • chirp: Similar because both are bird calls; differs because chirp is a single short sharp note, trill a rapid run of notes.
  • roll: Similar because both (in phonetics) mean a vibrated consonant; differs because roll is colloquial for the rolled r, trill the precise phonetic term.
  • shake: Similar because both name a tremulous musical ornament; differs because shake is an older English name for the trill, now archaic.
  • vibrate: Similar because both mean rapid oscillation; differs because vibrate is general and mechanical, trill specifically musical and vocal.
