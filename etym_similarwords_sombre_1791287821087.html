• somber (US): Similar because it is the same word in American spelling; differs only in spelling, not meaning or register.
  • gloomy: Similar because it means dark and depressing; differs because it stresses low light and low spirits more than gravity.
  • grave: Similar because it means seriously solemn; differs because it stresses weight and importance rather than darkness.
  • solemn: Similar because it means dignified and serious; differs because it can be ceremonial and respectful, while sombre is more shadowed.
  • sober: Similar because it means serious and restrained; differs because it stresses lack of excess rather than darkness.
  • morose: Similar because it means sullen and gloomy; differs because it implies bad temper, while sombre can be merely serious.
  • lugubrious: Similar because it means mournfully gloomy; differs because it is more literary and exaggerated, almost theatrical.
  • funereal: Similar because it means like a funeral, dark and sad; differs because it explicitly evokes death rites.
  • dreary: Similar because it means dull and depressing; differs because it stresses monotony and weather more than dignity.
  • melancholy: Similar because it means pensive sadness; differs because it is more inward and wistful, while sombre can be outward bearing.
  • dour: Similar because it means stern and gloomy; differs because it is sterner, often Scottish, and implies obstinate grimness.
  • grim: Similar because it means stern and forbidding; differs because it is harsher and more frightening than sombre.
