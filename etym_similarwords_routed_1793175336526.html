• Defeated: Similar because both name victory over an enemy; differs because defeated is the neutral general term, while routed specifies shattering collapse and headlong flight.
  • Overwhelmed: Similar because both describe a force crushed beyond resistance; differs because overwhelmed stresses engulfing weight, like a wave, while routed stresses the resulting disintegration and pursuit.
  • Crushed: Similar because both mean destroyed as a fighting force; differs because crushed is grinding and total, while routed pictures the specific moment ranks break and men run.
  • Vanquished: Similar because both belong to heroic diction of utter conquest; differs because vanquished is lofty and final, the epic word, while routed is tactical, naming the battlefield mechanics of flight.
  • Scattered: Similar because a routed host is literally scattered across the countryside; differs because scattered only disperses, while routed adds defeat, terror, and pursuit to the dispersal.
  • Dispersed: Similar because both break up a gathered body; differs because dispersed can be neutral or even gentle, a crowd going home, while routed is always violent and shameful.
  • Annihilated: Similar because both erase an army as a force; differs because annihilated kills or destroys to nothing, while a routed army survives as fugitives — beaten men, not dead ones.
  • Repulsed: Similar because both turn attackers back; differs because repulsed drives off an assault with the enemy still formed, while routed means the enemy's formation itself has dissolved.
  • Put to flight: Similar because it is the literal definition of routing; differs because put to flight is the analytical phrase, while routed is the single hammer-blow word.
