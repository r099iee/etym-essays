PIE *meh₁- "to exert oneself, strive" (reconstructed; c. 4500–2500 BCE) — some authorities instead cite an o-grade base *mō- "will, spirit, mind"; the shape of the ultimate root is debated → Proto-Italic *mōs "custom, manner, will" (reconstructed) → Latin mōs, mōris "manner, custom, habit, humour, self-will" (attested from the 3rd c. BCE, e.g. Plautus) → Latin morōsus "full of one's own habits, self-willed, peevish, hard to please" (mōs + suffix -ōsus "full of"; attested 1st c. BCE, e.g. Cicero) → English morose (adjective, learned borrowing, first attested 1560s) ◄ TARGET Note on the root: the PIE antecedent of mōs is disputed. The standard reconstruction groups it with *meh₁- (exertion, will, spirit), matching the Germanic *mōdaz ("mind, heart, courage," giving English mood); some scholars instead derive mōs from *med- ("to measure, give counsel"), so the ultimate root is not securely fixed. The Proto-Italic and Latin stages are secure.
