• Spicy: similar because it suggests exciting, mildly indecent content; differs because it is more informal and often promises explicit gossip or sexual detail rather than literary vigour.
  • Risqué: similar because it means borderline indecent; differs because it is borrowed straight from French, sounds more refined, and usually refers to performance or humour rather than prose style.
  • Saucy: similar because it implies playful impropriety; differs because it is lighter, often affectionate, and can describe a person’s manner rather than a text.
  • Bawdy: similar because it means humour about sex; differs because it is earthier and more frankly coarse, with a long association with stage comedy.
  • Ribald: similar because it describes sexually explicit humour; differs because it is literary and stronger, suggesting gross or unrestrained coarseness.
  • Earthy: similar because it suggests frank, bodily language; differs because it is not necessarily sexual and often implies natural robustness.
  • Suggestive: similar because it hints at sexual meaning; differs because it is cooler and more clinical, describing the hinting rather than the lively effect.
  • Indecent: similar because it crosses propriety; differs because it is a stronger moral judgement, not a compliment.
  • Lewd: similar because it concerns sexual explicitness; differs because it is strongly disapproving and implies offensiveness.
  • Colourful: similar because it describes vivid, entertaining language; differs because it lacks any sexual implication.
  • Lively: similar because it means full of energy; differs because it says nothing about flavour or impropriety.
  • Spirited: similar because it suggests vigour and dash; differs because it emphasises courage or animation rather than piquancy.
  • Vigorous: similar because it describes forceful prose; differs because it stresses strength, not spice.
  • Pungent: similar because it means sharply flavoured or expressed; differs because it is primarily about smell or taste and can be negative.
  • Tangy: similar because it means sharply flavoured; differs because it is almost always literal about food and drink.
  • Zesty: similar because it suggests lively sharpness; differs because it is brighter and more cheerful, with no sexual overtone.
