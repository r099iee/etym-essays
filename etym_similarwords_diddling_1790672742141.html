• dawdling: Similar because it names wasting time; differs because dawdling stresses slowness, diddling stresses trivial fiddling.
  • dallying: Similar because it names idle trifling; differs because dallying often implies flirtation or delay, diddling implies fiddly busywork.
  • fiddling: Similar because it names aimless handling of details; differs because fiddling is purely manipulative, diddling adds cheating or pedantry.
  • twiddling: Similar because it names idle finger-play; differs because twiddling is physical and neutral, diddling is intellectual or roguish.
  • trifling: Similar because it names treating serious things lightly; differs because trifling is general, diddling is folksy and specific.
  • dabbling: Similar because it names amateur playing with a subject; differs because dabbling is dilettante interest, diddling is pettier and more dismissive.
  • pottering: Similar because it names amiable busywork; differs because pottering is affectionate, diddling is mildly contemptuous.
  • tinkering: Similar because it names fiddly adjustment; differs because tinkering aims at repair, diddling aims at nothing.
  • fudging: Similar because it names small dishonest adjustment; differs because fudging blurs figures, diddling cheats persons.
  • swindling: Similar because it names cheating; differs because swindling is serious fraud, diddling is petty and comic.
  • fleecing: Similar because it names cheating for money; differs because fleecing implies stripping bare, diddling implies nibbling.
  • short-changing: Similar because it names petty monetary cheating; differs because it is literal and transactional, diddling is broader.
  • pedantry: Similar because in this context it names fussy detail-mongering; differs because pedantry is rule-bound, diddling is aimless.
