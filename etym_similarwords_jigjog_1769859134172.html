• Trot: Similar because both denote a fast, regular gait; differs because a trot is a standardized, rhythmic two-beat diagonal horse gait, while jigjog stresses an irregular, jarring, uncoordinated bobbing.
  • Jolt: Similar because both describe a jerky, jarring movement; differs because a jolt is a single sudden shock, while jigjog is a continuous series of springy bounces.
  • Hobble: Similar because both denote an unsteady pace; differs because hobble implies lameness, pain, or impairment, while jigjog is energetic movement that is merely uncoordinated.
  • Clatter: Similar because both describe noisy, rattling movement; differs because clatter emphasizes the loud sound of feet or wheels striking a surface, while jigjog focuses on the bouncing motion itself.
  • Shuffle: Similar because both name an ungraceful walk; differs because shuffle is a dragging, sliding motion, while jigjog is a bouncy, up-and-down motion.
  • Jounce: Similar because both mean to move up and down with jolts; differs because jounce is a plain, neutral verb, while jigjog is a playful, onomatopoeic reduplication.
  • Bounce: Similar because both involve springy up-and-down movement; differs because bounce is general and often cheerful, while jigjog is specifically irregular, jolting, and comically ungraceful.
  • Jerk: Similar because both describe abrupt, irregular motion; differs because jerk is a sudden, isolated twitch, while jigjog is a continuous bouncing rhythm.
  • Jiggle: Similar because both suggest small, quick, light movement; differs because jiggle is usually small-amplitude and of a body part or object, while jigjog describes a whole pace or gait.
  • Waddle: Similar because both describe an ungainly way of moving; differs because waddle is the sideways, rocking walk of ducks or fat persons, while jigjog is an up-and-down bouncing.
  • Lope: Similar because both name an easy, bounding gait; differs because a lope is relaxed and smooth, while a jigjog is jerky and jolting.
  • Bob: Similar because both name an up-and-down motion; differs because bob is a single, simple vertical movement, while jigjog is a repeated, uneven, gait-like rhythm.
