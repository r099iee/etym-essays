• thoroughly: Similar because it denotes completeness of degree; differs because it lacks any bodily image or comic slang register.
  • completely: Similar because it signals totality; differs because it is neutral and formal, without the surfeit or irritation nuance.
  • utterly: Similar because it intensifies to the limit; differs because it is more formal and does not imply accumulated provocation.
  • entirely: Similar because it means fully; differs because it describes wholeness rather than saturation to a physical limit.
  • to the hilt: Similar because it uses a physical-limit metaphor for totality; differs because it suggests committed support rather than irritated surfeit.
  • up to the eyes: Similar because it maps excess onto body-part fullness; differs because it usually describes busyness or involvement, not pique.
  • fed up to the back teeth: Similar because it expresses exasperated surfeit with an anatomical endpoint; differs because it stresses weariness rather than acute pique.
  • to the core: Similar because it means through and through; differs because it suggests depth of character rather than overflow to the throat.
  • soundly: Similar because it can intensify annoyance or defeat; differs because it lacks humour and physical imagery.
  • deeply: Similar because it marks strong feeling; differs because it implies inward depth rather than upward fullness.
