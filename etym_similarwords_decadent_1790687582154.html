• degenerate: Similar because both name decline from a better state; differs because degenerate implies loss of type or stock (biological-moral corruption), harsher and more clinical than decadent.
  • effete: Similar because both allege enervated overrefinement; differs because effete stresses exhausted sterility (no longer productive), while decadent stresses rich excess.
  • dissolute: Similar because both name loose, indulgent morals; differs because dissolute targets personal conduct (drink, dissipation), while decadent can describe whole cultures and styles.
  • debauched: Similar because both evoke sensual excess; differs because debauched implies active corruption and orgiastic behaviour, stronger than decadent’s languor.
  • corrupt: Similar because both name rot within; differs because corrupt centres on dishonesty and venality (bribes, power), while decadent centres on luxury and decline.
  • declining: Similar because both name downward movement; differs because declining is the neutral descriptive term, while decadent adds moral-aesthetic judgment and ripeness.
  • overripe: Similar because both image maturity tipping into rot; differs because overripe is metaphorical and gentle (fruit, styles), lacking decadent’s moral history.
  • self-indulgent: Similar because both name pampering of appetite; differs because self-indulgent is everyday psychology, while decadent historicises the indulgence as civilisational symptom.
  • sybaritic: Similar because both name devoted luxury; differs because sybaritic admires or neutrally describes pleasure-loving (from Sybaris), while decadent judges it as decline.
  • hedonistic: Similar because both pursue pleasure; differs because hedonism is a philosophy or lifestyle choice, while decadence is a historical-cultural condition.
  • fin-de-siècle: Similar because both evoke exquisite late-period style; differs because it is period-specific (1890s) and often admiring, while decadent spans eras and judges.
  • waning: Similar because both name fading vigour; differs because waning is astronomical-neutral (moon, powers), without moral or aesthetic content.
  • enervated: Similar because both allege sapped vitality; differs because enervated stresses weakness and listlessness, while decadent stresses richness amid the weakness.
