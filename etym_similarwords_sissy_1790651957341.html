• coward: Similar because it denotes fearfulness and avoidance of risk; differs because it lacks the gendered, effeminacy-based insult and is a neutral moral judgement.
  • wimp: Similar because it mocks weakness and timidity; differs because it stresses physical feebleness rather than femininity and is slightly less gendered.
  • pansy: Similar because it insults a man as effeminate and flower-like; differs because it draws on floral delicacy imagery and carries a stronger homophobic history.
  • softie: Similar because it denotes gentleness and easy tears; differs because it is affectionate or teasing rather than contemptuous.
  • mama's boy: Similar because it shames a male as dependent and unmanly; differs because it targets attachment to mother rather than sister-like femininity.
  • crybaby: Similar because it mocks tearfulness and complaint; differs because it focuses on whining and can apply to any gender or age without effeminacy charge.
  • weakling: Similar because it denotes lack of strength or toughness; differs because it is physical and ungendered, without the diminutive sister-based sting.
  • chicken: Similar because it taunts cowardice; differs because it uses animal imagery and dares to action rather than impugning manhood via femininity.
  • effeminate: Similar because it describes feminine-presenting males; differs because it is a formal descriptive adjective, not a schoolyard noun-insult.
  • namby-pamby: Similar because it dismisses something as feebly sentimental; differs because it targets wishy-washy speech or sentiment, often for things rather than boys.
