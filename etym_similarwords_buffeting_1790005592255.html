• battering: Similar because both mean repeated heavy blows; differs because battering implies heavier damage and destruction, buffeting implies survivable rhythmic blows.
  • pounding: Similar because both describe rhythmic beating (waves pounding, winds buffeting); differs because pounding stresses weight and noise, buffeting stresses being knocked about.
  • pummelling / pommeling: Similar because both mean beating with fists; differs because pummelling is continuous fist assault, buffeting is often environmental and intermittent.
  • beating: Similar because generic repeated striking; differs because beating is neutral-general, buffeting is specifically blunt, repeated, and often weather-driven.
  • lashing: Similar because wind and rain lash as they buffet; differs because lashing evokes whip-like cutting strokes, buffeting evokes blunt thuds.
  • whipping: Similar because source pairs them (buffeting, whipping tears); differs because whipping stresses thin swift strokes that sting, buffeting stresses broad blows that shake.
  • knocking about: Similar because both imply tossing and disorientation; differs because knocking about is colloquial and general, buffeting is literary-technical.
  • harrying / harassing: Similar because both describe relentless assault; differs because harrying is tactical worrying, buffeting is physical pounding.
  • assailing: Similar because both mean attacking repeatedly; differs because assailing is formal-military, buffeting is tactile-meteorological.
  • rocking / shaking: Similar because buffeting shakes structures (aircraft buffeting); differs because rocking/shaking describe motion result, buffeting names the blows causing it.
