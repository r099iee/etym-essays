• mattock: Similar because it is a hand digging tool with a handle and cross-blade; differs because it is heavier with pick/axe ends for breaking hard ground, not shallow weeding.
  • pickaxe: Similar because it breaks and tills earth by striking; differs because it uses pointed ends for hard rock and deep breaking, not surface cultivation.
  • spade: Similar because it is a core hand tillage implement; differs because it cuts and lifts soil with a foot-driven blade for digging, not scraping.
  • shovel: Similar because it moves and tills soil by hand; differs because it scoops and lifts rather than chops and scrapes weeds.
  • trowel: Similar because it is a small hand cultivation tool; differs because it is one-handed for transplanting and close work, not standing row work.
  • rake: Similar because it is a long-handled soil-working tool; differs because it levels, gathers, and smooths with teeth, not cutting weed roots.
  • harrow: Similar because it stirs soil and kills weeds; differs because it is animal- or tractor-drawn with spikes/discs, not a hand tool.
  • plough / plow: Similar because it is the classic tillage implement contrasted with hoe-culture; differs because it inverts furrows deeply with animal or machine power.
  • cultivator: Similar because it loosens soil and destroys weeds between rows; differs because it usually has multiple tines and is often mechanized.
  • dibber / dibble: Similar because it is a primitive hand planting tool in hoe-cultures; differs because it pokes holes for seed, not tilling.
  • to weed: Similar because hoeing largely means weeding; differs because it is the task, not the instrument, and can be done by hand-pulling.
  • to till: Similar because hoeing is a form of tilling; differs because tilling covers all soil preparation including ploughing.
