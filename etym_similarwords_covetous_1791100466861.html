• greedy: Similar because both want excessively; differs because greedy wants more of anything, covetous specifically craves another's possessions.
  • acquisitive: Similar because both seek to acquire; differs because acquisitive can be neutral-collecting, covetous is morally wrongful.
  • avaricious: Similar because both love money immoderately; differs because avaricious hoards wealth, covetous eyes others' wealth.
  • rapacious: Similar because both seize graspingly; differs because rapacious is violent and predatory, covetous may be silent eyeing.
  • grasping: Similar because Dickens pairs them and both clutch; differs because grasping stresses the hand's action, covetous stresses the heart's desire.
  • envious: Similar because both are pained by another's good; differs because envious resents, covetous additionally wants to take.
  • jealous: Similar because both involve possessive desire; differs because jealous fears losing one's own, covetous wants another's.
  • desirous: Similar because both long for; differs because desirous can be innocent, covetous is always illicit.
  • craving: Similar because both hunger; differs because craving is visceral urge, covetous is moral judgment on that urge.
  • materialistic: Similar because both prize possessions; differs because materialistic is a worldview, covetous is an act of envy.
  • mercenary: Similar because both serve gain; differs because mercenary sells services for money, covetous lusts after others' goods.
  • wrenching / scraping / clutching: Similar because Dickens's cluster shares squeezing imagery; differs because those are verbs of motion, covetous is the character trait behind them.
