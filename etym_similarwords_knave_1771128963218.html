• Rogue: Similar because both denote a dishonest, roguish man; differs because rogue can be charming and romanticized, while knave is base and contemptible without charm.
  • Scoundrel: Similar because both denote an unprincipled, dishonorable man; differs because scoundrel is general and modern, while knave carries archaic class-based baseness ("low-born servant-boy").
  • Rascal: Similar because both can mean a mischievous or dishonest person; differs because rascal is lighter and often affectionate, while knave is a harsher moral condemnation.
  • Villain: Similar because both denote a wicked person; differs because villain is grander and more serious, while knave implies petty, sneaky baseness and servant-class heritage.
  • Varlet: Similar because both began as "boy-servant" and became insults; differs because varlet is rarer, more archaic, and lighter, while knave is harsher and better known.
  • Blackguard: Similar because both denote a contemptible low fellow; differs because blackguard is more theatrical and violent, while knave stresses deceit and petty dishonesty.
