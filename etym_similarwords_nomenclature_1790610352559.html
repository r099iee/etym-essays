• terminology: Similar because it means specialized words of a field; differs because it includes all technical terms and concepts, while nomenclature focuses specifically on naming and classification systems.
  • taxonomy: Similar because it concerns classification and naming of organisms or items; differs because it emphasizes hierarchical ordering, whereas nomenclature emphasizes the names and rules themselves.
  • classification: Similar because it organizes entities into groups; differs because it is the logical division, not necessarily the naming code.
  • vocabulary: Similar because it is a stock of words; differs because it is general and individual, while nomenclature is systematic and authorized.
  • lexicon: Similar because it is the word-stock of a language or field; differs because it is linguistic and descriptive rather than regulatory.
  • jargon: Similar because it denotes specialized language; differs because it is often pejorative and informal, while nomenclature claims official precision.
  • glossary: Similar because it lists terms with definitions; differs because it is a documentary aid, not the naming system itself.
  • onomastics: Similar because it studies names and naming; differs because it is the scholarly discipline, not the set of names.
  • designation: Similar because it is an official name or title; differs because it is a single act of naming rather than a whole system.
  • codification: Similar because it implies systematic rule-making; differs because it applies to laws or rules generally, not specifically names.
