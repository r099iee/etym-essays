• Conciseness: Similar because it denotes expressing much in few words; differs because it stresses density of content while brevity stresses shortness of form or time.
  • Terseness: Similar because it denotes polished shortness; differs because it adds a brusque, finished edge, while brevity can be plain and open.
  • Succinctness: Similar because it denotes orderly compression; differs because it implies neat packaging, while brevity simply implies little extent.
  • Pithiness: Similar because it denotes forceful compactness; differs because it requires substantive vigour, while a brevity can be empty or merely short.
  • Laconicism: Similar because it denotes Spartan few-wordedness; differs because it implies deliberate reticence of character, while brevity is a property of texts or durations.
  • Curtess: Similar because it denotes shortness of speech; differs because curtness is rude and abrupt (often spelled curtness), while brevity is neutral or praiseworthy.
  • Epigrammaticism: Similar because it denotes witty compactness; differs because it demands pointed cleverness, while brevity demands only shortness.
  • Transience: Similar because it captures brevity of time; differs because it stresses fleetingness and passing away, while brevity stresses measurable shortness.
