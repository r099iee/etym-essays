• Nothing: Similar because it is the direct modern equivalent meaning not anything; differs because nothing is the neutral everyday word while naught is archaic and literary outside fixed idioms.
  • Nought: Similar because it is the same historical word and still means zero or nothing; differs because nought is now the British spelling for the mathematical cipher while naught carries the literary nothing sense.
  • Nil: Similar because both name zero or nothing, especially in scores; differs because nil is a clipped Latin borrowing used in sport and technical registers while naught belongs to proverb and poetry.
  • Zero: Similar because both can name the number 0 and by extension utter failure; differs because zero is the precise mathematical term while naught is evocative and moralising rather than exact.
  • None: Similar because both deny existence or amount; differs because none answers how many or how much of a stated set while naught declares absolute nothingness.
  • Null: Similar because both describe absence of value or effect; differs because null is legal and technical (null and void) while naught is literary and idiomatic.
  • Void: Similar because both evoke emptiness and ineffectiveness; differs because void stresses an empty space or cancelled force while naught stresses the outcome being nothing.
  • Aught: Similar because it is the positive twin from which naught is built, completing the anything-nothing pair; differs because aught means anything at all, the exact opposite in polarity.
  • Trifle: Similar because to set something at naught is to treat it as a trifle; differs because trifle is a small thing of little value while naught is no thing at all.
