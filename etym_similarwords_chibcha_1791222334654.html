• Muisca: Similar because the same highland people; differs because Muisca is the self-name (people/person), Chibcha the Spanish book-name.
  • Mosca: Similar because colonial variant for the same people; differs because archaic spelling in missionary grammars.
  • Chibchan peoples: Similar because wider family including U'wa and Kogi; differs because Chibcha alone often means just the Muisca.
  • Tairona: Similar because neighbouring Colombian high civilization and goldworkers; differs because Sierra Nevada coastal culture, not Bogotá plateau.
  • Quimbaya: Similar because Colombian goldworking culture; differs because Middle Cauca region, famed for lost-wax poporos.
  • Tolima: Similar because Colombian archaeological culture; differs because Magdalena valley, distinct ceramics.
  • U'wa: Similar because living Chibchan-speaking group; differs because eastern Andes cloud forest, still spoken language.
  • Kogi (Kogui): Similar because Chibchan descendants; differs because Sierra Nevada, preserved priestly tradition.
  • Bari-Motilón: Similar because Chibchan family members; differs because Perijá lowlands, different history.
  • Inca: Similar because Andean intensive agricultural empire; differs because Peruvian Quechua empire far larger and southern.
  • Arawak: Similar because northern South American Indigenous stock; differs because Arawakan is a separate, larger lowland family.
  • Guane: Similar because Chibchan-affiliated neighbours of Santander; differs because distinct chiefdom, absorbed earlier.
