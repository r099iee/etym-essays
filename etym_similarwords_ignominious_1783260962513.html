• Shameful: Similar because both denote disgrace; differs because shameful is plainer and more inward, pointing to an act that should cover the agent with shame, without the public loss of name.
  • Disgraceful: Similar because both mean dishonouring; differs because disgraceful stresses the public loss of favour or standing, the falling from grace, rather than the loss of one's good name.
  • Dishonorable: Similar because both describe a breach of what honour demands; differs because dishonorable weighs against a code of honour (personal or national), while ignominious stresses the public degradation of reputation itself.
  • Humiliating: Similar because both describe a lowering of dignity; differs because humiliating is psychological, about what the sufferer feels, while ignominious is about public verdict and reproach.
  • Infamous: Similar because both mean notoriously disgraced; differs because infamous goes further, implying public fame for badness, while ignominious need not carry such notoriety.
  • Degrading: Similar because both denote a lowering of worth or status; differs because degrading is a general term for anything that reduces dignity, while ignominious specifically marks the loss of a good name in public.
  • Debasing: Similar because both denote a reduction in moral standing; differs because debasing emphasizes the corruption of character or value, while ignominious emphasizes external shame and reputational ruin.
  • Contemptible: Similar because both denote what deserves scorn; differs because contemptible focuses on the meanness of the act itself, while ignominious focuses on the public shame it brings.
  • Discreditable: Similar because both denote damage to reputation; differs because discreditable is milder and more provisional, while ignominious implies lasting, public disgrace.
  • Mortifying: Similar because both denote acute embarrassment; differs because mortifying is intensely personal and psychological, while ignominious is institutional and public.
  • Abject: Similar because both describe a state of shame and lowliness; differs because abject stresses utter degradation of condition, while ignominious stresses the loss of name and honour.
