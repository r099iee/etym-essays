• Clenched: Similar because both describe a tightly closed fist; differs because clenched stresses the hard, closed grip and is the most common word for an angry hand, while balled emphasizes roundness — the hand become a sphere.
  • Fisted: Similar because both describe the hand as a fist; differs because fisted is blunter and without the image of curvature, whereas balled keeps the shape of a ball.
  • Curled: Similar because both describe a hand gathered inward; differs because curled suggests a gentler, less aggressive gathering, while balled is hard, compact, and almost weapon-like.
  • Knotted: Similar because both describe tense muscular bunching; differs because knotted evokes painful bunches of muscle — a spasm — while balled is a clean sphere, a fist rounded into readiness.
  • Folded: Similar because both describe the hands disposed in a pose; differs because folded is passive and weak — arms crossed or hands loosely joined — the opposite of the tight, stored energy of balled.
  • Bunched: Similar because both describe things gathered closely together; differs because bunched is looser and applies to fabric or people crowding, while balled is a tight, rounded, spherical compression.
  • Squeezed: Similar because both describe compression; differs because squeezed implies external pressure on something, while balled is a self-gathering — the hand forming itself into a sphere from within.
  • Gripped: Similar because both describe a hand under tension; differs because gripped implies holding onto something — an object or a surface — while balled describes the hand alone, clenched around nothing but itself.
  • Doubled: Similar because both describe a hand made compact ("doubled fist"); differs because doubled emphasizes the folding over itself, while balled emphasizes the rounded spherical shape achieved.
  • Contracted: Similar because both describe a muscle shortened and tensed; differs because contracted is clinical and anatomical, while balled is concrete and colloquial — a hand shaped into a ball.
