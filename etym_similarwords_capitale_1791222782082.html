• capital: Similar because it is the direct modern reflex meaning principal wealth; differs because capital is English everyday-economics, while capitale is the Latin etymon.
  • principal: Similar because it means main sum as opposed to interest; differs because principal is financial-legal English, while capitale is Latin stock.
  • stock: Similar because stock is inventory that breeds increase; differs because stock is Germanic-commercial, while capitale is Latin-juridical.
  • property: Similar because capitale meant property; differs because property is general, while capitale stresses head-count principal.
  • assets: Similar because assets are owned resources; differs because assets is balance-sheet modern, while capitale is agrarian origin.
  • funds: Similar because funds are money put to use; differs because funds implies earmarked sums, while capitale implies breeding stock.
  • principal (loan): Similar because loan principal mirrors capitale vs usura; differs only in modern specificity.
  • corpus (fund): Similar because corpus is principal kept intact; differs because corpus is body-metaphor, while capitale is head-metaphor.
  • estate: Similar because estate is total holdings; differs because estate includes land, while capitale prototypically is movables-herd.
  • holdings: Similar because holdings are what is held; differs because holdings is neutral-modern, while capitale is historical.
  • livestock: Similar because capitale was counted in beasts; differs because livestock names animals, while capitale names their value.
  • chattel: Similar because chattel continues capitale via French; differs because chattel is movables-law, while capitale is the Latin source.
  • cattle: Similar because cattle continues Norman catel from capitale; differs because cattle is now animals only, while capitale is value-stock.
