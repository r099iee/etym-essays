• Baize: Similar because both are dense napped woollen cloths for covering; differs because baize is woven and dyed green for tables and doors, while felt is unwoven matting for hats and yurts.
  • Flannel: Similar because both are soft warm woollen fabrics; differs because flannel is loosely woven and brushed, suiting shirts and suits, while felt has no weave at all.
  • Tweed: Similar because both are hardy rustic woollens of country life; differs because tweed is a woven patterned suiting, while felt is plain pressed matting.
  • Serge: Similar because both clothe working folk and uniforms durably; differs because serge is a smooth twill weave, while felt is a weaveless mat.
  • Blanketing: Similar because both are thick fulled woollens against cold and weather; differs because blanketing is loom-woven for beds and coats, while felt is fulled straight from loose fibre.
  • Fleece: Similar because both keep shepherds warm from the same sheep; differs because fleece names the raw shorn wool or its modern synthetic echo, while felt names wool already beaten into cloth.
  • Wadding: Similar because both pad and insulate with matted fibre; differs because wadding is loose stuffing hidden inside quilts, while felt is a firm sheet used openly.
  • Melton: Similar because both are dense fulled woollen cloths with a matted face; differs because melton is loom-woven then heavily fulled for coats and uniforms, while felt skips the loom entirely.
  • Sensed: Similar because as past of feel, felt overlaps all perception verbs; differs because sensed is detached detection, while felt carries warmth, sympathy, and bodily immediacy.
