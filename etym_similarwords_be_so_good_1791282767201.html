• Be so kind: Similar because it frames a request as kindness; differs because kind stresses benevolence of disposition, while good stresses general virtue and compliance.
  • Be so obliging: Similar because it asks favour in courteous terms; differs because obliging explicitly names putting oneself out, more self-abasing than good.
  • Be good enough: Similar because it equates compliance with goodness; differs because good enough can sound slightly more impatient and less grand than be so good.
  • Please: Similar because it softens an imperative into a request; differs because please is neutral and universal, while be so good is formal, dated and class-marked.
  • Kindly: Similar because kindly + imperative (kindly shut the door) issues polite orders; differs because kindly is terser and more bureaucratic, lacking the compliment structure.
  • Would you mind: Similar because it phrases command as question; differs because it offers notional refusal (mind = object), while be so good assumes goodness will comply.
  • Could you possibly: Similar because it hedges a command with modality; differs because it pleads ability and possibility, while be so good pleads virtue.
  • Do me the favour: Similar because it casts obedience as favour; differs because favour names the debt openly, while be so good disguises it as character.
  • I would be obliged if: Similar because it trades compliance for gratitude; differs because it promises reciprocal obligation, while be so good merely praises.
  • Pray (do): Similar because pray + imperative (pray tell me) is an archaic softener; differs because pray begs earnestly, while be so good flatters.
  • Will you kindly: Similar because it combines volition with kindness; differs because it can sound peremptory-official, while be so good sounds clubman-genteel.
  • If you please: Similar because it appends deference to a command; differs because it is postposed and more servile in tone than the magisterial be so good.
