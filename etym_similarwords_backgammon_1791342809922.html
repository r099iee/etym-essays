• Tables: Similar because it is the direct historical family of medieval board games from which backgammon evolved; differs because tables is the archaic generic ancestor term covering various rule configurations without the doubling cube or specific modern backgammon bearing-off rules.
  • Tavla: Similar because it is the popular Turkish, Greek, and Middle Eastern variant played on the identical board; differs because tavla uses different opening setups, forbids the doubling cube, moves at lightning speed, and carries distinct Mediterranean coffeehouse traditions.
  • Checkers (Draughts): Similar because it uses flat round discs on a divided board; differs because checkers is played on an eight-by-eight grid of alternating squares, involves diagonal hopping captures, contains zero dice or elements of chance, and is entirely deterministic.
  • Chess: Similar because it is an ancient two-player intellectual board game; differs because chess features differentiated pieces with unique movements, zero randomness, and aims at king entrapment rather than a linear race to bear off pieces.
  • Pachisi (Ludo): Similar because it is a dice-driven cross-and-circle race game where pieces can be struck back to start; differs because Pachisi is played on a cruciform board by up to four players and lacks the complex tactical blocking, prime-building, and doubling mechanics of backgammon.
  • Go: Similar because it is an ancient strategy board game; differs because Go is played with black and white stones on a grid of intersections, focuses on territorial encirclement, and contains no dice or race elements.
  • Mancala: Similar because it is an ancient pit-and-pebble counting game; differs because Mancala involves rhythmic sowing of seeds around hollowed pockets without dice or linear bearing off.
  • Gammon: Similar because it represents a victory condition within the identical game; differs because a gammon is a double-value win where the loser has borne off no checkers, whereas a backgammon is a triple-value win where the loser also has checkers on the bar or in the winner’s home board.
  • Dominoes: Similar because it is a traditional tabletop game combining chance (tile draw) and strategy; differs because dominoes uses spotted rectangular tiles matched end-to-end rather than checkers racing on a marked board.
  • Cribbage: Similar because it is a classic British parlor game scored on a peg-board; differs because cribbage is fundamentally a card game where the board merely tracks accumulated points rather than hosting tactical combat.
  • Senet: Similar because it is the ancient Egyptian thirty-square race game using casting sticks; differs because Senet is an archaic precursor with distinct religious symbolism and layout, obsolete for thousands of years.
  • Royal Game of Ur: Similar because it is the ancient Mesopotamian twenty-square race game using tetrahedral dice; differs because it is a museum-piece antiquity whose full original rules were lost until modern archaeological decipherment.
