• Sullen: Similar because it is a gloomy, withdrawn state; differs because sullen implies resentful, hostile brooding that may break out in sulks, while glum is silent and passive without hostility.
  • Morose: Similar because it is gloomily dejected; differs because morose suggests a bitter, ill-tempered gloominess that colours dealings with others, while glum keeps the misery to oneself.
  • Dejected: Similar because it is cast down in spirits; differs because dejected is sadder but softer, the spirits cast down by disappointment, without the heavy, lowered look that glum implies.
  • Melancholy: Similar because it is a low, gloomy state; differs because melancholy adds a pensive, reflective, sometimes lasting tinge, while glum is a plain, silent, temporary sourness.
  • Gloomy: Similar because both describe a dark, low state; differs because gloomy leans toward darkness of atmosphere and outlook, while glum focuses on the silent, sullen face and mood.
  • Downcast: Similar because both describe low spirits; differs because downcast focuses on the physical dropped gaze and appearance, while glum names the whole sullen demeanour.
  • Dour: Similar because it is a grim, sternly gloomy state; differs because dour is Scottish and implies an unyielding, severe severity, while glum is softer and more passively sorrowful.
  • Moody: Similar because both describe a low, changeable state of feeling; differs because moody stresses sudden changes and temperament, while glum is a steady, silent dejection.
  • Surly: Similar because both describe a bad-tempered, withdrawn manner; differs because surly implies active rudeness and irritability, while glum is wordless and passive.
  • Lugubrious: Similar because it is a mournful, gloomy state; differs because lugubrious is theatrical and exaggerated in its mournfulness, while glum is quiet and understated.
  • Crestfallen: Similar because it describes dejection after disappointment; differs because crestfallen pictures a visibly deflated posture after a specific setback, while glum is a general brooding mood.
