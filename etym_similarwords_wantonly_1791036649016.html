• Deliberately: Similar because it means intentionally; differs because it lacks the moral condemnation of unjustifiability.
  • Wilfully: Similar because it means on purpose with stubborn persistence; differs because it stresses obstinacy rather than cruelty or waste.
  • Recklessly: Similar because it means without care for consequences; differs because it emphasizes risk-taking rather than motiveless malice.
  • Maliciously: Similar because it means with intent to harm; differs because malice requires spite, while wantonly can be mere indifference.
  • Cruelly: Similar because it involves causing suffering; differs because cruelty stresses enjoyment of pain, wantonness stresses lack of justification.
  • Arbitrarily: Similar because it means without reason or principle; differs because it is bureaucratic and cold, not necessarily destructive.
  • Gratuitously: Similar because it means uncalled-for and excessive; differs because it is often used for insults or violence that add nothing.
  • Needlessly: Similar because it means without need; differs because it is milder and purely practical, without moral outrage.
  • Shamelessly: Similar because it means without restraint or decency; differs because it stresses loss of honour rather than harm.
  • Lasciviously (archaic overlap): Similar because historic wanton included lewdness; differs because modern wantonly rarely means sexual.
  • Extravagantly: Similar in the wasteful sense; differs because extravagance can be generous or splendid, not necessarily blameworthy.
