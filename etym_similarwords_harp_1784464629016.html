• Lyre: Similar because both are ancient, plucked string instruments of courtly and poetic prestige; differs because the lyre is smaller, with a yoke frame (two arms and a crossbar) and a Greek/classical pedigree, while the harp has a full triangular or arched frame with strings rising in an open plane.
  • Zither: Similar because both are plucked string instruments; differs because a zither lies flat on a table or the lap, its strings stretched over a board, with no standing frame and no pillar.
  • Lute: Similar because both are plucked instruments of old and high music; differs because the lute is fretted, pear-shaped, with a rounded back and a neck, played with fingers or plectrum, whereas the harp has open unfretted strings in a frame.
  • Psaltery: Similar because it is a medieval plucked string instrument; differs because the psaltery is a flat, zither-like box with strings plucked or struck, without the harp's standing frame.
  • Cithara: Similar because it was a large plucked instrument of classical antiquity associated with lyric poetry; differs because it is a yoke-framed lyre-type, not a triangular frame harp.
  • Viol: Similar because both are instruments of the old European high-music tradition and appear together in Tolkien's scene; differs because the viol is bowed and fretted, with a flat back and consort tuning, while the harp is plucked with open strings.
  • Fiddle / Violin: Similar because both are string instruments of traditional and art music; differs because they are bowed and unfretted, with four strings and a neck, not plucked open strings in a frame.
  • Kantele: Similar because it is a Nordic plucked instrument of bardic tradition; differs because the kantele is a zither-type lying flat, with few strings, not a frame harp.
  • Kora: Similar because it is a plucked, harp-like West African instrument with a gourd resonator; differs because the kora is a bridge-harp-lute hybrid with two planes of strings and a different playing technique and cultural tradition.
  • Guitar: Similar because both are plucked string instruments of popular and art music; differs because the guitar is fretted, with a neck and fingerboard and a body played horizontally, not a framed harp.
