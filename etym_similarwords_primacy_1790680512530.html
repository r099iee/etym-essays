• supremacy: Similar because it means highest authority; differs because it stresses absolute superiority and often military or legal finality.
  • hegemony: Similar because it means dominance; differs because it implies leadership over allies and ideological consent, often Greek-coined and academic.
  • dominance: Similar because it means prevailing power; differs because it is broader (biology, markets) and more force-based.
  • preeminence: Similar because it means outstanding distinction; differs because it stresses excellence rather than command.
  • priority: Similar because it concerns coming first; differs because it is sequential and procedural (queues, tasks).
  • precedence: Similar because it governs ordering; differs because it is rule-bound (protocol, heraldry).
  • superiority: Similar because it asserts higher standing; differs because it is comparative and often quantitative.
  • ascendancy: Similar because it means rising dominance; differs because it stresses the process of gaining power.
  • sovereignty: Similar because it names supreme authority; differs because it is legal-territorial.
  • leadership: Similar because it implies going first; differs because it is personal and guiding rather than structural.
  • predominance: Similar because it means prevailing; differs because it is statistical (most numerous or influential).
  • primacy effect (collocation): Similar because it uses the same root sense; differs because it is a technical memory term.
