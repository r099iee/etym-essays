• standard: Similar because it denotes a benchmark for judgment; differs because it is more formal and institutional, less tied to equality.
  • norm: Similar because it denotes expected average behaviour; differs because it is sociological and statistical, without face-value sense.
  • average: Similar because it denotes typical level; differs because it is mathematical mean, while par is normative expectation.
  • equal: Similar because it denotes sameness of level; differs because it is adjective of identity, while par is noun of benchmark.
  • equivalence: Similar because it denotes equal value; differs because it is abstract and technical, longer and formal.
  • benchmark: Similar because it denotes reference point; differs because it implies measured comparison for improvement.
  • criterion: Similar because it denotes standard for judgment; differs because it is a rule applied, often plural criteria.
  • model: Similar because it denotes exemplar; differs because it implies imitation, not just equality.
  • mean: Similar because it denotes middle value; differs because it is statistical, not idiomatic for health or golf.
