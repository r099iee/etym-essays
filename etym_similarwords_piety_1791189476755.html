• devoutness: Similar because both mean earnest religious dedication; differs because devoutness stresses heartfelt earnestness, piety stresses dutiful reverence.
  • godliness: Similar because both denote holy living; differs because godliness stresses God-like character, piety stresses worshipful duty.
  • holiness: Similar because both imply sacred purity; differs because holiness stresses separation from sin, piety stresses reverent observance.
  • devotion: Similar because both mean loving dedication; differs because devotion is broader (person, cause), piety is specifically religious or filial duty.
  • reverence: Similar because both mean deep respect; differs because reverence is attitude of awe, piety is reverence enacted as duty.
  • veneration: Similar because both honour the sacred; differs because veneration stresses worshipful honour, piety stresses obedient duty.
  • sanctity: Similar because both evoke sacredness; differs because sanctity is state of being holy, piety is practice of honouring holiness.
  • religiosity: Similar because both describe religious observance; differs because religiosity often implies excessive or showy observance, piety can be quiet and sincere.
  • sanctimony: Similar because both display moral uprightness; differs because sanctimony is always hypocritical pretence, piety may be genuine.
  • filial duty: Similar because both honour parents; differs because filial duty is specific kin obligation, piety generalizes it to gods and traditions.
  • faithfulness: Similar because both imply loyal adherence; differs because faithfulness stresses constancy, piety stresses reverent duty.
  • obedience: Similar because both submit to higher authority; differs because obedience is compliance with command, piety is loving reverent compliance.
