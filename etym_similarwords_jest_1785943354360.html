• Joke: Similar because both name a humorous remark or prank — the everyday core sense of jest; differs because "joke" is neutral, modern, and far more frequent, while "jest" is literary, formal, or deliberately archaic and can carry overtones of courtly wit.
  • Quip: Similar because both denote a witty remark; differs because a quip is a sharp, clever, swift comeback, whereas a jest may be a story, a wordplay, or general playful banter with no pointed edge.
  • Witticism: Similar because both are humorous remarks; differs because a witticism foregrounds verbal cleverness and intellectual brilliance, while a jest can be simple, silly, or physical.
  • Banter: Similar because both involve playful, teasing exchange; differs because banter is a sustained two-way raillery between people, while a jest is a single joke, remark, or playful act.
  • Pleasantry: Similar because both are light, polite humorous remarks; differs because pleasantries are conventionally polite small-talk and never sharp or pointed, while a jest can be teasing or even barbed.
  • Gibe / jibe: Similar because both can be a mocking remark; differs because a gibe is a taunt aimed to wound or mock, whereas a jest is fundamentally playful and not meant to hurt.
  • Jeer: Similar because both are remarks made at someone; differs because a jeer is a hostile, contemptuous taunt (as of a crowd), the opposite of a jest's good humour.
  • Wisecrack: Similar because both are quick, humorous remarks; differs because "wisecrack" is informal, American, and flippant, with none of "jest"'s literary or historical weight.
  • Gag: Similar because both are jokes; differs because "gag" is stage and vaudeville slang for a routine joke line, while "jest" is literary and non-professional.
  • Prank / practical joke: Similar because both are playful, non-serious acts, and "prank" can be an occasional synonym; differs because a prank is a physical practical trick played on someone, while a jest is primarily verbal.
  • Fun / sport: Similar because both express playfulness and amusement, the spirit of jest; differs because "fun" is an abstract mass-noun for amusement and "sport" (in the "play" sense) a game-like activity, whereas a jest is a concrete remark or act.
  • Fooling / clowning: Similar because both name playful, unserious behaviour, as with a jester; differs because fooling and clowning describe comic performance and buffoonery, whereas jest names the witty remark itself.
  • Jesting (gerund): Similar because it is the action noun of the same verb; differs because it names the activity ("jesting and laughter") rather than a single joke.
  • In jest = as a joke: Similar because the phrase means "not seriously"; differs because it is a fixed adverbial idiom, not a noun for the remark itself.
