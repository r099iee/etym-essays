• hail: Similar because it is hard ice falling from the sky; differs because hailstones are larger layered ice from thunderstorms, while sleet is smaller winter mix.
  • snow: Similar because it is frozen winter precipitation; differs because snow is soft crystals that drift, while sleet is wet and stings.
  • freezing rain: Similar because it is rain that freezes on contact; differs because it falls as liquid and ices surfaces, while sleet falls already partly frozen.
  • ice pellets: Similar because in America this IS sleet; differs because as a phrase it is technical and precise, while sleet is everyday.
  • graupel: Similar because it is soft snow pellets; differs because it is technical, fragile, and crushable, while sleet is icier and harder.
  • slush: Similar because it is half-melted snow-water mix; differs because slush lies on the ground, while sleet falls from the sky.
  • drizzle: Similar because it is light wet precipitation; differs because drizzle is fine liquid mist, with no ice or sting.
  • wintry shower: Similar because forecasters use it for sleet-snow bursts; differs because it describes the event pattern, not the particle type.
  • blizzard: Similar because it is violent winter precipitation; differs because it stresses wind and snow volume, not icy mixture.
  • hailstorm: Similar because icy particles bombard; differs because it is a summer convective storm with large stones, not winter transition fall.
