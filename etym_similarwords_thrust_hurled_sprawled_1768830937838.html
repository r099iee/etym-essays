• Push (for thrust): Similar because both name applying force to move something; differs because push is continuous and gentle (you push a door), while thrust is sharp, sudden, and directed at a specific point.
  • Shove: Similar because both name pushing with force; differs because shove is rough, sideways, and bodily, whereas thrust is precise and penetrating — the push of a lance or a piston.
  • Drive: Similar because both name forceful action; differs because drive implies sustained force and control (you drive a nail), while thrust is a single concentrated jab that stops dead.
  • Ram: Similar because both name violent pushing; differs because ram is brute head-on collision, whereas thrust is pointed and directional — a blade, not a battering ram.
  • Prod: Similar because both name a small, pointed push; differs because prod is a light, repeated jab of a finger or a stick, while thrust is a hard, penetrating, full-force push.
  • Poke: Similar because both name a pointed push; differs because poke is casual and finger-like, while thrust is forceful, sharp, and weapon-like.
  • Press: Similar because both name applying force; differs because press is sustained and even, an unbroken pressure, whereas thrust is sudden, concentrated, and momentary.
  • Stab: Similar because both name a piercing push; differs because stab implies a wounding penetration with a blade, while thrust is the pushing force itself, whether or not it pierces.
  • Lunge: Similar because both name a sudden forward drive; differs because lunge is the bodily movement of the attacker, while thrust is the directed force at the point of contact.
  • Threw (for hurled): Similar because both name projecting something through the air; differs because threw is the general verb, while hurled adds maximum force and momentum — a catapult, not a hand.
  • Flung: Similar because both name throwing with violence; differs because flung is careless release with no aim, while hurled implies deliberate power and often a target (he hurled the javelin at the mark).
  • Pitched: Similar because both name throwing; differs because pitched implies a controlled arc, while hurled is a flat, ballistic blast of force.
  • Cast: Similar because both name throwing; differs because cast is formal and directed (casting a net), while hurled is raw, violent, and full of momentum.
  • Slung: Similar because both name throwing with a swinging motion; differs because slung is pendular and arcing, while hurled is a straight, explosive projection.
  • Heaved: Similar because both name throwing with effort; differs because heaved is a great, slow lift of something heavy, while hurled is fast, violent, and driven by impact.
  • Launched: Similar because both name sending something forcibly; differs because launched is deliberate and mechanical, while hurled is human, sudden, and furious.
  • Catapulted: Similar because both name violent projection; differs because catapulted is mechanical, from a machine, while hurled is the raw force of a body or a blow.
  • Spread (for sprawled): Similar because both name extending over an area; differs because spread is orderly and deliberate, while sprawled is awkward, uncontrolled, and ungainly.
  • Stretched: Similar because both name the body extended; differs because stretched is deliberate and linear (stretched out on a bed), while sprawled is chaotic, limbs scattered every way.
  • Splayed: Similar because both name limbs spread out; differs because splayed emphasizes the outward fanning of the parts, while sprawled emphasizes the fallen, graceless whole.
  • Scattered: Similar because both name things spread about; differs because scattered applies to separate things thrown about, while sprawled applies to one body or thing spread in an ungainly mass.
  • Lolled: Similar because both name an ungraceful resting posture; differs because lolled is a relaxed, lazy hanging of the body, while sprawled is a fallen, involuntary, disorderly spread.
  • Lounged: Similar because both name a casual resting pose; differs because lounged is chosen and comfortable, while sprawled is fallen and involuntary, without elegance.
  • Slumped: Similar because both name a collapsed posture; differs because slumped is a vertical collapse into a heap (slumped in a chair), while sprawled is a horizontal, limbs-out spread.
  • Collapsed: Similar because both name falling down; differs because collapsed is the sudden giving way of support, while sprawled is the resulting posture of the fallen body.
