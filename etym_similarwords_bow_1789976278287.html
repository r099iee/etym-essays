• Prow: Similar because it is the forepart of a ship; differs because prow is poetic and stresses the stem curve, while bow is technical and whole forepart.
  • Stem: Similar because it is the front edge of a hull; differs because stem is the cutwater timber itself, while bow is the region.
  • Fore / Forecastle: Similar because they denote forward ship parts; differs because fore is directional and forecastle is a deck structure, while bow is hull geometry.
  • Longbow / Crossbow: Similar because they share the bent-wood weapon root (/boh/); differs because they name specific weapons, while bow alone is generic.
  • Knot / Bow-knot: Similar because a bow is a looped knot; differs because knot is generic, while bow specifies releasable double loops.
  • Violin bow / Fiddlestick: Similar because it is a bent stick drawing sound; differs because it is horsehair on wood for strings, not cordage or weaponry.
  • Curtsey / Genuflection: Similar because they are reverential body-bends like a bow (/bau/); differs because curtsey is female-coded knee-bend and genuflection is kneeling, while bow is waist/neck forward.
  • Bend / Curve / Arc: Similar because they describe the shared bent shape; differs because they are generic geometry, while bow names culturally fixed objects.
