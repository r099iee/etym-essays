• frugality: Similar because it means economical use of resources; differs because frugality is the abstract principle while thrift is its practical exercise.
  • economy: Similar because it denotes careful management; differs because economy can describe systems while thrift describes personal conduct.
  • thriftiness: Similar because it is the noun of quality from thrifty; differs only in that thrift is both virtue and institution while thriftiness is purely the trait.
  • prudence: Similar because it implies wise foresight with money; differs because prudence is broader wisdom while thrift is specifically saving.
  • providence: Similar because it means foresighted provision; differs because providence is grander and often divine while thrift is domestic.
  • parsimony: Similar because it means sparingness; differs because parsimony is usually blamed as stinginess while thrift is praised as virtue.
  • miserliness: Similar because both avoid spending; differs because miserliness hoards selfishly while thrift saves purposefully.
  • austerity: Similar because it involves restraint; differs because austerity is severe and often imposed while thrift is voluntary and cheerful.
  • saving: Similar because it is the act of keeping money; differs because saving is a single act while thrift is a habit of character.
  • savings: Similar because they are the product of thrift; differs because savings are the pile while thrift is the behavior that builds it.
  • conservation: Similar because it avoids waste of resources; differs because conservation is usually ecological while thrift is usually financial.
  • husbandry: Similar because good husbandry manages resources well; differs because husbandry governs farms and households broadly while thrift governs spending narrowly.
  • temperance: Similar because it restrains appetite; differs because temperance concerns drink and desire while thrift concerns money.
  • industriousness: Similar because Victorians paired it with thrift as twin virtues; differs because industriousness earns while thrift keeps.
