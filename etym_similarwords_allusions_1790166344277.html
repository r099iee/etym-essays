• reference: Similar because it points to another source; differs because it is generic and can be explicit, while an allusion is always indirect and covert.
  • citation: Similar because it invokes an authority or text; differs because it is formal and explicit with source details, while an allusion gives no such apparatus.
  • quotation: Similar because it borrows another's words; differs because it reproduces them verbatim in quotes, while an allusion merely hints.
  • mention: Similar because it brings something to mind; differs because it names directly, while an allusion deliberately avoids naming.
  • hint: Similar because it suggests indirectly; differs because it is everyday and vague, while an allusion points to a specific cultural store.
  • suggestion: Similar because it implies without stating; differs because it proposes an idea, while an allusion evokes a prior text or story.
  • insinuation: Similar because it conveys obliquely; differs because it is usually pejorative and sly, while an allusion is usually erudite and playful.
  • innuendo: Similar because it carries a veiled secondary meaning; differs because it is typically disparaging or sexual, while an allusion is literary.
  • echo: Similar because it reverberates an earlier voice; differs because it stresses sonic or structural resemblance, while an allusion stresses referential intent.
  • invocation: Similar because it calls another power or author to mind; differs because it is overt and often ritual, while an allusion is covert.
  • tribute / homage: Similar because it honours a predecessor; differs because it is openly acknowledged, while an allusion may be sly or unmarked.
