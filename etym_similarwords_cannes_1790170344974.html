• Nice: Similar because it is a neighbouring Riviera resort with promenade and carnival; differs because it is larger, urban and administrative capital, while Cannes is smaller and festival-defined.
  • Saint-Tropez: Similar because it is a Côte d'Azur playground of yachts and stars; differs because it is a former fishing village with bohemian myth, while Cannes is palace-hotel and red-carpet formal.
  • Monaco / Monte Carlo: Similar because it offers Riviera casinos and glamour; differs because it is a sovereign principality built on gambling, while Cannes glamour is cinema-based.
  • Deauville: Similar because it is a French resort with film festival and boardwalk; differs because it is Norman-Channel, understated-elegant, while Cannes is Mediterranean-sunny and global.
  • Venice (Lido): Similar because it hosts a rival historic film festival; differs because it is a sinking lagoon city with Biennale heritage, while Cannes is a purpose-built festival machine.
  • Biarritz: Similar because it is a 19th-century aristocratic seaside invention; differs because it is Atlantic-surf, while Cannes is Mediterranean-calm.
