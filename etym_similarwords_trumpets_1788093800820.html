• Bugles: Similar because both are brass signalling instruments with a bright, carrying tone; differs because a bugle is valveless, plays only notes of the harmonic series, and is tied to military drill.
  • Horns: Similar because both are brass wind instruments producing loud calls; differs because horn is the generic family word and in orchestras usually means the French horn, with a mellow, conical tone.
  • Cornets: Similar because both are soprano brass instruments of similar range; differs because the cornet has a conical bore and a softer, more lyrical tone, beloved in brass bands.
  • Clarions: Similar because both are high, piercing trumpets used for calls; differs because clarion is archaic-poetic and survives mainly in "clarion call", a metaphor for a rousing summons.
  • Fanfares: Similar because both denote the brilliant ceremonial sound of trumpets; differs because a fanfare is a short musical flourish, not an instrument.
  • Tuckets: Similar because both are trumpet flourishes; differs because tucket is an obsolete Elizabethan term for a specific short trumpet signal.
  • Sennets: Similar because both are trumpet signals; differs because sennet is an archaic stage-direction term for a set of notes announcing an entrance or procession.
  • Flourishes: Similar because both are showy brass passages; differs because a flourish can be played on any instrument and means ornamentation generally.
  • Calls: Similar because both are signals that summon attention; differs because call is generic for any signalling sound, human or animal.
  • Blasts: Similar because both are loud, sudden sounds; differs because blast is generic (wind, explosion) and not tied to the instrument.
  • Alarums: Similar because both warn and summon; differs because alarum is an archaic word for a general call to arms, not an instrument.
  • Shofars: Similar because both are ancient horn instruments blown as ritual or warning calls; differs because the shofar is a ram's horn, valveless, and exclusively Jewish liturgical.
  • Trump (archaic): Similar because it is the same word family, an older form meaning "trumpet"; differs because it survives only in "the last trump", and the card-game trump is an unrelated word (French triomphe).
