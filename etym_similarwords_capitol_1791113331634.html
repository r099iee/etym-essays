• statehouse: Similar because it also denotes a state legislature building; differs because it is plainer, more generic, and lacks the neoclassical Roman allusion.
  • legislature: Similar because it refers to the law-making body housed in a capitol; differs because it is the institution/people, not the building itself.
  • capitol building: Similar because it is essentially synonymous; differs only in explicitness and formality.
  • parliament: Similar because it is a legislative seat; differs because it denotes the British-style institution and its building, not an American domed capitol.
  • assembly: Similar because it can mean a legislative chamber; differs because it emphasizes the gathered members rather than architecture.
  • senate house: Similar because it houses upper-chamber deliberation; differs because it is narrower, referring to one chamber only.
  • courthouse: Similar because it is another monumental civic building symbolizing authority; differs because it houses courts, not legislators.
  • city hall: Similar because it is a seat of local government with ceremonial architecture; differs because it is municipal and executive, not state legislative.
  • citadel: Similar because the original Capitolium was a citadel sanctuary; differs because today citadel means fortress, with military rather than legislative force.
  • temple: Similar because the Roman Capitolium was literally a temple; differs because temple is now religious, while capitol is secular-political.
