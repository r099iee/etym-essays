• Eager: Similar because it means keenly desiring; differs because eager is momentary-forward (eager to start), avid is habitual-hungry (avid reader for life).
  • Keen: Similar because it means enthusiastically interested, especially British; differs because keen is lighter everyday praise, avid adds devouring intensity.
  • Enthusiastic: Similar because it means full of lively interest; differs because enthusiastic stresses outward warmth, avid stresses inward craving.
  • Ardent: Similar because it means passionately devoted; differs because ardent is burning-romantic (ardent lover, admirer), avid is consuming-appetitive.
  • Fervent: Similar because it means intensely earnest; differs because fervent is solemn-religious (fervent prayer), avid is hungry-secular.
  • Zealous: Similar because it means energetically devoted to a cause; differs because zealous adds missionary rigour, avid adds pleasure.
  • Passionate: Similar because it means driven by strong feeling; differs because passionate is emotional-erotic, avid is appetitive-habitual.
  • Voracious: Similar because it means devouring hugely, especially reading; differs because voracious keeps ravenous animal metaphor explicit, avid has softened it.
  • Greedy: Similar because Latin avidus meant greedy; differs because greedy now censures selfish excess, avid praises when the object is worthy.
  • Covetous: Similar because it means graspingly desirous of what others have; differs because covetous is moral-theological envy, avid is psychological hunger.
