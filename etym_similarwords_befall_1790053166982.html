• happen to: Similar because it denotes occurrence affecting someone; differs because happen to is neutral everyday while befall is literary and fated, usually gloomy.
  • occur to: Similar because it takes place; differs because occur is formal-neutral event while befall requires human experiencer as goal.
  • overtake: Similar because calamity comes upon victim; differs because overtake implies pursuit and catching up while befall implies descent from above.
  • strike: Similar because disaster hits suddenly; differs because strike is violent impact while befall is enveloping arrival.
  • hit: Similar because misfortune reaches someone; differs because hit is blunt colloquial blow while befall is solemn encompassing.
  • afflict: Similar because suffering comes upon; differs because afflict is prolonged torment inflicted while befall is moment of arrival.
  • betide: Similar because it is archaic happen to, woe betide; differs because betide is even rarer and ominous-warning while befall is narrative-record.
  • beset: Similar because troubles surround; differs because beset is harassed on all sides while befall is single falling event.
  • transpire: Similar because it comes to pass; differs because transpire is formal leakage into knowledge while befall is fateful arrival upon person.
  • supervene: Similar because it comes upon as addition; differs because supervene is legal-medical intervention while befall is doom-laden.
