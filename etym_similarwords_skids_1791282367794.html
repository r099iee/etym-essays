• Slides: Similar because it means smooth gliding motion; differs because slide can be controlled and neutral, skid implies loss of traction.
  • Slips: Similar because it denotes loss of footing or grip; differs because slip is often brief and light, skid implies longer dragging slide.
  • Glides: Similar because it means smooth movement; differs because glide is graceful and controlled, skid is accidental.
  • Skates: Similar because it involves sliding on low friction; differs because skate is usually intentional sport, skid is unintended.
  • Swerves: Similar because it involves sudden loss of straight course; differs because swerve stresses steering aside, skid stresses sliding.
  • Veers: Similar because it means to change direction; differs because veer can be deliberate, skid is forced by surface.
  • Hydroplanes: Similar because it is sliding on water; differs because it is technical and specific to aquaplaning tyres.
  • Jackknifes: Similar because it is uncontrolled vehicle folding; differs because it describes articulated lorries folding, not general sliding.
  • Stumbles: Similar because it shows loss of control; differs because stumble is tripping on feet, skid is sliding.
  • Plummets: Similar in figurative sense of rapid decline; differs because plummet is vertical fall, skid is lateral slide.
