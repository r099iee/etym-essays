• Chestnut: Similar because it is a reddish-brown horse colour; differs because chestnut has no black points while bay has black mane, tail and legs.
  • Sorrel: Similar because it denotes a red-coated horse; differs because sorrel is lighter copper-red, while bay is brown with black extremities.
  • Brown / Seal brown: Similar because it is a dark equine coat; differs because brown is near-black overall, while bay shows a clearly red-brown body.
  • Black: Similar because it is a basic horse colour sharing black pigment; differs because black is black all over, while bay restricts black to points.
  • Dun: Similar because it can show a tan body with dark points; differs because dun adds a dorsal stripe and primitive marks, while bay does not.
  • Buckskin: Similar because it has a tan body with black points; differs because buckskin needs a cream-dilution gene, while bay is undiluted.
  • Roan: Similar because it describes mixed coat colour; differs because roan mixes white hairs through the body, while bay is solid red-brown.
  • Grey: Similar because it is a basic horse colour recorded in stud books; differs because grey lightens with age to white, while bay is stable for life.
  • Palomino: Similar because it is a golden-reddish colour; differs because palomino has a white mane, while bay has a black mane.
  • Piebald: Similar because it is a horse colour pattern in the same herd; differs because piebald is patched black-and-white, while bay is solid.
  • Bayard (archaic): Similar because it once meant a bay horse; differs because bayard became a generic or proper name, while bay stays a colour term.
