• Publius Aelius Hadrianus: Similar because both names denote the same man; differs because the full tria nomina is the formal Roman style, while "Hadrian" is the conventional English short form.
  • Adrian: Similar because both descend from Latin Hadrianus; differs because Adrian is the vernacular form (popes, saints, given names), usually not used for the emperor in historical prose.
  • Trajan: Similar because both are emperors of the same adoptive line; differs because Trajan expanded the empire, while Hadrian consolidated and renounced some of those eastern conquests.
  • Antoninus Pius: Similar because both are Antonine emperors in Gibbon's list; differs because Antoninus Pius is Hadrian's adopted successor, not the border-builder himself.
  • Antoninus (Marcus Aurelius): Similar because both are emperors whose deaths Gibbon uses as boundaries; differs because Hadrian's reign is interior to the happy period, whereas the death of the last Antonine closes it.
  • Nerva: Similar because both are the first two names in Gibbon's list of virtuous administrators; differs because Nerva (AD 96-98) founded the adoptive line, while Hadrian consolidated it a generation later.
  • Five Good Emperors: Similar because both refer to the same rulers; differs because it is the modern collective label for Nerva through Marcus Aurelius, not the name of one man.
  • Hadrianic: Similar because both derive from the same emperor; differs because Hadrianic is the derived adjective for the period and style, while Hadrian is the personal name.
