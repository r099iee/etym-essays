• dessert apple / eating apple: Similar because it is the modern category for pippins; differs because dessert apple is technical and generic, while pippin is heritage and seedling-specific.
  • Cox / Ribston (Cox’s Orange Pippin, Ribston Pippin): Similar because they are the famous pippin varieties; differs because each names one cultivar, while pippins names the class.
  • codling / codlin: Similar because it is the companion heritage apple class; differs because codlins are for cooking, while pippins are for eating fresh.
  • crab / crab-apple: Similar because it is the wild ancestor and opposite; differs because crabs are small, sour and inedible raw, while pippins are selected sweet.
  • pip: Similar because pippin is named for and grown from it; differs because pip is the seed, while pippin is the fruit grown from seed.
  • beauty / humdinger / crackerjack: Similar because figurative pippin means a first-rate specimen; differs because these are general slang, while pippin keeps orchard charm.
  • peach / plum (figurative): Similar because fruit names praise persons; differs because peach stresses soft loveliness, while pippin stresses wholesome excellence.
  • russet: Similar because many pippins are russeted heritage apples; differs because russet names skin texture, while pippin names origin type.
  • warden: Similar because it is another old named eating-baking apple; differs because wardens are for baking and keeping, while pippins are for dessert.
  • cider apple: Similar because it is the bitter counterpart in Ruskin’s antithesis; differs because cider apples are sharp and tannic for pressing, while pippins are sweet for eating.
