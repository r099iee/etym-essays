• lineage: Similar because it means ancestral line; differs because lineage stresses the drawn line itself, while descent stresses transmission downward.
  • ancestry: Similar because it is collective forebears; differs because ancestry looks backward to founders, while descent looks forward to heirs.
  • extraction / origin: Similar because both name stock or source; differs because extraction is formal-literary (of humble extraction), while descent is everyday genealogical.
  • pedigree: Similar because it is recorded descent; differs because pedigree implies documented pure breeding, while descent may be obscure or mixed.
  • heritage / inheritance: Similar because what descends is inherited; differs because heritage is what is received culturally, while descent is the blood path.
  • decline / fall: Similar because moral descent is decline; differs because decline is gradual worsening, while descent pictures vertical dropping.
  • slope / drop / declivity: Similar because spatial descent is a slope; differs because slope is the ground form, while descent is the act or course of going down.
  • raid / incursion: Similar because military descent is a raid; differs because raid is modern and general, while descent (upon) is period and seaborne.
  • derivation: Similar because Darwinian descent is derivation; differs because derivation is logical or linguistic sourcing, while descent is biological begetting.
  • ascent (antonym): Similar because it shares the climb-scale; differs because ascent rises, while descent lowers — the pair defines the vertical axis.
