• Puff: Similar because it means exaggerated promotional praise; differs because it is openly contemptuous, while blurb can be neutral trade jargon.
  • Plug: Similar because it is a public recommendation of a product; differs because a plug is usually spoken (on air, on stage) rather than printed on a jacket.
  • Endorsement: Similar because it is an authoritative statement of approval; differs because it is formal and contractual, while a blurb is a marketing snippet.
  • Testimonial: Similar because it is a written statement praising something; differs because testimonials certify quality or character generally, not just books.
  • Recommendation: Similar because it advises others to try something; differs because it can be private and disinterested, while a blurb is public and commercial.
  • Jacket copy: Similar because it is the text printed on a book jacket; differs because it is the neutral insider term covering all jacket text, of which the blurb is the praising part.
  • Teaser: Similar because it is a short enticing preview; differs because teasers withhold information to create curiosity, while blurbs summarise and praise.
  • Synopsis: Similar because it is a brief summary of plot; differs because a synopsis is neutral and complete (often for agents or students), while a blurb sells.
  • Summary: Similar because it condenses content briefly; differs because it aims at accuracy rather than temptation.
  • Advertisement: Similar because it is paid promotional text; differs because it is the general category, while a blurb is book-jacket praise specifically.
  • Hype: Similar because it is extravagant promotional excitement; differs because hype is the surrounding noise, while a blurb is one concrete text.
  • Spiel: Similar because it is a glib sales patter; differs because a spiel is spoken and often lengthy, while a blurb is short and written.
  • Write-up: Similar because it is a short published account; differs because a write-up may be a review (positive or negative), while a blurb is always praise.
  • Tagline: Similar because it is a catchy promotional line; differs because a tagline brands a whole work or campaign in a phrase, while a blurb describes.
