• Measure: Similar because it denotes the same metrical unit of music; differs because measure is the preferred American term for the content, while bar is British and also names the dividing line.
  • Phrase: Similar because it is a short coherent musical thought; differs because a phrase can span several bars and implies melodic completeness, while a bar is strictly metrical.
  • Strain: Similar because it means a short tune or melody snatch; differs because strain is literary and melodic, while bar is technical and countable.
  • snatch: Similar because a snatch of song is a brief hummed fragment; differs because snatch stresses incompleteness, while bar is a precise unit.
  • Motive: Similar because it is a short recurring musical idea; differs because motive (motif) is compositional and developmental, while bar is merely mensural.
  • Riff: Similar because it is a short repeated musical figure; differs because riff is jazz/pop slang with groove connotations, while bar is neutral notation.
  • Lick: Similar because it is a brief stock musical phrase; differs because lick is player slang for a flourish, while bar is the written container.
  • Line: Similar because a melodic line unfolds in bars; differs because line is linear and vocal, while bar is the vertical division.
  • Stanza: Similar because it is a verse unit of song; differs because stanza is textual (words), while bar is temporal (beats).
  • Chorus: Similar because it is a singable repeated section; differs because chorus is large and structural, while a bar is its smallest building block.
  • Verse: Similar because it is a section of song one might hum; differs because verse is narrative and multi-bar, while bar is atomic.
  • Beat: Similar because beats compose bars; differs because beat is the pulse unit, while bar is the grouped measure of beats.
  • Note: Similar because notes make up bars; differs because a note is a single pitched sound, while a bar contains many notes.
