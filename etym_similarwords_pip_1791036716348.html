• Annoyance: Similar because the pip is irritation; differs because annoyance is generic and current, pip is period slang and milder-comic.
  • Irritation: Similar because both mean vexation; differs because irritation can be physical itch, pip is mood.
  • The blues: Similar because both mean low spirits; differs because blues is musical-American and sadder, pip more peevish.
  • Miff: Similar because to be miffed is to be slightly offended; differs because miff stresses wounded pride, pip stresses general fed-upness.
  • Hump (to get the hump): Similar because it means to become sulky; differs because it is still current British slang and more sullen.
  • Sulks: Similar because it is peevish low mood; differs because sulks implies silent withdrawal, pip can be vocal complaint.
  • Disgust: Similar in the fed-up extension; differs because disgust is stronger revulsion.
  • Depression (mild): Similar because pip includes gloom; differs because depression is clinical and serious, pip deliberately trivial.
  • Bore (to give a pain): Similar because bores give the pip; differs because bore is cause, pip is effect.
  • Needle (to get on nerves): Similar because it irritates; differs because needle implies deliberate provocation.
  • Peeve: Similar because a pet peeve irritates; differs because peeve is American-current, pip Edwardian-British.
  • Doldrums: Similar because it means listless low spirits; differs because doldrums is nautical-calm metaphor, pip avian-illness metaphor.
