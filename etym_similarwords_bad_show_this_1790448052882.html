• Bad luck: Similar because it commiserates misfortune; differs because bad luck blames chance, while bad show judges the performance of events with schoolboy moral colour.
  • Poor show: Similar because it is the direct milder variant; differs because poor show is softer and more pitying, while bad show is blunter and more verdict-like.
  • Bad form: Similar because it condemns ungentlemanly conduct; differs because bad form targets manners, while bad show targets the whole business or outcome.
  • Pity: Similar because Bertie means what a pity; differs because pity is neutral-modern, while bad show is period slang with a sporting metaphor.
  • Shame: Similar because it voices disapproval (what a shame); differs because shame can imply moral taint, while bad show stays at the level of sporting disappointment.
  • Hard lines: Similar because it is contemporary school slang for tough luck; differs because hard lines is purely sympathetic, while bad show retains a hint of judgement.
  • Tough break: Similar because it consoles after failure; differs because tough break is American-informal, while bad show is English-public-school.
  • Rotten luck: Similar because it laments a sticky time; differs because rotten luck is colloquial and emotive, while bad show is clipped and stoical.
  • Good show (antonym): Similar because it shares the identical show metaphor; differs because it praises pluck and success, while bad show laments failure.
