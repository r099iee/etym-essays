• Hieroglyphs: Similar because both are ancient pictorial scripts deciphered in the 19th century; differs because hieroglyphs are Egyptian picture-signs carved and painted, while cuneiform is Mesopotamian wedge-marks pressed in clay.
  • Pictographs: Similar because early cuneiform began as pictographs; differs because pictographs name any picture-writing in general, while cuneiform names the specific mature wedge system and its three millennia of use.
  • Syllabary: Similar because cuneiform signs often work syllabically and the source sentence lists the Japanese syllabary beside it; differs because a syllabary writes each syllable with one sign by design, while cuneiform mixes logograms, syllables, and determinatives.
  • Logograms: Similar because many cuneiform signs stand for whole words; differs because logograms describe a function any script can use, while cuneiform is the historical system itself.
  • Clay tablets: Similar because tablets are the standard vehicle of cuneiform; differs because clay tablets name the physical medium, while cuneiform names the script pressed into it.
  • Akkadian: Similar because Akkadian is the great Semitic language written in cuneiform; differs because Akkadian is a language, while cuneiform is a script that also writes Sumerian, Hittite, and others.
  • Sumerian: Similar because Sumerian inventors created the script; differs because Sumerian is a language isolate of southern Iraq, while cuneiform outlived it by two thousand years in other tongues.
  • Epigraphy: Similar because both concern ancient inscriptions and their reading; differs because epigraphy is the scholarly discipline, while cuneiform is one of its chief objects.
  • Wedge-shaped: Similar because it translates the Latin etymology directly; differs because wedge-shaped is plain descriptive English for any taper, while cuneiform carries the full Mesopotamian and anatomical heritage.
