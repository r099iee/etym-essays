• slingshot: Similar because it hurls stones with elastic force; differs because it uses a Y-frame and rubber rather than whirled cords.
  • lasso: Similar because it is a whirled cord weapon for capture; differs because it snares rather than launches a free missile.
  • boomerang: Similar because it is a thrown primitive weapon in the same list; differs because it relies on airfoil return rather than a strap.
  • bow: Similar because it launches projectiles at range; differs because it stores energy in bent wood rather than rotation.
  • trebuchet: Similar because it slings heavy shot far; differs because it is a siege engine, not a hand strap.
  • bandage: Similar because a medical sling supports like a bandage; differs because bandage wraps a wound rather than suspending weight.
  • brace: Similar because it supports an injured limb; differs because brace is rigid stabilisation, while sling is soft suspension.
  • harness: Similar because it bears and distributes load with straps; differs because harness secures the body for safety rather than cradling a limb.
  • holster: Similar because a rifle sling carries like a holster; differs because holster is a fitted case, not a loop.
  • pouch: Similar because the missile cradle of a sling is a pouch; differs because pouch alone lacks cords and throwing function.
  • strap: Similar because every sling is a strap arrangement; differs because strap is the generic material, sling the functional loop.
  • cradle: Similar because a baby sling cradles like a cradle; differs because cradle is rigid furniture, sling is wearable cloth.
