• spears: Similar because both are thrusting pole weapons; differs because spear is generic, lance implies cavalry use.
  • pikes: Similar because both are long infantry spears; differs because pike is longer (4–6 m) for foot squares.
  • javelins: Similar because both are light spears; differs because javelin is thrown, lance is couched/thrust.
  • halberds: Similar because both are polearms; differs because halberd combines axe-hook and spear.
  • bayonets: Similar because both are thrusting blades on shafts; differs because bayonet fixes to a firearm.
  • assegais: Similar because African thrusting/throwing spears; differs because Zulu term, shorter shaft.
  • harpoons: Similar because barbed spears for thrusting; differs because for whales/fish with line and barb.
  • tridents: Similar because three-pronged spears; differs because fishing/gladiatorial, three points.
  • lancets: Similar because diminutive surgical blades; differs because small double-edged medical knife.
  • foils / epees: Similar because thrusting swords from lance tradition; differs because fencing sport, not polearm.
  • arrows: Similar because shafted missile weapons; differs because shot from bows, not thrust.
  • darts: Similar because thrown points; differs because short, light, often poisoned.
