• Supercilious: Similar because both name disdainful superiority; differs because supercilious specifically evokes raised eyebrows (Latin supercilium "eyebrow") and a sneering, mocking contempt, while haughty is a colder, more aloof pride without the sneer.
  • Arrogant: Similar because both mean having an exaggerated sense of one's own importance; differs because arrogant stresses an overbearing claim to rights and merits, while haughty stresses the cold, condescending manner of looking down on others.
  • Disdainful: Similar because both express contempt for what is beneath one; differs because disdainful focuses on the feeling or expression of scorn toward a specific thing, while haughty describes the general proud bearing.
  • Imperious: Similar because both suggest a commanding, superior manner; differs because imperious implies a demand to be obeyed and an autocratic will, while haughty is about proud aloofness rather than command.
  • Lordly: Similar because both suggest aristocratic superiority; differs because lordly may be dignified or even admirable ("lordly calm"), while haughty is always negative.
  • Overbearing: Similar because both describe an oppressive sense of superiority; differs because overbearing actively dominates and crushes others, while haughty merely looks down without acting.
  • Proud: Similar because both involve self-esteem; differs because proud can be positive (justified satisfaction) or neutral, while haughty is exclusively a fault.
  • Condescending: Similar because both imply looking down on others; differs because condescending involves treating others as inferior while pretending to be gracious, while haughty is openly contemptuous.
  • Contemptuous: Similar because both express strong disregard; differs because contemptuous names the emotion of scorn toward a target, while haughty names the overall proud character.
  • Snobbish: Similar because both suggest thinking oneself above others; differs because snobbish is tied to social class and status-seeking, while haughty is about personal pride and demeanor.
  • Aloof: Similar because both suggest emotional distance from others; differs because aloof is emotionally detached and reserved without necessarily being proud, while haughty is actively prideful.
  • Conceited: Similar because both involve an inflated sense of self; differs because conceited is a vain, self-admiring opinion of one's worth, while haughty is an outward manner of contempt toward others.
  • Vainglorious: Similar because both involve excessive pride; differs because vainglorious stresses boastful vanity and display, while haughty is quiet, cold, and withdrawn.
  • High-and-mighty: Similar because both convey arrogance; differs because high-and-mighty is informal and suggests self-importance that claims authority, while haughty is formal and literary.
  • Stuck-up: Similar because both describe thinking oneself better than others; differs because stuck-up is informal, social, and implies snobbery, while haughty is a dignified literary register.
  • Lofty: Similar because both derive from "high" imagery; differs because lofty may be admirable ("lofty ideals") or physically high, while haughty always means proud contempt.
