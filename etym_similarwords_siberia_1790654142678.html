• the North: Similar because it denotes cold remoteness; differs because it is generic and lacks Siberia's Russian-Asian specificity.
  • the Arctic: Similar because it denotes polar cold and tundra; differs because it is a circumpolar zone rather than a Russian region.
  • the taiga: Similar because it names Siberia's boreal forest; differs because it is a biome found also in Canada and Scandinavia.
  • the tundra: Similar because it evokes treeless frozen plain; differs because it is an ecological zone, not a place name.
  • the steppe: Similar because it covers southern Siberian grassland; differs because steppe extends far beyond Siberia.
  • the Far East: Similar because Russian administration groups eastern Siberia with it; differs because it centres on the Pacific littoral.
  • exile: Similar because Siberia connotes banishment; differs because exile is a condition, Siberia its archetypal location.
  • the wilderness: Similar because Siberia figures as vast wild land; differs because wilderness is generic while Siberia is mapped and peopled.
  • the Gulag: Similar because camps define modern Siberian memory; differs because Gulag names the camp system, not the region itself.
  • the Urals (as threshold): Similar because Urals mark Siberia's western gate; differs because they are the boundary range, not the expanse beyond.
