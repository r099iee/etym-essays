• paraffin wax: Similar because it is a solid wax used for candles and coatings; differs because it is petroleum-derived alkanes, odourless and cheaper, not secreted by bees.
  • carnauba wax: Similar because it is a natural hard wax for polishes and food glaze; differs because it comes from Brazilian palm leaves and is much harder and higher-melting.
  • candelilla wax: Similar because it is a plant wax used in balms and polishes; differs because it derives from a desert shrub and is more brittle.
  • propolis: Similar because it is another bee-hive product used in balms and varnishes; differs because it is resinous bee glue, not true wax for comb.
  • sealing wax: Similar because it is a melted wax for seals and crafts; differs because it is traditionally shellac-resin based, not beeswax, and used for stamping.
  • tallow: Similar because it is a rendered animal fat once used for candles and soap; differs because it is triglyceride fat, softer, smellier, and not a wax ester.
  • lanolin: Similar because it is an animal wax used in cosmetics; differs because it is wool grease from sheep, chemically a wax ester but emollient and lanolin-scented.
  • spermaceti: Similar because it was a prized animal wax for fine candles; differs because it came from sperm-whale head oil and is now obsolete.
  • soy wax: Similar because it is a candle-making wax; differs because it is hydrogenated soybean oil, vegan, softer and lower-melting.
  • wax: Similar because it is the generic superordinate for all such substances; differs because it is broader and includes mineral, plant, animal, and synthetic waxes.
  • cerumen (earwax): Similar because it is a waxy secretion with protective function; differs because it is human bodily secretion, not commercial or structural.
  • encaustic: Similar because it is a beeswax-based painting medium; differs because it denotes the technique/paint, not the raw material.
