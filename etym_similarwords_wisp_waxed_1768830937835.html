• Streak (for wisp): Similar because both name a thin trace of something; differs because a streak is a long, straight smear — linear, fast, and with no texture — while a wisp is twisted, irregular, hair-fine, and quasi-material.
  • Shred: Similar because both name a small piece of something light; differs because a shred is a torn fragment that implies prior violence, whereas a wisp is loosely gathered, not torn.
  • Filament: Similar because both name a slender, thread-like body; differs because a filament is a fine technical thread — of a bulb, a fibre, a plant — while a wisp is an irregular, loosely gathered bunch with no mechanical regularity.
  • Strand: Similar because both name a thin length of material; differs because a strand is one thread among many in a coherent rope or skein, while a wisp is a loose, twisted, quasi-material tuft.
  • Plume: Similar because both can name a light column of smoke; differs because a plume has shape and continuity, like a feather, while a wisp is barely a presence at all — irregular and dissolving.
  • Puff: Similar because both name a small amount of smoke; differs because a puff is a round, momentary billow, whereas a wisp is a slender extended thread, fibrous and nearly incorporeal.
  • Tendril: Similar because both are thin and curling; differs because a tendril is an organic, growing plant-part that climbs, while a wisp is dry, lifeless, and drifting.
  • Tuft: Similar because both are small, loosely gathered bunches; differs because a tuft is a compact cluster of hairs or grass with a base, while a wisp is drawn out and spread thin.
  • Ghost: Similar because both can mean a barely present, insubstantial thing; differs because ghost is a full supernatural being, while a wisp is only a faint trace of substance.
  • Grew (for waxed): Similar because both name increase; differs because grew is the general, neutral verb of increase, while waxed is organic, smooth, and fated — the filling of the moon.
  • Increased: Similar because both name becoming larger; differs because increased is quantitative and instrumental (increased the dose), while waxed is spontaneous and organic (the moon waxed).
  • Swelled: Similar because both name growth in size; differs because swelled implies distension of a contained body, while waxed implies gradual, luminous filling without pressure.
  • Expanded: Similar because both name becoming larger; differs because expanded suggests spreading outward into space, whereas waxed suggests a steady, organic augmentation in intensity or brightness.
  • Intensified: Similar because both can name an increase of degree; differs because intensified implies deliberate or external reinforcement, while waxed is natural and automatic.
  • Augmented: Similar because both name increase; differs because augmented is formal and often additive (augmenting an army or a salary), while waxed is organic growth from within.
  • Mounted: Similar because both name a rise in degree; differs because mounted suggests climbing to a height (mounting anger), while waxed suggests filling and brightening toward fullness.
  • Enlarged: Similar because both name becoming larger; differs because enlarged is physical and mechanical enlargement, while waxed carries the poetic inevitability of growth.
