• Osier: Similar because it is a willow; differs because an osier is specifically a willow cultivated for basket-making, while "willow" names the tree itself.
  • Withy / Withe: Similar because both are pliant willow material; differs because a withy is a pliant willow twig used for binding, a part of the tree rather than the whole.
  • Sallow: Similar because it is an older English name for certain willows; differs because sallow descends from a different Germanic root (Old English sealg, from PIE *salik-) and is often confused with "sallow" meaning pale or sickly.
  • Poplar: Similar because it is a riverside tree; differs because poplars are a wholly different genus (Populus), celebrated for trembling rather than bending leaves, and they carry none of the sorrowful symbolism of the willow.
  • Weeping willow: Similar because it is a willow; differs because "weeping willow" names specifically the drooping, pendulous cultivars (chiefly Salix babylonica and hybrids), while "willow" covers the whole genus including upright species.
  • Wicker: Similar because both are woven willow material; differs because wicker is the finished woven product (baskets, furniture), made of willow withes, while "willow" names the tree and its wood.
  • Aspen: Similar because both are quick-growing riverside trees with pliant twigs; differs because the aspen (Populus tremula) is a poplar, named for its trembling leaves, and belongs to a different genus with different craft uses.
  • Hazel: Similar because both supply pliant wood for weaving and binding; differs because hazel (Corylus) is a shrub of the birch family, valued for nuts and flexible rods, but is not a willow and has none of the waterside or mournful symbolism.
