• Roma: similar because it names the same people; differs because it is the modern self-designation and is not pejorative.
  • Romani: similar because it is the preferred adjective and language name; differs because it is not the plural ethnic noun and carries no Egyptian-origin error.
  • Romany: similar because it is an endonym-derived older English term for the same people and language; differs because it is dated and literary rather than a general plural label.
  • Sinti: similar because it is a Roma subgroup long settled in western Europe; differs because it names only one group, not all Roma.
  • Kale: similar because it is a Roma subgroup in Spain, Portugal, and Finland; differs because it is regional and does not cover the whole population.
  • Travellers: similar because many are itinerant and are often confused with Roma; differs because Irish, Scottish, and other Travellers are distinct communities with different histories and languages.
  • Bohemians: similar because it is a French-derived exonym for Roma; differs because it is foreign, historical, and also means artists and unconventional people.
  • Gitanos: similar because it is the Spanish exonym for Roma; differs because it belongs to a different national tradition and is not an English word.
  • Zingari: similar because it is an Italian exonym for Roma; differs because it is foreign and can be pejorative.
  • Egyptians: similar because it is the historical source of Gypsy; differs because it literally names people of Egypt and is not an ethnic label for Roma.
  • Gyppo: similar because it is a British slang shortening of Gypsy; differs because it is more openly abusive and informal.
