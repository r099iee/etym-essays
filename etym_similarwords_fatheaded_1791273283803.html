• Stupid: Similar because it denotes low intelligence or poor judgement; differs because it is general and clinical, while fatheaded adds comic contempt and obstinacy.
  • Thick-headed: Similar because it images a thick skull blocking thought; differs because it stresses dull slowness, while fatheaded stresses both silliness and self-satisfaction.
  • Boneheaded: Similar because it is insulting slang for very foolish; differs because it is American and blunter, while fatheaded is older British comic slang.
  • Blockheaded: Similar because it means dull and uncomprehending like a block; differs because it implies wooden insensibility, while fatheaded implies swollen self-importance.
  • Thick: Similar because British slang for stupid; differs because it is brief and broad, while fatheaded specifically pictures the head as the seat of folly.
  • Daft: Similar because it means silly or foolish; differs because it can be affectionate and northern, while fatheaded is always scornful.
  • Obtuse: Similar because it means slow to understand; differs because it is formal and often deliberate, while fatheaded is colloquial and abusive.
  • Doltish: Similar because it means stupid and clumsy; differs because it is literary, while fatheaded belongs to schoolboy and Wodehouse banter.
  • Fatuous: Similar because it means inanely silly and self-satisfied; differs because it is elevated and smug, while fatheaded is earthy and bodily.
  • Inane: Similar because it means empty-headed silliness; differs because it describes remarks as vacuous, while fatheaded describes the person as constitutionally foolish.
  • Pigheaded: Similar because it combines stupidity with obstinacy; differs because it stresses wilful refusal to change, while fatheaded stresses inability to understand.
  • Muttonheaded: Similar because it is a comic meat-based insult for stupidity; differs because it pictures sheep-like meek folly, while fatheaded pictures swollen conceit.
  • Half-witted: Similar because it means lacking sense; differs because it suggests pitiable deficiency, while fatheaded suggests blameworthy conceited folly.
