• Literature: Similar because both denote written works and written culture; differs because in its modern sense literature means imaginative writing and is narrower, while letters includes all serious written learning — history, oratory, philosophy, correspondence.
  • Learning: Similar because both name cultivated knowledge; differs because learning is broader and non-verbal — one may have learning in mathematics — while letters is specifically the bookish, literate tradition.
  • Humanities: Similar because both oppose the scholarly arts to the sciences; differs because humanities is a modern curricular label, cooler and more administrative, without the dignified, almost reverential tone of letters.
  • Writing: Similar because both concern the written word; differs because writing names the physical act or system of inscription, the mere technology, while letters is the cultural edifice built upon it.
  • Scholarship: Similar because both belong to the world of learning; differs because scholarship names the disciplined activity of producing knowledge, while letters names the culture and tradition that results.
  • Culture: Similar because both denote a civilization's accumulated intellectual life; differs because culture is far broader, embracing customs, arts, and institutions beyond the written tradition.
  • Correspondence / Epistles: Similar because both use the plural of 'letter' to mean written communications; differs because they name the concrete practice of letter-writing, not the institutional sense of scholarship and literature.
  • Erudition: Similar because both connote deep learning; differs because erudition stresses the personal store of knowledge, while letters denotes the shared written tradition.
