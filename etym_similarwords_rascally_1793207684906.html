• Roguish: Similar because both mean playfully villainous with charm; differs because roguish is almost always affectionate (a roguish smile), while rascally keeps a coarser edge that can mean genuinely worthless.
  • Mischievous: Similar because both describe naughty behaviour that stops short of crime; differs because mischievous is lighter and child-centred, while rascally suggests a knowing rogue, old enough to understand the rules he breaks.
  • Knavish: Similar because both name dishonest, trickster conduct; differs because knavish is archaic and purely condemnatory (Shakespeare’s knaves), while rascally can wink and forgive.
  • Scoundrelly: Similar because both derive from nouns for villains; differs because scoundrelly is graver and more moralistic, while rascally is earthier, often applied to land and things as well as men.
  • Scampish: Similar because both praise the lovable rogue; differs because scampish is fond from the first syllable (a scamp is forgiven already), while rascally retains the sting of genuine disapproval.
  • Villainous: Similar because both condemn wicked conduct; differs because villainous is melodramatic and total (villains tie victims to rails), while rascally is smaller-scale — shabby tricks, not crimes.
  • Sorry: Similar because a sorry nag and a rascally common both condemn poor quality; differs because sorry pities the thing, while rascally blames it, as if the heath chose to be poor.
  • Scrubby: Similar because both describe poor thin vegetation on bad land; differs because scrubby is neutral description of stunted growth, while rascally adds Cobbett’s moral fury at the soil itself.
  • Mangy: Similar because both damn the shabby and neglected; differs because mangy properly means diseased and patchy-coated (mangy dogs), while rascally ranges over rogues, tricks, inns, commons, and suppers.
