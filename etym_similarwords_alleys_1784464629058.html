• Lanes: Similar because both are narrow passageways for going along; differs because a lane may be rural, named, or road-like and often wider, while an alley is a tight built passage between walls, usually unglamorous and urban.
  • Passages: Similar because both are ways through or between places; differs because a passage is the general word for any connecting way, while an alley is the specific narrow between-buildings corridor.
  • Corridors: Similar because both are connecting passages; differs because a corridor is typically indoor, roofed, and planned (as in a building or ship), while an alley is an outdoor narrow way between structures.
  • Tunnels: Similar because both are confined ways; differs because a tunnel is underground boring, roofed and carved, while an alley is an open-air passage between buildings.
  • Streets: Similar because both are urban ways; differs because a street is a full public thoroughfare with buildings facing it, while an alley is a minor back passage, narrow and secondary.
  • Walkways: Similar because both are places for walking along; differs because a walkway is a broad functional term for any foot-path (including bridges, ramps, and indoor routes), while an alley specifically threads between walls.
  • Paths: Similar because both are linear routes; differs because a path is general and may be rural, unbuilt, or informal, while an alley is a passage defined by surrounding built structures.
  • Culs-de-sac: Similar because both are minor urban spaces off main ways; differs because a cul-de-sac is a dead-end street with houses, while an alley usually passes through between buildings rather than terminating in dwellings.
  • Arcades: Similar because both are built passages; differs because an arcade is a roofed or covered shopping or walking passage, often grand, while an alley is open-air and humble.
  • Byways / backways: Similar because both are secondary, minor routes; differs because a byway is any out-of-the-way route (rural or urban), while an alley is specifically the narrow built passage between structures.
