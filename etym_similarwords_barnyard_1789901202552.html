• Farmyard: Similar because it denotes the working enclosure of a farm; differs because it is broader and more British, covering the whole farm centre rather than the barn-adjacent yard specifically.
  • Courtyard: Similar because it is an enclosed yard beside buildings; differs because it is architectural and domestic rather than agricultural and animal-centred.
  • Foldyard: Similar because it is a yard for confining livestock; differs because it is chiefly British and dialectal, often for sheep or cattle folds.
  • Corral: Similar because it confines horses or cattle; differs because it is American western, railed, and for handling rather than general barn work.
  • Paddock: Similar because it is a small fenced field for horses; differs because it is grassed and for grazing or exercise, not trampled working ground.
  • Pasture: Similar because livestock occupy it; differs because it is open grazing land, not a built yard.
  • Coop / Henhouse: Similar because poultry are kept there; differs because it is a small shelter or cage, not the whole yard.
  • Stable-yard: Similar because horses are groomed and kept there; differs because it is horse-specific and paved or gravelled around stables.
  • Feedlot: Similar because cattle are confined and fed there; differs because it is industrial-scale and commercial, not a traditional mixed-farm yard.
