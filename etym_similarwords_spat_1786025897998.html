• Tiff: Similar because both denote a brief, petty quarrel between intimates; differs because tiff specifically emphasizes a touch of petulance, mild sulking, or wounded vanity, whereas spat implies a sharper, more energetic verbal exchange.
  • Squabble: Similar because both involve noisy disputes over trivial matters; differs because squabble emphasizes noisy, undignified, overlapping bickering that may drag on, while a spat is typically shorter and sharper.
  • Altercation: Similar because both describe verbal clashes; differs because an altercation is much more formal, intense, public, and potentially hostile, often involving raised voices and security intervention.
  • Bicker: Similar because both refer to minor disputes; differs because bicker is primarily an iterative verb emphasizing continuous, petty, bad-tempered back-and-forth carping over trivial details.
  • Quarrel: Similar because both denote an angry disagreement; differs because a quarrel is a broader, heavier category that can encompass long-standing hostility, deep emotional grievances, and broken relationships.
  • Row: Similar because both denote verbal arguments; differs because a row (rhyming with cow) is British colloquial English emphasizing extreme noise, shouting, commotion, and public disturbance.
  • Feud: Similar because both are conflicts; differs fundamentally because a feud is an enduring, multi-generational, deeply bitter state of reciprocal hostility, whereas a spat lasts only minutes or hours.
