• model: Similar because it denotes something fit to be copied; differs because model is plain and versatile, while exemplary is formal and morally charged.
  • ideal: Similar because it denotes perfection worth aiming at; differs because ideal stresses abstract perfection, while exemplary stresses visible imitation.
  • admirable: Similar because it denotes praiseworthy goodness; differs because admirable invites warm approval, while exemplary demands copying.
  • commendable: Similar because it denotes conduct deserving praise; differs because commendable is mild and official, while exemplary is superlative.
  • meritorious: Similar because it denotes goodness deserving reward; differs because meritorious is bureaucratic (medals, citations), while exemplary is moral-pedagogic.
  • sterling: Similar because it denotes tested, genuine excellence; differs because sterling uses a coinage metaphor, while exemplary uses a display metaphor.
  • blameless: Similar because it denotes faultless conduct; differs because blameless only denies fault, while exemplary asserts positive model-ness.
  • archetypal: Similar because it denotes a representative pattern; differs because archetypal is descriptive-structural, while exemplary is normative (ought-to-copy).
  • illustrative: Similar because it denotes serving as an example; differs because illustrative is neutral-logical, while exemplary adds moral elevation.
  • deterrent (as in exemplary punishment): Similar because exemplary punishment deters; differs because deterrent names only the frightening function, while exemplary names exhibition for either copying or avoidance.
