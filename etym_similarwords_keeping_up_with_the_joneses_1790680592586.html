• status-seeking: Similar because it denotes pursuing rank in others’ eyes; differs because it is a general motive label, while the idiom names the specific neighbour-emulation treadmill.
  • conspicuous consumption: Similar because it denotes display-driven spending; differs because it is Veblen’s technical term, analytical rather than wryly idiomatic.
  • emulation: Similar because it denotes copying a model’s behaviour; differs because it is neutral and broad, lacking the idiom’s satire of suburban rivalry.
  • peer pressure: Similar because it denotes conformity driven by a reference group; differs because it usually concerns youth behaviour and norms, not household spending races.
  • rat race: Similar because it denotes exhausting competitive striving; differs because it centres on work and career grind rather than consumption display.
  • one-upmanship: Similar because it denotes outdoing others point by point; differs because it is overt and combative, while Joneses-keeping is anxious and imitative.
  • materialism: Similar because it denotes valuing possessions highly; differs because it names a value system, not the comparative dynamic itself.
  • affluenza: Similar because it denotes the discontents of affluence and overconsumption; differs because it stresses psychological malaise rather than the neighbour race.
  • positional competition: Similar because it denotes rivalry over rank-ordered goods; differs because it is economists’ jargon, bloodless where the idiom is vivid.
  • social climbing: Similar because it denotes striving for higher standing; differs because it aims at entering a higher class, while Joneses-keeping defends parity with equals.
  • bandwagon effect: Similar because it denotes following what others do; differs because it is about joining trends, not defending status against specific neighbours.
  • lifestyle inflation: Similar because it denotes spending rising with income and surroundings; differs because it describes the budgetary mechanism, not the satirical social portrait.
