• Convey: Similar because it means to carry meaning to others; differs because it stresses transport (words convey ideas), while impart stresses generous bestowal.
  • Communicate: Similar because it means to share information; differs because it is neutral and two-way, while impart is one-way giving of something valuable.
  • Transmit: Similar because it means to pass on; differs because it is technical-mechanical (signals, disease), while impart is human and enriching.
  • Bestow: Similar because it means to give formally; differs because it implies ceremonial honour, while impart implies sharing knowledge or qualities.
  • Confer: Similar because it means to grant; differs because it is official (confer degrees), while impart is broader, including flavour and motion.
  • Grant: Similar because it means to give; differs because it implies permission or request fulfilled, while impart implies sharing a part.
  • Disclose: Similar because it means to reveal information; differs because it stresses secrecy lifted, while impart stresses value shared.
  • Divulge: Similar because it means to reveal; differs because it implies confidential leaking, while impart is open and legitimate.
  • Reveal: Similar because it means to make known; differs because it stresses uncovering, while impart stresses giving.
  • Instil / Instill: Similar because it means to introduce values gradually; differs because it stresses slow infusion, while impart can be a single act of telling.
  • Infuse: Similar because it means to fill with a quality; differs because it images soaking, while impart images handing a share.
  • Lend: Similar because it means to give temporarily; differs because it implies return, while impart implies permanent gain.
  • Pass on: Similar because it means to transfer; differs because it is informal and neutral, while impart is formal and weighty.
