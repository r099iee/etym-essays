• prior: Similar because a prior deputises for or heads a lesser house; differs because a prior ranks below an abbot and may be appointed rather than elected.
  • archimandrite: Similar because it is the Eastern Orthodox equivalent, head of a monastery; differs because it belongs to the Greek/Slavonic tradition, while abbot is Western Latin.
  • abbess: Similar because she heads a convent with parallel authority; differs because abbess governs women, while abbot governs men.
  • monk / friar: Similar because both live the religious life under vows; differs because monks and friars are members, while the abbot is their elected father-superior.
  • prelate / dignitary: Similar because mitred abbots rank as church princes; differs because prelate is generic for high clergy, while abbot specifies monastic headship.
  • minister / pastor (Presbyterian): Similar because after the Reformation they replace abbots as local religious heads in Scotland; differs because they are elected preachers without monastic rule, while abbots rule cloistered communities.
  • commendator: Similar because in 16th-century Scotland he held an abbey's revenues and title; differs because commendators were often lay nobles, while true abbots were professed monks.
  • The Monastery (Scott novel): Similar because it is the sister volume read alongside The Abbot in the source; differs because The Monastery is set in the Borders, while The Abbot is set at Loch Leven.
  • Waverley novel / historical romance: Similar because The Abbot belongs to Scott's series; differs because these name the genre, while Abbot names the single Lochleven volume.
  • father-superior: Similar because it is the functional modern paraphrase of abbot; differs because it is descriptive and order-neutral, while abbot is the formal canonical title.
