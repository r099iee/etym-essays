• Probation: Similar because both are supervised liberty instead of prison; differs because probation usually replaces custody from the start, while parole follows time already served inside.
  • Licence (release on licence): Similar because both name conditional freedom revocable on breach; differs because licence is the British administrative term for the document, while parole names the whole institution and its hearing.
  • Amnesty: Similar because both free offenders from punishment; differs because amnesty wipes the offence away for a group, while parole keeps the sentence alive for the individual under watch.
  • Pardon: Similar because both shorten or end punishment by mercy; differs because a pardon forgives and closes the case, while parole merely suspends custody on good behaviour.
  • Furlough: Similar because both let a confined person out temporarily on trust; differs because furlough is brief leave that always ends back inside, while parole aims at lasting supervised freedom.
  • Parol: Similar because both descend from the same French word for spoken pledge; differs because parol survives only in legal phrases about oral evidence, while parole owns the prison-release sense.
  • Word of honour: Similar because parole began as exactly such a pledge; differs because the word of honour is the promise itself, while parole is now the whole supervised-release system built upon it.
