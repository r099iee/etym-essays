• paralysing (paralyzing): Similar because both denote rendering immobile; differs because paralysing is participial and dynamic (actively freezing), paralytic is adjectival and stative (pertaining to the condition).
  • immobilising: Similar because both stop movement; differs because immobilising is physical-technical (immobilise a limb), paralytic adds neurological and figurative dread.
  • incapacitating: Similar because both disable function; differs because incapacitating is general (any incapacity), paralytic specifically evokes loss of nerve conduction.
  • debilitating: Similar because both weaken; differs because debilitating implies progressive weakening, paralytic implies sudden total arrest.
  • crippling: Similar because both disable; differs because crippling is now often deemed insensitive for persons and suggests maiming, paralytic is clinical and specific.
  • numbing: Similar because both deaden response; differs because numbing stresses loss of sensation, paralytic stresses loss of motion or will.
  • petrifying: Similar in fear-sense (petrified with fear); differs because petrifying evokes turning to stone, mythic and sudden, paralytic evokes nerve failure, medical and sustained.
  • inhibiting: Similar because both restrain action; differs because inhibiting is psychological-technical and partial, paralytic is total blockage.
  • stultifying: Similar because both deaden vitality; differs because stultifying implies dulling by boredom or repression, paralytic implies freezing by fear or reflection.
  • stifling: Similar because both suppress; differs because stifling suggests smothering air or creativity, paralytic suggests severed impulse.
  • debilitative: Similar because both describe weakening effects; differs because debilitative is formal-medical and chronic, paralytic can be acute and figurative.
  • prostrating: Similar because both lay low; differs because prostrating suggests collapse from exhaustion or grief, paralytic suggests intact consciousness without power to move.
