• Denim: Similar because it is the direct descendant and modern term for the fabric; differs because "denim" is the anglicized, shortened form, while "serge de Nîmes" is the original French phrase.
  • Jean: Similar because it refers to a durable twilled fabric also named after a city of origin (Genoa) and used for similar garments; differs because "jean" historically referred to a different type of fabric (often fustian or a cotton-linen blend) from a different city, though it now often refers to the garment made of denim.
  • Serge: Similar because it describes the type of twill weave fabric; differs because "serge" is a general category, while "serge de Nîmes" specifies a particular serge from a particular place, often cotton and indigo-dyed.
  • Canvas: Similar because it is a heavy, durable plain-woven fabric used for workwear; differs because canvas typically has a plain weave, whereas serge de Nîmes (denim) has a distinctive twill weave.
  • Duck cloth: Similar because it is a strong, plain-woven cotton fabric used for work clothes and sails; differs because, like canvas, it is typically plain-woven, not twilled like serge de Nîmes.
