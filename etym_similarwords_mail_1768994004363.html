• armor: Similar because both denote protective covering; differs because "armor" is the general category (plate, leather, fabric, metal), while "mail" specifically names the flexible ring-and-scale fabric.
  • chain mail: Similar because it IS mail; differs only in that it adds the explicit "chain" to name the ring-and-link fabric (a modern pleonasm of the 18th century).
  • cuirass: Similar because both are armor; differs because a cuirass is a rigid breast-and-back plate, not flexible rings.
  • hauberk: Similar because both are mail garments; differs because a hauberk is specifically the long coat of mail — a garment made OF mail, not the material itself.
  • scale armor / lamellar: Similar because both are flexible armors of overlapping pieces; differs because scale and lamellar use overlapping plates or scales, whereas "mail" classically names interlocked rings.
  • plate: Similar because both are armor; differs because plate is rigid and jointed, not flexible like mail.
  • harness: Similar because in medieval usage a "suit of harness" meant a full suit of armor; differs because "harness" also means horse-gear and, in modern use, a safety restraint.
  • carapace: Similar because both denote a natural protective covering, as "mail" is applied to the vortlup; differs because "carapace" is strictly zoological, without the military metaphor.
  • shell / plating: Similar because both are hard protective layers; differs because these are material coverings of animals or machines, not armor fabric.
  • mesh: Similar because both descend from the "net" sense (Latin macula = the mesh of a net); differs because "mesh" names the open netting itself, not the armor built of its links.
  • scale: Similar because both appear in "scale mail"; differs because "scale" is the individual overlapping unit, "mail" the assembled protective fabric.
  • armature: Similar because both denote protective or supportive structures; differs because "armature" is modern (electrical, sculptural), "mail" the medieval metal fabric.
