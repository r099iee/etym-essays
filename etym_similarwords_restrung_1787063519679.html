• strung: Similar because it is the same action (fitting strings) without the prefix; differs because it reports the first stringing or simple tensioning, while restrung specifically means fitted anew.
  • restung: Similar because it is a rare variant past participle of the same verb; differs because it is nonstandard and mostly archaic.
  • restringed: Similar because it is the regular-form participle of the same verb; differs because it is rare and generally avoided in favour of restrung.
  • rethreaded: Similar because it describes passing a new thread or cord through beads or needles; differs because threading is for needles, beads, and cords, not for tension-bearing instrument or racquet strings.
  • rewired: Similar because it means “fitted again with new wiring”; differs because it is electrical and technical, not musical or textile.
  • retuned: Similar because it describes restoring an instrument’s condition; differs because tuning adjusts pitch, whereas restringing replaces the strings themselves.
  • restored: Similar because both convey bringing something back to good condition; differs because restoration is far broader and lacks the specific image of fresh strings.
  • refurbished: Similar because it denotes renewing an object; differs because it implies comprehensive cleaning and repair, not the single act of replacing cords.
  • repaired: Similar because it means fixed after damage; differs because it covers all kinds of fixes, while restrung is precise about the strings.
