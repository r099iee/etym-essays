• San: Similar because it denotes the same hunter-gatherer peoples; differs because it is the preferred modern term, while Bushmen is dated/colonial.
  • Ju/'hoansi: Similar because they are a specific San group; differs because it is a self-name for one community in Namibia/Botswana, not the blanket label.
  • !Kung: Similar because it is a major San group/language; differs because it is specific, while Bushmen lumps many distinct groups.
  • Khoikhoi: Similar because they are neighbouring Khoe-speaking peoples often paired with San as Khoe-San; differs because Khoikhoi were herders, San were foragers.
  • Khoe-San: Similar because it is the collective for herders plus foragers; differs because it is modern inclusive scholarly term.
  • Hottentot: Similar because it is the parallel dated colonial label for Khoikhoi neighbours; differs because it is now an outright slur, while Bushmen is contested but sometimes reclaimed.
  • hunter-gatherers: Similar because it describes the San economy; differs because it is a general anthropological category worldwide, not a people.
  • foragers: Similar because it means people living by gathering/hunting; differs because it is technical-economic, not ethnic.
  • aborigines: Similar because it means first peoples; differs because lato sensu global, and capitalised Aborigines means Australians specifically.
  • palaeolithic peoples: Similar because San were sometimes called living Stone Age peoples; differs because it is evolutionist framing now rejected.
  • Boesman (Afrikaans): Similar because it is the Afrikaans cognate; differs because register is everyday Afrikaans, with same sensitivity debate.
  • bushman (Australian): Similar because spelling is identical except capitalisation; differs because it means white frontier woodsman in Australia, not San.
