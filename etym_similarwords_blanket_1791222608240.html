• quilt: Similar because it is a thick bed covering for warmth; differs because a quilt has stitched layers and padding, blanket usually single woven layer.
  • duvet: Similar because it is a soft bed cover; differs because duvet is a bag with down/feather filling inside a cover, blanket flat.
  • comforter: Similar because it warms beds; differs because American comforter is thick padded bag, blanket thinner and often wool.
  • coverlet: Similar because it covers beds decoratively; differs because coverlet is light outer spread, blanket heavier for warmth.
  • throw: Similar because it is a small blanket for sofas; differs because throw is smaller, decorative, not full-bed size.
  • afghan: Similar because it is a crocheted wrap; differs because afghan is knitted/crocheted in pieces, blanket often woven whole.
  • eiderdown: Similar because it is a warm down-filled cover; differs because eiderdown uses duck down and is puffier, now often called duvet.
  • rug: Similar because in British use a rug can be a lap blanket; differs because rug usually means floor carpet, blanket for body.
  • shawl: Similar because it wraps the body for warmth; differs because shawl is worn over shoulders, smaller and often triangular.
  • cover: Similar because it means something laid over; differs because cover is generic superordinate, blanket specific soft textile.
  • mantle: Similar because it covers like a cloak; differs because mantle is literary, often snow or responsibility, not bedding.
  • pall: Similar because it is a cloth covering; differs because pall is funereal or gloomy, draped over coffin, not for warmth.
