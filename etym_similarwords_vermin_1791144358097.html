• pests: Similar because both denote harmful organisms; differs because pest is the broadest neutral term, vermin more specifically creeping/gnawing creatures with stronger disgust.
  • parasites: Similar because both live off hosts; differs because parasite is biological, living on/in another organism, vermin includes free-living rats and insects.
  • rodents: Similar because rats and mice are prototypical vermin; differs because rodent is zoological order, vermin functional pest category.
  • insects / bugs: Similar because cockroaches, lice, fleas overlap; differs because insect is scientific class, vermin value-judgment of harmfulness.
  • worms: Similar because original etymological core; differs because worm is specific legless invertebrate, vermin the whole infestation.
  • lice: Similar because classic human vermin; differs because lice specific ectoparasites, vermin general.
  • fleas: Similar because biting household vermin; differs because flea single species group, vermin collective.
  • rats: Similar because archetypal granary vermin; differs because rat one animal, vermin the class.
  • mice: Similar because grain-eating store pests; differs because mouse specific small rodent, vermin broader.
  • cockroaches: Similar because household infestation; differs because cockroach specific insect, vermin any such pest.
  • weevils: Similar because grain-store vermin par excellence; differs because weevil specific beetle, vermin general.
  • varmints (US): Similar because dialectal variant for troublesome animals; differs because varmint includes larger predators like coyotes and is rural-colloquial, vermin more urban and inclusive of insects.
  • scum (figurative): Similar because contemptuous term for despised people; differs because scum is purely insulting, vermin retains literal pest sense.
  • nuisances: Similar because unwanted harmful things; differs because nuisance is legal-general, vermin biological-specific.
