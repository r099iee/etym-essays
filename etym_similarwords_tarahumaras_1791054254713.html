• Rarámuri: Similar because it is the peoples own endonym for the same group; differs because Rarámuri is preferred respectful self-name while Tarahumaras is the older Spanish-derived exonym plural.
  • Tarahumara (singular): Similar because it denotes the same person, language or culture; differs because singular names one member while Tarahumaras counts several actors.
  • Guarijío: Similar because they are a neighbouring Uto-Aztecan canyon people with shared language branch; differs because Guarijío are a distinct smaller group, not Rarámuri.
  • Tepehuan: Similar because they are neighbouring Sierra Madre Indigenous farmers with parallel mission history; differs because Tepehuan speak a different Uto-Aztecan branch and lack the running emblem.
  • Yaqui: Similar because they are a renowned northern Mexican Indigenous people resisting colonisation; differs because Yaqui are Sonoran desert farmers with separate language and history.
  • Huichol (Wixárika): Similar because they are a famed Sierra Indigenous group preserving ceremony; differs because Huichol culture centres on peyote pilgrimage, not endurance running.
  • Pueblo peoples: Similar because they are maize-growing canyon and mesa villagers of the greater Southwest; differs because Pueblos are US-based with distinct architecture and languages.
  • Chichimeca: Similar because it is a colonial umbrella for northern hunter-gatherers; differs because it is a vague outsider label, while Tarahumara names a specific settled group.
  • Mexicans: Similar because Tarahumaras are Mexican citizens of Chihuahua; differs because Mexican is national, while Tarahumara is Indigenous-ethnic within it.
  • ultra-runners: Similar because modern media frames Tarahumaras as supreme endurance runners; differs because ultra-runner is a sport category anyone can join, not an ethnicity.
