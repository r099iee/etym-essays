• Gallic / Gaulish: Similar because they denote the ancient Celtic peoples and language of the same western European world; differs because they are confined to Gaul (modern France), while Celtic is the umbrella covering Gaulish, Celtiberian, Brittonic, and Goidelic alike.
  • Gaelic: Similar because it names a Celtic language; differs because it refers specifically to the Goidelic tongues of Ireland and Scotland, one branch of the wider family rather than the family itself.
  • Brittonic: Similar because it is a Celtic language branch; differs because it covers only the Insular tongues (Welsh, Breton, Cornish), excluding the Continental and Goidelic branches.
  • Goidelic: Similar because it is the sister Insular branch to Brittonic; differs because it groups Irish, Scottish Gaelic, and Manx, the Q-Celtic side, as opposed to the P-Celtic Brittonic side.
  • Celtiberian: Similar because it is an ancient Celtic language; differs because it was spoken on the Iberian peninsula, a Continental Celtic language distinct from the Gaulish and Insular forms.
  • Galatian: Similar because it is a Continental Celtic language and people; differs because it was spoken by the Celts who settled in central Anatolia in the 3rd century BC, far from western Europe.
  • Teutonic / Germanic: Similar because it is a neighbouring Indo-European family in the same nineteenth-century comparative scheme; differs because it denotes the Germanic branch that did NOT displace Latin, in direct contrast to Celtic in the source passage.
  • Indo-European: Similar because Celtic is a branch of the Indo-European family; differs because Indo-European is the entire superfamily, of which Celtic is only one member.
