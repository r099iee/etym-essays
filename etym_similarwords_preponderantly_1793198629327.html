• Predominantly: Similar because both mean for the most part by outweighing the rest; differs because predominantly stresses ruling sway and control, while preponderantly stresses tipping weight on the scales.
  • Mainly: Similar because both name the greater part; differs because mainly is the plain everyday word, while preponderantly is formal and evokes deliberate weighing.
  • Mostly: Similar because both quantify the bulk; differs because mostly is casual and approximate, while preponderantly claims a weighed, evidenced majority.
  • Largely: Similar because both concede exceptions within a bulk claim; differs because largely is about big extent, while preponderantly is about heavier weight winning.
  • Chiefly: Similar because both pick out the leading portion; differs because chiefly ranks heads and leaders, while preponderantly weighs masses on a balance.
  • Principally: Similar because both name the main element formally; differs because principally appeals to principle and first rank, while preponderantly appeals to measured overweight.
  • Primarily: Similar because both put one thing first among many; differs because primarily stresses order and origin, while preponderantly stresses the verdict of the scales.
  • Overwhelmingly: Similar because both describe decisive majorities; differs because overwhelmingly crushes with vast excess, while preponderantly tips with enough weight, leaving the minority standing.
  • Decisively: Similar because both settle a contest; differs because decisively names the final cut of judgment, while preponderantly names the weight that produced it.
