• Longed: Similar because both name intense desire for something absent; differs because longing is purely the desire, while pined adds the idea of wasting away under it — grief consuming the body.
  • Yearned: Similar because both name deep, tender longing; differs because yearning emphasizes the tender, painful reaching of the heart, while pining emphasizes the physical decline and wasting that accompany the longing.
  • Ached: Similar because both name a painful emotional state; differs because ached focuses on the pain felt in the present moment, while pined implies a sustained wasting away over time.
  • Craved: Similar because both name a strong desire; differs because craving is often physical or appetitive (food, substances), while pining is the longing of grief, love, or homesickness.
  • Hankered: Similar because both name an earnest desire; differs because hankered is a mild, often colloquial desire, while pined is intense, sorrowful, and physically destructive.
  • Hungered / Thirsted: Similar because both name intense desire, often metaphorical; differs because hungered and thirsted compare desire to appetite, while pined compares it to torment and slow wasting.
  • Wished / Desired: Similar because both name wanting something; differs because wished and desired are ordinary, neutral wanting, without the grief and physical decline that pined carries.
  • Languished: Similar because both name a decline or drooping of strength; differs because languished can be mere listless weakness or neglect, while pined specifically couples the decline with longing or grief.
  • Withered / Wasted (away): Similar because both name physical decline; differs because withered and wasted focus on the loss of vigor and substance itself, while pined names the emotional cause (longing or grief) that produces the decline.
  • Declined: Similar because both name a loss of strength; differs because declined is neutral and general (health, fortune), while pined is specific to grief and desire.
  • Sickened: Similar because both name becoming unwell; differs because sickened is physical illness (or moral disgust), while pined is the emotional wasting of longing.
  • Fretted: Similar because both name restless distress; differs because fretted is anxiety and worry of short duration, while pined is prolonged, sorrowful wasting.
  • Repined: Similar because both name sorrowful discontent; differs because repined (archaic) is murmuring complaint against one's lot, while pined is silent, longing, and consuming.
  • Sighed: Similar because both name the expression of longing; differs because sighed names the audible breath of sorrow, while pined names the whole internal wasting.
  • Grieved: Similar because both name deep sorrow; differs because grief is sorrow over loss in general, while pining is specifically longing for the absent or the lost, with a wasting quality.
  • Drooped / Wilted: Similar because both name a loss of vitality; differs because drooped and wilted are mostly physical (plants, posture) or momentary, while pined is a prolonged emotional-and-physical state.
  • Mourned: Similar because both name sorrow over loss; differs because mourning is the public or ritual expression of grief, while pining is the private, consuming longing, sometimes for what was never possessed.
