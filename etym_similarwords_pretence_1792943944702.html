• Pretext: Similar because both are excuses screening true motives; differs because a pretext is the stated false reason itself, while pretence is the whole maintained show.
  • Facade: Similar because both are false fronts hiding reality; differs because a facade is architectural and static — the face of the building — while pretence is acted and sustained.
  • Charade: Similar because both are enacted deceptions; differs because a charade is an absurd or transparent performance, while pretence may fool everyone for years.
  • Sham: Similar because both denounce what is bogus; differs because sham is blunt and contemptuous, while pretence is cool and analytical.
  • Deception: Similar because both hide truth by design; differs because deception is the broader genus including single lies, while pretence is the sustained acted show.
  • Guise: Similar because both dress truth in disguise; differs because a guise is the outward costume or manner assumed, while pretence is the ongoing performance within it.
  • Masquerade: Similar because both are disguised proceedings; differs because masquerade suggests festive or social disguise, while pretence serves plots, excuses, and everyday camouflage.
  • Affectation: Similar because both are put-on displays; differs because affectation is mannered display for admiration, while pretence aims to deceive about facts.
  • Subterfuge: Similar because both are tricks evading honesty; differs because subterfuge is the clever stratagem itself, while pretence is the innocent face worn while using it.
