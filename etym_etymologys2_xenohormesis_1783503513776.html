XENOHORMESIS is a modern scientific compound built from two Greek roots; each root has its own separate chain. CHAIN 1 — the element xeno- "foreign": PIE *ghos-ti- (Proto-Indo-European, "stranger, guest, host," denoting the mutual obligations of host and guest; the reconstruction itself is debated — the initial cluster is reconstructed variously, and Beekes considers Greek xénos possibly a Pre-Greek substrate loan, though the pan-Indo-European cognate set Latin hostis, Germanic *gastiz, Slavic *gostь makes the connection plausible) → Greek xénos (ξένος, "guest, stranger, foreigner"; attested from Homer, 8th c. BCE; the same base gave xenía, ritualized guest-friendship) → combining form xeno- (entered European learned coinages from the 19th c., e.g. xenophobia, 1903) → xenohormesis (English scientific compound, coined 2003 by Howitz & Sinclair in Nature) → XENOHORMESIS ◄ TARGET CHAIN 2 — the base hormesis "beneficial stress response": PIE *ser- (Proto-Indo-European, "to flow, run, move swiftly"; proposed root of Greek hormē — NOTE: the ultimate PIE attribution is debated; some scholars link the Greek cluster to *h₃er- "to rouse, set in motion," and an origin internal to Greek cannot be fully excluded) → Greek hormāein / hormân (ὁρμᾶν, "to set in motion, urge on, impel, excite"; Homeric onward) → Greek hormḗ (ὁρμή, "onset, impulse, rapid motion, eagerness"; attested 5th c. BCE) → Greek hormētikós (ὁρμητικός, "impelling, stimulating"; classical) → Greek hormēsis (ὁρμησις, "a rapid motion, impulse"; ancient Greek) → hormesis (English technical term, coined 1943 by the plant pathologists Chester Southam and John Ehrlich, building on the 19th-century Arndt-Schulz law) → xenohormesis (English, 2003, Howitz & Sinclair: xeno- "foreign" + hormesis, literally "foreign beneficial-stress") → XENOHORMESIS ◄ TARGET
