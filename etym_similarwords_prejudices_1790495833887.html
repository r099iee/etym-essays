• bias: Similar because it means a leaning for or against; differs because bias is the modern neutral-technical term, while prejudices stresses pre-judgment without experience.
  • preconception / prejudgment: Similar because both are judgments formed beforehand; differs because these name the act, while prejudices names the settled opinions.
  • partiality / partisanship: Similar because both favour one side; differs because partiality is open allegiance, while prejudice may be unconscious.
  • bigotry: Similar because it is obstinate intolerance; differs because bigotry is hardened and hateful, while prejudices may be soft, affectionate or corrigible.
  • intolerance: Similar because it refuses other views; differs because intolerance is active refusal, while prejudice is prior misjudgment.
  • stereotype: Similar because it is a fixed image of a group; differs because stereotype is the cognitive template, while prejudice adds adverse feeling.
  • predilection / proclivity / penchant: Similar because Ruskin’s prejudices are likings; differs because these are avowed tastes, while prejudice implies unexamined ground.
  • prepossession: Similar because it is a prior occupying of the mind; differs because prepossession is literary and often favourable, while prejudices is everyday and usually adverse.
  • narrow-mindedness / parochialism: Similar because both resist new evidence; differs because these describe character, while prejudices describes opinions.
  • discrimination (adverse): Similar because prejudice produces it; differs because discrimination is behaviour, while prejudices are attitudes behind it.
