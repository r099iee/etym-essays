• Pantry: Similar because it is a room or cupboard for household food; differs because the pantry historically held bread and dry goods (its name from Latin panis ‘bread’), while the larder was the cool meat-and-fat store — loaf vs. pig in origin.
  • Cellar: Similar because it is a storage space for provisions; differs because it is subterranean and used for long-term stores — wine, casks, root vegetables — rather than everyday food kept close at hand.
  • Buttery: Similar because it is an old household food-and-drink store; differs because it originally held butts (casks) of ale rather than food, and is now archaic — a liquor store, not a meat store.
  • Store-room / storeroom: Similar because it is a general place for keeping provisions; differs because it is a plain, modern, purely functional term with none of the larder's cosy domestic or historical flavour.
  • Cupboard: Similar because it is a piece of furniture for storing food; differs because a cupboard is a small closed cabinet, while a larder is traditionally a whole cool room or large walk-in store.
  • Stillroom: Similar because it is an old household store-room; differs because the stillroom (in a great house) was for preserves, spices, cordials, and distillation — the pharmacist's corner — not the meat-and-fat store.
  • Spence: Similar because it is an archaic household store-room; differs because the spence was a general dispensing room or larder for daily servings, not specifically the cool meat store — and it is now dialectal or historical.
  • Scullery: Similar because it is a functional domestic room beside the kitchen; differs because the scullery was for washing dishes and rough work, not for storing food.
