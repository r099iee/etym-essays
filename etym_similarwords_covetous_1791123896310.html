• Avaricious: Similar because it means greedily acquisitive; differs because avaricious stresses hoarding money itself, while covetous stresses envying another's specific goods.
  • Greedy: Similar because it means wanting more than enough; differs because greedy is broader and can concern food or praise, while covetous specifically wants what belongs to someone else.
  • Acquisitive: Similar because it means eager to acquire possessions; differs because acquisitive can sound neutral or corporate, while covetous is openly moral condemnation.
  • Grasping: Similar because it means clutching for gain; differs because grasping emphasizes the seizing hand, while covetous emphasizes the envious heart behind it.
  • Rapacious: Similar because it means predatory greed; differs because rapacious implies violent plunder, while covetous can be quiet, pinching hoarding.
  • Miserly: Similar because it means hoarding stingily; differs because miserly stresses refusing to spend, while covetous stresses desiring to take.
  • Stingy: Similar because it means ungenerous with money; differs because stingy is colloquial about not giving, while covetous is literary about wrongly wanting.
  • Envious: Similar because it means resenting another's advantages; differs because envious can concern beauty or talent without wanting to steal, while covetous wants to possess the thing.
  • Jealous: Similar because it means fearing loss to a rival; differs because jealous guards what one has (lover, position), while covetous schemes to get what another has.
  • Cupidinous: Similar because it is a rare synonym from same Latin cupido; differs because cupidinous is pedantic and obscure, while covetous is the standard biblical term.
  • Materialistic: Similar because it means valuing possessions overmuch; differs because materialistic is a modern sociological label, while covetous is a moral-theological accusation.
  • Mercenary: Similar because it means motivated by money; differs because mercenary implies doing anything for pay, while covetous implies desiring another's goods specifically.
  • Possessive: Similar because it means wanting to own and control; differs because possessive often concerns people and relationships, while covetous concerns property and status.
