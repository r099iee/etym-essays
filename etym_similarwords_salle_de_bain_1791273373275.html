• Salle de bains (plural): Similar because it is the standard modern French spelling for bathroom; differs because plural bains is now prescribed, while singular bain is older or literary.
  • Cabinet de toilette: Similar because it denotes a room for washing and dressing; differs because it suggests a smaller washroom or powder room, often without a full bath.
  • Bathroom: Similar because it is the direct English equivalent; differs because in English it euphemistically includes toilets, while French often separates salle de bain from toilettes / WC.
  • Washroom: Similar because it politely names a room for washing; differs because it is North American and often public, while salle de bain is domestic and French.
  • Lavatory: Similar because it originally meant a place for washing; differs because it is now formal for toilet, while salle de bain centres on bathing.
  • WC (water-closet): Similar because French flats list salle de bain and WC together; differs because WC is the toilet alone, often in a separate tiny room.
  • Powder room: Similar because it euphemises a small guest washroom; differs because it implies no bath, only basin and toilet for retouching.
  • Shower room: Similar because it is a room for full-body washing; differs because it specifies a shower rather than a bath, narrower than salle de bain.
  • Bath: Similar because it can metonymically mean the bathroom (run a bath); differs because it strictly names the tub, not the room.
  • Salle d'eau: Similar because it is a French room for washing with shower and basin; differs because it by definition has no bathtub, only a shower, smaller than a full salle de bain.
  • Toilettes: Similar because it is where French speakers go for the toilet; differs because it is kept lexically and often physically apart from the bathing room.
  • En-suite: Similar because it describes a bathroom attached to a bedroom; differs because it describes layout, not function, while salle de bain names function.
