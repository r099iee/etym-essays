• Khoikhoi: Similar because correct autonym for the same peoples; differs because respectful self-name meaning "real people," replacing the slur.
  • Khoekhoe: Similar because language/culture name for Khoikhoi-Nama speech; differs because properly linguistic term, not an ethnic slur.
  • Nama: Similar because largest surviving Khoikhoi subgroup in Namibia/South Africa; differs because specific nation, not blanket colonial label.
  • San / Bushmen: Similar because neighbouring Khoisan hunter-gatherers often paired with Hottentots in old books; differs because distinct foraging cultures and languages, Bushman also now sensitive.
  • Khoisan: Similar because umbrella for Khoikhoi + San click-speaking peoples; differs because modern linguistic/anthropological coinage (1920s), not colonial slur.
  • Griqua: Similar because mixed Khoikhoi-European frontier community once called Hottentots; differs because specific creole nation with own identity and history.
  • Kaffir (historical): Similar because parallel colonial slur for Bantu-speaking Africans; differs because from Arabic kafir unbeliever, now the most taboo slur in South Africa, distinct target group.
  • Aborigines / Natives (historical): Similar because generic colonial labels for Indigenous peoples; differs because global, not specific to Cape pastoralists, and similarly outdated.
  • Bushman (historical): Similar because paired term Bosjesman for San in same Cape sources; differs because refers to hunter-gatherers, also now replaced by San.
  • Herero: Similar because neighbouring Namibian pastoralists often contrasted with Hottentots; differs because Bantu-speaking, distinct culture and German-colonial genocide history.
