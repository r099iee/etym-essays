• Archetype: Similar because both represent an original, foundational model or standard; differs because archetype emphasizes an ancient, inherited, or primordial symbol/character type embedded in the collective unconscious (e.g., the hero archetype), whereas paradigm denotes an intellectual, structural, or methodological framework.
  • Exemplar: Similar because both serve as an ideal model or pattern worthy of imitation; differs because an exemplar is an individual person, object, or instance that embodies a standard of excellence, while a paradigm is the broader structural system or pattern itself.
  • Framework: Similar because both provide a supporting conceptual structure for organizing ideas; differs because framework emphasizes practical, skeletal guidelines and structural boundaries, whereas paradigm implies a deeper, all-encompassing cognitive lens and worldview.
  • Prototype: Similar because both serve as early models for subsequent development; differs because a prototype is a preliminary, functional working model of a physical product built for testing and iteration before mass production, rather than a theoretical cognitive worldview.
  • Model: Similar because both represent patterns or abstractions of reality; differs because model is a much broader, everyday word that can mean a scale reproduction, a mathematical simulation, or a person posing for art, lacking the epistemological depth of paradigm.
