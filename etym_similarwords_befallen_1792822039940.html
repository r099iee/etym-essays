• Happened: Similar because both mean occurred as events in time; differs because happened is the plain neutral everyday word for anything, while befallen is solemn and fateful, reserved for destinies and disasters.
  • Overtaken: Similar because both describe events catching up with passive victims; differs because overtaken suggests pursuit (night overtook them, ruin overtook him), while befallen suggests descent from above, like weather.
  • Struck: Similar because both picture calamity hitting its target; differs because struck is violent and instant (lightning struck, tragedy struck), while befallen is slower, heavier, more providential.
  • Afflicted: Similar because both describe suffering that arrives unasked; differs because afflicted names ongoing torment (afflicted with grief, with drought), while befallen names the arriving event itself.
  • Visited: Similar because the Bible speaks of plagues visiting and befalling alike; differs because visited upon stresses an agent's deliberate punishment, while befallen can be mere fate without a punisher.
  • Occurred: Similar because both record that something took place; differs because occurred is flat, bureaucratic, and agentless (the accident occurred at noon), while befallen always happens to someone, personally and weightily.
  • Descended: Similar because both imagine fate falling from above; differs because descended is literal motion downward (night descended, the chairman descended), while befallen is the completed metaphysical landing of an event.
  • Transpired: Similar because both are formal words for things coming to pass; differs because transpired is boardroom Latin for events as facts, while befallen is storybook Germanic for events as destiny.
