• Spin (for whirled): Similar because both name rapid rotation; differs because spin is mechanical and even, usually about one’s own axis, while whirl combines great speed with envelopment — the spinner is drawn into the motion.
  • Swirl: Similar because both name circular motion; differs because swirl is slower, wetter, and eddying — the lazy spiral of cream in coffee — while whirl is fast, dry, and vertiginous.
  • Twirl: Similar because both name turning rapidly; differs because twirl is playful, a finger-twisting of hair or a baton, while whirl is a force that seizes and carries the body.
  • Gyrate: Similar because both name circular movement; differs because gyrate implies slow, showy circling, whereas whirl is the fastest and most enveloping of the spin-words.
  • Revolve: Similar because both name motion in a circle; differs because revolve describes orbital motion around an external centre (the planets revolve), while whirl is spinning on or into one’s own vortex.
  • Rotate: Similar because both name turning about an axis; differs because rotate is the technical, neutral word for turning, without speed, force, or envelopment.
  • Eddy: Similar because both name circular fluid motion; differs because eddy is a small, localized back-current in water or air, while whirl is a large, fast, enveloping spin.
  • Wheel: Similar because both name turning motion; differs because wheel implies turning on a pivot with direction, whereas whirl is aimless, violent, and self-absorbing.
  • Threw (for flung): Similar because both name projecting something through the air; differs because threw is the general verb, while flung adds suddenness, violence, and indifference to the landing.
  • Hurled: Similar because both name throwing with great force; differs because hurled is a projectile launched by muscular power and aiming, while flung is released carelessly, without concern for where it lands.
  • Tossed: Similar because both name a light throw; differs because tossed is gentle and casual, a flip of the wrist, whereas flung is violent and whole-bodied.
  • Pitched: Similar because both name throwing; differs because pitched implies a deliberate arc and aim (pitching a ball or a tent), while flung is an unaimed, careless release.
  • Cast: Similar because both name projecting something; differs because cast is formal and directed (casting a net, casting lots), while flung is raw and careless.
  • Slung: Similar because both name throwing with a swinging motion; differs because slung implies a pendular swing (slung over the shoulder, slung from a sling), whereas flung is a straight, violent release.
  • Heaved: Similar because both name throwing with effort; differs because heaved is a great, slow, lifting throw of something heavy, while flung is quick, light, and contemptuous.
  • Launched: Similar because both name sending something forcefully into the air; differs because launched implies deliberate initiation (launching a rocket, a ship, a campaign), while flung is reckless and indifferent.
  • Propelled: Similar because both name driving something forward; differs because propelled is mechanical and neutral, while flung carries violent, careless human force.
