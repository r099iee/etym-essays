• Attempts: Similar because both name tries at a thing; differs because attempts stress effort against difficulty (often failed), while essays stress experiment and learning — an attempt strains, an essay explores.
  • Trials: Similar because both test capacity before commitment; differs because trials are formal and probationary (clinical trials, trial periods), while essays are freer first passes with no verdict but instruction.
  • Experiments: Similar because both probe the unknown by doing; differs because experiments belong to method and hypothesis (labs, controls), while essays belong to craft and art — the bench versus the workbench.
  • Tests: Similar because both put quality to proof; differs because a test measures against a standard (pass or fail), while an essay discovers what the standard might be — examination versus exploration.
  • Drafts: Similar because both are provisional versions before the finished work; differs because a draft is an unfinished stage of the same piece (first draft, final draft), while an essay is a complete small try alongside the great work.
  • Studies: Similar because both are preparatory works (a study for a portrait, studies in craft); differs because studies analyse and prepare systematically, while essays attempt more playfully — the sketchbook versus the playground.
  • Exercises: Similar because both train the hand through practice; differs because exercises drill assigned motions (scales, conjugations), while essays venture something new — practice versus trial flight.
  • Compositions: Similar because every school essay is a composition; differs because compositions cover all put-together work (music, essays, flower arrangements), while essays name the short attempting kind — modest, personal, and provisional.
  • Articles: Similar because both are short non-fiction prose on a subject; differs because an article informs or argues with journalistic finish, while an essay wanders and wonders — reportage versus rumination.
  • Endeavours: Similar because both reach toward something hard; differs because endeavours are earnest and strenuous (noble endeavours), while essays are lighter — trying with curiosity rather than straining with duty.
