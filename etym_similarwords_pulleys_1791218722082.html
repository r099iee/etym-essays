• Blocks: Similar because a block is a pulley in a housing; differs because block names the casing plus sheave, pulley names the wheel itself.
  • Tackles (block and tackle): Similar because tackle is a pulley system for mechanical advantage; differs because tackle implies multiple sheaves and rope falls, not one wheel.
  • Winches: Similar because both haul with rope; differs because winch winds rope on a drum with a crank, pulley only redirects it.
  • Windlasses: Similar because both lift well-buckets or anchors; differs because windlass is a horizontal drum axle, pulley is a grooved wheel.
  • Capstans: Similar because both multiply pulling force; differs because capstan is a vertical drum pushed round, not an overhead wheel.
  • Hoists: Similar because both raise heavy loads; differs because hoist is the whole lifting apparatus, pulley is one component.
  • Cranes: Similar because cranes contain pulleys; differs because crane is the large jib machine, pulley is its small wheel.
  • Levers: Similar because both are simple machines giving advantage, paired in the source; differs because lever is a rigid bar on a fulcrum, not a wheel.
  • Wheels: Similar because a pulley is a specialised wheel; differs because wheel is generic and rolls on ground, pulley is grooved and fixed aloft.
  • Rollers: Similar because both are round friction-reducers in the source sequence; differs because roller goes under a load, pulley guides a rope above it.
  • Gears / Cogs: Similar because belt pulleys and gears both transmit rotation; differs because gears mesh teeth directly, pulleys link by belt or rope.
  • Sheaves: Similar because a sheave is the grooved wheel inside a block; differs because sheave is the technical term, pulley the everyday one.
