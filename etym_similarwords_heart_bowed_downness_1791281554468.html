• downheartedness: Similar because it means dejection with heart + down; differs because it is an established dictionary word, less whimsical and shorter.
  • heavy-heartedness: Similar because it images the heart weighed by sorrow; differs because it stresses weight rather than bowing posture.
  • disheartenment: Similar because it denotes loss of spirit; differs because it focuses on discouragement after hope, not tender sadness.
  • dejection: Similar because it means low spirits; differs because it is formal Latinate and clinical, without bodily image.
  • melancholy: Similar because it names pensive sadness; differs because it suggests temperament and depth, often aestheticised.
  • gloom: Similar because it covers dark low mood; differs because it is short, atmospheric, and can imply pessimism.
  • despondency: Similar because it means loss of hope; differs because it is stronger and closer to despair.
  • low spirits: Similar because it maps mood onto height like bowed-down; differs because it is plain idiom, not a nonce compound.
  • heartache: Similar because it locates sorrow in the heart; differs because it stresses pain rather than bowed posture.
  • blues: Similar because it means passing sadness; differs because it is casual American slang, not biblical-literary.
  • dumps: Similar because it denotes temporary glumness; differs because it is colloquial and slightly comic, without spiritual overtone.
  • woefulness: Similar because it nominalises sorrow with -ness; differs because it stresses woe and lament rather than quiet bowing.
