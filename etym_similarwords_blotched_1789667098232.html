• Mottled: Similar because it denotes irregular colour patching; differs because it is often neutral or decorative, while blotched implies blemish or discoloration.
  • Spotted: Similar because it denotes dotted marking; differs because spots are small, defined, and often natural, while blotches are larger, ragged, and marred.
  • Stained: Similar because it denotes discoloration by foreign matter; differs because stains soak and spread uniformly, while blotches sit as discrete islands.
  • Splotched: Similar because it is a near-synonym for large irregular patches; differs because it is rarer and more liquid, suggesting spilled paint, while blotched suits skin and print.
  • Blotchy: Similar because it is the adjectival doublet; differs because blotchy stresses tendency to blotch, while blotched stresses completed state.
  • Marbled: Similar because it denotes veined two-tone patterning; differs because it is prized and stone-like, while blotched is fault-like.
  • Dappled: Similar because it denotes light-and-dark patching; differs because it is poetic-positive of sun and shade, while blotched is clinical-negative.
  • Freckled: Similar because it denotes small brown skin marks; differs because freckles are tiny, even, and often charming, while blotches are large and disfiguring.
  • Blemished: Similar because it denotes spoiled surface; differs because it is generic moral-cosmetic fault, while blotched specifies patch-like visible form.
  • Discoloured: Similar because it denotes loss of normal colour; differs because it can be uniform yellowing or fading, while blotched requires patchiness.
