• barred: Similar because it denotes transverse striped marking; differs because it is general to any body part, while bar-tailed specifies the tail.
  • banded: Similar because it denotes encircling bands of colour; differs because it often implies broader, fewer bands and is common for neck or belly, not specifically tail pattern.
  • striped: Similar because it denotes linear contrasting marks; differs because stripes are usually longitudinal as well as transverse and lack the technical heraldic-bar sense.
  • streaked: Similar because it denotes linear plumage markings; differs because streaks are thin, lengthwise and often blurry, while bars are crisp and transverse.
  • mottled: Similar because it denotes variegated plumage useful for camouflage; differs because mottling is irregular blotches, not ordered bars.
  • speckled: Similar because it denotes contrasting plumage spots; differs because speckles are small dots, not continuous bars.
  • black-tailed: Similar because it is a parallel ornithological tail compound distinguishing godwits; differs because it denotes solid colour rather than barred pattern.
  • white-tailed: Similar because it is the same compounding pattern for tail diagnosis; differs because it denotes largely white rectrices, not barring.
  • fork-tailed: Similar because it describes tail shape-pattern vocabulary; differs because it denotes shape (forked) rather than colour pattern.
