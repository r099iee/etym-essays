• Boa (alone): Similar because it names the same snakes and genus; differs because boa alone can also mean the feather stole, while boa-constrictor specifies the snake.
  • Python: Similar because it is another huge non-venomous constricting snake; differs because pythons are Old World (Africa, Asia, Australia) and lay eggs, while true boas are New World and bear live young.
  • Anaconda: Similar because it is a giant South American boid that constricts; differs because anaconda is aquatic and heavier, while common boa-constrictors are more arboreal and smaller.
  • Kingsnake / ratsnake: Similar because many colubrids also constrict prey; differs because they are smaller and slender, while boa-constrictors are proverbially huge.
  • Rattlesnake / viper: Similar because they are large showy snakes of the Americas; differs because they kill by venom, while constrictors kill by pressure.
  • Cobra: Similar because it is a famous large tropical snake; differs because cobras are elapid venomous hooded snakes, while boas are non-venomous coils.
  • Serpent (literary): Similar because it denotes a large snake in elevated diction; differs because serpent is generic and biblical, while boa-constrictor is zoologically specific.
  • Constrictor (alone): Similar because it names the killing method; differs because constrictor alone is used for muscles and various snakes, while boa-constrictor names the Linnaean species and popular type.
  • Feather boa: Similar in name only, sharing boa by shape analogy; differs because it is a garment, not an animal.
  • Leviathan (figurative): Similar because both evoke huge coiling power; differs because Leviathan is mythic and marine, while boa-constrictor is real and terrestrial.
