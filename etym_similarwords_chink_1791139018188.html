• crack: Similar because it is a narrow break; differs because it implies damage, while chink can be a built gap.
  • crevice: Similar because it is a narrow opening; differs because it is usually in rock or earth, larger and natural.
  • cranny: Similar because it is a small opening/nook; differs because it suggests a cosy recess, often paired as nooks and crannies.
  • cleft: Similar because it is a split; differs because it is deeper, often in wood or rock.
  • fissure: Similar because it is a slit; differs because it is formal-geological or anatomical.
  • slit: Similar because it is long-narrow opening; differs because it suggests a cut, not necessarily in a wall.
  • slot: Similar because it is a narrow aperture; differs because it is functional, for inserting things.
  • aperture: Similar because it lets light through; differs because it is technical (optics, photography).
  • gap: Similar because it is an opening; differs because it is wider and less slit-like.
  • rift: Similar because it is a split; differs because it is larger, often metaphorical (rift between parties).
  • opening: Similar because it passes air/light; differs because general term, not the slit image.
  • keyhole: Similar because Dickens pairs them as small inlets; differs because it is a specific lock-hole shape.
  • peephole: Similar because you see through; differs because it is intentional for looking.
  • clink (sound homonym): Similar in sound only (chink of coins); differs because it is acoustic, not spatial.
