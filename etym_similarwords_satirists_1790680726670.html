• satirist (singular kin): Similar because it names the same role; differs only in number — one mocker versus the guild of mockers.
  • lampoonist: Similar because it denotes a writer of sharp personal attacks; differs because lampoons target named individuals coarsely, while satire often aims at types and systems.
  • parodist: Similar because it denotes mocking through imitation; differs because parody mimics a style or work, while satire attacks morals and manners.
  • ironist: Similar because it denotes saying the opposite of what is meant to wound or amuse; differs because irony is a technique, satire the mission it may serve.
  • caricaturist: Similar because it denotes exaggerating features to comic effect; differs because the medium is visual distortion rather than verbal argument.
  • pasquinader: Similar because it denotes an anonymous mocker of authority; differs because it is archaic and stresses clandestine posting rather than literary form.
  • critic: Similar because it denotes judging works and manners; differs because criticism may be earnest and systematic, while satire must wound through laughter.
  • moralist: Similar because the satirist claims a corrective purpose; differs because the moralist preaches directly, the satirist shames sideways through ridicule.
  • wit: Similar because it denotes brilliance with words at others’ expense; differs because wit seeks applause for cleverness, satire seeks reform through scorn.
  • cynic: Similar because it denotes a scoffing, disenchanted observer; differs because cynicism doubts all virtue, while satire assumes some standard worth defending.
  • comedian: Similar because modern comics perform satirical mockery; differs because comedy aims first to amuse, satire first to correct.
  • polemicist: Similar because it denotes an aggressive controversialist; differs because polemic argues directly, satire ambushes through laughter.
