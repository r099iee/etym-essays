• Lettrism: Similar because it is the direct English rendering of the same movement; differs because English form is used in Anglophone histories while lettrisme preserves French flavour.
  • concrete poetry: Similar because it treats words as visual objects; differs because it emerged in the 1950s in Brazil and Switzerland and is less metaphysical and noisy.
  • sound poetry: Similar because it performs phonetic matter without semantics; differs because it stresses voice and performance over painted letters.
  • Dada: Similar because it is an anti-art precursor that played with nonsense syllables; differs because Dada is broader, earlier and more nihilistic.
  • hypergraphy: Similar because it is Isou's own term for writing beyond alphabet with invented signs; differs because it names the technique, not the movement.
  • calligraphy: Similar because it aestheticises letter shapes; differs because it is traditional craft, not avant-garde destruction.
  • typography: Similar because it designs letters as image; differs because it is commercial and legibility-bound.
  • Situationism: Similar because it split off from Lettrist International and kept manifesto militancy; differs because it turned to urban politics rather than letters.
  • visual poetry: Similar because it fuses image and text; differs because it is a generic umbrella without Isou's doctrine.
  • onomatopoeia: Similar because Lettrists loved pure noises; differs because it is a device, not a philosophy.
