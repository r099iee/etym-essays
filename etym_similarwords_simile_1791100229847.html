• metaphor: Similar because it compares without literal identity; differs because metaphor asserts identity (he is a lion) while simile marks comparison with like or as.
  • analogy: Similar because it maps one domain onto another; differs because analogy is extended reasoning, often explanatory, while simile is a brief figure.
  • comparison: Similar because it sets things side by side; differs because comparison is the generic act, while simile is the literary device.
  • parallel: Similar because it draws correspondence; differs because parallel stresses structural likeness over poetic image.
  • allegory: Similar because it sustains comparison; differs because allegory is a whole narrative with hidden meaning, not a single like/as phrase.
  • parable: Similar because it teaches through likeness; differs because parable is a story with a moral, while simile is a sentence-level image.
  • metonymy: Similar because it is a figure of substitution; differs because metonymy replaces by association (crown for king), not by likeness.
  • synecdoche: Similar because it is a related trope; differs because it substitutes part for whole rather than comparing.
  • personification: Similar because it creates vivid imagery; differs because it gives human traits to things rather than comparing via like/as.
  • hyperbole: Similar because similes are often hyperbolic; differs because hyperbole is exaggeration itself, not the comparison frame.
  • image / imagery: Similar because similes produce mental pictures; differs because imagery is the general effect, simile one technique.
  • trope: Similar because simile belongs to tropes; differs because trope is the superordinate category of figurative turns.
