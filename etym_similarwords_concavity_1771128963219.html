• Cavity: Similar because both name an empty space within or on a surface; differs because a cavity is a bounded hole, often pathological or accidental (a dental cavity, a bodily cavity), while a concavity is the deliberate structural geometry of an inward curve.
  • Hollow: Similar because both denote an inward, empty area; differs because hollow is naturalistic and rustic (a hollow in a tree trunk, a fog-filled valley), while concavity is formal, sterile, and precisely measured.
  • Depression: Similar because both are sunken or lowered areas; differs because a depression is usually shallow, topographical, or psychological, while a concavity is a precisely defined inward curve.
  • Indentation: Similar because both are inward cuts; differs because an indentation is a small notch or impression in an edge or surface, while a concavity is a broad, three-dimensional, curved hollow.
  • Dent: Similar because both are inward deformations; differs because a dent is an accidental, roughly circular impression made by force, while a concavity is a designed or measurable curve.
  • Crater: Similar because both are bowl-shaped hollows; differs because a crater is a specific, usually circular depression formed by impact or eruption, while concavity is a general geometric property.
  • Dip: Similar because both suggest a downward or inward curving; differs because a dip is a small, informal sag in a surface, while concavity is a formal, geometrically described curve.
  • Trough: Similar because both are long, channel-like hollows; differs because a trough is an open, elongated container or depression, while a concavity need not be elongated or open-topped.
  • Basin: Similar because both are hollow, bowl-like spaces; differs because a basin is a functional, usually roughly circular hollow (a washbasin, a river basin), while concavity names the curved shape itself.
  • Cup: Similar because both describe a hollow that can receive something; differs because a cup is a small drinking vessel, while concavity is the abstract quality of curving inward.
  • Socket: Similar because both are hollowed recesses that receive an object; differs because a socket is a specific fitted hollow (an eye socket, a power socket), while concavity is general and shape-oriented.
  • Void: Similar because both imply emptiness or absence; differs because a void is pure emptiness without shape, while a concavity is an emptiness with a definite inward-curving geometry.
  • Recess: Similar because both are set-back hollows in a surface; differs because a recess is an architectural niche or alcove with its own boundaries, while a concavity is the curve itself.
  • Bowl: Similar because both are hollow, open-topped forms; differs because a bowl is a physical vessel, while concavity is the abstract property that a bowl's interior possesses.
