• wicker: Similar because it is the same pliant-twig medium; differs because wicker is the material or adjective, wickerwork is the finished weave or ware.
  • basketry: Similar because both are woven-vessel crafts; differs because basketry covers all methods including coiling, wickerwork specifies rod lattice.
  • basketwork: Similar because it is virtually synonymous woven ware; differs because basketwork stresses vessel function, wickerwork stresses lattice texture.
  • cane work: Similar because cane is woven for seats and baskets; differs because cane work uses split rattan peel, wickerwork uses whole withies.
  • rattan: Similar because rattan makes wicker-like furniture; differs because rattan names tropical vine, wickerwork names the weave.
  • lattice: Similar because both are criss-cross open structures; differs because lattice is generic geometry in wood or metal, wickerwork is specifically pliable twigs.
  • trellis: Similar because trellis is lattice for plants; differs because trellis is a garden frame, wickerwork is portable ware and texture.
  • wattle: Similar because wattle is woven hazel for walls and fences; differs because wattle is architectural hurdle, wickerwork includes small vessels and furniture.
  • hurdle: Similar because hurdles are woven fencing panels; differs because hurdle is a farm fence unit, wickerwork is the broader craft.
  • hamper: Similar because hampers are often wicker vessels; differs because hamper is a lidded container type, wickerwork is material and method.
  • weaving: Similar because both interlace strands; differs because weaving typically makes cloth on a loom, wickerwork makes rigid lattice without a loom.
  • woodwork: Similar because both are -work crafts in natural material; differs because woodwork is carpentry of rigid timber, wickerwork is bending of green shoots.
