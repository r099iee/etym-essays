• Black (person): Similar because it denotes a person of African ancestry; differs because it is the current respectful term, while Negro is dated.
  • African American: Similar because it denotes Black Americans; differs because it stresses African heritage and citizenship, post-1980s preferred formal term.
  • Afro-American: Similar because it was a 1960s-70s synonym for Black American; differs because it is itself now dated, intermediate between Negro and African American.
  • coloured (historical): Similar because it was another Jim Crow-era polite term; differs because in US it is now offensive, while in South Africa Coloured means mixed-race specifically.
  • person of colour: Similar because it is modern inclusive; differs because it covers all non-white peoples broadly, not Black specifically.
  • Blackamoor (historical): Similar because it was an early modern English term for Black Africans; differs because it is archaic exoticising, even older than Negro.
  • Moor (historical): Similar because it once meant dark-skinned African/Muslim; differs because it originally meant North African/Muslim, vague and medieval.
  • African: Similar because it denotes someone from Africa; differs because it is continental/national, not diaspora-specific like Negro was for Americans.
  • Caribbean-American: Similar because it denotes Black diaspora in US; differs because it specifies Caribbean origin.
  • Negroid (anthropological, obsolete): Similar because it was the racial-taxonomy adjective; differs because it is pseudo-scientific classification now rejected and offensive.
  • nigger (slur, taboo): Similar because it shares the Latin/Spanish root; differs because it was always contemptuous and is now unspeakable slur, while Negro was once dignified — must never be confused or euphemised.
  • Black British / Black South African: Similar because they are modern national Black identities; differs because they specify other diasporas, not American Negro.
