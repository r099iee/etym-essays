• Futurism adherents / Marinettians: Similar because direct members of the 1909 movement; differs because circumlocution, not lexicalized movement name.
  • Cubo-Futurists: Similar because Russian wing fusing Cubism and Futurism; differs because specifically Russian, more linguistic-experimental, less machine-cult.
  • Vorticists: Similar because English avant-garde reacting to Futurism (Wyndham Lewis, Pound); differs because Anglo, more abstract-geometric, explicitly anti-Futurist sentimentality.
  • Constructivists: Similar because post-war avant-garde of construction, typography and design; differs because utilitarian, leftist and Russian/Soviet, rejecting Futurist individualist bravado.
  • Dadaists: Similar because fellow anti-print provocateurs named in same sentence; differs because anti-war, nonsense and chance versus Futurist pro-war speed cult.
  • Surrealists: Similar because later avant-garde inheriting typographic freedom; differs because dream and unconscious rather than machine and speed.
  • Modernists: Similar because umbrella term for early-20th-century break with tradition; differs because far broader, includes Joyce, Eliot, Woolf with no machine worship.
  • avant-gardists: Similar because militant advance-guard artists; differs because generic military metaphor, not specific program.
  • iconoclasts: Similar because breakers of conventions; differs because general attitude, not historical membership.
  • futurologists / futurists (lowercase): Similar because oriented to the future; differs because social-science forecasters, not artists, no capital or manifesto.
