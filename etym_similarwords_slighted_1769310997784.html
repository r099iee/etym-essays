• Snubbed: Similar because both name deliberate social rejection; differs because a snub is an overt, sharp, pointed refusal of acknowledgement, while a slight is often subtler — a studied omission or neglect that wounds pride.
  • Spurned: Similar because both name rejection; differs because spurn implies contemptuous refusal of something offered (love, help), while slight implies withholding respect from a person.
  • Ignored: Similar because both name the withholding of attention; differs because ignored can be neutral or accidental, while slighted always implies deliberate, hurtful neglect.
  • Disregarded: Similar because both name failing to heed someone; differs because disregarded is neutral oversight or inattention, while slighted carries the sting of wounded pride.
  • Neglected: Similar because both name the withholding of proper attention; differs because neglected usually implies failure of care or duty, while slighted implies deliberate social belittlement.
  • Overlooked: Similar because both name being passed over; differs because overlooked is usually unintentional and pitying, while slighted is perceived as intentional and insulting.
  • Insulted: Similar because both name the infliction of offence; differs because insulted usually involves active, verbal, or direct attack, while slighted is the quieter injury of indifference and omission.
  • Affronted: Similar because both name wounded dignity; differs because affronted responds to an open, public offense to honour, while slighted responds to neglect and the withholding of respect.
  • Offended: Similar because both name the taking of umbrage; differs because offended is the broadest term for any hurt feelings, while slighted specifies the injury of being treated as small or insignificant.
  • Rebuffed: Similar because both name rejection; differs because rebuff implies a sharp refusal of an advance or request, while slight implies passive disregard.
  • Cold-shouldered: Similar because both name deliberate social coldness; differs because cold-shouldering is an active, visible show of coolness, while a slight can be a quiet omission.
  • Cut (as in "cut someone dead"): Similar because both name deliberate social disregard; differs because cutting is a conspicuous, performative snub, while a slight is subtler and can be half-noticed.
  • Dissed: Similar because both name disrespect; differs because dissed is informal slang for verbal disrespect, while slighted is formal and describes neglectful treatment.
  • Disparaged: Similar because both name the lowering of a person's worth; differs because disparage attacks reputation through words and criticism, while slight attacks standing through neglect.
  • Belittled: Similar because both name making a person seem small; differs because belittle is active and verbal, the explicit shrinking of a person's importance, while slight is the withholding of the attention that would acknowledge importance.
  • Deprecated: Similar because both name the lowering of worth; differs because deprecate is formal and usually applied to things and practices, while slight applies to persons.
  • Scorned: Similar because both name contemptuous disregard; differs because scorn is an open, felt contempt, while a slight may be an icy indifference without visible emotion.
  • Disdained: Similar because both name the treatment of someone as beneath consideration; differs because disdain is a haughty emotional attitude, while a slight is a social act.
  • Humiliated: Similar because both name the lowering of a person's dignity; differs because humiliation is public and shaming, while a slight can be private and quiet — the wound of being weighed and found small.
  • Passed over: Similar because both name the failure to select or acknowledge; differs because passed over implies being skipped for a promotion or honour, a specific institutional slight.
