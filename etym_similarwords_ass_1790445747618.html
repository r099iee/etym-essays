• donkey: Similar because it names the same animal; differs because donkey is the neutral everyday zoological term, while ass is archaic for the beast and insulting for the person.
  • jackass: Similar because it denotes a foolish, obnoxious person via the male donkey; differs because jackass is coarser and more contemptuous than the often affectionate ass.
  • fool: Similar because it denotes a stupid person; differs because fool is fully general, while ass adds the flavour of stubborn, braying obstinacy.
  • idiot: Similar because it denotes gross stupidity; differs because idiot is clinical-turned-general abuse, while ass is barnyard metaphor with comic warmth.
  • nincompoop: Similar because it denotes a silly, fatuous person; differs because nincompoop is old-fashioned and purely comic, while ass remains in live everyday use.
  • blockhead: Similar because it denotes dense stupidity; differs because blockhead stresses a thick, uncomprehending skull, while ass stresses perverse obstinacy.
  • dolt: Similar because it denotes a dull, stupid fellow; differs because dolt is literary and static, while ass implies actively making a spectacle of one's folly.
  • arse (British): Similar because in American pronunciation it is the same backside word; differs because in Britain arse carries the anatomical/vulgar load, leaving ass free for donkeys and fools.
  • buttocks: Similar because it denotes the same anatomy as vulgar ass; differs because buttocks is clinical and neutral, while ass is taboo and aggressive.
  • mule: Similar because it denotes a related stubborn equine used as character metaphor; differs because mule metaphors stress stubbornness alone, while ass metaphors stress stupidity plus stubbornness.
