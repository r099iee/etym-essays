• Oboe: Similar because it is a woodwind orchestral instrument played with a reed; differs because it is double-reed with a narrower conical bore and a more nasal tone, not single-reed and cylindrical like the clarinet.
  • Saxophone: Similar because it is a single-reed wind instrument; differs because it is made of metal, has a conical bore, and is a 19th-century invention, not a wooden cylindrical woodwind.
  • Flute: Similar because it is a woodwind instrument that plays in the same ensembles; differs because it is edge-blown with no reed at all, while the clarinet uses a single cane reed.
  • Chalumeau: Similar because it is the clarinet's single-reed ancestor with a cylindrical bore; differs because it lacks the register key and the extended range that define the modern clarinet.
  • Recorder: Similar because it is a simple woodwind instrument; differs because it is a fipple flute with a whistle mouthpiece, not a reed instrument.
  • Bassoon: Similar because it is a double-reed woodwind in the orchestra; differs because it is double-reed, conical, and much lower in pitch, with a folded tube rather than the clarinet's straight bore.
  • Clarion: Similar because it shares the clear, bright, ‘ringing’ semantic stem (Latin clarus); differs because a clarion is a high, shrill trumpet or its call—a brass instrument, not a reed woodwind.
  • Licorice stick (jazz slang): Similar because jazz musicians use it as a slang name for the clarinet; differs because it is an informal, colloquial nickname rather than the standard instrument name.
  • Bass clarinet: Similar because it is a member of the same clarinet family; differs because it is the larger, lower-pitched member with a curved neck and bell, not the standard soprano clarinet of the text.
