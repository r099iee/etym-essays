• Latvian: similar because it names the same language and people; differs because it is the modern standard endonym-derived English term, whereas Lettish is archaic and German-mediated.
  • Lett: similar because it is the older English name for a Latvian person; differs because it denotes a person, not the language, and is even rarer than Lettish.
  • Lettic: similar because it is a linguistic adjective for the same Baltic branch; differs because it is a technical synonym that never became the ordinary name of the modern nation.
  • Baltic: similar because Latvian belongs to the Baltic branch; differs because it is broader, covering Lithuanian, Old Prussian, and the reconstructed proto-language.
  • Lithuanian: similar because it is the sister East Baltic language; differs because it is a distinct language with a separate literary tradition and is not mutually intelligible with Latvian.
  • Latgalian: similar because it is a variety closely connected with Latvian; differs because it is a regional dialect or language with its own written norm, not a synonym for the standard language.
  • Livonian: similar because it was spoken in Latvia and influenced Latvian; differs because it is a Finnic, not Baltic, language and is now nearly extinct.
  • Old Prussian: similar because it belongs to the Baltic branch; differs because it is a West Baltic language that died out in the eighteenth century.
  • Lettland: similar because it is the German and Scandinavian name for Latvia; differs because it is a country name, not a language or ethnic adjective.
  • latviesu: similar because it is the Latvian endonym for the language; differs because it is not English and does not carry the archaic, external perspective of Lettish.
