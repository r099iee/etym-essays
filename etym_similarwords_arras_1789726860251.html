• Tapestry: Similar because it is a woven pictorial wall hanging; differs because tapestry is the general modern term, arras specifically recalls medieval Arras work and Shakespearean concealment.
  • Hanging: Similar because it means cloth suspended on a wall for warmth or show; differs because hanging is neutral-household, arras is rich, figured, and literary.
  • Curtain: Similar because it is a cloth screen that veils and is drawn or pierced; differs because curtain is everyday-window, arras is palace-wall and fixed.
  • Drapery: Similar because it denotes heavy cloth arranged in folds; differs because drapery stresses folds and fabric, arras stresses woven pictures and hiding-place.
  • Screen: Similar because it hides what is behind while allowing stabbing or peering; differs because screen is functional-furniture, arras is textile-pictorial.
  • Veil: Similar because it is a thin covering that conceals yet reveals pattern; differs because veil is light-bridal or religious, arras is heavy-secular and martial.
  • Hangings (arras-hangings): Similar because they are the set of tapestries furnishing a hall; differs because hangings is collective-plural, arras can be one piece.
  • Embroidery / Needlework: Similar because arras-work was imitated in stitching; differs because embroidery is sewn on cloth, arras is woven on a loom.
  • Pall: Similar because it is a cloth spread over coffin or altar; differs because pall is funereal-liturgical, arras is domestic-narrative.
