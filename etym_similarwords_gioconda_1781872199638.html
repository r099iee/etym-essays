• Mona Lisa: Similar because both name the same painting by Leonardo; differs because Mona Lisa stresses the given name Lisa (from monna, "madam"), while La Gioconda stresses marital identity and the surname's charge of cheerfulness.
  • La Joconde: Similar because it is the French title of the same painting; differs because it is the Gallicized form, carrying French art-historical resonance rather than the Italian jocund root.
  • Portrait: Similar because it describes the work's genre; differs because it is a generic label that erases the specific cultural-Italian resonance and the smile-centred myth.
  • Masterpiece: Similar because it ranks the painting's achievement; differs because it abstracts the work into status, losing the person-linked, smile-centred emblem that Gioconda preserves.
  • Icon: Similar because it denotes the painting's cultural weight; differs because it turns the work into a general symbol, without the jocund/Giocondo etymological halo Pater exploits.
  • Sitter: Similar because both point to the depicted person; differs because sitter is a neutral technical art-historical term for the person portrayed, not the cultural name of the painting.
  • Sfumato: Similar as part of the painting's mystique; differs because it names Leonardo's smoky chiaroscuro technique, not the painting or its title.
  • Giocondo: Similar in sharing the surname root; differs because Giocondo is the masculine surname/adjective (the merchant's family), while Gioconda is its feminine form naming the woman and, by extension, the portrait.
