• Horrified: similar because it names intense shock at something dreadful; differs because it stresses fear and loathing, while appalled stresses moral condemnation.
  • Shocked: similar because it covers the initial jolt; differs because it is broader and can be morally neutral, whereas appalled always implies disapproval.
  • Aghast: similar because it suggests being stopped short; differs because aghast emphasises open-mouthed astonishment, while appalled emphasises revulsion.
  • Dismayed: similar because it involves loss of composure; differs because dismay is milder and often tied to disappointed hopes rather than moral horror.
  • Outraged: similar because it reacts to wrongdoing; differs because outrage is active anger and a demand for justice, while appalled is a recoil of horror.
  • Disgusted: similar because it involves repulsion; differs because disgust is often physical and visceral, while appalled is more mental and evaluative.
  • Stunned: similar because it describes being temporarily unable to respond; differs because stunned lacks the explicit moral judgement that appalled carries.
  • Sickened: similar because cruelty can produce both; differs because sickened foregrounds bodily nausea, while appalled is cooler and more public.
  • Scandalised: similar because it involves moral shock; differs because scandalised specifically implies offence at a breach of propriety or reputation.
  • Flabbergasted: similar because it means utterly astonished; differs because it is informal and comical, with no moral weight.
  • Dumbfounded: similar because it describes speechless shock; differs because it centres on bewilderment rather than ethical revulsion.
  • Distressed: similar because it names painful emotion; differs because distress is broader and can be caused by grief or worry, not necessarily by wrongdoing.
  • Repulsed: similar because it implies strong aversion; differs because repulsion is instinctive and physical, while appalled includes a judgement about what ought not to be.
  • Appalling: similar because it is the same root used adjectivally; differs because appalling usually describes the thing that causes shock, while appalled describes the person who feels it.
