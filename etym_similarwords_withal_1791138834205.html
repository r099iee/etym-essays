• besides: Similar because it adds an item; differs because it is current and can govern a noun, while withal is archaic and postposed.
  • moreover: Similar because it adds information; differs because it is sentence-initial and formal-modern, not archaic-postposed.
  • also: Similar because it signals addition; differs because it is neutral and flexible in position.
  • too: Similar because it means as well; differs because it is informal, short and always postposed without archaic colour.
  • as well: Similar because it heaps an extra trait; differs because it is phrasal and modern.
  • furthermore: Similar because it continues an enumeration; differs because it is essay-formal and only discourse-level.
  • likewise: Similar because it adds a parallel; differs because it stresses similarity, not mere addition.
  • therewith: Similar because it is an archaic -with compound meaning with that; differs because it is instrumental, not additive.
  • thereby: Similar because it is archaic-formal connective; differs because it means by that means, not in addition.
  • notwithstanding: Similar because withal could concede; differs because it explicitly marks contrast.
  • nevertheless: Similar because both can concede while adding; differs because nevertheless is adversative, not merely additive.
  • along with that: Similar because it expresses co-presence; differs because it is wordy modern paraphrase.
