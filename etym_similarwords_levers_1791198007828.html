• crowbars: Similar because both pry with a fulcrum; differs because crowbar is the heavy bent steel type, while lever is the generic principle.
  • pry bars: Similar because both prise things open; differs because pry bar is American everyday term, while lever is technical or British control term.
  • jimmies (jennies): Similar because both force doors; differs because jimmy implies burglary and thin blade, while lever implies legitimate engineering.
  • handspikes: Similar because both are wooden leverage poles; differs because handspike is nautical/cannonry register, while lever is general.
  • capstan bars: Similar because both multiply manpower; differs because capstan bars fit capstans to wind ropes, while levers work on any fulcrum.
  • handles: Similar because both are gripped to operate; differs because handle is generic grip, while lever must pivot to amplify.
  • pedals: Similar because both are foot controls that pivot; differs because pedals are foot-pressed, while levers are usually hand-pulled.
  • switches: Similar because both select machine states; differs because switch is electrical, while lever is mechanical motion.
  • fulcrums (companion): Similar because both belong to lever system; differs because fulcrum is the pivot point, while lever is the moving bar.
  • influences: Similar because levers of power influence; differs because influence is abstract social effect, while lever implies instrumental advantage point.
  • leverage (finance): Similar because both amplify force/capital; differs because leverage is ratio and strategy, while levers are concrete tools or pressures.
  • treadles: Similar because both transmit foot force by pivoting; differs because treadles drive cyclic machines like looms, while levers usually make single strokes.
