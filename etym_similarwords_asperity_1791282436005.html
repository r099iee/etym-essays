• harshness: Similar because it denotes rough, severe quality; differs because it is broader and blunter, lacking asperity's tactile-literary edge.
  • acrimony: Similar because it means bitterness of manner; differs because it stresses moral resentment rather than curt roughness.
  • acerbity: Similar because it means sharpness of temper or taste; differs because it is rarer and often implies sourness.
  • causticity: Similar because it means biting, corrosive wit; differs because it stresses burning sarcasm over cold curtness.
  • irritability: Similar because it describes easily provoked sharpness; differs because it names the disposition, not the uttered tone.
  • curtness: Similar because it is short, ungracious speech; differs because it stresses brevity rather than grinding edge.
  • roughness: Similar because it is the physical root sense; differs because it is plain and general, while asperity is formal.
  • ruggedness: Similar because it means uneven, hard surface; differs because it is often admiring (sturdy), while asperity is forbidding.
  • severity: Similar because it denotes strict, grave harshness; differs because it implies authority rather than texture.
  • austerity: Similar because it means stern, bare rigour; differs because it stresses self-denial and bareness over sharp tone.
  • churlishness: Similar because it is surly bad temper; differs because it stresses boorish manners rather than cutting edge.
  • testiness: Similar because it is snappish annoyance; differs because it is petty and transient, while asperity can be sustained and dignified.
