• Sullen: Similar because both describe brooding, cheerless ill-humour; differs because sullen stresses a silent, stubborn refusal to speak or engage, while morose describes the overall sour, gloomy disposition of which sullenness is one symptom.
  • Sulky: Similar because both describe bad-tempered withdrawal; differs because sulky is petulant, childish, and often brief — a sulk is a pout — whereas morose is a heavy, mature, settled sourness.
  • Surly: Similar because both describe ill-humoured behaviour; differs because surly emphasizes active rudeness, gruffness, and hostility toward others, while morose centres on gloomy, withdrawn dissatisfaction.
  • Dour: Similar because both describe heavy, joyless severity; differs because dour (Scottish/Northern, from Latin durus "hard") is a cold, unyielding, stern strictness, whereas morose is actively sour and peevish.
  • Gloomy: Similar because both describe darkness of mood; differs because gloomy is the broadest word — it fits weather, rooms, and prospects as well as persons — while morose specifically describes a sullenly ill-tempered human disposition.
  • Glum: Similar because both describe dejected low spirits; differs because glum is a dull, silent, cheerless dejection that invites sympathy, while morose is an aggressive sourness that repels it.
  • Moody: Similar because both describe a dark temper; differs because moody emphasizes unpredictable shifts of mood, whereas morose is a constant, settled gloom.
  • Saturnine: Similar because both describe a heavy, gloomy disposition; differs because saturnine (from the planet Saturn, of the "melancholic" humour) is a learned, sardonic, slow-burning gloom, whereas morose is the plain word for sullen ill-temper.
  • Melancholy: Similar because both describe persistent sadness; differs because melancholy is pensive, sorrowful, often gentle or even pleasurable sadness, while morose is irritable, sour, and unattractive.
  • Churlish: Similar because both describe ill-tempered surliness toward others; differs because churlish emphasizes boorishness and bad manners in society, while morose emphasizes the gloomy inner disposition.
  • Grouchy / Crochety: Similar because both describe irritable bad temper; differs because these are colloquial, fussy, often comic registers, while morose is a formal, heavy word for settled sourness.
