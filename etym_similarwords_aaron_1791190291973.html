• Moses: Similar because inseparable brother and mission partner; differs because Moses is lawgiver-prophet, Aaron priest-spokesman.
  • Miriam: Similar because sibling prophetess in exodus trio; differs because Miriam leads women in song, Aaron leads sacrifice.
  • High priest: Similar because Aaron defines the office; differs because high priest is title held by successors, Aaron is founding person.
  • Levite: Similar because Aaron is a Levite founder; differs because Levite is tribal class, Aaron is individual patriarch of priests.
  • Priest: Similar because both mediate between God and people; differs because priest is generic function, Aaron is biblical prototype.
  • Spokesman: Similar because Aaron is Moses's mouth; differs because spokesman is role, Aaron adds kinship and priesthood.
  • Mediator: Similar because both intercede; differs because mediator is abstract, Aaron is narrative embodiment.
  • Patriarch: Similar because both command ancestral honour; differs because patriarchs found tribes, Aaron founds priesthood.
  • Harun: Similar because Harun is Arabic form of same man; differs because Harun signals Qur'anic register, Aaron biblical English.
  • Aharon: Similar because Aharon is Hebrew original; differs because Aharon signals Israeli/Jewish use, Aaron Anglicised.
  • Eleazar: Similar because son and successor as high priest; differs because Eleazar continues, Aaron originates.
  • Melchizedek: Similar because both are priestly types; differs because Melchizedek is mysterious eternal priest, Aaron hereditary.
