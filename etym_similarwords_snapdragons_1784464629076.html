• Dragon: Similar because it supplies the "dragon" root of the name; differs because a dragon is the mythical beast itself, while a snapdragon is only the flower that looks like its snout.
  • Antirrhinums: Similar because they are the same plant; differs because antirrhinum is the botanical Latin / Greek name ("counter-nose"), while snapdragon is the vivid folk name.
  • Toadflax: Similar because it is a closely related snap-mouth flower (Linaria, once grouped with Antirrhinum); differs because toadflax is a smaller, different genus, named for the toad rather than the dragon.
  • Foxgloves: Similar because they are mouth-like cottage-garden flowers with the same folk-naming habit; differs because a foxglove is a bell-shaped Digitalis flower (a fox's glove), not a snapping two-lipped bloom.
  • Lilies: Similar because they are garden flowers named as firework shapes in the same sentence; differs because a lily is a different flower and flower-name, not the snap-mouth plant.
  • Laburnums: Similar because they are flowering plants in the same Tolkien list; differs because a laburnum is a yellow-flowered tree, not a snap-mouth flower.
  • Snap-beans: Similar because they share the descriptive snap- element (the pod breaks with a snap); differs because snap-beans are edible garden beans, not ornamental flowers.
