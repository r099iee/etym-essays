• Doorway: Similar because both mark an opening in a wall; differs because a doorway is any opening meant for a door and need not be curved, while an arch announces itself — a load-bearing curve that holds the gap open.
  • Gateway: Similar because both are openings made to be closed by a gate; differs because the arch in the passage is precisely a gateway whose gate is gone — the gate is a function, the arch a structure.
  • Portal: Similar because both are grand thresholds of importance; differs because a portal is a decorated, ceremonial doorway of cathedral or palace, while an arch is any curved member, humble or grand, gaining its glamour from the work the curve does.
  • Vault: Similar because both are built from the same arched geometry; differs because a vault is the arched ceiling or roof spanning a space — the arch built in three dimensions — while an arch is the single curved member.
  • Arcade: Similar because both are arch-built structures; differs because an arcade is a series or row of arches, often carried on columns, while an arch is a single span.
  • Arc: Similar because both descend from the same Latin 'arcus' and name a curve; differs because an arc is the geometric curve itself, without the engineering of supporting weight — an arch is an arc doing work.
  • Bow: Similar because the arch and the bow share one name-history (Latin arcus) and one bent shape; differs because the bow is the weapon that stores elastic energy to shoot, while the arch is the stone or brick curve that carries weight — one bends to launch, the other to hold.
  • Span: Similar because both describe the distance bridged across an opening; differs because a span is the measured gap itself, and can be crossed by any structure, while an arch is a specific curved way of crossing it.
