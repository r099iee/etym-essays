• Barrel: Similar because both are hooped wooden containers for liquids; differs because barrel is the general word for the class and also a specific size (about 36 imperial gallons), while cask is the brewing and cooperage term for the whole family of wooden maturation vessels.
  • Keg: Similar because both are containers for beer; differs because a keg is smaller and today usually metal and pressurized with CO2, the modern rival to the traditional wooden cask, and "cask versus keg" is a famous cultural divide in British beer.
  • Hogshead: Similar because both are coopered vessels in the same family; differs because a hogshead is a specific large size (about 54–63 gallons), a precise measure, while cask is the general term covering all sizes.
  • Tun: Similar because both are large cellar vessels; differs because a tun is the largest standard size and historically the tax measure of the wine and beer trades, while cask spans the whole range of sizes.
  • Butt: Similar because both are large cooperage for aging; differs because a butt is a specific very large cask size (about 108–126 gallons), traditionally the sherry and port vessel, while cask is the generic term.
  • Firkin: Similar because both are coopered vessels; differs because a firkin is a small cask (about 9–10 gallons), historically a standard of the English ale trade, while cask names the class rather than one size.
  • Vat: Similar because both are large containers for liquids; differs because a vat is usually an open vessel used for fermenting or storage, while a cask is a closed, hooped, maturing vessel built for transport and aging.
  • Casket: Similar because both words descend from the same source family (a diminutive of cask); differs because a casket is a small box — today usually a coffin or a jewel case — while a cask is the large wooden vessel for liquids.
