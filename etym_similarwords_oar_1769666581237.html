• Paddle: Similar because both are bladed poles used to move a boat through water; differs because a paddle is held freely in the hands with no fulcrum, while an oar pivots against a fixed point (rowlock/thole) on the boat.
  • Scull: Similar because a scull is a short oar used in pairs (one in each hand) by a single rower, or a single oar worked over the stern for steering/propulsion; differs because scull denotes these specific single-handed arrangements, while oar is the general term for the long-bladed rowing implement.
  • Sweep (sweep oar): Similar because a sweep is a large oar pulled by one rower in crew racing; differs because sweep is racing jargon for the single-oar-per-rower configuration (vs sculling's two), while oar covers all such implements.
  • Blade: Similar because the blade is the flat, water-pushing end of the oar; differs because blade names only that part, and in modern rowing "blade" has become slang for the whole oar — a part-for-whole metonymy.
  • Pole/Quant: Similar because both are long poles used to move a boat; differs because a pole or quant pushes against the riverbed (punting), while an oar pushes against the water through a fulcrum.
  • Rudder: Similar because a steering oar functions like a rudder; differs because a rudder is a fixed blade that steers only (no propulsion), while an oar both propels and can steer.
  • Rowlock: Similar because the rowlock is the fitting that holds and pivots the oar — the two form one working system; differs because the rowlock is part of the boat (the fulcrum), not the rowing implement itself.
