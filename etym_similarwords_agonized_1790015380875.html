• anguished: Similar because both mean wrung with deep pain; differs because anguished is state of grief, while agonized adds active wrestling and audible spasm.
  • tormented: Similar because both mean cruelly afflicted; differs because tormented stresses repeated infliction, while agonized stresses contest-like throes.
  • tortured: Similar because both mean subjected to extreme pain; differs because tortured implies inflicter and instrument, while agonized can be self-wrestling.
  • racked: Similar because both mean stretched with pain (on the rack); differs because racked is bodily-archaic (racked with cough), while agonized covers mind and voice.
  • harrowed: Similar because both mean lacerated by suffering; differs because harrowed (dragged harrow) is literary-desolate, while agonized is vocal-contorted.
  • excruciated: Similar because both mean cross-like torment; differs because excruciating describes causing pain, while agonized describes undergoing and showing it.
  • distressed: Similar because both mean upset and pained; differs because distressed is milder-general, while agonized is extreme and spasmodic.
  • suffering: Similar because both mean enduring pain; differs because suffering is neutral-ongoing, while agonized is acute-climactic.
  • pained: Similar because both show hurt in face or voice; differs because pained can be slight-wincing, while agonized is contorted-writhing.
  • wretched: Similar because both evoke pitiable misery; differs because wretched is abject condition, while agonized is throbbing struggle.
  • despairing: Similar because both lose hope under pain; differs because despairing stresses hopelessness, while agonized stresses striving despite hopelessness.
