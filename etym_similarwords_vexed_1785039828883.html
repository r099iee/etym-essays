• Annoyed: Similar because both name a mild, everyday state of irritation; differs because annoyed is the plain, neutral modern word, while vexed is more literary and slightly old-fashioned.
  • Irritated: Similar because both describe rising displeasure; differs because irritated suggests a sharper, more physical sense of being rubbed the wrong way, whereas vexed is cooler and more cerebral.
  • Frustrated: Similar because both involve displeasure at an obstacle; differs because frustrated emphasises the thwarting of a goal or desire, while vexed need not imply any aim that was blocked.
  • Exasperated: Similar because both can mean greatly annoyed; differs because exasperated is markedly stronger, on the verge of losing patience, while vexed remains moderate and understated.
  • Peeved: Similar because both denote light, rueful irritation; differs because peeved is casual and colloquial, whereas vexed keeps a dignified, bookish air.
  • Nettled: Similar because both name a stinging, pricking irritation; differs because nettled is more personal — the irritation of a provoked wound — while vexed is a more diffuse bad temper.
  • Aggrieved: Similar because both describe displeasure; differs because aggrieved carries a sense of being treated unjustly, a grievance, which vexed lacks.
  • Provoked: Similar because both describe being stirred to annoyance; differs because provoked implies an external cause that deliberately roused you, while vexation may arise from mere circumstances.
  • Tormented: Similar because both descend from the same Latin source and can mean troubled; differs because tormented is the archaic strong sense — severe, prolonged suffering — whereas modern vexed is mild.
  • Harried: Similar because both can describe being bothered repeatedly; differs because harried suggests being chased or pressed by duties or pursuers, a running annoyance, while vexed is static.
  • Harassed: Similar because both derive from the vigorous Latin sense of vexare; differs because harassed today implies persistent, often oppressive pressure or unwanted attention, far stronger than vexed.
  • Disgruntled: Similar because both name a dissatisfied mood; differs because disgruntled suggests sullen, simmering discontent, while vexed is a shorter, lighter flash of annoyance.
