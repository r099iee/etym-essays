• abaft: Similar because it also means toward the stern; differs because abaft is position inside or relative to the ship (toward stern from amidships), while astern is outside beyond the stern.
  • aft: Similar because it means at or near the stern; differs because aft is general rear area aboard, while astern is strictly behind the vessel in the water.
  • behind: Similar because it means to the rear of; differs because it is generic land English, lacking nautical precision and motion implication.
  • backward / backwards: Similar because it denotes rearward motion; differs because it is general direction, not anchored to a hull or wake.
  • rearward: Similar because it means toward the rear; differs because it is formal military-aviation term, not specifically maritime.
  • astern of: Similar because it is the prepositional form of same root; differs only in syntax, taking an object (astern of the flagship).
  • downstream / in the wake: Similar because it evokes trailing behind in flow; differs because it implies current or wake, not hull orientation.
  • trailing: Similar because it means falling behind in race; differs because it is general competition term, not directional command.
