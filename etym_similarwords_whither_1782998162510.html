• Where: Similar because both ask about place; differs because where asks for a static location ('Where are you?'), while whither asks for the goal of motion ('Whither are you going?' = to what place).
  • Whence: Similar because it is the third member of the same archaic directional set; differs because it asks for the source or origin ('from what place') rather than the destination.
  • Thither: Similar because it belongs to the same archaic directional system and shares the -th- spelling; differs because it is demonstrative ('to that place') rather than interrogative.
  • Hither: Similar because it is the demonstrative twin of thither in the same system; differs because it points 'to this place' (near the speaker), and is likewise not a question word.
  • Wither: Similar in pronunciation and spelling shape only; differs because it is a verb meaning 'to shrivel or fade', etymologically unconnected and a classic spelling trap.
  • Whithersoever: Similar because it is built on whither; differs because it is intensified and relativized, meaning 'to whatever place' rather than asking 'to what place'.
  • Whereto: Similar because it also means 'to what place' in formal usage; differs because it is a transparent compound of where + to, never fully naturalized, and far rarer than whither.
  • Whitherward: Similar because it names the direction of travel; differs because the -ward suffix adds a sense of 'in the direction of', and the word is even more archaic than whither itself.
