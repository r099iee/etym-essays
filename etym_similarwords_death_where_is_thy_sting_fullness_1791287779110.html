• exultation: Similar because it denotes triumphant rejoicing; differs because it is a standard noun without the biblical parody and hyphen-joke.
  • triumph: Similar because it means victorious joy; differs because it implies actual victory rather than merely an irritating manner.
  • gloating: Similar because it captures distasteful self-satisfaction; differs because it stresses malice toward the loser rather than cosmic taunt.
  • jubilance: Similar because it means exuberant joy; differs because it is warmer and less smug than the target.
  • elation: Similar because it means high-spirited uplift; differs because it is internal feeling, not an aura perceived by others.
  • crowing: Similar because it means boastful display after winning; differs because it is colloquial and vocal, while the target is a pervasive manner.
  • swagger: Similar because it denotes ostentatious confidence; differs because it emphasizes gait and bearing, not theological echo.
  • smugness: Similar because it denotes offensive self-satisfaction found distasteful; differs because it lacks the resurrection-victory allusion.
  • flush of victory: Similar because it denotes the glow after success; differs because it is a phrase for a transient state, not a -ness trait.
  • exuberance: Similar because it means overflowing spirits; differs because it is generally likable energy, not gloating.
