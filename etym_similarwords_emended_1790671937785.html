• amended: Similar because both remove faults to improve; differs because amend improves substance, conduct or law, while emend restores text to correctness.
  • corrected: Similar because it fixes errors; differs because it is general and neutral, lacking emend's specifically textual-scholarly and conjectural charge.
  • rectified: Similar because it makes right; differs because it implies straightening technical or moral error, not philological restoration.
  • revised: Similar because it re-works a draft; differs because revision may rewrite freely, while emendation claims fidelity to an original.
  • redacted: Similar because it is editorial work on documents; differs because redaction selects, arranges or censors, not necessarily corrects corrupt letters.
  • edited: Similar because it prepares text for publication; differs because it is broad, covering selection and styling, while emend is narrowly corrective.
  • copy-edited / proofread: Similar because they clean proofs; differs because they are trade-technical and routine, while emend invokes scholarship and conjecture.
  • restored: Similar because it returns to an earlier true state; differs because restoration is material or architectural, emendation verbal.
  • expurgated: Similar because it purges text; differs because it removes obscenity or offence on moral grounds, not error on evidential grounds.
  • collated: Similar because it compares witnesses in textual criticism; differs because collation gathers variants, emendation chooses or invents the true reading.
  • conjectured (a reading): Similar because many emendations are conjectures; differs because conjecture proposes, emendation enacts.
  • improved: Similar because emending betters; differs because improvement is open-ended, emendation is bounded by fidelity.
