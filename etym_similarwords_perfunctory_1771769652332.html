• Cursory: Similar because both describe quick, shallow attention to a task; differs because cursory emphasizes speed and surface coverage (a cursory glance), while perfunctory adds the motive of duty done with little heart — the act is performed for form's sake.
  • Superficial: Similar because both imply lack of depth; differs because superficial judges the depth of content or understanding, while perfunctory judges the effort and spirit of the performance itself.
  • Mechanical: Similar because both describe unthinking, routine action; differs because mechanical can be a neutral description of habit or automation, while perfunctory is evaluative and usually pejorative about human attention.
  • Routine: Similar because both apply to habitual, customary actions; differs because routine is a neutral label for regular procedure, whereas perfunctory adds the criticism of being done without genuine engagement.
  • Half-hearted: Similar because both describe action lacking enthusiasm; differs because half-hearted suggests divided or weak commitment, while perfunctory emphasizes getting the duty over with merely to satisfy form.
  • Pro forma: Similar because both describe compliance for the record; differs because pro forma stresses formal compliance to satisfy a rule or document (a pro forma invoice, a pro forma hearing), while perfunctory stresses the low-effort manner of doing it.
  • Automatic: Similar because both imply action without thought; differs because automatic suggests reflex or mechanism without moral criticism, while perfunctory implies a deliberate (if minimal) discharge of obligation.
  • Careless: Similar because both describe inattentive execution; differs because careless stresses neglect and possible error, while perfunctory stresses dutiful minimum effort — the perfunctory act is done, just without care.
  • Hasty: Similar because both describe hurried, shallow performance; differs because hasty emphasizes speed and possibly premature action, while perfunctory does not necessarily imply speed, only minimal engagement.
  • Listless: Similar because both suggest action lacking energy or spirit; differs because listless describes a general lack of energy or enthusiasm (of persons and moods), while perfunctory qualifies the manner of a specific act.
  • Offhand: Similar because both describe careless, casual treatment; differs because offhand suggests casualness or indifference in remark or manner, while perfunctory retains the sense of discharging a duty.
  • Indifferent: Similar because both involve lack of interest; differs because indifferent is a state of feeling (not caring), while perfunctory is the behavioural manner that shows the indifference.
  • Token: Similar because both describe a gesture that satisfies a form without substance; differs because token is nominal or symbolic in extent, while perfunctory describes the manner of performance.
  • Negligent: Similar because both involve failure to give proper care; differs because negligent implies culpable neglect that may cause harm, while perfunctory implies minimal but technically performed duty.
  • Slipshod: Similar because both describe careless, sloppy work; differs because slipshod emphasizes untidy, slovenly execution and error, while perfunctory emphasizes dutiful minimum effort without sloppiness necessarily.
