• Slobbering: similar because it describes saliva running from the mouth; differs because it is wetter, messier and more disgusted in tone.
  • Slavering: similar because it means letting saliva flow; differs because it is more literary and can also mean fawning flattery.
  • Salivating: similar because it names saliva production; differs because it is the neutral physiological term and need not imply visible drooling.
  • Dribbling: similar because liquid escapes in drops; differs because dribbling is a thinner, lighter flow and is the usual British word for a baby's saliva.
  • Drivelling: similar because it means talking nonsense; differs because drivel is the older, more literary term for feeble or childish talk.
  • Babbling: similar because it describes incoherent speech; differs because babbling is rapid and continuous and has no saliva image.
  • Raving: similar because it means wild, senseless talk; differs because raving implies fever or madness rather than weak-mindedness.
  • Gushing: similar because it suggests uncontrolled expression; differs because gushing is enthusiastic and sentimental, not bodily.
  • Fawning: similar because it can imply abject admiration; differs because fawning is flattery and servility, not appetite.
  • Lusting: similar because it names strong desire; differs because lusting is explicit and sexual, while drooling is a comic bodily metaphor.
  • Wanting: similar because it implies desire; differs because wanting is neutral and general, while drooling suggests shameless excess.
  • Idiotic: similar because drooling can imply stupidity; differs because idiotic is a judgement of intelligence, not a description of speech or saliva.
