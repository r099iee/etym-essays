• unease: Similar because it names lack of ease or comfort; differs because unease is more general and physical, while disquiet stresses mental agitation over an idea or prospect.
  • anxiety: Similar because it names worried anticipation; differs because anxiety is stronger, often clinical, and can be objectless, whereas disquiet is milder and usually directed.
  • apprehension: Similar because it names fearful expectation; differs because apprehension points to a future dreaded event, while disquiet can be present-tense restlessness.
  • foreboding: Similar because it names a sense that something bad will happen; differs because foreboding is more ominous and intuitive, disquiet more reflective.
  • restlessness: Similar because it names inability to rest; differs because restlessness stresses physical or mental motion, disquiet stresses troubled feeling.
  • perturbation: Similar because it names disturbance of calm; differs because perturbation is more formal and technical, often momentary.
  • agitation: Similar because it names disturbed excitement; differs because agitation is more outward and vehement, disquiet more inward and subdued.
  • trepidation: Similar because it names trembling fear; differs because trepidation implies timidity before an undertaking, disquiet implies sustained concern.
  • malaise: Similar because it names vague discomfort; differs because malaise is bodily or societal and diffuse, disquiet is mental and more focused.
  • angst: Similar because it names deep existential unease; differs because angst is philosophical and intense, disquiet is everyday and moderate.
  • unrest: Similar because it names collective disturbance; differs because unrest implies potential action or protest, disquiet implies mood alone.
  • discomposure: Similar because it names loss of composure; differs because discomposure is momentary embarrassment or confusion, disquiet is lingering worry.
