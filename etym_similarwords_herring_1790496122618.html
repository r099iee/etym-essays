• Whitebait: Similar because it is small silvery shoaling fish eaten whole; differs because whitebait are juveniles of herring and sprats, while herring proper are adult.
  • Sprat: Similar because it is a tiny North Sea clupeid often confused with young herring; differs because sprat is a distinct smaller species, while herring is larger and the fishery staple.
  • Sardine (pilchard): Similar because it is another oily shoaling clupeid cured in tins; differs because sardine is warm-water Mediterranean, while herring is cold-water Atlantic.
  • Shad: Similar because it is a large anadromous herring relative; differs because shad runs up rivers to spawn, while herring spawns at sea.
  • Anchovy: Similar because it is a small oily forage fish salted and tinned; differs because anchovy is much smaller, stronger, and Mediterranean, while herring is milder and northern.
  • Mackerel: Similar because it is another oily shoaling North Sea food fish; differs because mackerel is scombroid with stripes and richer flesh, while herring is clupeid and leaner.
  • Kipper: Similar because it is herring prepared by splitting and smoking; differs because kipper names the cured product, while herring names the live fish and species.
  • Bloater: Similar because it is lightly smoked whole Yarmouth herring; differs because bloater is the specific cure, while herring is the generic fish.
  • Red herring (food): Similar because it is hard-smoked herring; differs because as food it is one cure among many, while as idiom it means a false trail.
  • Pilchard: Similar because it is the Cornish name for adult sardines, another canned clupeid; differs because pilchard is south-western and tinned, while herring is eastern and barrelled or smoked.
