• Sri Lanka: Similar because it denotes the same island country; differs because it is the official post-1972 endonym, while Ceylon is the historical colonial exonym.
  • Taprobane: Similar because it is an ancient Greek-Roman name for the same island; differs because it derives from Tambapanni copper-land and belongs to classical geography.
  • Serendib: Similar because it is a medieval Arabic-Persian name for the island; differs because it survives mainly in the story of serendipity, not as a political name.
  • Lanka: Similar because it is the short indigenous name for the island; differs because it comes from Ramayana mythology and is used poetically and politically.
  • Tambapanni: Similar because it is an ancient Pali name for the island; differs because it means copper-palmed and refers to Vijaya's landing beach in chronicles.
  • Ceilao: Similar because it is the Portuguese form of the same name; differs because it reflects 16th-century Lusitanian spelling and pronunciation.
  • British Ceylon: Similar because it denotes the island under British rule; differs because it specifies the 1796-1948 crown colony administration.
  • Dominion of Ceylon: Similar because it is the 1948-1972 independent state; differs because it marks the transitional dominion period before the republic.
  • India: Similar because it is the nearby South Asian neighbour and former imperial context; differs because it is a separate vast mainland country, not the island.
  • Madagascar: Similar because it is another large Indian Ocean island with colonial plantation history; differs because it lies off Africa with Malagasy culture, not South Asian.
  • Zanzibar: Similar because it is a spice island of colonial trade; differs because it is a Tanzanian archipelago famed for cloves, not tea and cinnamon.
  • Maldives: Similar because it is a nearby Indian Ocean island nation; differs because it is a low coral atoll chain with Islamic Dhivehi culture.
