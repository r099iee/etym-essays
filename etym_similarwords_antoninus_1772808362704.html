• Marcus Aurelius: Similar because both names denote the same emperor; differs because "Marcus Aurelius" stresses the Stoic philosopher-king and the Meditations, while "Antoninus" stresses dynastic title and the Antonine line.
  • Antoninus Pius: Similar because both share the family name and the dynasty; differs because Pius is the adoptive predecessor and first bearer of the imperial cognomen, while Gibbon's "Marcus Antoninus" is the last of the line whose death marks the turn.
  • Commodus: Similar because both are imperial names of the same dynasty; differs because Commodus names the rupture — hereditary succession and subsequent chaos — the opposite of Antonine virtue.
  • The Antonines (the two Antonines): Similar because both refer to the same family line; differs because the plural collective label covers Antoninus Pius and Marcus Aurelius together, while the singular "Antoninus" picks out one man.
  • Five Good Emperors: Similar because both refer to the same rulers; differs because it is a modern collective tag for the whole adoptive line (Nerva to Marcus Aurelius), not a personal name.
  • Mark Antony (Marcus Antonius): Similar because both rest on the same Latin nomen Antonius; differs because Mark Antony is the triumvir of the first century BCE, a very different person from the Antonine emperors of the second century AD.
  • Pax Romana: Similar because both evoke the empire's peaceful height; differs because Pax Romana is an era-label for the structural peace, while Antoninus is the man whose death Gibbon uses to close that era.
  • Meditations: Similar because both point to the same emperor's legacy; differs because Meditations is the title of his philosophical work, not a name or a dynasty.
