• Congo River: Similar because it is the core physical referent of Congo; differs because it names only the waterway, not the states or forest.
  • Congo Basin: Similar because it denotes the drainage area called Congo; differs because it is strictly geographical/ecological, not political.
  • Democratic Republic of the Congo (DRC): Similar because it is the largest modern state called Congo; differs because it specifies Kinshasa-Congo (formerly Zaire), not the river or the other republic.
  • Republic of the Congo: Similar because it is the second modern state called Congo; differs because it means Brazzaville-Congo, smaller and west of the river.
  • Zaire: Similar because it was the official name (1971-1997) for DRC and the river; differs because it is a dated political renaming, now historic.
  • Kingdom of Kongo: Similar because it is the precolonial namesake polity; differs because historians spell it with K and it refers to the 1390-1914 kingdom, not modern states.
  • Central Africa: Similar because Congo lies at its heart; differs because it is a broad region including Chad, Cameroon, CAR, not specifically Congo.
  • Upper Congo: Similar because it is part of the Congo River system; differs because it means only the upstream Lualaba stretches.
  • Congo Free State: Similar because it was the 1885-1908 colonial entity in the same territory; differs because it denotes Leopold II's personal colony and its atrocities, not the present country.
  • Belgian Congo: Similar because it was the 1908-1960 colony preceding DRC; differs because it is a historical administrative term.
  • Kikongo / Kongo people: Similar because they are the ethnolinguistic source of the name; differs because they name a people/language, not the river or state.
  • Equatorial Africa: Similar because it describes the same tropical zone; differs because it is climatic, not a proper place-name.
