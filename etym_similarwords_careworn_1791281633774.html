• haggard: Similar because it describes a tired lined face from suffering; differs because it is stronger and suggests wild exhaustion or illness, less dignified.
  • gaunt: Similar because it describes thin worn appearance from hardship; differs because it emphasizes thinness and hollowness of cheeks rather than worry lines.
  • drawn: Similar because it describes a strained tired face; differs because it focuses on tight pinched features from immediate pain or fatigue, not long history.
  • weary: Similar because it expresses tiredness from burden; differs because it is general and temporary, not necessarily etched on the face.
  • worried: Similar because it expresses anxiety; differs because it names the inner feeling, not the visible wearing effect over time.
  • anxious: Similar because it conveys care and unease; differs because it is psychological and present-focused, without the sense of long erosion.
  • troubled: Similar because it suggests burden and distress; differs because it is broader and can be momentary, less visual.
  • harassed: Similar because it suggests strain from pressures; differs because it implies external pestering and agitation rather than sorrowful wearing.
  • weather-beaten: Similar because it describes a face lined by exposure; differs because the agent is sun, wind, and age, not worry.
  • worn: Similar because it means eroded by use or time; differs because alone it lacks the specific cause of care and sympathy.
  • wan: Similar because it describes pale tired looks; differs because it stresses pallor and feebleness, more poetic and physical.
  • forlorn: Similar because it conveys sad abandoned looks; differs because it emphasizes loneliness and hopelessness rather than labour of care.
