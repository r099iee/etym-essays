• Byproduct: Similar because both name something produced incidentally by a process aimed at something else; differs because byproduct is the generic neutral term for any secondary product, while spandrel specifically names a byproduct forced by the structural constraints of other selected features.
  • Side effect: Similar because both describe an effect that accompanies the primary intended effect; differs because side effect is a looser everyday and medical term implying mere accompaniment, whereas spandrel carries the stronger claim of geometrical or structural inevitability.
  • Epiphenomenon: Similar because both name a secondary phenomenon that arises from a primary process; differs because epiphenomenon is used in philosophy and neurology for a secondary effect with no causal power, while a spandrel can later be co-opted and become functional.
  • Exaptation: Similar because both concern features not originally selected for their current function; differs because exaptation names the process of later co-option (the reuse), while spandrel names the incidental origin itself — a spandrel becomes an exaptation only when it is subsequently pressed into service.
  • Vestigial structure: Similar because both are biological "leftovers"; differs because a vestigial structure once had a function that it has since lost and is typically degenerating, whereas a spandrel never had a function to lose.
  • Adaptation: Similar because both are biological features discussed under selection; differs because an adaptation is a trait shaped by selection for its present function, whereas a spandrel is precisely the trait that was not selected for.
  • Emergent property: Similar because both arise from the interaction of other features; differs because an emergent property is a system-level effect of parts working together, while a spandrel is an incidental structural leftover rather than a cooperative product.
  • Corollary: Similar because both are consequences that follow from something else; differs because corollary is a logical or mathematical term meaning a proposition that follows from a proven one, with no biological or architectural content.
