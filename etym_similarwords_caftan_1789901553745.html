• Robe: Similar because it denotes a long loose outer garment; differs because robe is generic and includes bathrobes and ceremonial gowns, while caftan specifies the straight Turkish-Russian cut.
  • Tunic: Similar because it denotes a long-top garment with sleeves; differs because tunic is usually shorter, often hip or knee length, while caftan is ankle length.
  • Gown: Similar because it denotes a long flowing garment; differs because gown is now chiefly women's formal or academic dress, while caftan is unisex and ethnically marked.
  • Mantle: Similar because it denotes a loose outer covering; differs because mantle is usually a cloak without sleeves, while caftan always has long sleeves.
  • Cloak: Similar because it denotes outer covering for warmth or status; differs because cloak is sleeveless and fastened at the neck, while caftan is sleeved and front-opening.
  • Abaya: Similar because it denotes a long Middle Eastern outer robe; differs because abaya is specifically a women's black cloak, usually sleeved but head-to-toe, while caftan is broader and often male.
  • Djellaba: Similar because it denotes a North African long robe; differs because djellaba has a pointed hood and is Maghrebi, while caftan is Turkish-Persian without a hood.
  • Kimono: Similar because it denotes a long wrapped robe with wide sleeves; differs because kimono is Japanese with overlapping front and wide belt, while caftan buttons or sashes differently.
  • Dressing gown: Similar because it denotes a loose house coat; differs because dressing gown is indoor Western nightwear, while caftan is outdoor or formal ethnic dress.
  • Housecoat: Similar because it denotes a loose comfortable covering; differs because housecoat is domestic and informal, while caftan can be ceremonial honour wear.
