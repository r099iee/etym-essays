• Cant: Similar because it denotes secret thieves vocabulary; differs because cant also means hypocritical pious talk, while argot is neutral-technical for group slang.
  • Slang: Similar because it denotes lively informal words; differs because slang is open to all speakers, while argot is closed and exclusionary by design.
  • Jargon: Similar because it denotes special group vocabulary; differs because jargon serves precise professional need, while argot serves secrecy and solidarity.
  • Lingo: Similar because it denotes a group way of talking; differs because lingo is breezy and journalistic, while argot is learned and slightly exotic.
  • Parlance: Similar because it denotes characteristic manner of speech; differs because parlance is formal and neutral, while argot implies raffish insider colour.
  • Patois: Similar because it denotes non-standard local speech; differs because patois stresses regional dialect with its own sounds, while argot shares grammar and changes only words.
  • Vernacular: Similar because it denotes everyday native speech; differs because vernacular is the unmarked common tongue, while argot is a marked in-group overlay.
  • Idiom (in French sens): Similar because French idiome can mean group usage; differs because English idiom usually means a fixed phrase, while argot means a whole lexicon.
  • Shoptalk: Similar because it denotes work-group chat unintelligible to outsiders; differs because shoptalk is occupational and practical, while argot is often criminal or playful.
  • Backslang / Verlan: Similar because they are productive argot mechanisms of inversion; differs because they name techniques, while argot names the resulting variety.
  • Dialect: Similar because both mark group belonging; differs because dialect has distinct pronunciation and grammar tied to place, while argot is lexical disguise within one dialect.
  • Cryptolect: Similar because it denotes a secret language variety; differs because cryptolect is the technical hypernym, while argot is its classic French example.
