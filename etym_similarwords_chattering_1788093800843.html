• jabbering: Similar because both denote rapid, voluble speech; differs because jabbering is slurred and semi-unintelligible and even more dismissive, whereas chattering can be perfectly clear though trivial.
  • prattling: Similar because both denote childish, trivial talk; differs because prattling is babyish and naive in tone, while chattering is faster, more mechanical and not necessarily childish.
  • babbling: Similar because both denote continuous, low-value speech; differs because babbling suggests incoherence (or the sounds of babies), whereas chattering suggests noise more than nonsense.
  • gibbering: Similar because both denote rapid, senseless talk; differs because gibbering implies panic or madness and is far darker in register (“gibbering idiot”), while chattering is lighter.
  • twittering: Similar because both denote rapid bird-like sounds; differs because twittering is lighter, higher-pitched and proper to birds (or social-media posts), whereas chattering is harsher and broader in application.
  • gabbling: Similar because both denote talking too fast; differs because gabbling emphasises speed that swallows words, while chattering emphasises quantity and triviality of talk.
  • yammering: Similar because both denote continuous talk; differs because yammering is whining, complaining lament, whereas chattering is neutral-to-gossipy and usually cheerful or nervous rather than mournful.
  • clattering: Similar because both denote a rapid rattling noise; differs because clattering is hard, metallic and louder, while chattering is light, rapid and dry.
  • rattling: Similar because both denote rapid repetitive noise (teeth, windows); differs because rattling is generic for any rattle, while chattering specifically evokes speech-like clicking.
  • tittle-tattling: Similar because both denote idle talk; differs because tittle-tattle is specifically gossip about other people's affairs, whereas chattering is any trivial talk whatever.
  • chuntering: Similar because both denote continuous low-level talk; differs because chuntering is British, grumbling under the breath, slower and lower, while chattering is bright and rapid.
  • blathering: Similar because both denote foolish prolonged talk; differs because blathering is long-winded and stupid, whereas chattering is quick, light and not necessarily foolish.
