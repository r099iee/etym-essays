• upstart: Similar because it means a newly risen person resented for presumption; differs because it is blunt Anglo-Saxon and can be political, while parvenu is French and social.
  • nouveau riche: Similar because it denotes new wealth with vulgar display; differs because it is a class label, while parvenu is an individual sneer.
  • arriviste: Similar because it is a French borrowing for ambitious climber; differs because it stresses ruthless ambition and scheming, not just newness.
  • social climber: Similar because it seeks higher status; differs because it emphasizes active climbing, while parvenu stresses having arrived but not belonging.
  • climber: Similar because it rises by effort; differs because it is general and shorter, lacking the French class sting.
  • pretender: Similar because it claims a station dubiously; differs because it often involves false royal claims, broader than social taste.
  • impostor: Similar because it fakes belonging; differs because it implies fraud, while parvenu wealth may be real but manners judged false.
  • interloper: Similar because it intrudes where not welcome; differs because it is about trespass generally, not class ascent.
  • outsider: Similar because it is not of the inner circle; differs because it is neutral and can be sympathetic, while parvenu is contemptuous.
  • newcomer: Similar because it has recently arrived; differs because it is neutral and temporal, without judgment of taste.
  • nabob: Similar because it mocked Indians-returned rich in 18th c. Britain; differs because it is historically specific and archaic.
  • plutocrat: Similar because it wields new money power; differs because it stresses rule by wealth, not social acceptance.
  • vulgarian: Similar because it sneers at vulgar taste; differs because it attacks manners directly, not necessarily new wealth.
