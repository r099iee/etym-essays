• Unearthed: Similar because it means brought hidden things to light; differs because unearthed stresses digging up, ferreted stresses persistent nosing pursuit.
  • Rooted out: Similar because it means found and removed from concealment; differs because rooted out often implies eradicating (corruption), ferreted implies discovering.
  • Ferreted out / flushed out: Similar because both use hunting metaphor for exposing; differs because flushed out stresses driving into the open quickly, ferreted stresses prolonged search.
  • Dug up: Similar because it means retrieved by digging; differs because dug up is physical and neutral, ferreted adds clever persistence.
  • Excavated: Similar because it means systematically uncovered; differs because excavated is archaeological-formal, ferreted is informal-vivid.
  • Discovered: Similar because it means found; differs because discovered can be accidental or grand, ferreted is always laborious.
  • Uncovered: Similar because it means revealed; differs because uncovered is general, ferreted specifies how — by nosing.
  • Exhumed: Similar because it means brought from hiding; differs because exhumed is funereal-literal, ferreted is investigative.
  • Rummaged: Similar because it means searched messily; differs because rummaged describes the messy action, ferreted includes successful finding.
  • Scoured: Similar because it means searched thoroughly; differs because scoured suggests sweeping over area, ferreted suggests nosing into holes.
  • Tracked down: Similar because it means pursued to discovery; differs because tracked down uses footprint-following metaphor, ferreted uses burrow-nosing metaphor.
  • Nosed out: Similar because it is almost synonymous via smell metaphor; differs because nosed out is slightly more instinctual, ferreted more active-worrying.
  • Winkled out: Similar because British winkle out means coaxed from shell; differs because winkled stresses coaxing, ferreted stresses hunting.
  • Investigated: Similar because it means systematically inquired; differs because investigated is formal-procedural, ferreted is colourful-persistent.
