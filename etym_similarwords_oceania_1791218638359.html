• Australasia: Similar because it covers Australia, New Zealand and neighbours; differs because it is narrower, usually excluding Polynesia and Micronesia.
  • Polynesia: Similar because it is a major subregion of Oceania; differs because it names only the eastern triangle Hawaii–Rapa Nui–New Zealand, not Melanesia or Australia.
  • Melanesia: Similar because it is the western island subregion of Oceania; differs because it excludes Polynesia, Micronesia and Australia.
  • Micronesia: Similar because it is the small-atoll subregion of Oceania; differs because it is only the northwestern islands.
  • Pacific Islands: Similar because it denotes the same islands; differs because it often excludes Australia and is descriptive rather than a formal continent name.
  • South Pacific: Similar because it evokes the same seas; differs because it is informal and tourist-tinged, not a UN region.
  • Asia-Pacific: Similar because it includes Oceania plus Asia; differs because it is an economic bloc, far wider and mainland-inclusive.
  • Australian continent: Similar because Australia anchors Oceania; differs because continent names the landmass alone, not the islands.
  • Antipodes: Similar because it historically meant Australia–New Zealand from a British viewpoint; differs because it is Eurocentric slang, not a neutral region name.
  • South Seas: Similar because it is the old literary name for the same waters; differs because it is archaic and romantic, not used in statistics.
  • Moana Pacific: Similar because it names the same ocean world from an Indigenous perspective; differs because it centres Islander identity rather than colonial cartography.
