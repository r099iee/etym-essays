• Kalimantan: Similar because it denotes the Indonesian part of the same island; differs because it covers only ~73% and is an Indonesian administrative term, not the whole island.
  • Sabah: Similar because it is a Bornean territory; differs because it is one Malaysian state in the north, not the entire island.
  • Sarawak: Similar because it is a Bornean Malaysian state; differs because it is only the northwestern portion once ruled by the White Rajahs.
  • Brunei: Similar because it is a Bornean nation and likely source of the name; differs because it is a tiny sovereign sultanate, not the island.
  • Sumatra: Similar because it is another huge western Indonesian island with rainforest and orangutans; differs because it lies west of Borneo with distinct peoples and history.
  • Java: Similar because it is another major Indonesian island; differs because it is densely populated, volcanic, and the political core, unlike forested Borneo.
  • Sulawesi: Similar because it is a neighbouring large Indonesian island; differs because of its K-shape, different fauna, and separate cultures.
  • New Guinea: Similar because it is another equatorial megadiverse island; differs because it lies east, is larger, and is split between Indonesia and Papua New Guinea.
  • Sundaland: Similar because Borneo is its centre biogeographically; differs because Sundaland is a submerged-continental region including Malay Peninsula, Sumatra, Java, and Borneo.
  • Dayak: Similar because Dayaks are the iconic Indigenous peoples of Borneo; differs because Dayak names peoples, not the island itself.
  • East Malaysia: Similar because it covers the Malaysian part of Borneo; differs because it excludes Kalimantan and Brunei.
  • Malay Archipelago: Similar because Borneo belongs to it; differs because the archipelago comprises thousands of islands across two nations.
