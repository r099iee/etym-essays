• Evangelist: Similar because preaches gospel to convert; differs because focuses on proclamation itself, not necessarily foreign posting or institutional mission.
  • Preacher: Similar because delivers religious message; differs because usually serves settled congregation, not sent abroad.
  • Proselytizer: Similar because seeks converts; differs because often pejorative for aggressive conversion, while missionary can include humanitarian service.
  • Apostle: Similar because sent one (biblical); differs because original Twelve or revered founder, far higher sanctity than modern missionary.
  • Cleric / priest / minister: Similar because ordained religious functionary; differs because pastoral/sacramental role at home, not defined by being sent.
  • Pastor: Similar because shepherds flock spiritually; differs because settled congregational care, opposite of itinerant mission.
  • Chaplain: Similar because ministers outside parish (army, hospital); differs because serves existing members in secular institution, not converts.
  • Crusader: Similar because zealous campaigner; differs because militant, often violent holy-war history, while missionary is (ideally) persuasive.
  • Emissary / envoy: Similar because one sent on behalf of authority; differs because secular diplomatic, no religious conversion aim.
  • Aid worker / humanitarian: Similar because modern missionaries run clinics/schools; differs because secular NGOs avoid evangelism, focus purely on relief.
  • Advocate / champion: Similar because secular missionary sense of zealous promoter; differs because general, lacks religious sending and sacrifice connotations.
  • Disciple: Similar because follower spreading teaching; differs because learner-follower, not necessarily commissioned sender.
