• There: Similar because both point to a place away from the speaker; differs because there is the static locative ("at that place"), while thither is the goal-word meaning "to that place," a motion a speaker must actively make.
  • Whither: Similar because both are directional adverbs of the old demonstrative system; differs because whither is interrogative and relative ("to which place?"), while thither states a definite, known destination.
  • Hither: Similar because both are archaic motion-words built with the same suffix; differs because hither points to the speaker's own place ("to this place"), while thither points away ("to that place").
  • Hence: Similar because both are old directional adverbs of the same demonstrative family; differs because hence is ablative, marking origin ("from this place"), while thither is allative, marking a goal.
  • Thence: Similar because both belong to the archaic system of direction-words; differs because thence is ablative ("from that place"), the exact opposite in direction of thither's "to that place."
  • Yonder: Similar because both name a place at a distance; differs because yonder visually gestures at a place in sight and is locative, while thither names motion toward a destination that need not be seen.
  • Thitherward(s): Similar because both derive from the same stem and mean "toward that place"; differs because thitherward is the rarer, more emphatic directional variant, stressing the course or heading rather than the arrival.
  • To that place: Similar because both convey the same allative meaning; differs because the periphrasis is neutral modern English, stripped of thither's archaic gravity and ceremonial tone.
