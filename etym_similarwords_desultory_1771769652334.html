• Haphazard: Similar because both describe things done without a plan; differs because haphazard stresses chance and random arrangement, without desultory's buried image of leaping or vaulting about.
  • Sporadic: Similar because both describe occurrence at irregular intervals; differs because sporadic emphasizes irregular timing in time, while desultory emphasizes jumping from topic to topic without connection.
  • Cursory: Similar because both can describe quick, shallow treatment; differs because cursory means superficial speed over a surface, while desultory means scattered variety and lack of continuous course.
  • Digressive: Similar because both involve wandering from a main line; differs because digressive implies a main line that still exists (the digression leaves and returns to it), while desultory work may never establish a main line at all.
  • Aimless: Similar because both describe activity without purpose; differs because aimless is broader and more totalizing — desultory effort can be energetic and purposeful in each moment yet still unfocused across its course.
  • Discursive: Similar because both describe moving from subject to subject; differs because discursive may be neutral or even positive in essayistic prose (digressions as a literary mode), while desultory in educational contexts is almost always a fault.
  • Fitful: Similar because both describe irregular, interrupted activity; differs because fitful emphasizes irregular bursts and stops in time, while desultory emphasizes discontinuity of subject or plan.
  • Intermittent: Similar because both describe stopping and starting; differs because intermittent is neutral and temporal (it comes and goes), without desultory's sense of leaping between disconnected things.
  • Erratic: Similar because both describe irregular, unsteady behaviour; differs because erratic emphasizes unpredictable, wayward motion or conduct, while desultory emphasizes lack of a connected plan.
  • Unmethodical: Similar because both describe work without system; differs because unmethodical is the plain procedural label, while desultory keeps the vivid image of jumping about.
  • Scattered: Similar because both describe things spread about without order; differs because scattered is a general spatial metaphor, while desultory specifically implies leaping between points without settling.
  • Random: Similar because both describe lack of order; differs because random stresses chance selection with no principle, while desultory can describe a person's own energetic but unsystematic choices.
  • Capricious: Similar because both describe unpredictable change; differs because capricious stresses whim and sudden change of mind, while desultory stresses scattered, disconnected activity without strong emphasis on whim.
  • Wayward: Similar because both describe divergence from a settled course; differs because wayward stresses stubborn or perverse deviation, while desultory stresses mere lack of continuous plan.
  • Rambling: Similar because both describe wandering discourse; differs because rambling suggests long-winded, sprawling extension (of talk or writing), while desultory suggests disconnected leaps between points.
  • Inconstant: Similar because both describe changeableness; differs because inconstant emphasizes fickleness of purpose or feeling, while desultory emphasizes discontinuous, scattered activity.
