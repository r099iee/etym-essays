• devoutly: Similar because it means with deep religious commitment; differs because devoutly stresses inward fervour, while piously stresses dutiful observance and can be ironic.
  • reverently: Similar because it means with awe and respect; differs because reverently fits places and persons generally, while piously specifically evokes religious or loyal duty.
  • dutifully: Similar because Roman pietas underlies both; differs because dutifully is obedience to obligation, while piously adds worshipful feeling.
  • faithfully: Similar because both keep faith with God or memory; differs because faithfully stresses constancy over time, while piously stresses manner of expression.
  • prayerfully: Similar because it names the devout manner in worship; differs because prayerfully is strictly devotional, while piously covers loyal and memorial acts outside prayer.
  • religiously: Similar because it can mean scrupulously or as if from religion; differs because religiously often means regularly or strictly, while piously means in spirit of reverence.
  • sanctimoniously: Similar because it describes ostentatious holiness; differs because sanctimonious is always condemnatory hypocrisy, while piously may be sincere or only lightly ironic.
  • hypocritically: Similar because ironic piously overlaps it; differs because hypocritically names deliberate deceit, while piously may be self-deception or mere show.
  • earnestly / solemnly: Similar because pious manner is earnest and solemn; differs because these lack the religious-loyal content, marking tone only.
  • loyally / patriotically (in Ruskin’s sense): Similar because oak-apple piety is political loyalty felt as religion; differs because loyal is allegiance to a person or cause, while piously frames that allegiance as worship.
