• window: Similar because both are openings in a wall that admit light and air; differs because window is the neutral, generic term for any such opening, while casement specifies a side-hinged frame that swings open.
  • sash: Similar because both are framed, glazed window units; differs because a sash slides vertically or horizontally in grooves, while a casement swings on side hinges like a door.
  • pane: Similar because both belong to a window; differs because a pane is only the single sheet of glass, not the frame or the opening, while casement names the whole hinged window structure.
  • shutter: Similar because both are fitted to an opening to control light and air; differs because a shutter is a solid cover that blocks light rather than admitting it, while a casement is glazed and lets light in.
  • lattice: Similar because both are old-fashioned window types; differs because a lattice has small diamond or square panes held by thin wooden bars and often no hinges, while a casement is a hinged unit with regular panes.
  • dormer: Similar because both are window structures on a building; differs because a dormer is a vertical window projecting from a sloping roof, defined by position, while a casement is defined by its side-hinged opening.
  • skylight: Similar because both admit light from outside; differs because a skylight is a window in a roof or ceiling, usually fixed or top-hinged, while a casement is a side-hinged wall window.
  • mullion: Similar because both are parts of window construction; differs because a mullion is the vertical dividing bar between window sections, not an opening unit at all.
  • transom: Similar because both are window elements; differs because a transom is the horizontal bar across a window or the small window above a door, while a casement is a hinged opening unit.
  • fenestration: Similar because both belong to window terminology; differs because fenestration is the abstract architectural term for the arrangement of windows in a building, while casement names a single physical window type.
