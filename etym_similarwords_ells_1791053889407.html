• cubit: Similar because it is also a forearm-based ancient length; differs because cubit is biblical/classical (about 18 inches) while ell is medieval English cloth measure (45 inches).
  • yard: Similar because it replaced the ell as the English cloth unit; differs because yard is 36 inches, shorter and still current, while ell is obsolete.
  • fathom: Similar because it is another body-based measure (outstretched arms, 6 feet); differs because fathom measures depth and rope, not cloth.
  • span: Similar because it is a hand-based old unit (9 inches); differs because span is much shorter and from hand width, not forearm.
  • hand: Similar because it is a body-part unit still used for horses (4 inches); differs because hand is tiny and specialised, while ell was general commercial.
  • foot: Similar because it is a surviving body-based foot-length unit (12 inches); differs because foot is standard today, ell is archaic.
  • inch: Similar because it pairs with ell in the proverb; differs because inch is the smallest customary unit, ell the large greedy one.
  • rod / pole / perch: Similar because they are obsolete English land measures; differs because they measure land (5.5 yards), not cloth.
  • chain: Similar because it is another obsolete survey length (22 yards); differs because chain is for land surveying, ell for drapery.
  • aune: Similar because it is the French equivalent cloth-ell; differs because aune varied around 47–55 inches and belongs to French metrology.
  • metre / meter: Similar because it is the modern replacement standard length; differs because metre is decimal, universal, and defined by physics, not anatomy.
  • bolt (of cloth): Similar because it also quantifies fabric; differs because bolt is a roll of indefinite length, while ell is a precise linear unit.
