• jointers: Similar because both are long bench planes for trueing; differs because jointer specifically denotes the longest trying plane for edges.
  • smoothers: Similar because both finish surfaces; differs because smoother is the short final plane, while plane is generic.
  • jointers vs jack planes: Similar because both level boards; differs because jack is shorter and for rough work, jointer for straightness.
  • scrapers: Similar because both smooth without deep cutting; differs because scrapers drag a burr, while planes cut with a bevelled iron.
  • chisels: Similar because both pare wood with steel; differs because chisels are pushed by hand or mallet for carving, while planes ride on a sole.
  • rasps: Similar because both shape curves; differs because rasps grate with teeth, while planes shave cleanly.
  • routers: Similar because both cut profiles and rebates; differs because routers spin a bit, while planes slide a fixed iron.
  • sanders: Similar because both prepare finish; differs because sanders abrade with grit, while planes cut fibres.
  • spokeshaves: Similar because both shave with a sole-guided iron; differs because spokeshaves are short for curves and spokes, while planes are for flats.
  • adzes: Similar because both level timbers; differs because adzes swing like axes for rough hewing, while planes push for fine flatness.
  • drawknives: Similar because both shave wood; differs because drawknives are pulled with two handles, while planes are pushed on a sole.
  • floats: Similar because both flatten plaster or wood; differs because floats are masonry tools, while planes are joinery tools.
