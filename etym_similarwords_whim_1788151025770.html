• Caprice: similar because both name sudden, arbitrary changes of mind; differs because caprice is the grander word — from Italian capriccio — stressing abrupt reversal and unreliability, while a whim is lighter and can be charming.
  • Fancy: similar because both are passing likes; differs because fancy includes imaginative pleasure (a flight of fancy) and is gentler, while whim stresses pure arbitrariness.
  • Impulse: similar because both are sudden urgings; differs because impulse is more motoric and instinctive — the urge to act — while whim is more cognitive and playful, a notion rather than a push.
  • Notion: similar because both are fleeting ideas; differs because notion is neutral cognition (a vague idea) with no willfulness or unpredictability built in.
  • Vagary: similar because both denote erratic behaviour; differs because vagary usually appears in the plural — the vagaries of fortune, weather, fashion — and suggests meandering unpredictability more than a single impulse.
  • Quirk: similar because both describe the odd and unexpected; differs because a quirk is a stable personal mannerism (a quirk of speech), while a whim is a one-off mental event.
  • Mood: similar because both can send behaviour in arbitrary directions; differs because a mood is an enduring emotional state, while a whim is a momentary decision.
  • Crotchet: similar because both are old-fashioned words for an odd, whimsical notion; differs because crotchet (17th-18th c., from "small hook") is now rare, arch, or humorous, and stresses eccentricity rather than suddenness.
  • Bee in one's bonnet: similar because both describe an arbitrary fixation; differs because the idiom suggests a lasting preoccupation, while a whim passes as quickly as it came.
