• damned (I’m damned): Similar because it is the direct stronger oath of surprise; differs because it is profane, while blowed is its bowdlerised polite substitute.
  • blasted: Similar because it is a mild imprecation of surprise or annoyance; differs because it invokes explosion, while blowed invokes wind knocking one down.
  • dashed (I’m dashed): Similar because it is a genteel Wodehouse-era euphemism; differs because it is upper-class mincing, while blowed is working-class nautical.
  • darned: Similar because it substitutes for damned; differs because it is American-sewing metaphor, while blowed is British-sea metaphor.
  • buggered (I’m buggered): Similar because it expresses floored surprise; differs because it is coarse, while blowed is parlour-safe.
  • astonished: Similar because I’m blowed states astonishment; differs because it is neutral description, while blowed performs it as oath.
  • flabbergasted: Similar because it denotes comic extreme surprise; differs because it is latinate Hullabaloo, while blowed is short Anglo-Saxon breath.
  • gobsmacked: Similar because it denotes struck-dumb surprise; differs because it is modern slang (mouth-smacked), while blowed is period slang (wind-struck).
  • floored: Similar because blow-me-down imagines being knocked flat; differs because it is metaphorical defeat, while blowed keeps the wind image.
  • winded: Similar because literal blowed once meant out of breath; differs because it is physiological, while exclamatory blowed is emotional.
