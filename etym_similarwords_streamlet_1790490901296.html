• rivulet: Similar because it is a very small stream; differs because rivulet is slightly more literary-French and often implies a plain or meadow setting, while streamlet stresses diminutive smallness anywhere.
  • brook: Similar because it is a small natural stream; differs because brook is the plain everyday word, while streamlet is a marked diminutive emphasising tininess and prettiness.
  • brooklet: Similar because it is an exact diminutive synonym (little brook); differs because brooklet is rarer and built on brook, while streamlet is built on stream and far commoner.
  • rill: Similar because it is a tiny channel or trickle; differs because rill is more poetic and can be a furrow or artificial channel, while streamlet is clearly natural running water.
  • runnel / runlet: Similar because both mean a small stream or thin flow; differs because runnel keeps a northern, ballad flavour and runlet is very rare, while streamlet is standard southern literary.
  • beck: Similar because it is a northern English small stream; differs because beck is dialectal and topographic (Yorkshire, Lakes), while streamlet is non-regional and stylistic.
  • burn: Similar because it is the Scots word for the same glen water Ruskin means; differs because burn is Scots everyday speech, while streamlet is the English visitor's picturesque term for it.
  • creek: Similar because it can mean a small inlet stream; differs because creek in America and Australia can be a substantial river, while streamlet can never be large.
  • stream: Similar because it is the base word and shares flowing-water meaning; differs because stream is the generic size, while streamlet explicitly marks the smallest end of the scale.
  • freshet: Similar because it is a small fresh-water stream; differs because freshet stresses freshness and spate after rain or thaw, while streamlet stresses permanent small size.
  • tributary: Similar because a streamlet usually feeds a larger water; differs because tributary names the relation (feeder), while streamlet names the size, whatever its relation.
  • trickle: Similar because it describes a thin small flow; differs because trickle is the manner of flowing (verb and noun), while streamlet is the little channel itself.
