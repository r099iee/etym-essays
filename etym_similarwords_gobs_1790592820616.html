• Loads: Similar because it denotes large indefinite quantities in informal speech; differs because loads suggests weight or cartloads rather than mouthfuls or lumps.
  • Heaps: Similar because it expresses abundance by metaphor of piling; differs because heaps evokes stacked piles while gobs evokes gooey lumps and mouthfuls.
  • Tons: Similar because it hyperbolically indicates huge amount; differs because tons is a weight metaphor and more American-neutral, gobs is more British-comic.
  • Plenty: Similar because it means more than enough; differs because plenty is neutral and standard, gobs is slangy and exuberant.
  • Masses: Similar because it means a large aggregate; differs because masses is more formal and can imply people, gobs implies stuff or qualities.
  • Wads: Similar because it means thick lumps or bundles, especially of money; differs because wads stresses compact bundles, gobs stresses shapeless abundance.
  • Scads: Similar because it is slang for large amounts; differs because scads is chiefly American and slightly dated, gobs is Anglo-American nautical-school slang.
  • Oodles: Similar because it playfully means lots; differs because oodles is cutesy American, gobs is hearty and slightly vulgar.
  • Bunches: Similar because it means many; differs because bunches implies clustering, gobs implies overflowing mass.
  • Stacks: Similar because it quantifies informally; differs because stacks suggests neat piling, especially money, while gobs suggests messy plenty.
