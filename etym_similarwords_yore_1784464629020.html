• Past: Similar because both name time gone by; differs because past is the neutral, general word for any earlier time, with none of yore's archaic elevation or emotional charge.
  • Antiquity: Similar because both name ancient times; differs because antiquity is learned and civilizational, naming a historical period rather than a legendary distance.
  • Olden days / olden times: Similar because both evoke time long past; differs because these are phrase-bound and faintly folksy, not the compact mythic noun yore.
  • Formerly: Similar because both indicate an earlier time; differs because formerly is a flat adverb of circumstance, while yore is a noun of legendary remoteness.
  • Once: Similar because both can suggest a former time; differs because once is thinner and more fairy-tale, needing context ("once upon a time") to reach yore's legendary reach.
  • Bygone(s): Similar because both mean "gone by" in time; differs because bygones is casual and often refers to past grievances or episodes, not a whole legendary age.
  • Ago: Similar because both place events in the past; differs because ago is relative and quantitative, always needing a measure ("long ago"), while yore stands alone as a noun.
  • Days of old: Similar because both are elevated phrases for the legendary past; differs because "days of old" is a collocation built on the ordinary adjective old, lacking yore's fossil-noun compactness.
  • Long ago: Similar because both denote the remote past; differs because "long ago" is an adverbial phrase, while yore is a noun that can fill subject and object positions ("the dwarves of yore").
