• oak-gall / gall-nut: Similar because they name the same cynipid growth; differs because gall is the technical term for any such growth, while oak-apple names only the round apple-like spring gall.
  • marble-gall: Similar because it is another round oak-gall (Andricus kollari); differs because marble-gall is hard, brown, and many-celled, while oak-apple is spongy, green-rosy, and single-celled.
  • knopper-gall: Similar because it is an oak gall worn in folk custom; differs because knopper deforms the acorn cup, while oak-apple grows on leaf and bud.
  • Aleppo gall: Similar because it is the true ink-gall of commerce; differs because Aleppo comes from Quercus infectoria and is tannin-rich, while oak-apple is British and tannin-poor.
  • oak-leaf / oak-bough: Similar because both were worn on 29 May as loyalist badges; differs because leaf and bough are foliage, while oak-apple is the gall-fruit.
  • cockade: Similar because it is a button-hole political badge; differs because cockade is ribbon (white, blue, tricolour), while oak-apple is a natural object gilded.
  • button-hole (flower): Similar because Ruskin wore his gall there; differs because button-hole now means a flower, while oak-apple was its loyalist substitute.
  • acorn: Similar because it is the true fruit of the oak often confused with the gall; differs because acorn holds the seed, while oak-apple holds a wasp grub.
  • crab-apple: Similar because it is a small wild apple-like fruit; differs because crab-apple is genuine Malus fruit, while oak-apple is insect-made sham fruit.
  • Royal Oak (emblem): Similar because it names the Boscobel tree and the 29 May cause; differs because Royal Oak names the tree and the pubs, while oak-apple names the wearable gall.
