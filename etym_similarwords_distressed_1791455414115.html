• Afflicted: similar because it describes someone suffering from illness, misfortune, or pain; differs because it stresses an external blow or disease rather than the inner emotional strain that “distressed” often implies.
  • Anguished: similar because it names intense mental pain; differs because it is stronger and more specifically agonising, whereas “distressed” can be milder and more situational.
  • Anxious: similar because it involves worry and unease; differs because it points forward to feared outcomes, while “distressed” describes present suffering.
  • Troubled: similar because it covers worry and disturbance; differs because it is broader and cooler, often suggesting a lasting condition rather than an acute episode.
  • Upset: similar because it means emotionally disturbed; differs because it is informal and usually implies a specific recent cause.
  • Distraught: similar because it describes severe emotional disturbance; differs because it is narrower and more intense, suggesting a near-frantic loss of composure.
  • Stressed: similar because it evokes pressure; differs because it is modern and informal, and often concerns workload rather than sorrow.
  • Miserable: similar because it names unhappiness; differs because it is a settled mood of wretchedness rather than a response to a particular pressure.
  • Wretched: similar because it covers suffering and hardship; differs because it is stronger and more literary, and often implies destitution or contemptibility.
  • Harrowed: similar because it suggests a mind torn by experience; differs because it implies prolonged, scarring trauma rather than immediate strain.
  • Damaged: similar because it can describe worn or impaired things; differs because it is physical and evaluative, lacking the emotional sympathy of “distressed.”
  • Weathered: similar because it describes surfaces worn by exposure; differs because it is neutral or admiring, whereas “distressed” in fashion implies deliberate artificial ageing.
  • Insolvent: similar because it applies to financial distress; differs because it is a precise legal status, not a general condition of strain.
  • Defaulting: similar because it concerns failure to pay; differs because it names a specific act, while “distressed” describes the broader financial condition.
