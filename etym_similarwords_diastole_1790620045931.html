• systole: Similar because it is the paired cardiac phase; differs because it is contraction and ejection, the opposite half-cycle.
  • dilation: Similar because it means expansion; differs because it is generic and lacks rhythmic pairing.
  • relaxation: Similar because diastole is myocardial relaxation; differs because it is general muscular rest, not cyclic filling.
  • expansion: Similar because it means growing larger; differs because it can be permanent, while diastole is always temporary and rhythmic.
  • distension: Similar because it means swelling out; differs because it often implies pathological stretching.
  • refilling: Similar because ventricles refill in diastole; differs because it names function, not phase.
  • lengthening: Similar because metrical diastole lengthens a syllable; differs because it is prosodic.
  • luminal filling: Similar because it describes chamber filling; differs because it is descriptive physiology jargon.
  • repose: Similar because diastole is cardiac rest; differs because it is literary rest, not technical.
  • asystole vs diastole: Similar because both involve absence of contraction; differs because asystole is arrest, diastole is healthy pause.
