• wickerwork: Similar because it is woven plant-material ware; differs because it stresses wicker rods and lattice texture, while basketry covers all methods including coiling.
  • wicker: Similar because it denotes woven willow material; differs because it is the material or furniture style, while basketry is the craft or collective product.
  • weaving: Similar because both interlace strands; differs because weaving uses loom and yarn for cloth, basketry uses stiff withies for vessels without a loom.
  • plaiting: Similar because it braids strands; differs because plaiting is a technique for hair or straw, basketry is the whole vessel art.
  • twining: Similar because it is a core basketry stitch; differs because twining is one method, basketry is the umbrella term.
  • coiling: Similar because it builds baskets by spiral stitching; differs because coiling is one technique, basketry includes wicker and plaiting too.
  • pottery: Similar because it is a parallel vessel craft often paired historically; differs because pottery shapes clay by fire, basketry weaves fibers without fire.
  • ceramics: Similar because both make containers for storage; differs because ceramics are kiln-fired and waterproof, basketry is lightweight and permeable.
  • handicraft: Similar because basketry is a handicraft; differs because handicraft is generic, basketry is specific to woven containers.
  • handiwork: Similar because it implies hand-made ware; differs because it is vague praise, basketry names the exact medium.
  • cane work: Similar because cane is woven for chairs and baskets; differs because cane work often means furniture seating, basketry means vessels.
  • rattan work: Similar because rattan is a basketry material; differs because it specifies tropical vine, while basketry includes willow, grass, bamboo.
