• ivory: Similar because it is prized tooth material for carving; differs because ivory usually means elephant or walrus tusk, larger and regulated, elk-teeth smaller.
  • tusks: Similar because they are elongated teeth used as trophy and material; differs because tusks are large protruding teeth (boar, walrus), elk-teeth tiny vestigial canines.
  • fangs: Similar because they are pointed canine teeth; differs because fangs suggest predators or snakes, functional piercing, elk-teeth ornamental.
  • canines: Similar because elk-teeth are anatomically upper canines; differs because canine is technical term for any dog-like tooth, not the ornament-money unit.
  • scrimshaw: Similar because it is carved tooth art; differs because scrimshaw is the craft/product, often on whale tooth, not the raw elk tooth itself.
  • wampum: Similar because it is shell-bead ornament money; differs because wampum is quahog/whelk shell beads of Eastern Woodlands, not teeth.
  • cowries: Similar because they are small beautiful valuables used as money; differs because cowries are sea shells, pan-tropical currency, not hunting trophies.
  • beads: Similar because they are strung ornaments serving as money; differs because beads are manufactured glass or stone, not animal teeth.
  • dentalium shells: Similar because they are tusk-shaped shells used as Plains money; differs because dentalium is marine mollusc, elk-teeth terrestrial mammal.
  • trophies: Similar because they display hunting success; differs because trophy is generic (antlers, hides), elk-teeth specific countable ivories.
  • regalia: Similar because elk-teeth dresses are ceremonial regalia; differs because regalia is collective ceremonial outfit, not the material unit.
  • keepsakes: Similar because saved teeth are mementoes; differs because keepsake is sentimental, not monetary or zoological.
