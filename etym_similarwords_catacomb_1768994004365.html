• Tomb: Similar because both are burial places; differs because the tomb is a single grave or chamber, a point, while the catacomb is an extended underground network of galleries and recessed niches.
  • Crypt: Similar because both are underground burial spaces; differs because the crypt is a vault beneath a specific church, usually holding the saintly or elite, while the catacomb is a wider labyrinthine cemetery hewn from rock.
  • Vault: Similar because both are arched underground chambers; differs because the vault need not be funerary at all — treasure-vaults, bank-vaults — while the catacomb is defined by its purpose of mass burial.
  • Sepulchre: Similar because both name a place of burial; differs because the sepulchre is a monumental, chiefly biblical single grave, while the catacomb is an engineered underground system holding thousands.
  • Necropolis: Similar because both are a "city of the dead"; differs because the necropolis is an extensive burial complex, often above ground, lacking the underground, honeycombed concreteness of the catacomb.
  • Ossuary: Similar because both are places for the dead; differs because the ossuary is a container or room for bones alone, not a network of burial galleries with recessed niches.
  • Mausoleum: Similar because both are monuments for the dead; differs because the mausoleum is a grand above-ground tomb-building for an individual or family, while the catacomb is a vast underground cemetery.
  • Cemetery: Similar because both are burial grounds; differs because the cemetery is the modern, general, above-ground term, stripped of the catacomb's depth, antiquity, and underground engineering.
  • Burial ground: Similar because both name a place of burial; differs because a burial ground is a plain, open, neutral site, while the catacomb is subterranean, engineered, and saturated with religious and gothic associations.
  • Charnel house: Similar because both involve mass death; differs because the charnel house is a building for depositing corpses or bones, lacking the labyrinthine underground galleries and burial niches of the catacomb.
  • Undercroft: Similar because both are subterranean chambers; differs because the undercroft is a vaulted room below a church, architectural and general-purpose, while the catacomb is a burial system.
