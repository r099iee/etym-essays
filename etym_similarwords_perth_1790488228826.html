• St John's Toun / St Johnstone: Similar because it is the historic alias of the same Scottish city; differs because it names the saint's town, while Perth names the copse-town.
  • The Fair City: Similar because it is the affectionate epithet of Scottish Perth; differs because it is descriptive praise, while Perth is the official name.
  • Scone: Similar because it is the crowning place inseparable from Perth; differs because Scone is village and palace, Perth the burgh and market.
  • Dundee: Similar because it is the neighbouring Tay city downstream; differs because Dundee is industrial juteopolis and port, Perth inland administrative capital.
  • Edinburgh: Similar because it succeeded Perth as capital; differs because Edinburgh is metropolis and present capital, Perth former and provincial.
  • Bertha (Roman fort): Similar because it is the Roman precursor three miles north; differs because Bertha is archaeological fort, Perth medieval burgh.
  • Perth, Western Australia: Similar because it shares the identical name by deliberate commemoration; differs because Australian Perth is a modern sunbelt metropolis, Scottish Perth a small historic city.
  • Perthshire: Similar because it is the county named after the town; differs because shire is region, Perth the town itself.
  • Inverness: Similar because it is another Highland-edge former capital and market town; differs because Inverness guards the Great Glen, Perth guards the Tay ford.
  • Stirling: Similar because it is another central-Scottish bridge-town and former capital; differs because Stirling guards the Forth, Perth the Tay.
