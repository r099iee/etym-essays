• Explanatory: Similar because it clarifies meaning; differs because it is general and local (a note), while expository signals a systematic genre or mode.
  • Informative: Similar because it conveys information; differs because it stresses usefulness of content, while expository stresses methodical setting-forth.
  • Instructive: Similar because it teaches; differs because it implies a lesson learned, while expository can be neutral description.
  • Didactic: Similar because it teaches systematically; differs because it adds moral instruction and can sound preachy, while expository aims at neutral clarity.
  • Illustrative: Similar because it makes ideas clear with examples; differs because it works by instances, while expository works by definition, classification, and analysis.
  • Elucidatory: Similar because it sheds light; differs because it is rare and formal, while expository is standard pedagogical jargon.
  • Explicative: Similar because it unfolds meaning; differs because it suggests detailed interpretation (explicating a poem), while expository suggests straightforward information.
  • Hermeneutic: Similar because it concerns interpretation; differs because it is philosophical and theory-laden, while expository is classroom-practical.
  • Descriptive: Similar because it presents facts; differs because it paints qualities and appearances, while expository analyzes structure and causes.
  • Analytical: Similar because it breaks subjects into parts; differs because it stresses reasoning, while expository stresses clear presentation.
  • Documentary: Similar because it records fact; differs because it is a medium/genre (film, report), while expository is a rhetorical mode.
  • Educational: Similar because it aims to teach; differs because it is broad (any learning context), while expository is specifically about explaining in discourse.
