• imbalance: Similar because both denote a loss of evenness or proportion. Differs because imbalance is a colloquial, general word for any inequality (a diet imbalance, a trade imbalance) without implying a prior calculated state, while disequilibrium is formal and technical, naming a system displaced from a defined equilibrium.
  • instability: Similar because both describe a lack of steadiness. Differs because instability emphasises the tendency to change or collapse unpredictably, while disequilibrium specifies the loss of a prior state of balance and is more quantitative and system-oriented.
  • unbalance: Similar because both involve the loss of balance. Differs because unbalance is simpler and often mental (a person thrown off balance emotionally), while disequilibrium is the formal, scientific term used of markets, ecosystems, and physical systems.
  • chaos: Similar because both describe disorder. Differs because chaos implies a total absence of order or framework, while disequilibrium presupposes an existing equilibrium that has been disrupted — it is a loss, not an abyss.
  • perturbation: Similar because both describe a disturbance of a system. Differs because perturbation names the disruptive force or the deviation itself, typically small and transient, while disequilibrium names the resulting state of imbalance.
  • asymmetry: Similar because both describe an unequal arrangement. Differs because asymmetry is a neutral structural description of unequal sides, without the temporal implication of a lost balance that disequilibrium carries.
  • volatility: Similar because both suggest a system not at rest. Differs because volatility stresses rapid, large fluctuation over time (especially in markets), while disequilibrium stresses the static condition of being off balance.
  • disruption: Similar because both involve the breaking of a prior condition. Differs because disruption is a generic term for any interruption, while disequilibrium is specifically the loss of balance in a system that had an equilibrium reference point.
  • imbalance-of-payments deficit: Similar in economics, both name a state where national accounts are not in balance. Differs because the full phrase is narrower and purely financial, while disequilibrium is the general theoretical term covering all markets and sectors.
