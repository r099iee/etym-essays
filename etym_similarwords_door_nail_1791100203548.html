• stud: Similar because it is a decorative head fastening boards; differs because stud is generic for any boss, while door-nail specifies door joinery.
  • boss: Similar because it is a round ornamental projection; differs because boss can be cast ornament, not necessarily a clinched nail.
  • clench nail: Similar because it is hammered dead and turned over; differs because it is the technical smith term, not the idiomatic compound.
  • rosehead nail: Similar because it is a hand-forged nail with broad head; differs because it suits many timbers, not only doors.
  • cut nail: Similar because it fastens planks firmly; differs because it is machine-cut and modern, lacking the idiom.
  • spike: Similar because it is a large heavy nail; differs because spike is longer and structural, not decorative door furniture.
  • tack: Similar because it pins with a broad head; differs because tack is small and temporary, while door-nail is large and permanent.
  • rivet: Similar because it is clinched to join plates; differs because rivet joins metal with bucked tails, while door-nail joins wood.
  • bolt: Similar because it secures doors strongly; differs because bolt slides or screws with a nut rather than hammer-clinching.
  • knocker: Similar because it strikes the door-nail plate; differs because knocker is the moving striker, not the nail itself.
  • deadbolt: Similar because it shares door security and dead vocabulary; differs because it is a locking mechanism, not a stud.
  • doornail cliché: Similar because dead as mutton and stone-dead share absolute-dead intensification; differs because only door-nail carries the Dickens quotation.
