• greed: Similar because it denotes insatiable desire; differs because greed is broader (money, power) and more moralised, while voracity centres on devouring appetite.
  • gluttony: Similar because it means overeating; differs because gluttony is specifically a vice of excess food/drink, while voracity includes metaphorical devouring (books, markets).
  • ravenousness: Similar because it means extreme hunger; differs because ravenousness stresses painful hunger-need, voracity stresses greedy manner of consumption.
  • rapacity: Similar because it means plundering greed; differs because rapacity stresses violent seizure from others, voracity stresses swallowing capacity.
  • voraciousness: Similar because it is the same root quality; differs because voraciousness is the more common nominalisation of voracious, nearly synonymous but slightly less literary.
  • edacity: Similar because it means gross eating, gorging; differs because edacity is rare, technical, purely alimentary, lacking voracity's figurative range.
  • insatiability: Similar because it means inability to be satisfied; differs because insatiability is abstract and neutral, voracity is visceral and image-rich.
  • avidness / avidity: Similar because it means eager craving; differs because avidity is enthusiastic and often positive, voracity is darker and more animal.
  • hunger: Similar because it denotes desire to eat; differs because hunger is a basic need, voracity is excess beyond need.
  • appetite: Similar because it denotes desire for food or experience; differs because appetite can be healthy and selective, voracity is indiscriminate and excessive.
  • craving: Similar because it denotes intense desire; differs because craving is episodic and specific, voracity is habitual and general.
  • omnivorousness: Similar because it denotes eating everything; differs because omnivorousness is biological breadth, voracity is intensity and greed.
