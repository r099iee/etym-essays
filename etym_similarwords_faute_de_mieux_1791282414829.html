• for lack of better: Similar because it states the same compensatory motive; differs because it is plain English and less formal or arch than the French phrase.
  • as a stopgap: Similar because it denotes a temporary substitute; differs because it stresses provisional timing rather than absence of alternatives.
  • by default: Similar because it describes winning by absence of competitors; differs because it is neutral-procedural, while faute de mieux adds rueful resignation.
  • as a last resort: Similar because it signals settling after options failed; differs because it implies desperation and finality rather than mild making-do.
  • for want of: Similar because it shares the "lack compels choice" logic; differs because it is native, older-fashioned, and governs a specific noun.
  • in default of: Similar because it is a formal legal equivalent for absence; differs because it is technical and lacks ironic colour.
  • provisionally: Similar because both accept imperfection for now; differs because it promises review, while faute de mieux merely shrugs.
  • perforce: Similar because it conveys necessity-driven acceptance; differs because it stresses compulsion rather than comparative judgment.
  • faute (as excuse): Similar because both plead lack; differs because faute alone is incomplete without specifying what is lacking.
  • makeshift (adjective): Similar because it describes an improvised substitute; differs because it characterises the thing's quality rather than the chooser's motive.
