• Guitar: Similar because it is a fretted plucked lute; differs because guitar has flat wooden soundboard and mellow sustain, while banjo has drum skin head and piercing twang.
  • Mandolin: Similar because it is a bright plucked folk instrument; differs because mandolin is small with double steel strings and bowl back, while banjo is round with skin head.
  • Ukulele: Similar because it is a small plucked folk lute; differs because ukulele is Hawaiian small guitar-voice for gentle strum, while banjo is loud and percussive.
  • Lute: Similar because banjo is historically a lute family member; differs because classical lute has pear body and soft gut voice, while banjo has drum body and cutting voice.
  • Sitar: Similar because it is a long-necked plucked lute with drone strings; differs because sitar is Indian classical with sympathetic strings, while banjo is Atlantic folk with single drone.
  • Balalaika: Similar because it is a folk plucked triangle lute; differs because balalaika is Russian with triangular wood body, while banjo is round with membrane.
  • Xalam / Ngoni / Akonting: Similar because they are the West African skin-lute ancestors; differs because they are gourd-bodied village instruments, while banjo is their industrial American descendant.
  • Banjolele: Similar because it is a banjo-uke hybrid; differs because banjolele is small uke scale with banjo head for novelty, while banjo proper is full scale for folk and bluegrass.
  • Zither: Similar because it is a plucked string box; differs because zither is table-laid with many unstopped strings, while banjo is necked and fretted.
  • Fiddle: Similar because it is the banjo partner in old-time string bands; differs because fiddle is bowed, while banjo is plucked, their pairing defining the genre.
