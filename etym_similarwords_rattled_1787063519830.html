• Clattered: Similar because both describe a series of sharp, hard collision sounds; differs because clattered stresses loud, harsh metallic contact, while rattled emphasises rapid repetition and can be lighter.
  • Clinked: Similar because both describe small hard objects striking each other; differs because clinked is a lighter, higher, metallic ping (as of glasses), whereas rattled is a longer, rougher succession of knocks.
  • Shaken: Similar because both describe being psychologically unsettled; differs because shaken is broader and more serious (deeply disturbed), while rattled implies a temporary loss of composure.
  • Jangled: Similar because both describe discordant metallic sounds and nervous agitation; differs because jangled is more specifically harsh, discordant, and nerve-racking, while rattled keeps its lively clattering quality.
  • Unsettled: Similar because both describe a disturbed state of mind; differs because unsettled is a general, long-lasting unease, while rattled is a sharper, more sudden shock to composure.
  • Clattered off / rattled off: Related as synonyms for speaking quickly; differs in that only rattled is idiomatic in "rattled off" for glib, rapid recitation.
