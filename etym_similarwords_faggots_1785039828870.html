• Kindling: Similar because both are wood for the fire; differs because kindling means small dry splinters used only to start a fire, while a faggot is a bound bundle that also feeds the burning.
  • Firewood: Similar because both are wood burned as fuel; differs because firewood denotes larger, seasoned pieces that burn long, not tightly bound bundles of twigs and brush.
  • Logs: Similar because both are fire fuel; differ because they are cut tree-trunks, heavy and long-burning, without the gathering-and-binding that defines a faggot.
  • Brushwood: Similar because both are small branches and scrub; differs because brushwood is loose and unbound, whereas a faggot is specifically tied into a bundle.
  • Fascine: Similar because it is a bound bundle of brushwood; differs because it is a military engineering bundle used to fill trenches and ramparts rather than hearth fuel.
  • Tinder: Similar because both belong to fire-lighting; differs because tinder is extremely dry, flammable material (fungus, bark, tow) for catching a spark, not a fuel bundle.
  • Sheaf: Similar because both are tied bundles of plant material; differs because a sheaf is a bound crop (wheat, barley) for harvest, not wood for burning.
  • Bundle: Similar because both mean a collection bound together; differs because bundle is the generic word for any tied package, while faggot names the specific tied firewood unit.
