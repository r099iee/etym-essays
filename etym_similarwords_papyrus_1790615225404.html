• scroll: Similar because it denotes a rolled manuscript, often papyrus; differs because it describes form, not material, and can be parchment.
  • parchment: Similar because it is an ancient writing material; differs because it is animal skin, more durable and suited to codices.
  • vellum: Similar because it is prepared skin for fine manuscripts; differs because it is calfskin, smoother and costlier than papyrus.
  • paper: Similar because it is a plant-based writing surface whose name derives from papyrus; differs because it is pulp-based, foldable, modern.
  • manuscript: Similar because papyri are manuscripts; differs because it is generic handwritten text, any material.
  • codex: Similar because it is an ancient book form succeeding scroll; differs because it is bound leaves, typically parchment, not roll.
  • tablet: Similar because it is an early writing support; differs because it is clay, wood, or wax, hard and incised, not vegetal sheet.
  • ostracon: Similar because it is an ancient cheap writing surface; differs because it is potsherd, used for notes, not long scrolls.
  • document: Similar because papyrus texts are documents; differs because it is content-generic, modern and legal.
