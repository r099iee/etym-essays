• hot-rodding: Similar because it means modifying cars for speed; differs because it names the whole subculture, not just the tuning act.
  • hopping up: Similar because it is a near-exact hot-rod synonym; differs because it is older and more period-specific.
  • tuning: Similar because it means adjusting an engine; differs because it is technical and neutral, without the illicit-loud tang.
  • modding: Similar because it means modifying; differs because it is broader (games, PCs) and contemporary.
  • tricking out: Similar because it means customizing showily; differs because it stresses appearance over horsepower.
  • pimping (out): Similar because it means flash-customizing a ride; differs because it is 2000s slang and stresses cosmetics.
  • juicing up: Similar because it means adding power; differs because it is more general and less automotive.
  • beefing up: Similar because it means strengthening; differs because it implies sturdiness rather than speed.
  • supercharging: Similar because it literally boosts power; differs because it names a specific device.
  • jazzing up: Similar because it means enlivening; differs because it applies to stories and décor, not engines.
  • personalizing: Similar because it makes a mass product one’s own; differs because it is broader and neutral.
