• corbel: Similar because it is a stone or timber wall-projection carrying weight; differs because corbel is specifically masonry and structural, while bracket is the generic term for any small support.
  • console: Similar because it is a decorative S-shaped wall support for shelves or cornices; differs because console implies carved ornament, while bracket is plainer and more functional.
  • cantilever: Similar because it projects from a wall to carry a load; differs because cantilever is an engineering principle of anchored beams, while bracket is the small fitting itself.
  • shelf / jump-seat: Similar because the source bracket functions as a small seat-shelf; differs because shelf names the board and jump-seat the furniture, while bracket names the supporting fixture.
  • support / prop / strut: Similar because all bear weight; differs because these are generic structural words, while bracket specifies the small L-shaped wall-fixed form.
  • parenthesis (round bracket): Similar because both enclose and set matter apart; differs because parenthesis names the ( ) marks in British formal use, while bracket is the wider family including [ ] and { }.
  • brace (curly bracket): Similar because braces { } join lines together; differs because brace stresses binding, while bracket stresses enclosing or grouping.
  • category / group / class: Similar because a tax or age bracket is a grouping; differs because these are abstract sets, while bracket keeps the image of limits that clasp members.
  • clamp / clip: Similar because they grip and hold; differs because clamps are movable tools, while brackets are fixed supports.
  • mount / fixture: Similar because both attach things to walls; differs because mount is the general installation term, while bracket is the specific hardware piece.
