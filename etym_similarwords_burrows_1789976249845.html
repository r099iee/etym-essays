• Tunnel: Similar because it is an underground passage; differs because tunnel stresses transit, while burrows stresses dwelling.
  • Hole: Similar because it is an opening in ground; differs because hole is generic, while burrows implies excavated animal home.
  • Den: Similar because it is an animal shelter; differs because den can be a surface hollow or cave, not necessarily dug.
  • Lair: Similar because it is a wild animal's refuge; differs because lair sounds larger and predatory (lion, dragon), while burrows are small-prey tunnels.
  • Warren: Similar because it is a network of rabbit tunnels; differs because warren is the whole colony system, while burrows are its individual holes.
  • Sett: Similar because it is a badger burrow system; differs because sett is species-specific to badgers.
  • Earth: Similar because huntsmen call a fox's burrow its earth; differs because it is hunting jargon, narrow to foxes.
  • Excavation / Digs: Similar because they are dug-out hollows; differs because they are human archaeological or military terms, not animal homes.
