• Town: Similar because it denotes a built settlement larger than a village; differs because town is generic-physical, while borough adds chartered administrative status.
  • Municipality: Similar because it means a self-governing urban district; differs because it is formal-Latinate and international, while borough is specifically Anglo-American with historic overtones.
  • District: Similar because it names a bounded administrative area; differs because district is neutral and often appointed, borough implies elected council and civic identity.
  • Ward: Similar because it is an electoral subdivision electing councillors; differs because a ward is a part of a borough, not the borough itself.
  • County: Similar because it is a larger tier of local government; differs because county is shire-scale and rural-inclusive, borough is town-scale and urban.
  • City: Similar because many boroughs aspire to or hold city status like Chelmsford; differs because city requires royal grant and cathedral or scale, borough requires only incorporation.
  • Burgh: Similar because it is the Scots cognate with identical fortified origin; differs because it marks Scottish law and pronunciation, borough marks English.
  • Township: Similar because it is a small local government unit; differs because it is chiefly American and rural-survey based, lacking borough’s chartered history.
  • Commune: Similar because it is a Continental self-governing municipality; differs because it carries French-revolutionary and rural associations alien to borough.
