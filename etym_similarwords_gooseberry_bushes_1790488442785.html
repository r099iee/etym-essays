• currant-bush (redcurrant / blackcurrant): Similar because it is a Ribes fruiting shrub of the same family; differs because currants are smooth, clustered, and thornless, while gooseberries are thorny and single-fruited.
  • bramble / blackberry-bush: Similar because it is a thorny fruiting shrub picked in hedges; differs because brambles trail and arch, while gooseberry-bushes are upright and pruned.
  • raspberry-cane: Similar because it is a soft-fruit garden row; differs because raspberries are aggregate drupes on biennial canes, while gooseberries are single berries on perennial wood.
  • shrub: Similar because a gooseberry-bush is a shrub; differs because shrub is generic, while gooseberry-bush specifies fruit and thorns.
  • thicket: Similar because plural bushes form a thicket; differs because thicket is wild tangle, while garden bushes are ordered rows.
  • hedge: Similar because gooseberries can hedge a plot; differs because hedge is boundary planting, while bushes are crop.
  • fruit-bush: Similar because it is the category; differs because fruit-bush is general, while gooseberry-bush is the species.
  • nursery-bush / young bush: Similar in garden-centre sales; differs because nursery stock is for planting, while established bushes bear.
  • gooseberry (fruit): Similar because it is the product of the bush; differs because berry is the edible part, while bush is the woody plant.
  • gooseberry fool (dish): Similar because it is what bushes are for; differs because fool is cream pudding, while bushes are horticulture.
