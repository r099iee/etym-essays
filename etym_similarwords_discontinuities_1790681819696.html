• gaps: Similar because both denote intervals of absence; differs because gap is colloquial, physical, and neutral, while discontinuity is formal and often implies a break in an expected continuity.
  • breaks: Similar because both denote interruptions; differs because break suggests a violent snap or pause, discontinuity suggests structural non-joining.
  • ruptures: Similar because both denote sharp separations; differs because rupture connotes tearing force and irreversibility, stronger than discontinuity.
  • interruptions: Similar because both denote suspension of flow; differs because interruption implies temporary stoppage with resumption, discontinuity implies lack of connection as such.
  • disruptions: Similar because both involve disturbed continuity; differs because disruption stresses disturbance of process by an agent, discontinuity stresses the resulting gap.
  • hiatuses: Similar because both denote lacunae in sequence; differs because hiatus is literary and temporal, discontinuity is technical and structural.
  • lacunae: Similar because both denote missing parts; differs because lacuna is philological and plural-learned, implying something lost that could be filled.
  • fissures: Similar because both denote splits; differs because fissure is concrete and geological/anatomical, discontinuity is abstract and general.
  • divergences: Similar because both denote failure to coincide; differs because divergence implies paths drifting apart, discontinuity implies no path at all across the interval.
  • incoherences: Similar because both denote logical non-fitting; differs because incoherence is internal unintelligibility, discontinuity is relational non-continuity with something else.
  • disjunctions: Similar because both denote separations; differs because disjunction is logical/linguistic separation of alternatives, discontinuity is broader ontological or sequential break.
  • chasms / gulfs: Similar because both evoke wide separations; differs because they are metaphorical and scalar, emphasising magnitude, while discontinuity is analytic and categorical.
