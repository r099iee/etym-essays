• Violin: Similar because a fiddle is physically the same four-stringed, hourglass-bodied bowed instrument as a violin; differs because violin is the classical concert name and technique, while fiddle signals folk, dance, and informal playing.
  • Viol: Similar because it is an old bowed string instrument; differs because the viol is a fretted Renaissance consort family with a flat back and a different hold, not a synonym for the violin-shaped fiddle.
  • Viola: Similar because it is a member of the same violin family of bowed strings; differs because it is the larger alto instrument with a lower range, not the same size and register as a fiddle.
  • Violoncello (cello): Similar because it is a bowed string instrument of the same family; differs because it is the large bass-voice instrument held between the knees, not a small handheld fiddle.
  • Lyre: Similar because it is an ancient string instrument used in music-making; differs because it is plucked, not bowed, and belongs to a different instrumental family.
  • Harp: Similar because it is a string instrument that can appear in the same ensembles; differs because it is plucked with the fingers and far larger, not a small bowed instrument.
  • Fiddler: Similar because it shares the fiddle stem and belongs to the folk-music world; differs because a fiddler is the player of the instrument, not the instrument itself.
  • Kit (kit-fiddle): Similar because it is a tiny bowed string instrument; differs because the kit is a miniature dance-master's violin carried in the pocket, while fiddles are ordinary small violins played in folk ensembles.
  • Rebec: Similar because it is a medieval bowed instrument used for dance music; differs because the rebec is a pear-shaped three-string instrument of medieval Europe, while the fiddle is the four-string violin design.
