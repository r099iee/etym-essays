• drafts: Similar because it is the identical word in American spelling; differs because draft (US) covers all the senses in one spelling, while draught (UK) is kept for air, liquid, depth, and the game.
  • currents (of air): Similar because both name moving air; differs because a current is a general flow (of air or water), while a draught is air drawn into an enclosed space through an opening.
  • breezes: Similar because both name gentle air movement; differs because a breeze is outdoor and mild, while a draught is indoor, cold, and drawn through gaps.
  • gusts: Similar because both name air movement; differs because a gust is a sudden, strong outdoor burst, while a draught is a steady, enclosed current.
  • winds: Similar because both are moving air; differs because wind is large-scale outdoor weather, while draught is localised, enclosed, and caused by pressure differences.
  • pulls: Similar because both descend from the verb "to draw" and name an act of drawing; differs because pull is general, while draught is the specific deverbal noun with many fixed senses.
  • sips / gulps (of drink): Similar because both name quantities of liquid taken at once; differs because a draught is a generous pull from a vessel, while a sip is tiny and a gulp is slangy.
  • swallows: Similar because both name amounts drunk at once; differs because swallow is physiological and neutral, while draught is literary and generous.
  • checkers: Similar because the American game is the same as British draughts; differs because checkers (US) is the same game with a different name and different pieces (checkers / checkermen).
