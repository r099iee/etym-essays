• barbarism: Similar because it is a rude uncivilized state; differs because barbarism in old theory is a higher stage than savagery and now means crude taste.
  • brutality: Similar because it is cruel inhuman violence; differs because brutality stresses physical force, savagery stresses wildness and ferocity.
  • cruelty: Similar because it inflicts suffering; differs because cruelty can be cold and calculated, savagery is fierce and untamed.
  • ferocity: Similar because it is savage fierceness; differs because ferocity is intensity of attack, savagery includes primitive condition.
  • atrocity: Similar because it is an act of extreme cruelty; differs because atrocity is a countable horrific deed, savagery the quality behind it.
  • barbarity: Similar because it is savage cruelty; differs because barbarity is more literary and moral, savagery more wild and visceral.
  • inhumanity: Similar because it denies human mercy; differs because inhumanity can be bureaucratic coldness, savagery heated wildness.
  • wildness: Similar because it is untamed natural state; differs because wildness can be neutral or admiring, savagery condemns cruelty.
  • primitiveness: Similar because it is early undeveloped state; differs because primitiveness is technical and neutral, savagery pejorative.
  • fierceness: Similar because it is intense aggressive force; differs because fierceness can be noble in defence, savagery rarely ennobles.
  • viciousness: Similar because it is deliberately cruel; differs because viciousness implies vice and spite, savagery untamed nature.
  • bloodthirstiness: Similar because it lusts for blood; differs because it is specifically homicidal appetite, narrower than savagery.
  • ruthlessness: Similar because it acts without pity; differs because ruthlessness can be efficient and modern, savagery archaic and feral.
