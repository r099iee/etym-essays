• Suppressed: Similar because both involve feelings or tears held back; differs because suppressed describes the active, forceful mental effort to quell an emotion, while unshed describes the physical, glistening state of the unfallen tears themselves.
  • Restrained: Similar because both suggest emotional self-control; differs because restrained is an abstract character trait or behavioral judgment, whereas unshed provides a direct physical sensory image.
  • Unwept: Similar because both indicate that tears were not shed; differs because unwept typically means that a deceased person or tragic event was unmourned by others (“he died unwept, unhonoured, and unsung”).
  • Unspilled: Similar because both refer to liquids that have not poured out; differs because unspilled is applied prosaically to drinks or industrial fluids, lacking the poetic and ocular romance of unshed.
  • Pent-up: Similar because both describe emotions confined within; differs because pent-up suggests explosive internal pressure ready to burst forth (pent-up rage), whereas unshed conveys poignant, quiet suspension.
  • Choked back: Similar because both denote weeping prevented from overflowing; differs because choked back focuses on the throat and vocal struggle (a sob strangled in the larynx), whereas unshed focuses on the eyes.
  • Unfallen: Similar because both describe that which has not dropped down; differs because unfallen applies to angels, snow, or empires, lacking the specific ocular intimacy of tears.
  • Retained: Similar because both indicate that something is kept inside; differs because retained is a cold, clinical, or bureaucratic term.
  • Bottled-up: Similar because both refer to contained feelings; differs because bottled-up is informal psychological modern jargon.
  • Intact: Similar because the substance remains undivided and unreleased; differs because intact is broad and mechanical, devoid of pathos.
  • Uncast: Similar because both can describe antlers, skins, or dice that have not been cast off; differs because uncast lacks any application to human tears or grief.
  • Swallowed: Similar because one speaks of “swallowed tears” or “swallowed grief”; differs because swallowed is an active physical metaphor of ingestion, rather than stationary pooling in the eye.
