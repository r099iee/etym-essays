• Chiffon: Similar because it is a light, elegant dress fabric used in the same garments; differs because chiffon is sheer and translucent, its character being transparency, while crêpe is opaque with a deliberately pebbled, matte surface.
  • Satin: Similar because it is a luxury fabric for dress and linings; differs because satin is glossy and smooth, built on light-reflecting floats, the exact visual opposite of crêpe’s matte crimp.
  • Georgette: Similar because it is a dull, crinkly, translucent silk fabric with a crêpe texture; differs because georgette is a specific, usually sheer variety of the crêpe family, not a distinct rival.
  • Gauze: Similar because it is a light, soft fabric with an open, airy quality; differs because gauze is plain and loosely woven without the deliberate crimping that defines crêpe.
  • Muslin: Similar because it is a plain, soft cotton fabric used for dress; differs because muslin is smooth, untextured, and un-crimped, lacking the pebbled surface essential to crêpe.
  • Pancake (food sense): Similar because a crêpe is a type of flat pancake; differs because crêpe is thinner, made from a pourable batter, and rolled or folded, while pancake is thicker and griddle-cooked with a raising agent.
