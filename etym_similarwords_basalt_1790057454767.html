• lava (rock): Similar because both are solidified volcanic material; differs because lava names molten flow or its product loosely, while basalt names the specific mafic rock type.
  • gabbro: Similar because identical magma chemistry; differs because gabbro cooled slowly underground into coarse crystals, while basalt froze fast into fine grains.
  • dolerite / diabase: Similar because same chemistry in shallow intrusions; differs because dolerite is medium-grained dyke-and-sill rock, while basalt is surface lava.
  • andesite: Similar because dark fine-grained volcanic rock; differs because andesite is intermediate-silica and paler, typical of continental arcs, while basalt is mafic and oceanic.
  • obsidian: Similar because mafic-to-felsic lava frozen too fast to crystallise; differs because obsidian is volcanic glass, while basalt is crystalline.
  • whinstone: Similar because quarrymen's dark hard igneous stone; differs because whinstone is regional trade jargon (N. England/Scotland), while basalt is the scientific name.
  • bluestone: Similar because builders' dark volcanic stone; differs because bluestone is commercial-Australian loose usage, while basalt is petrologically precise.
  • trap (rock): Similar because old quarrying term for dark step-weathering lavas; differs because trap is archaic-field slang, while basalt is modern taxonomy.
  • scoria: Similar because mafic ejecta; differs because scoria is frothy cinder full of holes, while basalt in the strict sense is dense lava.
  • volcanic rock (general): Similar because umbrella category; differs because it covers rhyolite to basalt, while basalt is one mafic member.
