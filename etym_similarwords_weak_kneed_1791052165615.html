• cowardly: Similar because it means lacking courage; differs because it is graver and implies desertion of duty, while weak-kneed stresses buckling and vacillation.
  • faint-hearted: Similar because it means timid and easily frightened; differs because it stresses heart/feeling, while weak-kneed stresses inability to stand firm.
  • spineless: Similar because it means lacking backbone/resolve; differs because spineless is more contemptuous and total, weak-kneed suggests momentary buckling.
  • lily-livered: Similar because it means cowardly in archaic idiom; differs because it is literary/Shakespearean and now humorous, while weak-kneed is still live political insult.
  • chicken-hearted: Similar because it means timid; differs because it is colloquial and slightly comic, evoking a chicken, not buckling knees.
  • pusillanimous: Similar because it means cowardly and irresolute; differs because it is formal Latinate and bookish, while weak-kneed is vivid Anglo-Saxon bodily image.
  • timid: Similar because it means shy and fearful; differs because timid can be gentle temperament, while weak-kneed implies failure of expected firmness.
  • irresolute: Similar because it means unable to decide firmly; differs because it is neutral about fear, stressing vacillation, while weak-kneed adds cowardice.
  • vacillating: Similar because it means wavering; differs because it describes behaviour, not character, and lacks the bodily metaphor.
  • feeble: Similar because it means lacking strength; differs because feeble is general physical or argumentative weakness, while weak-kneed is specifically moral buckling.
  • ineffectual: Similar because it means failing to act firmly; differs because it stresses outcome, not fear.
  • soft: Similar because soft on crime etc. means lenient; differs because soft can be positive (gentle), while weak-kneed is always critical.
