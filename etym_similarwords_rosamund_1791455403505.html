• Rosamond: similar because it is the same name in a long-established variant spelling; differs because it is slightly more archaic in feel and is common in older literary texts.
  • Rosamunde: similar because it is the German form of the same name; differs because it is associated with German literature and Schubert’s incidental music.
  • Rosemonde: similar because it is the French form; differs because it has a French spelling and a more continental literary flavour.
  • Rosmunda: similar because it is the Italian and older Germanic form; differs because it is closer to the Lombard queen and the medieval Latin record.
  • Roz: similar because it is a common diminutive of Rosamund; differs because it is informal, short, and can also stand for Rosalind or Rosemary.
  • Rose: similar because it is a flower name and the source of the folk etymology rosa munda; differs because Rose is a separate name with its own history and does not carry the “horse-protection” etymology.
  • Rosalind: similar because it is a literary English name beginning with Ros-; differs because it derives from a different Germanic compound and is associated with Shakespeare’s As You Like It.
  • Rosaline: similar because it is a romantic Ros- name; differs because it is a distinct name, famous from Romeo and Juliet and Love’s Labour’s Lost.
  • Rosanna: similar because it combines rose imagery with a feminine name; differs because it is usually a compound of Rose and Anna, not a Germanic “horse-protection” name.
  • Rosemary: similar because it is a familiar English female name with a plant association; differs because it derives from the herb ros marinus and has no connection with the Rosamund legend.
  • Rosa: similar because it is the Latin word for rose and a common name; differs because it is short, international, and directly floral rather than medieval and literary.
  • Fair Rosamund: similar because it is the fixed epithet for Rosamund Clifford; differs because it refers specifically to the legendary mistress, not to the name in general.
  • Henry II’s mistress: similar because it identifies the historical role associated with Rosamund Clifford; differs because it is a descriptive phrase, not a name.
