• annoying: Similar because it means causing irritation; differs because it is neutral and general, while pesky stresses trivial persistence and is more colloquial and dismissive.
  • irritating: Similar because it means provoking impatience; differs because it is formal and can describe serious pain, while pesky implies smallness and buzzing repetition.
  • vexatious: Similar because it means causing vexation, especially in law; differs because it is formal-legal and stronger, while pesky is folksy and light.
  • troublesome: Similar because it means causing trouble; differs because it can be serious (troublesome tumour), while pesky denies seriousness.
  • bothersome: Similar because it means causing bother; differs because it is milder and more polite, while pesky is more vivid and faintly amused.
  • irksome: Similar because it means wearisome; differs because it is literary and suggests tedium, while pesky suggests intrusive buzzing.
  • nagging: Similar for persistent pains and doubts (nagging cough); differs because it stresses continuous gnawing, while pesky stresses intermittent return.
  • plaguing: Similar in metaphor (plagued by doubts); differs because it retains biblical seriousness, while pesky is deliberately trivializing.
  • nettlesome: Similar because nettles sting trivially; differs because it is rare and literary, while pesky is everyday.
  • pesty: Similar because it is the doublet variant meaning identical; differs only in that pesty is now rare and feels more literal (like a pest), while pesky is standard.
  • importunate: Similar for pesky salesmen and beggars; differs because it is formal for persistent asking, while pesky covers all irritants.
  • meddlesome: Similar for interfering neighbours; differs because it stresses unwanted interference, while pesky stresses irritation.
  • fiddly: Similar for pesky details and tasks; differs because it is British for awkward-small jobs, while pesky is American and broader.
