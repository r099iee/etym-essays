• Tokharian: Similar because it is an older variant spelling of the same name and refers to the same languages; differs only in transliteration convention and is now less standard.
  • Agnean: Similar because it is another name for Tocharian A; differs because it is a narrower label for one of the two languages, not the whole branch.
  • Turfanian: Similar as a geographical label for Tocharian A, named after the Turfan oasis; differs because it describes find-spots rather than the linguistic family.
  • Kuchean: Similar because it names Tocharian B after the city of Kucha; differs because it covers only that language and is not used for the branch as a whole.
  • Indo-European: Similar because Tocharian is a branch of that family; differs because it is the whole family, vastly broader and not specific to Central Asia.
  • Indo-Iranian: Similar as another branch attested in the same region and period; differs because it is a distinct branch (Sanskrit, Avestan, Persian) with satem phonology, whereas Tocharian shows centum-like features.
  • Saka: Similar as an extinct Iranian language of the Tarim Basin, also attested in manuscripts; differs because Saka is Iranian, not Tocharian, and is closer to Khotanese.
  • Khotanese: Similar as a Silk Road manuscript language of the same region; differs because it is a Middle Iranian language, not an independent Indo-European branch.
  • Sogdian: Similar as a Central Asian lingua franca of the Silk Road; differs because it is Iranian and continued in use alongside Tocharian.
  • Yuezhi: Similar because the ancient people is sometimes linked to the Tokharoi and to Tocharian speakers; differs because it is an ethnonym from Chinese sources and the connection is debated.
