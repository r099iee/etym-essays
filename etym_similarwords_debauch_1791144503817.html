• Orgy: Similar because it denotes wild unrestrained indulgence; differs because it prototypically implies group sexual excess, while debauch centres on drink, food, and revelry generally.
  • Binge: Similar because it names an episode of immoderate consumption; differs because it is clinical/colloquial (binge-eating, binge-drinking) without the moral-corruption flavour.
  • Bender: Similar because it means a drinking spree; differs because it is slangy and alcohol-specific, lacking the literary and sexual range of debauch.
  • Spree: Similar because it is a bounded burst of indulgence; differs because it is morally neutral and cheerful (shopping spree), whereas debauch implies dissolution.
  • Revel: Similar because it denotes noisy merry-making; differs because revels can be innocent festivity, while a debauch is by definition intemperate.
  • Debauchery: Similar because it shares the root and the idea of dissolution; differs because it names the habitual condition, not the single bout.
  • Dissipation: Similar because it means a dissolute, pleasure-squandering life; differs because it stresses waste and decline rather than one wild episode.
  • Licentiousness: Similar because it denotes unbridled sensual behaviour; differs because it is a formal abstract noun for the quality, not an event.
  • Carouse: Similar because it means noisy drunken feasting; differs because it is specifically about drink and company, narrower than debauch.
  • Saturnalia: Similar because it names a riotous feast of licence; differs because it evokes the Roman festival and collective inversion of order, a grander and rarer word.
  • Bacchanalia: Similar because it denotes drunken orgiastic revelry; differs because it is classical, plural-leaning, and tied to Bacchic frenzy imagery.
  • Corruption: Similar because to debauch (verb) is to corrupt; differs because corruption covers bribery, rot, and dishonesty far beyond sensual seduction.
