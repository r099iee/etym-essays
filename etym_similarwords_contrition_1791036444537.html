• remorse: Similar because it is deep gnawing regret for wrongdoing; differs because remorse can be tormenting and backward-looking, contrition adds resolve to amend.
  • repentance: Similar because it means turning from sin with resolve; differs because repentance stresses changed life and action, contrition stresses crushed feeling.
  • penitence: Similar because it is sorrow shown in penance; differs because penitence emphasises suffering and outward penance.
  • penitency (rare): Similar as doublet of penitence; differs only in rarity.
  • compunction: Similar because it is pricking of conscience; differs because compunction is often a twinge before acting, contrition is crushing sorrow after.
  • regret: Similar because it is sorrow for what happened; differs because regret can be passive and non-moral, contrition is actively moral.
  • rue: Similar because it is bitter wishing-undone; differs because rue is literary and can be self-pitying.
  • shame: Similar because shame accompanies guilt; differs because shame focuses on exposed self, contrition on wronged other and God.
  • guilt: Similar because guilt is pained knowledge of wrongdoing; differs because guilt is the feeling-state, contrition is guilt crushed into resolve.
  • self-reproach: Similar because it is inward blame; differs because it lacks the theological crushing and amendment entailment.
  • apology: Similar because contrition is often expressed in apology; differs because apology is the speech act, contrition is the inward state that should underlie it.
  • atonement: Similar because atonement follows true contrition; differs because atonement is the reparative act, not the sorrow itself.
  • attrition (theological): Similar because it is imperfect sorrow for sin; differs because attrition is motivated by fear of punishment, perfect contrition by love of God.
  • humility: Similar because contrite persons are humble; differs because humility is general lowliness, contrition is specifically guilt-crushed.
