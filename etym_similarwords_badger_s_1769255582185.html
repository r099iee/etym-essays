• Brock’s: Similar because “brock” is the old native word for the badger (a Celtic loan) and “brock’s” means the same thing; differs because “brock” is archaic or dialectal now, with a flavour of folklore, whereas “badger’s” is the modern standard.
  • Beast’s: Similar because it can denote the face or feature of a wild animal; differs because “beast’s” is general — it names no particular species — whereas “a badger’s” is exact about which animal.
  • Creature’s: Similar because it refers to the property of an animal being; differs because “creature’s” is vaguer and softer, losing the precise natural-history identity that “badger’s” pins down.
  • Animal’s: Similar because it is a general possessive for any animal; differs because “animal’s” erases the species and with it the shock of a specifically badger’s face speaking.
  • Otter’s / weasel’s / stoat’s: Similar because these are fellow mustelids (the weasel family) with comparable burrowing, wild habits; differ because each names a different animal with a different build and face, so none could substitute for the distinctive badger’s striped countenance.
  • Wolverine’s: Similar because the wolverine is a large, powerful, solitary mustelid; differs because it is a northern forest animal, far more aggressive and rarely known to European readers, with none of the badger’s familiar folk associations.
  • Honey badger’s: Similar because the honey badger (ratel) is a close African relative famous for ferocity; differs because it is a different species, darker and more aggressive, with a different face and no European cultural baggage.
  • Possum’s / raccoon’s: Similar because both are burrowing or nocturnal animals with striped or masked faces; differ because they are unrelated families (marsupials and procyonids), and their faces lack the broad white-and-black badger striping of the mustelid.
  • Trufflehunter’s: Similar because in this very scene Trufflehunter is the badger, so “Trufflehunter’s” denotes the same face; differs because it names the individual character, not the species, and so loses the natural-history wonder of “a badger’s” face.
