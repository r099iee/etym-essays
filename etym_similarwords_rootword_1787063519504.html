• Stem: Similar because it functions as the structural foundation to which affixes attach; differs because a stem is specifically the base to which inflectional grammatical endings (e.g., plural -s, past tense -ed) are added, and a stem may already contain derivational affixes (e.g., in 'civilizations', 'civilize' is the root, 'civilization' is the stem).
  • Base: Similar because it refers to any morpheme or word part to which affixes can be joined; differs because base is a broader category that includes compound stems and derived intermediate forms, whereas a root word is strictly irreducible.
  • Lemma: Similar because it represents the canonical, uninflected headword of a family of word forms; differs because lemma is a lexicographical and computational dictionary entry convention (e.g., 'run' is the lemma for 'runs', 'running', 'ran'), whereas a root word is a physical morphological constituent.
  • Etymon: Similar because it denotes an original linguistic form from which other words descend; differs because etymon specifically refers to the historical, ancestral word in an earlier language (e.g., Latin 'pater' as the etymon of French 'père') rather than a synchronous structural morpheme in current grammar.
  • Primitive (Archaic): Similar because early grammarians used it for simple, uncompounded word bases; differs because primitive is an outdated 18th-century grammatical term largely abandoned in modern scientific morphology.
  • Radix: Similar because it is the classical Latin term for 'root' used in older grammatical treatises; differs because radix is primarily used in mathematics and botany today, having been superseded by root word in modern linguistics.
  • Morpheme: Similar because both represent foundational units of linguistic structure; differs because morpheme includes all grammatical units (prefixes, suffixes, inflections), whereas root word specifically refers to the central, meaning-bearing lexical morpheme.
