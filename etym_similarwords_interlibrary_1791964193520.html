• interlending: Similar because it names the same traffic of material between libraries; differs because it is a noun for the activity, preferred in British and IFLA usage, whereas interlibrary is an attributive adjective that must lean on a following noun.
  • interloan: Similar because it denotes a loan from one library to another; differs because it is a shortened professional noun (common in New Zealand and Australia) with a conversational tone, not a formal modifier.
  • ILL: Similar because it is the standard label for the same service; differs because it is an initialism of insider jargon, unusable as an ordinary adjective and meaningless outside the profession.
  • document delivery: Similar because it covers the supply of articles and copies between institutions; differs because it is broader — it includes commercial suppliers and never implies the return of an object.
  • resource sharing: Similar because it names the cooperative principle that interlibrary lending embodies; differs because it is a policy-level umbrella covering shared cataloguing, storage and acquisitions as well as loans.
  • consortial borrowing: Similar because it too describes borrowing across institutions; differs because it is restricted to members of a formal consortium with reciprocal rights, often initiated directly by the reader.
  • inter-institutional: Similar because it marks a relation between institutions; differs because it is entirely generic and says nothing about libraries or books.
  • intralibrary: Similar because it is built from the same two elements; differs because it is the opposite relation — movement or lending within a single library.
