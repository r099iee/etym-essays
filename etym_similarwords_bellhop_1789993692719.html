• bellboy: Similar because it names the same hotel luggage-carrier; differs because it is the older, more British and now dated term, explicitly marking youth and maleness.
  • bellman: Similar because it names the same role in American hotels; differs because it sounds slightly more adult and formal, the house term on staff lists.
  • porter: Similar because porters carry baggage in hotels and stations; differs because it is broader and British-standard, covering carriers the bell system never had.
  • bell attendant: Similar because it is the modern neutral title for the same job; differs because it is corporate-inclusive, erasing the hop's slang and the boy's age.
  • concierge: Similar because both serve hotel guests personally; differs because the concierge arranges and advises rather than carries, ranking far higher.
  • doorman: Similar because both greet and assist arrivals in uniform; differs because the doorman holds the entrance while the bellhop moves through the house.
  • page: Similar because pages run messages and escort in hotels and clubs; differs because the page is more ceremonial and less tied to luggage.
  • skycap: Similar because skycaps carry bags for tips at airports; differs because the setting is the terminal kerb, not the hotel lobby and corridors.
  • valet: Similar because valets attend personally to guests and cars; differs because valeting implies parking, pressing, and private service rather than lobby portering.
