• Prophet: Similar in delivering divine messages; differs because a prophet is an inspired human spokesperson, while an oracle is the shrine, answer, or medium through which the god speaks.
  • Seer: Similar in foretelling the future; differs because a seer relies on personal visionary power, while an oracle delivers formal responses from a deity at a sacred site.
  • Augur: Similar in divination; differs because an augur reads physical omens (birds, lightning), while an oracle speaks direct divine answers.
  • Soothsayer: Similar in predicting the future; differs because a soothsayer is a freelance diviner, whereas an oracle is institutionally tied to a god's shrine.
  • Sibyl: Similar as a female prophetess channeling divine utterance (the Cumaean Sibyl); differs because a sibyl is an ecstatic individual prophetess, whereas an oracle can be the place or the answer itself.
  • Prophecy: Similar in divine revelation; differs because prophecy is the message or content, while oracle is the medium, place, or utterance through which the message comes.
  • Authority: Similar in the modern sense of an infallible expert; differs because authority is the general quality of being trusted, while oracle retains the religious, absolute flavour of unerring pronouncement.
  • Riddle: Similar because the Delphic responses were proverbially ambiguous; differs because a riddle is a playful puzzle, while an oracle is a serious divine pronouncement that merely happened to be obscure.
