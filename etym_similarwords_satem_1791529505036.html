• hundred: Similar because it is the English meaning of Avestan satəm; differs because hundred is the ordinary numeral and not a linguistic label.
  • centum: Similar because it is the complementary label, also taken from the numeral "hundred"; differs because it names the western branch with velar reflexes, the opposite of satem.
  • śatám: Similar as the Sanskrit cognate of "hundred" and a classic satem reflex; differs because it is a Sanskrit word, not the English typological term.
  • sъto: Similar as the Old Church Slavonic cognate of "hundred"; differs because it is a Slavic form and belongs to a different branch of the family.
  • šimtas: Similar as the Lithuanian cognate of "hundred"; differs because it is a Baltic form with a different sibilant outcome.
  • simts: Similar as the Latvian cognate of "hundred"; differs because it is a specific Baltic form and not the label itself.
  • Avestan: Similar because it is the language from which satəm is borrowed; differs because Avestan is the language, while satem is a typological label.
  • Indo-Iranian: Similar as the core satem branch; differs because it names a genealogical subgroup, not the sound-change type.
  • Balto-Slavic: Similar as the other core satem branch; differs because it is a subgroup, and some of its members show incomplete satemization.
  • Albanian: Similar because it is often classed as satem; differs because its dorsal system is debated and it may preserve a three-way distinction.
  • Armenian: Similar because it is usually classed as satem; differs because its numeral for "hundred" is not a satem reflex and its history is contested.
  • sibilant: Similar because it names the class of sounds produced by satemization; differs because it is a phonetic term, not a language label.
  • isogloss: Similar because the centum–satem division is now described as one; differs because an isogloss is a boundary of a feature, not the feature itself.
