• bola: Similar because it denotes the same weapon in singular; differs because bolas is the usual lexicalised plural covering the whole weapon.
  • lasso: Similar because it is a hide-rope device for catching cattle by entanglement; differs because a lasso uses a running noose thrown by one rope rather than weighted balls.
  • lariat: Similar because it is a synonym of lasso for roping stock; differs because it emphasises the rope itself and cowboy technique, not weights.
  • riata: Similar because it is a braided rawhide roping thong; differs because it is material-specific and single-stranded.
  • snare: Similar because it traps by tightening cords; differs because a snare is usually stationary and set for small game, not thrown.
  • net: Similar because it entangles by mesh; differs because it covers broadly rather than wrapping with cords and weights.
  • sling: Similar because it is a primitive whirled throwing weapon; differs because a sling launches a single projectile rather than entangling.
  • boomerang: Similar because it is a thrown indigenous hunting weapon in the same museum list; differs because it stuns by impact and returns rather than tangling.
  • harpoon: Similar because it is a thrown hunting weapon with cord retrieval; differs because it pierces and holds rather than wrapping.
  • boladora / boleadora: Similar because it is the fuller Spanish name for the same weapon; differs because it is more technical and marks gaucho origin explicitly.
  • tether: Similar because it restrains by rope; differs because it is static restraint, not a projectile.
  • man-trap: Similar because it immobilises legs; differs because it is a sprung device on the ground, not thrown.
