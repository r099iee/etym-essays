• Vain: Similar because both describe excessive self-admiration; differs because vain focuses on admiring one's own appearance or achievements and seeking admiration, while conceited emphasizes the inflated opinion of one's worth overall.
  • Arrogant: Similar because both involve a sense of superiority; differs because arrogant stresses overbearing claims of rights and merits toward others, while conceited stresses the internal high opinion of oneself.
  • Self-important: Similar because both describe an inflated sense of one's own importance; differs because self-important stresses pomposity and the expectation of deference, while conceited stresses self-admiration.
  • Proud: Similar because both involve self-esteem; differs because proud can be positive or neutral (justified pride), while conceited is always an excessive, negative self-opinion.
  • Narcissistic: Similar because both describe excessive self-focus; differs because narcissistic is a clinical term for pathological self-love, while conceited is everyday overconfidence or vanity.
  • Egotistical: Similar because both involve excessive focus on oneself; differs because egotistical stresses self-centered talk and behavior, while conceited stresses the high opinion itself.
  • Smug: Similar because both involve self-satisfaction; differs because smug stresses complacent, irritating self-satisfaction, while conceited stresses inflated self-opinion.
  • Cocky: Similar because both describe confident self-importance; differs because cocky is informal and implies brash, flashy confidence, while conceited implies deeper vanity.
  • Supercilious: Similar because both involve thinking oneself superior; differs because supercilious stresses disdainful contempt for others (raised eyebrows), while conceited stresses self-admiration.
  • Haughty: Similar because both involve superiority; differs because haughty is a cold, aloof, disdainful bearing, while conceited is a warmer, more self-admiring vanity.
  • Overweening: Similar because both mean excessively self-confident; differs because overweening is formal and literary, implying arrogance that overreaches, while conceited is everyday.
  • Big-headed: Similar because both mean inflated self-opinion; differs because big-headed is informal slang, while conceited is standard.
  • Swollen-headed: Similar because both mean puffed up with self-importance; differs because swollen-headed is more colloquial and comic, while conceited is neutral-standard.
  • Pompous: Similar because both involve self-importance; differs because pompous stresses grand, self-important manner and speech (puffery), while conceited stresses the opinion itself.
  • Egotistical (variant): Similar because both involve self-regard; differs because egotism is the practice of talking about oneself, while conceit is the private inflated opinion.
