• struggled: Similar because it denotes strenuous effort against difficulty; differs because it stresses suffering and near-failure, while strove stresses noble aspiration.
  • laboured: Similar because it denotes worked hard with effort; differs because it is more physical and plodding, less lofty than strove.
  • endeavoured: Similar because it denotes earnest attempt toward a goal; differs because it is more formal and polite, less forceful and agonistic.
  • attempted: Similar because it denotes tried to do something; differs because it is neutral and can be single and brief, while strove implies sustained contention.
  • tried: Similar because it denotes made an effort; differs because it is general and colloquial, without dignity or resistance implication.
  • contended: Similar because it denotes competed or argued with effort; differs because it stresses rivalry and dispute more than inward aspiration.
  • vied: Similar because it denotes competed for superiority; differs because it is specifically rivalrous and often followed by with or for.
  • toiled: Similar because it denotes worked painfully hard; differs because it emphasizes wearisome labour, not goal-directed striving.
  • aspired: Similar because it denotes yearned toward higher goal; differs because it stresses desire and upward gaze, while strove stresses exertion itself.
  • grappled: Similar because it denotes wrestled with problem or foe; differs because it implies close clinching struggle, more physical than strove.
