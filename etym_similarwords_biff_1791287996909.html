• hit: Similar because it means to strike; differs because it is neutral and general, while biff is slangy and comic.
  • punch: Similar because it means to strike with the fist; differs because it is standard and technical, while biff is playful and echoic.
  • strike: Similar because it means to deliver a blow; differs because it is formal and broad, while biff is informal and specific to a whack.
  • smack: Similar because it means a sharp noisy slap; differs because it suggests an open hand, while biff suggests a fist.
  • slap: Similar because it means to hit with the hand; differs because it implies flat-hand contact and insult, while biff implies a bunched punch.
  • thump: Similar because it means a heavy blow; differs because it stresses dull weight, while biff stresses sharp suddenness.
  • wallop: Similar because it means a hard comic blow; differs because it is bigger and more painful than a biff.
  • bash: Similar because it is slang for a blow; differs because it can imply repeated or damaging hits, while biff is usually single.
  • whack: Similar because it is echoic slang for a smart blow; differs because it often uses a stick or object, while biff is usually fisticuffs.
  • bonk: Similar because it is comic slang for a knock on the head; differs because it is lighter and sillier than biff.
  • clip: Similar because it means a quick sharp blow (clip round the ear); differs because it stresses glancing contact, while biff is direct.
  • sock: Similar because it is slang for a hard punch; differs because it is American and heavier, while biff is British and lighter.
