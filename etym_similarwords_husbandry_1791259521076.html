• farming: Similar because it cultivates land and livestock; differs because farming is the occupation while husbandry is the skill and care with which it is done.
  • agriculture: Similar because it covers crop and stock production; differs because agriculture is the broad industry and science while husbandry is hands-on stewardship.
  • cultivation: Similar because it tills and grows; differs because cultivation focuses on crops while husbandry includes animals and household economy.
  • tillage: Similar because it works the soil; differs because tillage is one operation while husbandry is the whole management art.
  • animal husbandry - stockbreeding: Similar because both breed livestock; differs because stockbreeding stresses genetics while husbandry stresses overall care.
  • gardening: Similar because it tends plants; differs because gardening is usually small-scale and ornamental while husbandry is productive and economic.
  • stewardship: Similar because it manages entrusted resources; differs because stewardship is moral-religious duty while husbandry is practical farm craft.
  • management: Similar because it directs resources; differs because management is generic and corporate while husbandry is agrarian and frugal.
  • economy: Similar because it avoids waste; differs because economy is financial while husbandry is biological and domestic.
  • thrift: Similar because good husbandry requires thrift; differs because thrift saves money while husbandry tends living things.
  • housekeeping: Similar because it runs a household; differs because housekeeping is indoor and domestic while husbandry is field and farm.
  • conservation: Similar because both preserve resources; differs because conservation protects nature from use while husbandry uses nature sustainably.
  • crofting: Similar because it is small-scale farming; differs because crofting is a specific Scottish tenancy system while husbandry is universal practice.
  • pastoralism: Similar because it herds animals; differs because pastoralism is a nomadic lifestyle while husbandry is settled care.
