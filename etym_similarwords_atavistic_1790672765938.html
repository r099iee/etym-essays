• primitive: Similar because it evokes an early stage of development; differs because primitive describes the stage itself, atavistic describes its later reappearance.
  • primeval: Similar because it evokes the earliest times; differs because primeval is geological and sublime, atavistic is biological and diagnostic.
  • primordial: Similar because it names original beginnings; differs because primordial is cosmic and neutral, atavistic implies throwback.
  • regressive: Similar because it names going backward; differs because regressive stresses decline, atavistic stresses resurgence.
  • retrograde: Similar because it names backward movement; differs because retrograde is directional and critical, atavistic is hereditary.
  • throwback: Similar because it names reversion to an earlier type; differs because throwback is the noun for the instance, atavistic the adjective for the quality.
  • anachronistic: Similar because it names being out of its time; differs because anachronistic is chronological misplacement, atavistic is ancestral resurgence.
  • archaic: Similar because it names old-fashioned survival; differs because archaic stresses disuse, atavistic stresses reversion.
  • antediluvian: Similar because it mocks extreme old-fashionedness; differs because it is hyperbolic and comic, atavistic is scientific.
  • atavism (noun): Similar because it is the same root concept; differs because it names the phenomenon, atavistic describes exhibiting it.
  • vestigial: Similar because it names a survival from the past; differs because vestigial stresses reduced remnant, atavistic stresses reactivated trait.
  • tribal: Similar because in behaviour-talk it names primitive loyalty; differs because tribal is sociological, atavistic is evolutionary.
  • savage: Similar because it names untamed primitiveness; differs because savage is violent and colonial-loaded, atavistic is clinical.
  • barbaric: Similar because it names uncivilised cruelty; differs because barbaric judges culture, atavistic diagnoses biology or habit.
